List DSCP-to-Queue Mapping Table Configuration (LST DSCP2QUEMAP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of mapping tables between DSCPs and queues.

Note

None.

Parameters

ID Name Description
DSCP2QUEMAPID DSCP-to-Queue Mapping ID

Meaning: Indicates the ID of the mapping table between DSCPs and queues.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]The DSCP2QUEMAP MO with DSCP2QUEMAPID set to 0 cannot be removed.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To query the configuration of a DSCP-to-Queue Mapping Table, run the following command:
LST DSCP2QUEMAP:;
The result is as follows:

Output Description

Field Description

DSCP-to-Queue Mapping ID

Indicates the ID of the mapping table between DSCPs and queues.

Default Queue No.

Indicates the default number of the queue mapped to a DSCP.

User Label

Indicates the description of the mapping table between DSCPs and queues.

DSCP List Mapping to Queue 0

Indicates the list of DSCPs mapping to queue 0 in the mapping table.

DSCP List Mapping to Queue 1

Indicates the list of DSCPs mapping to queue 1 in the mapping table.

DSCP List Mapping to Queue 2

Indicates the list of DSCPs mapping to queue 2 in the mapping table.
