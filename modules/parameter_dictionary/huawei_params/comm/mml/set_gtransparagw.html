Set Gateway Global Transport Parameters (SET GTRANSPARAGW)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the global transport parameters for a gateway.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Configure Forward Mode in strict accordance with the actual networking. For non-cascaded base stations (without passerby data flow), set Forward Mode to HOST; for cascaded base stations (with passerby data flow), set Forward Mode to ROUTE. If cascaded base stations do not need intra-port data forwarding, disable Same Port Forward Switch. If you set Forward Mode to HOST for cascaded base stations, the services on the lower-level base station will be interrupted. To rectify this fault, set Forward Mode to ROUTE for the cascaded base stations.

  • For the UMPT/LMPT/UMDU/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UTRPc/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 board, the Forward Mode and Same Port Forward Switch parameters take effect according to the configured values. For other boards, the two parameters are set to ROUTE and Enable by default, respectively.

  • In the scenarios of co-transmission through panel, set Forward Mode to ROUTE for the base station that provides the co-transmission port, and meanwhile set Same Port Forward Switch to DISABLE when intra-port data forwarding is not required. If you set Forward Mode to HOST for the base station that provides the co-transmission port, services of base stations that do not provide the co-transmission port will be interrupted. To solve this problem, set Forward Mode to ROUTE for the base station that provides the co-transmission port. In co-transmission through backplane interconnection, the packet forwarding mode is not controlled by the Forward Mode parameter.

  • If the Ethernet OAM Type parameter is modified when the SET GTRANSPARAGW command is executed, ALM-25880 Ethernet Link Fault will be reported when the OAM Type of the devices to which CC is applied is different.

  • All the parameters in this command take effect only when the MODELSELECT parameter is set to HOSTGW (Host-Gateway Mode). The value of the MODELSELECT parameter can be queried using the LST MODELSELECT command.

  • The ARP aging time of this NE must be set according to the ARP aging time of the switch and router on the network. If the ARP aging time of this NE is longer than the ARP aging time of the network device, network issues such as broadcast storms may occur.

  • [Co-MPT,eNodeB,gNodeB]User-defined values of LPSCHSW and RATECFGTYPE only take effect on the main control board and UTRPc board; for the UTRP board, LPSCHSW and RATECFGTYPE are permanently set to be DISABLE and SINGLE_RATE respectively due to the board's limited capabilities. Whether the resource group scheduling weight is supported mostly depends on the board capabilities. If RATECFGTYPE is set to DUAL_RATE, LPSCHSW is enabled by default. Therefore, the user-defined setting of LPSCHSW does not take effect when RATECFGTYPE is set to DUAL_RATE.

  • [Co-MPT,eNodeB]The port mode adaptation function is not supported over an optical Ethernet port on an LMPT when the port status is detected as DOWN.

  • [NodeB]User-defined values of LPSCHSW and RATECFGTYPE only take effect on the UTRPc board; for the WMPT or UTRP board, LPSCHSW and RATECFGTYPE are permanently set to be DISABLE and SINGLE_RATE respectively due to the board's limited capabilities. Whether the resource group scheduling weight is supported mostly depends on the board capabilities. If RATECFGTYPE is set to DUAL_RATE, LPSCHSW is enabled by default. Therefore, the user-defined setting of LPSCHSW does not take effect when RATECFGTYPE is set to DUAL_RATE.

Parameters

ID Name Description
LPSCHSW Resource Group Scheduling Weight Switch

Meaning: Indicates the switch used to control whether to allocate bandwidths to transmission resource groups on the physical port based on their scheduling weights. When RATECFGTYPE (rate configuration type) is set to SINGLE_RATE and Physical Port Up Link OverBooking Switch or Physical Port Down Link OverBooking Switch is set to OFF, different values of this parameter lead to different bandwidth allocation methods as follows: (1) If this parameter is set to DISABLE and the sum of TX bandwidths of the associated resource groups exceeds the bandwidth of the physical port, each resource group is allocated a bandwidth that is directly proportional to its configured TX bandwidth; (2) If this parameter is set to ENABLE and the sum of TX bandwidths of the associated resource groups exceeds the bandwidth of the physical port, each resource group is allocated a bandwidth that is directly proportional to its scheduling weight. When RATECFGTYPE (rate configuration type) is set to DUAL_RATE, different values of this parameter lead to different CIR allocation methods as follows: (1) If the sum of CIRs of the associated resource groups exceeds the bandwidth of the physical port, each resource group is allocated a CIR that is directly proportional to its configured CIR; (2) If the sum of CIRs of the associated resource groups is smaller than the bandwidth of the physical port, each resource group is allocated a non-CIR that is directly proportional to its scheduling weight. In this case, the PIR of a resource group is the sum of the CIR and the non-CIR.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Modifications to this parameter affect the admission of new services and the quality of admitted services carried on resource groups.

Applicable Mode: G, U, L, N, R
RATECFGTYPE Rate Config Type

Meaning: Indicates the rate configuration mode of transmission resource groups in the BS, which can be set to SINGLE_RATE or DUAL_RATE. The dual rate configuration refers to the hybrid of the peak information rate (PIR) and committed information rate (CIR). If this parameter is set to SINGLE_RATE, the transmission resource group performs traffic shaping based on its transmit bandwidth. If this parameter is set to DUAL_RATE, the transmission resource group performs traffic shaping based on PIR and the transmission admission algorithm ensures that the non-flow-controllable traffic does not exceed CIR.

GUI Value Range: SINGLE_RATE(Single Rate), DUAL_RATE(Dual Rate)

Unit: None

Actual Value Range: SINGLE_RATE, DUAL_RATE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Modifications to this parameter affect the admission of new services and the quality of admitted services carried on resource groups.

Applicable Mode: G, U, L, N, R
SBTIME Switch Back Time

Meaning: Indicates the period during which the active and standby routes are switched over twice. This period indicates the interval between the time single-hop BFD detects that an active route changes from DOWN to UP and the time the active route becomes available. During the switchover, if the previous standby route becomes faulty, the system waits for 10 seconds and then switches back to the active route.

PORTULOBSW Physical Port Up Link OverBooking Switch

Meaning: Indicates the switch that is used to determine whether to enable UL overbooking admission control. It is used to determine the admission bandwidth of the resource group and facilitate admission control. The parameter takes effect only for LTE.

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the sum of uplink admission bandwidths of all logical ports carried on a physical port is allowed to be greater than the uplink bandwidth of the physical port. In this case, however, there is a risk of excessive admitted services if PORTULCACSW is set to ON.

If this parameter is set to OFF, the sum of uplink admission bandwidths of all logical ports carried on a physical port is not allowed to be greater than the uplink bandwidth of the physical port. In this case, there is no risk of excessive admitted services regardless of whether PORTULCACSW is set to ON.

Example

To set the global transport parameters for a gateway with the parameters as follows: Resource Group Scheduling Weight Switch: Enable, Rate Config Type: Dual Rate, Switch Back Time: 30, ARP Aging Time: 20, Priority Rule: DSCP, run the following command:
SET GTRANSPARAGW: LPSCHSW=ENABLE, RATECFGTYPE=DUAL_RATE, SBTIME=30, ARPAGINGTIME=20, PRIRULE=DSCP;
