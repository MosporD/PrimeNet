List Board Alarm Threshold (LST BRDALMTHLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configurations of the thresholds for reporting and clearing the board overload alarm.

Note

This command applies only to the BBP and MPT.

Example

To list the configurations of the thresholds for reporting and clearing the board overload alarm, run the following command:
LST BRDALMTHLD:;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the board is located.

Subrack No.

Indicates the subrack number of the board.

Slot No.

Indicates the slot number of the board.

Board Overload Alarm Report Threshold(%)

Indicates the threshold for reporting the board overload alarm. If the usage of the processing chip on the board is greater than or equal to this parameter value, ALM-26202 Board Overload is reported.

Board Overload Alarm Clear Threshold(%)

Indicates the threshold for clearing the board overload alarm. If the usage of the processing chip on the board is less than this parameter value, ALM-26202 Board Overload is cleared.
