List the DSCP to VLAN Priority Mapping Configuration (LST DSCPMAP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the mapping between DSCPs and VLAN priorities.

Note

None.

Parameters

ID Name Description
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Disuse statement: This parameter will be deleted in later versions. To mitigate the risk, it is recommended that this parameter not be used.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]DSCP parameters must be set to different values if VRFIDX parameters are same in two DSCPMAP MOs.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
DSCP Differentiated Service Codepoint

Meaning: Indicates the priority of a DSCP. A larger value of this parameter indicates a higher priority.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Differentiated Services Code Point parameter in the DSCP2PCPREF MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]DSCP parameters must be set to different values if VRFIDX parameters are same in two DSCPMAP MOs.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To list the DSCP to VLAN Priority Mapping Configuration whose VRF Index is 0 and Differentiated Service Codepoint is 0, run the following command:
LST DSCPMAP: VRFIDX=0, DSCP=0;
The result is shown as follows:
+++    0        2011-10-31 19:20:24
O&M    #70

Output Description

Field Description

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Differentiated Service Codepoint

Indicates the priority of a DSCP. A larger value of this parameter indicates a higher priority.

VLAN Priority

Indicates the priority of a VLAN. A larger value of this parameter indicates a higher priority.
