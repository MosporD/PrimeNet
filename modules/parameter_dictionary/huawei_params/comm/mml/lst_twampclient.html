List TWAMP Client Configuration (LST TWAMPCLIENT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the configuration of a TWAMP client.

Note

None.

Parameters

ID Name Description
CLIENTID Client Index

Meaning: Indicates the index of a TWAMP client.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To list the configuration of a TWAMP Client, run the following command:
LST TWAMPCLIENT:;
The result is shown as follows:

Output Description

Field Description

Client Index

Indicates the index of a TWAMP client.

IP Version

Indicates the IP protocol version of a TWAMP client.

Local IP Address

Indicates the local IPv4 address of a TWAMP client.

Peer IP Address

Indicates the peer IPv4 address of a TWAMP client.

Local IPv6 Address

Indicates the local IPv6 address of a TWAMP client.

Peer IPv6 Address

Indicates the peer IPv6 address of a TWAMP client.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

TWAMP Architecture

Indicates the architecture of a TWAMP client.

DSCP

Indicates the DSCP of TCP negotiation packets sent by a TWAMP client. This parameter is valid only when the TWAMP client is deployed in the full architecture.

Peer TCP Port No.

Indicates the peer TCP port number of a TWAMP client. This parameter is valid only when the TWAMP client is deployed in the full architecture.
