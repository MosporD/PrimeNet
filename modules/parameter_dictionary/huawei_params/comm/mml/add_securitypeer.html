Add Security Peer (ADD SECURITYPEER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a security peer required by secure automatic establishment.

Note

  • Ensure that the IPSec proposal name of the security peer has been configured by using the ADD IPSECPROPOSAL command.

  • If the following conditions are met during automatic setup of an IPv4 user-plane IPsec tunnel, the system will automatically configure the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects and set up an IPsec tunnel for the user plane:

    - IPSec Auto Configure Switch is set to ENABLE for both the USERPLANEHOST and USERPLANEPEER objects in the same endpoint group.

    - SeGW Switch is set to ENABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met during automatic setup of an IPv4 user-plane IPsec tunnel, the system will automatically configure the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects and set up an IPsec tunnel for the user plane:

    - IPSec Auto Configure Switch is set to ENABLE for both the USERPLANEHOST and USERPLANEPEER objects in the same endpoint group.

    - SeGW Switch is set to DISABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

  • Ensure that the IKE peer name of the security peer has been configured by using the ADD IKEPEER command.

  • The IPSec redundancy function is not supported in security object automatic setup scenarios. That is, the Redundancy Flag parameter in the IPv4 IKE peer of the security peer must be NONE(Non-redundancy).

  • Security peers numbered from 70000 to 89999 cannot be manually created or modified but can be manually deleted.

  • System specifications: If a UMPTa/UMPTb/UMDU is used as the main control board, a maximum of 384 security peers can be configured for a base station. If a UMPTe is used as the main control board, a maximum of 384 security peers can be configured for a base station. If a UMPTg/UMPTga is used as the main control board, a maximum of 512 security peers can be configured for a base station. If an LMPT/WMPT/GTMU is used as the main control board, a maximum of 128 security peers can be configured for a base station.

  • Board specifications: A UMPTa/UMPTb/UMDU supports the security peers specifications of 384. A UMPTe supports the security peers specifications of 384. A UMPTg/UMPTga supports the security peers specifications of 512. A UMPTa/UMPTb/UMDU supports a maximum of 256 IPv4 security peers, and a maximum of 128 IPv6 security peers. A UMPTe supports a maximum of 384 IPv4 security peers, and a maximum of 384 IPv6 security peers. A UMPTg/UMPTga supports a maximum of 384 IPv4 security peers, and a maximum of 512 IPv6 security peers.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the following conditions are met during automatic setup of an IPv4 control-plane IPsec tunnel, the system will automatically configure the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects and set up an IPsec tunnel for the control plane:

    - IPSec Auto Configure Switch for First Local IP and IPSec Auto Configure Switch for Second Local IP are set to ENABLE for both the SCTPHOST and SCTPPEER objects in the same endpoint group.

    - SeGW Switch is set to ENABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met during automatic setup of an IPv4 control-plane IPsec tunnel, the system will automatically configure the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects and set up an IPsec tunnel for the control plane:

    - IPSec Auto Configure Switch for First Local IP and IPSec Auto Configure Switch for Second Local IP are set to ENABLE for both the SCTPHOST and SCTPPEER objects in the same endpoint group.

    - SeGW Switch is set to DISABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

  • [Co-MPT,eNodeB,gNodeB]If the following conditions are met during automatic setup of an IPv6 IPsec tunnel, the system will automatically configure the SCTPLNK, TUNNELITF, ACL6, ACLRULE6, IPSECBINDITF, IPSECPOLICY, IKEPEER, INTERFACE, and IPROUTE6 objects and set up an IPsec tunnel:

    - IPSec Auto Configure Switch is set to ENABLE for the USERPLANEHOST, SCTPHOST, USERPLANEPEER, and SCTPPEER objects in the same endpoint group.

    - SeGW Switch is set to DISABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

Parameters

ID Name Description
SECURITYPEERID Security Peer ID

Meaning: Indicates the ID of a security peer. The value of SECURITYPEERID in the SECURITYPEER MOs configured by users ranges from 0 to 65535. The value of SECURITYPEERID in the SECURITYPEER MOs configured by the system ranges from 70000 to 89999.

GUI Value Range: 0~65535,70000~89999

Unit: None

Actual Value Range: 0~65535,70000~89999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If SECURITYPEERID is set to a value in the range of 0 to 65535, CTRLMODE must be set to MANUAL_MODE, and AUTOCFGFLAG must be set to MANUAL_CREATED. If SECURITYPEERID is set to a value in the range of 70000 to 89999, CTRLMODE must be set to AUTO_MODE, and AUTOCFGFLAG must be set to AUTO_CREATED.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SEGWSWITCH SeGW Switch

Meaning: Indicates whether to enable the peer end to perform IPSec negotiation with the local end through an SeGW. When this parameter is set to DISABLE, the peer end performs IPSec negotiation with the local end directly. When this parameter is set to ENABLE, the peer end establishes an IPSec tunnel to the local end through an SeGW.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(Disable)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
IPVERSION IP Version

Meaning: Indicates the IP protocol version of a security peer.

GUI Value Range: IPv4(IPv4), IPv6(IPv6)

Unit: None

Actual Value Range: IPv4, IPv6

MML Default Value: IPv4(IPv4)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]When IPVERSION in a SECURITYPEER MO is set to IPv6, AUTOCFGFLAG cannot be set to MANUAL_CREATED.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
PEERIKEIPV4 Peer IKE IP Address

Meaning: Indicates the IPv4 address of the IKE peer.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the SECURITYPEER MO, PEERIKEIPV4 must be a valid IP address of Class A, B, or C. In addition, it cannot be set to 127.x.x.x or 0.x.x.x.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the SECURITYPEER MO, this parameter is valid only when SEGWSWITCH is set to DISABLE and IPVERSION is set to IPv4.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
PEERIKEIPV6 Peer IKE IPv6 Address

Meaning: Indicates the IPv6 address of the IKE peer that corresponds to a service IP address. This parameter takes effect only in LTE and NR.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]In the SECURITYPEER MO, PEERIKEIPV6 must be set to a globally scoped unicast address.

-Others:

  • [Co-MPT, eNodeB, gNodeB]In the SECURITYPEER MO, this parameter is valid only when SEGWSWITCH is set to DISABLE and IPVERSION is set to IPv6.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
PEERNAME IKE Peer Name

Meaning: Indicates the name of the IKE peer. The IKE peer is the SeGW that performs IKE negotiation with the local end.

GUI Value Range: 1~15 characters

Unit: None

Actual Value Range: 1~15 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
IPSECPROPNAME IPSec Proposal Name

Meaning: Indicates the name of the IPSec proposal used for IPSec negotiation between the local end and the SeGW.

GUI Value Range: 1~15 characters

Unit: None

MML Default Value: None

Recommended Value: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

USERLABEL User Label

Meaning: Indicates the description of a security peer.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a security peer with the parameters as follows: Security Peer ID: 0, SeGW Switch: DISABLE, IP Version: IPv4, Peer IKE IP Address: 192.168.1.23, run the following command:
ADD SECURITYPEER: SECURITYPEERID=0, SEGWSWITCH=DISABLE, IPVERSION=IPv4, PEERIKEIPV4="192.168.1.23";
