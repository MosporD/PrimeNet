Modify Maintenance Status of Application (MOD APP)

Network Element: BTS3900, BTS5900

Function

Use this command to set the maintenance mode of the application. If the maintenance mode of an application has been set, an alarm to be reported will contain the information about the maintenance mode. When the maintenance mode of a co-MPT NE is NORMAL and one of its applications is also in the maintenance mode, the performance measurements of this application will be implausible.

Note

  • After the MPT is restarted, the application will be in the same maintenance status as it is before the restart.

  • [Co-MPT]In a base station where the GTMU supports SingleOM, this command cannot be executed.

APPST Start Time of Application Status Setting

Meaning: Indicates the start time of maintenance mode of the application. This time refers to the local time (including the DST offset) on the NE. If this parameter is not specified, the start time of the maintenance mode is 2000-01-01 00:00:00.

GUI Value Range: 2000-01-01T00:00:00+00:00~2037-12-31T23:59:59+00:00

Unit: None

Actual Value Range: 2000-01-01T00:00:00+00:00~2037-12-31T23:59:59+00:00

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

APPET End Time of Application Status Setting

Example

Example 1: To set the maintenance status of the application with the following parameters: Application ID: 2, Application maintenance Mode: NORMAL, run the following command:
MOD APP: AID=2, APPMNTMODE=NORMAL;

Example 2: To set the maintenance status of the application with the following parameters: Application ID: 2, Application maintenance Mode: INSTALL, Start Time of Application Status Setting: 2015&02&05&15&00&00, End Time of Application Status Setting: 2015&02&10&15&00&00, run the following command:
MOD APP: AID=2, APPMNTMODE=INSTALL, APPST=2015&02&05&15&00&00, APPET=2015&02&10&15&00&00;
