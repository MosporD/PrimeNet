List LLDP Local Global Info (LST LLDP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of an LLDP port.

Note

LLDP ports that are automatically generated cannot be queried using this command but can be queried using the DSP LLDP command.

Parameters

None.

Example

To list the configuration of the LLDP port information, run the following command: 
LST LLDP:;
The result is shown as follows:
+++    0        2018-04-24 17:45:59
O&M    #3504
%%LST LLDP:;%%
RETCODE = 0  Operation succeeded.

List LLDP Local Global Info
---------------------------
         LLDP ID  =  1
Ethernet Port ID  =  100
    Binding VLAN  =  Yes
         VLAN ID  =  3
   VLAN Priority  =  4
(Number of results = 1)


---    END

Output Description

Field Description

LLDP ID

Indicates the ID of an LLDP local entity.

Ethernet Port ID

Indicates the ID of the Ethernet port on the board to which the LLDP local information belongs.

Binding VLAN

Indicates whether the local LLDP port is associated with the VLAN. If the local LLDP port is bound to a VLAN, LLDP packets sent by the local end carry the VLAN ID.

VLAN ID

Indicates the VLAN ID of local LLDP port.

VLAN Priority

Indicates the VLAN priority of local LLDP port.
