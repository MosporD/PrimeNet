Display IPSec Bypass Switch (DSP IPSECBYPASSCFG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of the IPSec Bypass function.

Note

  • The IP addresses of the active and standby security gateways do not include the peer IP address of the IKE peer that is not bound to a specific port, nor the peer IP address of the IKE peer of which the control mode is AUTO_MODE.

  • When the system is not configured with any IKE peers or an IKE peer is not bound to any ports, the values of the Master SeGW IP parameter and Slave SeGW IP parameter are 0.0.0.0.

  • When an IKE peer whose Redundancy Flag is None(Non-redundancy) is not referenced by an IPSec tunnel pair, the peer IP address servers as the Master SeGW IP address and the Slave SeGW IP address is 0.0.0.0. For master and slave IKE peers, the Master SeGW IP address is the peer IP address of the master IKE peer and the Slave SeGW IP address is the peer IP address of the master IKE peer in use. The value of the Slave SeGW IP parameter is 0.0.0.0 in any of the following cases: (1) A master IKE peer has no slave IKE peer. (2) The master IKE peer is being used. (3) The system is in the IPSECBYPASS state.

  • When an IKE peer is referenced by an IPSec tunnel pair, the Master SeGW IP address and Slave SeGW IP address are the IP addresses of the IKE peer referenced by the master and slave security policies of the IPSec tunnel pair.

Parameters

None.

Example

To query basic information about IPSec Bypass Status,run the following command:
DSP IPSECBYPASSCFG:;
The result is shown as follows:

Output Description

Field Description

IPSec Bypass Switch

Indicates whether to enable the switchover of IPSec Bypass. If this parameter is set to DISABLE, the base station cannot switch between an IPSec network and a non-IPSec network.

IPSec Bypass Code

Indicates the password used for switching the base station between an IPSec network and a non-IPSec network.

IPSec Status

Indicates the state of IPSec Bypass.

Master SeGW IP

Indicates the IP address of the active security gateway when the base station is located in an IPSec network.

Slave SeGW IP

Indicates the IP address of the standby security gateway when the base station is located in an IPSec network.
