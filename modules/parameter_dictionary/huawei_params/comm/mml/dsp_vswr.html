Display VSWR Test Result (DSP VSWR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to display the results of an automatic voltage standing wave ratio (VSWR) test for the RRU or RFU transmit channel.

Note

  • The automatic voltage standing wave ratio (VSWR) test is periodically executed on the loaded RRU or RFU transmit channel. The RRU or RFU decides whether to report a VSWR alarm and light the VSWR indicator based on the test results.

  • The automatic VSWR test can be successfully executed only when the transmit power of the RRU is sufficiently strong. Otherwise, the returned result is NULL.

  • The VSWRs can be queried only for loaded TX channels.

  • The duration of automatic VSWR tests varies according to RRU or RFU types.

  • The precision of automatic VSWR tests differ from that of the VSWR tests started by running the STR VSWRTEST command.

  • Beamforming AAUs and MPMU modules do not support this function.

  • If the frequency range supported by the RF unit is greater than that supported by the antenna system componens, it is advised to configure the authorized downlink frequency band before querying the VSWR test result. Otherwise, the VSWR test result may be abnormal and the fause VSWR threshold crossed alarm may be reported. The components of the antenna system include antennas, feeders, jumpers, combiner-dividers, filters, tower-mounted amplifiers (TMAs) and POIs.

Example

To query the VSWR of an RRU with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, run the following command:
DSP VSWR: CN=0, SRN=60, SN=0;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the RRU or RFU where the TX channel is located.

Subrack No.

Indicates the subrack number of the RRU or RFU where the TX channel is located.

Slot No.

Indicates the slot number of the RRU or RFU where the TX channel is located.

TX Channel No.

Indicates the number of the TX channel of the RRU or RFU.

VSWR(0.01)

Indicates the current VSWR of the TX channel. When the TX power is relatively low , the S/N of the reflected signal passing through the detector channel is relatively low, which leads to the inaccuracy of the VSWR calculation, the value of this field will be displayed as NULL.
