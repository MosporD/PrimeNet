Start CFM Trace (CFMTRACE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to start the CFM link trace.

Note

  • Before running this command, ensure that the MD, MA, MEP, and RMEP are configured.

  • The PING, PING6, TRACERT, TRACERT6, CFMTRACE, CFMPING, and UDPECHO commands cannot be executed simultaneously on one board.

  • Before performing continuity check between the BS and an RMEP, ensure that the RMEP is configured on the BS.

  • To stop the execution of this command, press Ctrl+Q or run the STP PATHCHK command.

  • This command does not affect ongoing services.

  • If the Ethernet OAM Type parameter is modified when the SET ETHOAM command is executed, the CFM link trace will be stopped automatically.

Example

To start the CFM link trace with the parameters as follows: MD Name: CHINA, MA Name: SHANGHAI, Destination Type: MAC, MAC Address: 0023-8956-7895, run the following command:
CFMTRACE: MDNAME="CHINA", MANAME="SHANGHAI", DSTTYPE=MAC, MAC="0023-8956-7895";
The result is shown as follows:
