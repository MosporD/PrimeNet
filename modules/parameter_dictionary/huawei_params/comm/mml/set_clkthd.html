Set Clock Tracing Threshold (SET CLKTHD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the clock tracing mode of a specified main control board.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • An inappropriate setting results in the failure to lock the reference clock.

  • If the board in the specified slot is not a main control board, this command fails to be executed.

  • [Co-MPT]Use this command to set the clock tracing mode of a specified main control board. When Air Interface Soft Synchronization Enhancement is enabled, Clock Tracing Threshold must be set to ENABLE. If Air Interface Soft Synchronization Enhancement is enabled and the offset of the reference clock source exceeds the threshold, the system is not allowed to trace the reference clock source.

Example
