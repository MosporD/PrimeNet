Unblock Physical Port (UBL PHYPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to unblock a specified physical port.

Note

Currently, this command applies to the UMPT and UMDU only.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the physical port is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the subrack number of the board where the physical port is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the board where the physical port is located.

GUI Value Range: 6~7

Unit: None

Actual Value Range: 6~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
PT Port Type

Meaning: Indicates the type of the physical port.

GUI Value Range: CLK(CLK), TST(TST), HEI(HEI)

Unit: None

Actual Value Range: CLK, TST, HEI

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
PN Port No.

Meaning: Indicates the number of the physical port.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To unblock physical port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Port Type: CLK, Port No.: 0, run the following command:
UBL PHYPORT: CN=0, SRN=0, SN=7, PT=CLK, PN=0;
