Modify SCTP Peer (MOD SCTPPEER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify an SCTP peer.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB,eNodeB,gNodeB]If one or more of the following parameters in an SCTPPEER object are modified, the link objects that are automatically created for the SCTPPEER object will be modified, or removed and then added: First Peer IP Address, IPSec Auto Configure Switch for First Peer IP, Security Host ID for First Peer IP, Second Peer IP Address, IPSec Auto Configure Switch for Second Peer IP, Security Host ID for Second Peer IP, Peer SCTP Port No., VRF Index, Simple Mode Switch, and End Point Group ID. Link objects include SCTPLNK, CPBEARER, ACL, ACLRULE, IKEPEER, IPSECBIND or IPSECBINDITF, and IPSECPOLICY.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the following conditions are met, the system will remove the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects that are automatically configured for an SCTP link:

    - The value of IPSec Auto Configure Switch is changed from to ENABLE(Enable) to DISABLE(Disable) for the SCTPPEER object.

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the SCTPHOST object in the same end point group.

    - SeGW Switch is set to ENABLE(Enable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    If the following conditions are met, the system will remove the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects that are automatically configured for an SCTP link:

    - The value of IPSec Auto Configure Switch is changed from to ENABLE(Enable) to DISABLE(Disable) for the SCTPPEER object.

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the SCTPHOST object in the same end point group.

    - SeGW Switch is set to DISABLE(Disable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

  • [NodeB,eGBTS,eNodeB,gNodeB]In the same routing domain, if the first and second peer IP addresses of an SCTP peer are different from the peer IPv4 address in the BLKSCTPPEERIPV4 object and the value of Block Flag for the SCTP peer is UNBLOCK, the automatically generated SCTP link is unblocked. In the same routing domain, if the first or second peer IP address of an SCTP peer is the same as the peer IPv4 address in the BLKSCTPPEERIPV4 object or the value of Block Flag for the SCTP peer is BLOCK, the automatically generated SCTP link is blocked.

  • [NodeB,eGBTS,eNodeB,gNodeB]During self-setup of the control plane (for example, for the X2/eX2/uX2 interface), the port numbers of the SCTP hosts for adjacent base stations must be the same. In addition, the port number of the SCTP peer must be the same as the port number of the SCTP host for these base stations. Otherwise, the SCTP link negotiation fails.

  • [Co-MPT,eNodeB,gNodeB]In the same routing domain, if the first and second peer IPv6 addresses of an SCTP peer are different from the peer IPv6 address in the BLKSCTPPEERIPV6 object and the value of Block Flag for the SCTP peer is UNBLOCK, the automatically generated SCTP link is unblocked. In the same routing domain, if the first or second peer IPv6 address of an SCTP peer is the same as the peer IPv6 address in the BLKSCTPPEERIPV6 object or the value of Block Flag for the SCTP peer is BLOCK, the automatically generated SCTP link is blocked.

  • [Co-MPT,eNodeB,gNodeB]Modifying any of the following parameters interrupts service that references this SCTPPEER object: First Peer IP Address, First Peer IPv6 Address, IPSec Auto Configure Switch for First Peer IP, Security Peer ID for First Peer IP, Second Peer IP Address, Second Peer IPv6 Address, IPSec Auto Configure Switch for Second Peer IP, Security Peer ID for Second Peer IP, Peer SCTP Port No., VRF Index, Simple Mode Switch, and End Point Group ID.

  • [NodeB]Modifying any of the following parameters interrupts service that references this SCTPPEER object First Peer IP Address, IPSec Auto Configure Switch for First Peer IP, Security Peer ID for First Peer IP, Second Peer IP Address, IPSec Auto Configure Switch for Second Peer IP, Security Peer ID for Second Peer IP, Peer SCTP Port No., and VRF Index.

Parameters

ID Name Description
SCTPPEERID SCTP Peer ID

Meaning: Indicates the ID of the SCTP peer. The value of SCTPPEERID in the SCTPPEER MOs configured by users ranges from 0 to 65535. The value of SCTPPEERID in the SCTPPEER MOs configured by the system ranges from 70000 to 79999.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]If SCTPPEERID is set to a value in the range of 0 to 65535, CTRLMODE must be set to MANUAL_MODE, and AUTOCFGFLAG must be set to MANUAL_CREATED. If SCTPPEERID is set to a value in the range of 70000 to 79999, CTRLMODE must be set to AUTO_MODE, and AUTOCFGFLAG must be set to AUTO_CREATED.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, N
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the SCTPPEER MO, if IPVERSION is set to IPv4 and VRFIDX is set to a value in the range of 1 to 7, SIGIP1SECSWITCH cannot be set to ENABLE.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In the SCTPPEER MO, if IPVERSION is set to IPv4 and VRFIDX is set to a value in the range of 1 to 7, SIGIP2SECSWITCH cannot be set to ENABLE.
  • [Co-MPT, NodeB, eNodeB, gNodeB]When the SIMPLEMODESWITCH parameter in the SCTPPEER MO is not set to SIMPLE_MODE_OFF, the VRFIDX parameter in the SCTPPEER MO must be set to 0.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U, L, N

GUI Value Range: IPv4(IPv4), IPv6(IPv6)

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the SCTPPEER MO, if IPVERSION is set to IPv4 and VRFIDX is set to a value in the range of 1 to 7, SIGIP2SECSWITCH cannot be set to ENABLE.
  • [Co-MPT, NodeB, eNodeB, gNodeB]When the SIMPLEMODESWITCH parameter in the SCTPPEER MO is not set to SIMPLE_MODE_OFF, the IPVERSION parameter in the SCTPPEER MO cannot be set to IPv6.
  • [Co-MPT, eNodeB, gNodeB]In the SCTPPEER MO, if IPVERSION is set to IPv6 and CTRLMODE is set to MANUAL_MODE, SIGIP1SECSWITCH and SIGIP2SECSWITCH must be set to DISABLE.
  • [Co-MPT, eNodeB, gNodeB]In an SCTPPEER MO, if IPVERSION is set to IPv6, and SIGIP2SECSWITCH is set to ENABLE, SIGIP2SECPEERID must be the same as SIGIP1SECPEERID.

Service Interrupted After Modification: N/A

SIGIP1V4 First Peer IP Address

Meaning: Indicates the first peer SCTP IPv4 address, which is used by the base station to establish a signaling channel. That is, this address is the first peer IPv4 address for automatically establishing an SCTP link.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the SCTPPEER MO, SIGIP1V4 must be a valid IP address of Class A, B, or C. In addition, it cannot be set to 127.x.x.x or 0.x.x.x.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In the SCTPPEER MO, SIGIP2V4 must be different from SIGIP1V4.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U, L, N

SIGIP1SECSWITCH IPSec Auto Configure Switch for First Peer IP

Meaning: Indicates whether to use the first peer IP address to automatically set up an IPsec tunnel between the local and peer ends based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. The IPsec tunnel is used to encrypt data to be transmitted on the SCTP link that is set up using the first peer IP address of the SCTP peer. When the value of this parameter is changed from ENABLE to DISABLE using the MOD SCTPPEER command, the system automatically deletes the IPsec tunnel that has been automatically set up.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: If the networking mode does not support IPSec or IPSec tunnels are to be set up by manually configuring IPSec MOs, this parameter must be set to DISABLE.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the SCTPPEER MO, if IPVERSION is set to IPv4 and VRFIDX is set to a value in the range of 1 to 7, SIGIP1SECSWITCH cannot be set to ENABLE.
  • [Co-MPT, NodeB, eNodeB, gNodeB]When the SIMPLEMODESWITCH parameter in the SCTPPEER MO is not set to SIMPLE_MODE_OFF, both SIGIP1SECSWITCH and SIGIP2SECSWITCH parameters in the SCTPPEER MO must be set to DISABLE.
  • [Co-MPT, eNodeB, gNodeB]In the SCTPPEER MO, if IPVERSION is set to IPv6 and CTRLMODE is set to MANUAL_MODE, SIGIP1SECSWITCH and SIGIP2SECSWITCH must be set to DISABLE.
  • [Co-MPT, eNodeB, gNodeB]In an SCTPPEER MO, if IPVERSION is set to IPv6 and SIGIP2V6 is valid, SIGIP1SECSWITCH and SIGIP2SECSWITCH in the SCTPPEER MO must be set to DISABLE.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: Users cannot access an IPsec-protected network if this parameter is set to DISABLE and no IPsec tunnel has been set up between the SCTP host and the SCTP peer for the SCTP link or IPv6 SCTP link.

Applicable Mode: U, L, N

Example

To modify an SCTP peer with the parameters as follows: SCTP Peer ID: 0, Peer SCTP Port No.: 1090, User Label: signaling plane peer, run the following command:
MOD SCTPPEER: SCTPPEERID=0, PN=1090, USERLABEL="signaling plane peer";
