Set ModelSelect (SET MODELSELECT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the selection of models.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The operation will interrupt services or the OM channel of this NE or the lower-level NE and the NE must be reset to resume each function. You are advised to run the CFM CB command to enable configuration data rollback.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If Transmission Configuration Mode in the GTRANSPARA MO is set to OLD, when the MODELSELECT parameter is set to HOSTGW(Host-Gateway Mode), the loopback DEVIP object can borrow the IP address from the IFIP object. In this case, the effective IP address in the DEVIP object cannot be queried using the DSP DEVIP command and should be queried in the IFIP object from which the IP address is borrowed by running the DSP IFIP command.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If MODELSELECT parameter is set to TRADITION(Traditional Mode), the following must be true when an IP path is configured:

    - If Port Type is set to ETH(Ethernet Port) or ETHTRK(Ethernet Trunk), the local IP address of the IP path must be the same as the device IP address configured on the corresponding port.

    - If Port Type is set to PPP(PPP Link) or MPGRP(Multi-link PPP Group), the local IP address of the IP path must be the same as the device IP address configured on the corresponding port or the local IP address of the corresponding PPP link or multi-link PPP group.

    If the MODELSELECT parameter is set to HOSTGW(Host-Gateway Mode), and the device IP address corresponding to the local IP address is the same as a borrowing interface IP address when an IP path is configured, the port type and port No. of the IP path must be the same as the port type and port No. of the borrowing interface IP address.

    The value of the MODELSELECT parameter can be queried using the LST MODELSELECT command.

  • [Co-MPT,NodeB,eNodeB]If Transmission Configuration Mode in the GTRANSPARA MO is set to OLD, when the MODELSELECT parameter is set to TRADITION(Traditional Mode), the IP address used by the LOCALIP or WLOCALIP object or generated by PPP link or multi-link PPP group must be queried using the DSP DEVIP command. When the MODELSELECT parameter is set to HOSTGW(Host-Gateway Mode), the IP address used by the LOCALIP or WLOCALIP object or generated by PPP link or multi-link PPP group must be queried using the DSP IFIP command. If Transmission Configuration Mode in the GTRANSPARA MO is set to NEW, the IP address used by the LOCALIP or WLOCALIP object or generated by PPP link or multi-link PPP group must be queried using the DSP IPADDR4 command.

  • [gNodeB]If MODELSELECT parameter is set to TRADITION(Traditional Mode), the following must be true when an IP path is configured:

    -If Port Type is set to ETH(Ethernet Port) or ETHTRK(Ethernet Trunk), the local IP address of the IP path must be the same as the device IP address configured on the corresponding port.

    If the MODELSELECT parameter is set to HOSTGW(Host-Gateway Mode), and the device IP address corresponding to the local IP address is the same as a borrowing interface IP address when an IP path is configured, the port type and port No. of the IP path must be the same as the port type and port No. of the borrowing interface IP address.

    The value of the MODELSELECT parameter can be queried using the LST MODELSELECT command.

  • [gNodeB]When the MODELSELECT parameter is set to TRADITION(Traditional Mode), the IP address used by the LOCALIP or WLOCALIP object must be queried using the DSP DEVIP command. When the MODELSELECT parameter is set to HOSTGW(Host-Gateway Mode), the IP address used by the LOCALIP or WLOCALIP object must be queried using the DSP IFIP command.

Parameters

ID Name Description
MODELSELECT Model Select

Meaning: Indicates which transmission configuration MOs and parameters are to be used. When the system supports extended NEs or when the OM model must be consistent with that of extended NEs, set this parameter to HOSTGW(Host-Gateway Mode). In other scenarios, set this parameter to TRADITION(Traditional Mode) (default value).

When Transmission Configuration Mode is set to OLD(Old):

The following MOs or parameters are controlled in traditional mode:

- DEVIP MO

- Resource Group Scheduling Weight Switch, Rate Config Type, Switch Back Time, ARP Aging Time, Ping Filter Mode, Number of Packets Discarded Due to Fragmentation Failures, Ethernet OAM Type, Monitor Policy, IP Frame Error Rate Alarm Switch, IP Frame Error Rate Occur Threshold, IP Frame Error Rate Clear Threshold, Forward Mode, Same Port Forward Switch, and Port Mode Auto Switch in the GTRANSPARA MO

- IP Clock Priority in the DIFPRI MO

- Physical Port Up Link OverBooking Switch, Physical Port Down Link OverBooking Switch, Physical Port Up Link Admission Switch, and Physical Port Down Link Admission Switch in the TACALG MO

Only in traditional mode, a non-loopback DEVIP MO can be configured and the preceding parameters in other MOs can take effect.

The IFIP and GTRANSPARAGW MOs are controlled in host-gateway mode. Only in this mode, an IFIP MO can be configured and the parameters in the GTRANSPARAGW MO can take effect.

After this parameter value is modified, the NE must be reset to validate the controlled parameters.

When Transmission Configuration Mode is set to NEW(New), the DEVIP and IFIP MOs are no longer controlled. Other controlled MOs and parameters are the same as those when Transmission Configuration Mode is set to OLD(Old).

GUI Value Range: TRADITION(Traditional Mode), HOSTGW(Host-Gateway Mode)

Unit: None

Actual Value Range: TRADITION, HOSTGW

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

Run the following command to set the selection of models to host-gateway mode:
SET MODELSELECT: MODELSELECT=HOSTGW;
