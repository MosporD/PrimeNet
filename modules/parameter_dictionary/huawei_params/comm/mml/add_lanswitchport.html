Add L2 LAN Switch Port (ADD LANSWITCHPORT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a layer 2 LAN switch port of Ethernet type.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eNodeB]Only the layer 2 LAN switch ports of the Ethernet port need to be manually configured. The layer 2 LAN switch ports of air-interface link type can be automatically created but cannot be manually created.

  • [Co-MPT,eNodeB]Only the Ethernet port on a UMPT/UMDU with Subboard Type set to Base Board supports layer 2 LAN switching.

  • [Co-MPT,eNodeB]A base station supports only one layer 2 switch port of Ethernet type.

  • [Co-MPT,eNodeB]Only layer 2 switch port of Ethernet type with Port Index set to 0 can be added.

PORTIDX Port Index

Meaning: Indicates the index of a layer 2 LAN switch port on a layer 2 LAN switch of an NE.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Port Index parameter in the LSWPORT MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Example

To add an L2 lan switch port with the parameters as follows: Port Index: 0, Port Type: ETH, Slot No.: 6, Port No.: 0, run the following command: 
ADD LANSWITCHPORT: PORTIDX=0, PORTTYPE=ETH, SN=6, PN=0;
