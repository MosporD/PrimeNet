Add GDU (ADD GDU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a GNSS satellite signal Distribution Unit (GDU). When the GDU is added, a GDU subrack and a board are added at the same time.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Exercise caution when configuring the port number. If the port number is set to 0 or 1, the forcible switching mode is used. If the specified port is interfered or faulty, all output GNSS clock signals are abnormal, which may cause loss of the GNSS clock reference source and service loss.

ADDR Address

Meaning: Indicates the communication address of the GDU, which is determined by the settings of the 4-bit dual in-line package (DIP) switch on the GDU. The communication address is used by the GDU to communicate with the main control and transmission board. The value of this parameter must be consistent with the actual settings of the DIP switch. The 4-bit DIP switch can be treated as a 4-bit binary number. The settings of ON and OFF are represented by 1 and 0 respectively. Convert the 4-bit number from binary to decimal, and then the decimal number is used as the value of this parameter.

GUI Value Range: 1

Unit: None

Actual Value Range: 1

MML Default Value: 1

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, N, R, L
PN Port No.

Meaning: Indicates the input port of the GDU. If it is set to AUTO, the GDU automatically selects a port number. If it is set to 0 or 1, the GDU forcibly switches the port number. In automatic switching mode, the GDU selects a normal port according to the port status. In this way, the faults caused by the failure of a single port can be avoided automatically. If port 0 or port 1 is forcibly specified, all output GNSS clock signals are abnormal if this port is interfered or faulty, and as a result, the GNSS clock reference source may be lost and services may be affected. The default value is AUTO.

GUI Value Range: 0(0), 1(1), AUTO(Auto)

Example

To add an GDU with the parameter as follows: Cabinet No.: 0, Subrack No.: 40, Manager Port No.: 0, run the following command:
ADD GDU: CN=0, SRN=40, MPN=0;
