List Operation Log (LST OPTLOG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the operation log online. You can set Source, Operator, Domain, IP Mode, Workstation, Start Time, End Time, Command, Result, Error Code or Maximum Return Records during the execution of this command to filter the query results.

Note

  • The command lists 64 logs from 00:00:00 of that day in default parameter settings.

  • The value emscomm of Operator indicates that this log is generated due to interaction between the network management system (NMS) and the NE.

  • The value emscommts of Operator indicates that this log is generated due to interaction between the trace server in the NMS and the NE.

  • During log encryption and decryption, if you run the LST OPTLOG command, the system displays a message indicating that the system is busy. In this case, try again later.

  • The value emscommneteco of Operator indicates that this log is generated due to interaction between the NetEco and the NE.

Output Description

Field Description

Source

Indicates the source of the log record.

Operator

Indicates the NE operator. The value of this parameter is case-insensitive.

Domain

Indicates the domain attribute of the command.

Workstation

Indicates the IP address of the workstation where the command is executed.

Operate Type

Indicates the command operation type.

Operate Time

Indicates the time when the operation is responded to.

Result

Indicates the result of the operation.

Error Code

Indicates the error code of the command. When this parameter is set to 0, only the logs of successfully executed commands are queried.

Command Level

Indicates the level of the event that triggers log recording.

End Time

Indicates the time when log information querying ends. The time this command is being executed is considered the end time by default.

Operation Command Information

Indicates the detailed operation command.
