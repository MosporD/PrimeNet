Set Detection Period for OM Channel Automatic Establishment (SET DHCPDETECT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the delay for automatic detection of the remote maintenance channel and let the BS exit the steady state. During the detection, all the user-defined configurations are removed and the BS automatically attempts to restore the remote maintenance channel.

Note

  • Detect delay time takes effect only when the detection is initially started after configuration.

  • When the configurations of the base station take effect normally, the base station will enter the steady state after 30 minutes' continuous maintenance by the MAE. Later the base station will not enter the detect state to establish the remote maintenance channel automatically even if the base station cannot be maintained by the MAE.

Parameters

ID Name Description
DELAYTIME Detect Delay Time

Meaning: Indicates the period between the time when a remote maintenance channel fails and the time when automatic establishment of the detection phase is allowed. If no user configures or configuration time expires, this parameter value is displayed as NULL.

GUI Value Range: 10~720

Unit: min

Actual Value Range: 10~720

MML Default Value: 10

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the start time for detecting the automatic establishment of the remote maintenance channel with the parameter as follows: Detect Delay Time: 60, run the following command: 
SET DHCPDETECT: DELAYTIME=60;
