List VRET Configuration (LST VRET)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to list the configuration of one or all Virtual Remote Electrical Tilting (VRET) antennas.

Note

None.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the VRET antenna. The device number of the VRET antenna must be unique.

GUI Value Range: 60~254

Unit: None

Actual Value Range: 60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Example

To list the configuration of a VRET antenna with the Device No. set to 60, run the following command:
LST VRET: DEVICENO=60;
The result is shown as follows:
+++    0        2011-06-03 17:54:40
O&M    #99
%%LST VRET: DEVICENO=60;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Device No.

Indicates the device number of the VRET antenna. The device number of the VRET antenna must be unique.

Cabinet No.

Indicates the cabinet number of the AARU where the VRET antenna is located.

Subrack No.

Indicates the subrack number of the AARU where the VRET antenna is located.

Slot No.

Indicates the slot number of the AARU where the VRET antenna is located.

Subunit Quantity

Indicates the number of subunits contained in the VRET antenna.

Device Name

Indicates the name of the VRET antenna. The device name is optional, but the device name configured for each ALD must be unique.
