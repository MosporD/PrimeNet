Modify SAAL Link (MOD SAALLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to modify an SAAL link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB]Only configured SAAL links can be modified by running this command.

  • [Co-MPT,NodeB]The execution of this command may interrupt services carried on the SAAL link. For details, see the "Service Interrupted After Modification" of each parameter in this command.

Parameters

ID Name Description
SAALNO Link No.

Meaning: Indicates the number of the SAAL link.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
RU Rate Unit

Meaning: Indicates the unit of the Peak Cell Rate (PCR), Minimum Cell Rate (MCR), and Sustainable Cell Rate (SCR). Rate units are converted according to the following principle: 1 cell/s is equal to 0.424 kbit/s. If the rate is converted from cell/s to kbit/s, the result value must be rounded down to the nearest integer. For example, 73 cell/s is converted into 30 kbit/s.

GUI Value Range: KBPS(kbit/s), CELL/S(cell/s)

Unit: None

Actual Value Range: KBPS, CELL/S

MML Default Value: None

Recommended Value: KBPS(kbit/s)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U
ST Bearer Service Type

Meaning: Indicates the type of the service carried by the SAAL link. In flow control, services are classified into five categories: the Constant Bit Rate (CBR) service, Real-Time Variable Bit Rate (RTVBR) service, Non-Real-Time Variable Bit Rate (NRTVBR) service, Unspecified Bit Rate Plus (UBR+) service, and Unspecified Bit Rate (UBR) service.

If this parameter is set to CBR, the bandwidth is calculated based on the PCR.

If this parameter is set to VBR, the bandwidth is calculated based on the SCR.

If this parameter is set to UBR, the bandwidth is calculated based on the PCR.

If this parameter is set to UBR+, the bandwidth is calculated based on the MCR.

GUI Value Range: CBR(CBR), RTVBR(RTVBR), NRTVBR(NRTVBR), UBR+(UBR+), UBR(UBR)

Unit: None

Actual Value Range: CBR, RTVBR, NRTVBR, UBR+, UBR

MML Default Value: None

Recommended Value: CBR(CBR)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U
PCR Peak Cell Rate

Meaning: Indicates the Peak Cell Rate (PCR) of the SAAL link. The PCR is an ATM service-related parameter defined by the ATM forum for ATM communication management. In CBR transmission, the PCR value determines the frequency at which sampled data is transmitted. In ABR transmission, the PCR value determines the maximum value of Allowed Cell Rate (ACR).

GUI Value Range: 30~37265

Unit: None

Actual Value Range: 30~37265

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB]In an SAALLNK MO, if ST and RU are set to UBR+ and KBPS, respectively, MCR must be less than PCR.
  • [Co-MPT, NodeB]In an SAALLNK MO, if ST is set to UBR+ and RU is set to CELL/S, MCR must be less than PCR after the rate unit is changed to kbit/s and both rates are rounded down.
  • [Co-MPT, NodeB]In an SAALLNK MO, if ST is set to RTVBR or NRTVBR and RU is set to KBPS, SCR must be less than PCR.
  • [Co-MPT, NodeB]In an SAALLNK MO, if ST is set to RTVBR or NRTVBR and RU is set to CELL/S, SCR must be less than PCR after the rate unit is changed to kbit/s and both rates are rounded down.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U

CCTM Timer_CC

Meaning: Indicates the length of the SSCOP timer Timer_Cc. This timer specifies the time interval between transmissions of an SAAL PDU during link establishment or connection release. An SAAL PDU is retransmitted if no ACK to the PDU is received.

GUI Value Range: 100~65535

Unit: ms

MML Default Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

POLL Timer_Poll

Meaning: Indicates the length of the SSCOP timer Timer_Poll. If this timer expires, the SAAL protocol stack must send a POLL PDU to the peer end. The POLL PDU is used to query the status information about the peer end through an SSCOP connection.

GUI Value Range: 100~65534

Unit: ms

Actual Value Range: 100~65534

MML Default Value: None

Recommended Value: 750

Parameter Relationship:

-Configuration constraints:

Applicable Mode: U

Example

To modify an SAAL link with the parameters as follows: Link No.: 0, Rate Unit: KBPS, Bearer Service Type: CBR, Peak Cell Rate: 500, Timer_CC: 1000, Timer_Poll: 750, Timer_Idle: 15000, Timer_No_Response: 15100, Timer_Keep_Alive: 2000, Max Connection Control Count: 4, Max Poll Data Count: 25, Max STAT Count: 67, run the following command:
MOD SAALLNK: SAALNO=0, RU=KBPS, ST=CBR, PCR=500, CCTM=1000, POLL=750, IDLE=15000, NRTM=15100, KATM=2000, MAXCC=4, MAXPD=25, MAXLE=67;
