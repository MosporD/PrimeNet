List Connection Port to External NE (LST EXTCONNPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of a port that is connected to an external NE.

Note

None.

Parameters

ID Name Description
PORTID Port ID

Meaning: Indicates the ID of a port that is connected to an external NE.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, R, N

Example

To list the information about the connection Port to External NE, run the following command:
LST EXTCONNPORT:;
The result is shown as follows:  
+++    0        2017-12-15 03:38:58

Output Description

Field Description

Port ID

Indicates the ID of a port that is connected to an external NE.

Cabinet No.

Indicates the number of the cabinet where the physical port is located.

Subrack No.

Indicates the number of the subrack where the physical port is located.

Slot No.

Indicates the number of the slot where the physical port is located.

Port Type

Indicates the type of a physical port.

Port No.

Indicates the number of the physical port.

Sub Port No.

Indicates the number of a subport on the physical port. A QSFP or DSFP port is split using a conversion connector into four or two subports. Currently, the valid parameter values are only 0 and 1, indicating subports 0 and 1.

Rate

Indicates the rate of the physical port.
