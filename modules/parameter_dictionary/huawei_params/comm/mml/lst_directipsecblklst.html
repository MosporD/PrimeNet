List Blacklist for Direct IPSec Tunnel (LST DIRECTIPSECBLKLST)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configurations of the blacklist for direct IPSec tunnels.

Note

None.

Parameters

ID Name Description
SECURITYPEERIP Security Peer IP Address

Meaning: Indicates the IP address of a security peer in the IPSec blacklist. When an IP address of a security peer is added to the blacklist, no more IPSec tunnels to the security peer are automatically set up.

Disuse statement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter and is replaced by the Security Peer IPv4 Address parameter in the DIRECTIPSECBLACKLIST MO. Therefore, avoid using this parameter.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To list the configurations of the blacklist for direct IPSec tunnels, run the following command:
LST DIRECTIPSECBLKLST:;
The result is as follows:
+++    0        2016-09-05 10:24:49
O&M    #28
%%LST DIRECTIPSECBLKLST:;%%
RETCODE = 0  Operation succeeded.

List Blacklist for Direct IPSec Tunnel 
--------------------------------------
Security Peer IP Address  =  172.16.1.1
              User Label  =  eNodeBId_38601
(Number of results = 1)


---    END

Output Description

Field Description

Security Peer IP Address

Indicates the IP address of a security peer in the IPSec blacklist. When an IP address of a security peer is added to the blacklist, no more IPSec tunnels to the security peer are automatically set up.

User Label

Indicates the description of a security peer.
