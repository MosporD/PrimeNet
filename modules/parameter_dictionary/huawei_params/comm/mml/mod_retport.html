Modify RET Port (MOD RETPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a remote electrical tilting (RET) port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command can be executed only when the RRU corresponding to the port runs normally.

  • The power switches of the antenna port and RET port of the RRU cannot be set to ON at the same time. If both the power switches are set to ON, the system returns a message indicating that the execution of this command fails.

  • The undercurrent alarm threshold is usually set to 20% to 30% of the normal working current of the equipment. The overcurrent alarm threshold is set to 150% to 200% of the normal working current of the equipment. If an antenna is used in a non-regular installation scenario, the alarm threshold type must be set to UER_SELF_DEFINE. In general, the threshold for reporting or clearing a current alarm for a port is the sum of the thresholds for all ALDs connected to the port. Take the threshold for reporting an overcurrent alarm as an example. If there are N ALDs connected to the port, then: Threshold for reporting an overcurrent alarm for the port = This threshold for ALD 1 + This threshold for ALD 2 + ... + This threshold for ALD N. If a non-recommended ALD model is used, it is recommended that the alarm threshold type be set to UER_SELF_DEFINE.

  • When the power supply switch is set to ON, the links of ALDs that are working properly will be intermittently interrupted if this command is executed to modify a current alarm threshold or reset the power supply switch to on.

  • For a port on an RF module in a multimode base station, turning off the ALD power supply switch takes effect only when the ALD Power Switch parameter is set to OFF in each mode.

  • If the RET port is connected to an RPCU, ensure that Overcurrent Alarm Occur Threshold and Overcurrent Alarm Clear Threshold are properly configured.

PWRSWITCH ALD Power Switch

Meaning: Indicates the state of the ALD power supply switch. If SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), RAS (Remote Azimuth Steering Unit), or RGPS (Remote GPS) is used, the ALD power supply switch must be set to ON. In actual running, the RRU automatically sets this switch to OFF for an RET port when the ALM-26530 RF Module ALD Current Abnormal alarm is reported due to overcurrent, overcurrent protection, or undercurrent protection (the RRU supports undercurrent protection and Low Current Protect Switch is set to ON for the RRU) on the RET port. For details, see ALM-26530 RF Module ALD Current Abnormal.

THRESHOLDTYPE Current Alarm Threshold Type

Meaning: Indicates the type of the ALD current alarm threshold. This parameter is valid only if the ALD power supply switch is turned on. If this parameter is not set to UER_SELF_DEFINE, the current alarm thresholds must be set according to the ALD type and connection mode.

1. For RET antennas only (multi-wire cable), Undercurrent Alarm Occur Threshold must be set to 10 mA, Undercurrent Alarm Clear Threshold must be set to 15 mA, Overcurrent Alarm Occur Threshold must be set to 150 mA, and Overcurrent Alarm Clear Threshold must be set to 120 mA.

2. For RET antennas and AISUs, Undercurrent Alarm Occur Threshold must be set to 20 mA, Undercurrent Alarm Clear Threshold must be set to 25 mA, Overcurrent Alarm Occur Threshold must be set to 550 mA, and Overcurrent Alarm Clear Threshold must be set to 510 mA.

3. For AISUs only, Undercurrent Alarm Occur Threshold must be set to 10 mA, Undercurrent Alarm Clear Threshold must be set to 15 mA, Overcurrent Alarm Occur Threshold must be set to 350 mA, and Overcurrent Alarm Clear Threshold must be set to 300 mA.

4. For RGPS only, Undercurrent Alarm Occur Threshold must be set to 0 mA, Undercurrent Alarm Clear Threshold must be set to 10 mA, Overcurrent Alarm Occur Threshold must be set to 300 mA, and Overcurrent Alarm Clear Threshold must be set to 200 mA.

5. For RGPSs and AISUs, Undercurrent Alarm Occur Threshold must be set to 10 mA, Undercurrent Alarm Clear Threshold must be set to 15 mA, Overcurrent Alarm Occur Threshold must be set to 350 mA, and Overcurrent Alarm Clear Threshold must be set to 300 mA.

OOTHD Overcurrent Alarm Occur Threshold

Meaning: Indicates the overcurrent alarm occur threshold. When the overcurrent alarm occur threshold is lower than the maximum current supported by the hardware, the overcurrent alarm occur threshold prevails. In this case, when the ALD current value is greater than this threshold, ALM-26530 RF Unit ALD Current Out of Range is reported and the specific problem is overcurrent. When the overcurrent alarm occur threshold is higher than the maximum current supported by the hardware, the maximum current supported by the hardware serves as the overcurrent alarm threshold. In this case, when the ALD current value is the same as or greater than the maximum current supported by the hardware, ALM-26530 RF Unit ALD Current Out of Range is reported and the specific problem is overcurrent protection.

GUI Value Range: 0~3500

Unit: mA

Actual Value Range: 0~3500

Recommended Value: None

-Configuration constraints:

Example

To modify the configuration of an RET port with the parameters as follows: Cabinet No.: 0, Subrack No.: 63, Slot No.: 0, Port No.: RET_PORT, Power Switch: ON, THRESHOLDTYPE: RET_ONLY_MULTICORE, run the following command:
MOD RETPORT: CN=0, SRN=63, SN=0, PN=RET_PORT, PWRSWITCH=ON, THRESHOLDTYPE=RET_ONLY_MULTICORE;
