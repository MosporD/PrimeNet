Add Synchronous Ethernet Clock (ADD SYNCETH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a synchronous-Ethernet clock link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After a synchronous-Ethernet reference clock is added, the synchronous-Ethernet clock is only an optional reference clock source for the system.

  • No synchronous-Ethernet clock link can be configured on an Ethernet port if the speed of the port is set to 10M.

  • Adding an input link to a 1000 Mbit/s electrical port that is negotiated to work in master mode will interrupt the port for about 3 seconds. During the interruption, operations related to the ETHPORT may fail.

  • If the synchronous-Ethernet link is configured, the synchronous-Ethernet clock signal can be transferred to the next-level NE if the two NEs are cascaded by Ethernet.

  • If a synchronous-Ethernet link is added to a 1000 Mbit/s electrical port, ensure that the peer device do not work in slave mode. If the peer device works in slave mode, services will be interrupted or the OM channel will be disconnected.

  • Configuring the synchronous Ethernet output link will temporarily interrupt the port where the output link is located for 3 to 15 seconds. During the interruption, operations related to the ETHPORT may fail.

  • If a synchronous Ethernet output link has been configured and a synchronous Ethernet input link is added, the port where the input link is located is temporarily interrupted for 3 to 15 seconds. During the interruption, operations related to the ETHPORT may fail.

Parameters

ID Name Description
LN SyncEth Clock No.

Meaning: Indicates the number of the synchronous-Ethernet clock link. A maximum of two links can be configured currently.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the SYNCETH MO, when the value of TYPE is set to IN, the value of LN must be 0. When the value of TYPE is set to OUT, the value of LN must be 1.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
TYPE SyncEth Type

Meaning: Indicates the type of a synchronous-Ethernet clock link. It indicates whether the corresponding synchronous-Ethernet port is an input or output port. An input port is used to import clock signals to the NE, and an output port is used to export clock signals to other NEs. Only the synchronous-Ethernet clock of input type can serve as a clock source.

GUI Value Range: IN(Input), OUT(Output)

Unit: None

Actual Value Range: IN, OUT

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

SSM SSM Selection

Meaning: Indicates whether handling of SSM frames is supported. The setting of this parameter is consistent with the setting on the Ethernet clock server.

The synchronization status message (SSM) carries clock quality information, which is specified in ITU-T.

This parameter is valid only when the synchronous-Ethernet clock link is of the input type.

PRI Priority

Meaning: Indicates the priority of the clock source. The value 1 indicates that the current clock source has the highest priority, and the value 4 indicates that the current clock source has the lowest priority.

Example

To add a synchronous-Ethernet clock link with the parameters as follows: SyncEth Clock No.: 0, Slot No.: 6, Port No.: 0, run the following command:
ADD SYNCETH: LN=0, SN=6, PN=0;
