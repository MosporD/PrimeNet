Add AAS (ADD AAS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to add an Active Antenna System (AAS) to a specified chain/ring.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]Before an AAS is added, an AAS chain/ring must be added by running the ADD RRUCHAIN command.

  • [Co-MPT,NodeB,eGBTS,eNodeB]After an AAS is added, if links cannot be set up for the associated AAMU or links cannot work at the highest CPRI line rate, you need to run the STR CPRILBRNEG command to initiate negotiation.

If the user does not need to forcibly verify the AAS specifications using the MAE-Deployment, this parameter can be left unspecified. Example

To add an AAS with the parameters as follows: Cabinet No.: 0, Subrack No.: 70, Topo Position: TRUNK, AAS Chain No.: 0, AAS Position: 1, AAS Name : "AAS-1", AAU Specification: "AAU3902", run the following command:
ADD AAS: CN=0, SRN=70, TP=TRUNK, RCN=0, PS=1, AN="AAS-1", AAUSPEC="AAU3902";
