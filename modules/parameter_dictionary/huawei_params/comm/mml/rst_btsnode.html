Reset Base Station (RST BTSNODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to reset the configured in-position boards (excluding passive boards such as the UPEU and USCU) in a BS.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The reset of an NE causes service interruption, and the NE restarts automatically.

  • In a dual-mode NE, if there are peer services carried on the boards to be reset, the peer services are interrupted during the reset.

  • For a multimode base station using dual-star topology or CPRI MUX/eCPRI MUX, running this command interrupts services of peer mode.

  • If a multimode NE supports co-transmission and the shared port for co-transmission port is located on a board working in the current mode, running this command will interrupt the services of the peer mode.

  • You are not advised to reset the NE when the NE is being downloading, supplementing, or activating software. If the NE needs to be reset at this time, set the FOCRST parameter to YES.

  • The system always returns a message indicating that the resetting succeeds irrespective of whether the NE is successfully reset or not.

Parameters

ID Name Description
FOCRST Forced Reset Flag

Meaning: Indicates whether to forcibly reset an NE. When this parameter is set to NO, an NE cannot be forcibly reset if the NE is downloading, supplementing, or activating software, and if the command is RST BRDPWROFF, the system performs a security exit and then a power-off reset on the board. When this parameter is set to YES, an NE is forcibly reset no matter what kind of operations this NE is performing.

GUI Value Range: NO(NO), YES(YES)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(NO)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To reset the BS, run the following command:
RST BTSNODE:;
