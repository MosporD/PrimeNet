Acting Loss Measurement (ACT ETHLM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to activate the packet loss detection function on the Ethernet.

Note

  • If the MAC address configured on the remote MEP is all zeros and the remote MEP does not learn the actual MAC address, the packet loss detection function fails to be activated on the Ethernet.

  • Currently, the UMPT, UMDU, LMPT, GTMUc, UTRPc, UCCU, UBBPe (excluding UBBPe15), UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf1, UBBPf0, UBBPg1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 and UBBPg9 support this command.

  • If the Ethernet OAM Type parameter is modified by running the SET ETHOAM command, the packet loss measurements function will become invalid.

  • When the Port Type parameter is set to ETHTRK for a local MEP or is set to ETH and this Ethernet port has been added to an Ethernet trunk, Ethernet packet loss measurement cannot be activated.

  • System specifications: A maximum of 8 ETHLM objects can be configured.

  • Board specifications: A maximum of 8 ETHLM objects can be configured on a UCCU/UMPT/UMDU/LMPT/GTMUc/UTRPc/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

Example

To activate loss measurement with the parameters as follows: Session ID: 0, MD Name: aaa, MA Name: aaa, Mode: SLM, MEP ID: 1, Destination Type: RMEP, RMEP ID: 2, TX Interval: 1000ms, run the following command:
ACT ETHLM: SESSIONID=0, MDNAME="aaa", MANAME="aaa", MODE=SLM, MEPID=1, DSTTYPE=RMEP, RMEPID=2, INTERVAL=1000MS;
