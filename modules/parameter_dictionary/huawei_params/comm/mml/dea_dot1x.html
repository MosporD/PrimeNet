Deactivate IEEE 802.1X Authentication (DEA DOT1X)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to deactivate the 802.1X authentication.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This operation may interrupt the services or OM channels carried on this port. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet that provides the port on which IEEE 802.1X authentication is configured.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Port ID and Port Type parameter in the DOT1XAUTH MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Example

To deactivate the 802.1X authentication with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: Base Board, Port No.: 0, run the following command: 
DEA DOT1X: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PN=0;
