Add IPv6 ACL (ADD ACL6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an IPv6 access control list (ACL).

Note

  • [Co-MPT,eNodeB,gNodeB]On a BS, the total number of ACLs and ACL6s must be smaller than or equal to 584.

  • [Co-MPT,eNodeB,gNodeB]System specifications: If the UMPTa/UMPTb/UMDU is the main control board, a maximum of 188 ACL6s can be configured. If the UMPTe is the main control board, a maximum of 456 ACL6s can be configured. If the UMPTg/UMPTga is the main control board, a maximum of 584 ACL6s can be configured.

  • [Co-MPT,eNodeB,gNodeB]Board specifications: A maximum of 188 ACL6s can be configured on a UMPTa/UMPTb/UMDU. A maximum of 456 ACL6s can be configured on a UMPTe. A maximum of 584 ACL6s can be configured on a UMPTg/UMPTga.

  • [Co-MPT,eNodeB,gNodeB]If the UMPTa/UMPTb/UMDU is the main control board, a maximum of 320 ACLs and ACL6s can take effect on a BS. If the UMPTe is the main control board, a maximum of 456 ACLs and ACL6s can take effect on a BS. If the UMPTg/UMPTga is the main control board, a maximum of 584 ACLs and ACL6s can take effect on a BS.

  • [Co-MPT,eNodeB,gNodeB]An ACL6 takes effect together with packet filtering policy and IPsec policy group binding interface. That is, the ACL6 does not take effect when being configured, and takes effect when the packet filtering policy or IPsec policy group binding interface is configured.

  • [Co-MPT,eNodeB,gNodeB]User-configured IPv6 ACLs count in the specifications of automatically setup IPv6 ACLs even if the user-configured IPv6 ACLs are not referenced by any bearer.

Parameters

ID Name Description
ACLID IPv6 ACL ID

Meaning: Indicates the ID of the IPv6 ACL to which an IPv6 ACL rule belongs. An IPv6 ACL rule with an ACL ID ranging from 3000 to 3999 indicates a high-level rule based on the layer 3 and layer 4 information configured by users. An IPv6 ACL rule with an ACL ID ranging from 7000 to 7999 indicates a high-level rule based on the layer 3 and layer 4 information configured by the system.

GUI Value Range: 3000~3999,7000~7999

Unit: None

Actual Value Range: 3000~3999,7000~7999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]The ID of an IPv6 ACL that is manually configured must range from 3000 to 3999.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
ACLDESC Description

Meaning: Indicates the brief description of an IPv6 ACL.

GUI Value Range: 0~127 characters

Unit: None

Actual Value Range: 0~127 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To add an IPv6 ACL with the parameters as follows: IPv6 ACL ID: 3000, Description: Acl Group is created, run the following command: 
ADD ACL6: ACLID=3000, ACLDESC="Acl Group is created";
