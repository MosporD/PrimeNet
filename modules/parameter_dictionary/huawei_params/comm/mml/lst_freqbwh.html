List Frequency Bandwidth (LST FREQBWH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the effective bandwidth of an RRU or RFU carrier.

Note

  • This command applies only to UMTS.

  • When the queried value of Frequency Min Bandwidth of the RF module is 5000, the RF module may operate at the default manufacturing Frequency Min Bandwidth. For details, see the precautions for using the SET FREQBWH command.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the RRU or RFU is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]CN in the RRU MO is set to 0~15.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the RRU or RFU is located.

GUI Value Range: 4~5,60~254

Unit: None

Actual Value Range: 4~5,60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of SRN in the RRU MO ranges from 60 to 254. The value of SRN in the RFU MO ranges from 4 to 5.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the RRU or RFU.

GUI Value Range: 0~8

Unit: None

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the CABINET MO where the RFU MO is located is set to BTS3900AL, the value of SN in the RFU MO ranges from 0 to 8. Otherwise, the value of SN in the RFU MO ranges from 0 to 5. When the value of SRN in the RRU MO is set to 60, SN in the RRU MO ranges from 0 to 5. When the value of SRN in the RRU MO ranges from 61 to 254, the value of SN in the RRU MO ranges from 0 to 3.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When SN in the RRU MO is set to a value greater than 0 and RT in the RRU MO is not set to MPRF, SRN in the RRU MO must be set to 60, and TYPE in the CABINET MO where the RRU MO is located must be set to RFC5906 or IFS5906.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the effective bandwidth of an RRU or RFU carrier with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, run the following command:
LST FREQBWH: CN=0, SRN=60, SN=0;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the RRU or RFU is located.

Subrack No.

Indicates the number of the subrack where the RRU or RFU is located.

Slot No.

Indicates the slot number of the RRU or RFU.

Frequency Min Bandwidth(kHz)

Indicates the minimum effective bandwidth of the carrier. This parameter takes effect only to UMTS.
