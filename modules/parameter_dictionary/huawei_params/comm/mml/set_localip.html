Set Local OM IP Address (SET LOCALIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the IP address of the local maintenance channel. The IP address of the local maintenance channel refers to the IP address of the local maintenance Ethernet port on the board.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After this command is executed at the local end, if the new IP address for the local maintenance channel is different from the currently used IP address for the local maintenance channel, the local maintenance channel becomes unavailable. When this occurs, the message indicating operation succeeded cannot be reported.

  • In the same routing domain, the IP address of a local maintenance channel and that configured at another port must be on the network segments that are exclusive of each other. In the same routing domain, the two IP addresses are on the same network segment if the following conditions are met: (IPValueA & IPMaskA == IPValueB & IPMaskB) and (IPMaskA == IPMaskB). The two network segments are inclusive if the following conditions are met: (IPValueA & IPMask == IPValueB & IPMask) and (IPMask = IPMaskA & IPMaskB). & indicates the bitwise logical AND operation.

  • When a terminal equipped with the WDT software is directly connected to an NE through a USB port and the port mode is USB (which can be queried by running the DSP LOCALETHPORT command), the outputs of the DSP LOCALIP and LST LOCALIP commands may be different. In this case, ALM-26245 Configuration Data Inconsistency is not reported.

  • When a terminal equipped with the WDT software is directly connected to an NE through a USB port, the local maintenance IP address and mask are obtained from the terminal through the DHCP protocol.

  • During site deployment, the BS restores the current local maintenance IP address to the default value 192.168.0.49 if the IP address conflicts with the local IP address of a remote maintenance channel that is obtained by the DHCP server.

  • [NodeB,eNodeB]If an error message indicating an IP address conflict is displayed, search the existing IP addresses in the system that may conflict with the IP address for local maintenance by running the following commands: LST DEVIP, DSP DEVIP, LST OMCH, DSP OMCH, LST PPPLNK, DSP PPPLNK, LST MPGRP, DSP MPGRP, LST IPRT, and DSP IPRT. The conflicting IP address may be a device IP address, local IP address of a remote maintenance channel, local IP address of a PPP link, local IP address of an MP group, or next hop IP address of an IP route.

  • [gNodeB]If an error message indicating an IP address conflict is displayed, search the existing IP addresses in the system that may conflict with the IP address for local maintenance by running the following commands: LST DEVIP, DSP DEVIP, LST OMCH, DSP OMCH, LST IPRT, and DSP IPRT. The conflicting IP address may be a device IP address, local IP address of a remote maintenance channel, or next hop IP address of an IP route.

Parameters

ID Name Description
IP IP Address

Meaning: Indicates the IP address for local maintenance. The value of this parameter must meet the following conditions:

(1) It must be a valid IP address of Class A, B, or C, and cannot be set to 0.x.x.x or 127.x.x.x.

(2) It must be different from the local IP address of any remote maintenance channel and from any device IP address.

(3) It must be on different network segments from the IP address of any remote maintenance channel and from any device IP address.

(4) It must be different from any IP address configured on other ports.

(5) It must be on different network segments from the destination IP address of any IP route.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: Planned IP address for local maintenance on a board

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]IP in the LOCALIP MO must be set to a valid IP address of Class A, B, or C. In addition, it cannot be 127.x.x.x or 0.x.x.x.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a LOCALIP MO, neither the network ID nor the host ID can be all 0 or 1 in the logical operation result of IP and MASK.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
MASK Mask

Meaning: Indicates the subnet mask for the IP address of a local maintenance channel. This subnet mask must be a valid mask address and cannot be 0.0.0.0 or 255.255.255.255.

GUI Value Range: Valid subnet mask

Unit: None

Actual Value Range: Valid subnet mask

MML Default Value: None

Recommended Value: Planned subnet mask of the local maintenance channel on a board

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the binary value converted from MASK in the LOCALIP MO, 0 is not allowed to precede 1. MASK cannot be 0.0.0.0 or 255.255.255.255.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a LOCALIP MO, neither the network ID nor the host ID can be all 0 or 1 in the logical operation result of IP and MASK.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the IP address of the local maintenance with the following parameters: IP Address: "192.168.211.158", Mask: "255.255.255.0", run the following command:
SET LOCALIP: IP="192.168.211.158", MASK="255.255.255.0";
