List AAL2 Path Configuration (LST AAL2PATH)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the configuration of an AAL2 path.

Note

None.

Parameters

None.

Example

To list the configuration of an AAL2 path, run the following command:
LST AAL2PATH:;
The result is shown as follows:

Output Description

Field Description

Path ID

Indicates the number of an AAL2 path.

Node Type

Indicates the type of an AAL2 path. If the local end node is selected, the AAL2 path is used by local services. If the switching node is selected, the AAL2 path is used to connect to the controller through the hub BS. If the adjacent node is selected, the AAL2 path is used to connect to the lower-level BS through the hub BS.

Adjacent Node ID

Indicates the adjacent node ID of an AAL2 path.

Cabinet No.

Indicates the number of the cabinet where an AAL2 path is located.

Subrack No.

Indicates the number of the subrack where an AAL2 path is located.

Slot No.

Indicates the number of the slot where an AAL2 path is located.

Subboard Type

Indicates the type of sub-board on the board where an AAL2 path is established.

Bearer Service Type

Indicates the type of the service carried on an AAL2 path. From the perspective of flow control, services carried by an AAL2 path are classified into five categories: the constant bit rate (CBR) service, real-time variable bit rate (RTVBR) service, non-real-time variable bit rate (NRTVBR) service, unspecified bit rate plus (UBR+) service, and unspecified bit rate (UBR) service.

Join Transmission Resource Group

Indicates whether an AAL2 path joins a transmission resource group.

Transmission Resource Group ID

Indicates the number of the transmission resource group to which an AAL2 path is added.

Bearer Port Type

Indicates the type of port on which an AAL2 path is carried.

Bearer Port No.

Indicates the number of the port on which an AAL2 path is carried.

VPI

Indicates the virtual path identifier (VPI) of an AAL2 path.

VCI

Indicates the virtual channel identifier (VCI) of an AAL2 path.

Rate Unit

Indicates the unit of the peak cell rate (PCR), minimum cell rate (MCR), sustainable cell rate (SCR), and receive cell rate (RCR). 1 cell/s is equal to 0.424 kbit/s. If the rate is converted from cell/s to kbit/s, the result value must be rounded down to the nearest integer. For example, 73 cell/s is converted to 30 kbit/s.

Peak Cell Rate

Indicates the peak cell rate (PCR) of an AAL2 path, which is the maximum cell burst rate supported by the AAL2 path. The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality.

Sustain Cell Rate

Indicates the Sustainable Cell Rate (SCR) of the AAL2 path. The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality.

The SCR value determines the average rate at which cells are sent over a Variable Bit Rate (VBR) connection.

Min Cell Rate

Indicates the minimum cell rate (MCR) of an AAL2 path. The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality. The MCR is the minimum cell transmission rate acceptable by the user.

Max Burst Size(cell)

Indicates the maximum burst size (MBS). The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality.

Receive Cell Rate

Indicates the rate at which cells are received. This parameter must be consistent with the TX bandwidth configured on the controller. Otherwise, the RX bandwidth in the flow control algorithm will be inaccurate, affecting flow control.

Cell Delay Variation Tolerance(0.1microsecond)

Indicates the cell delay variation tolerance. The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality.

User Label

Indicates the user-defined information about an AAL2 path.
