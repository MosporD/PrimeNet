Update Vendor Certificate (UPD VENDORCERT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to replace an abnormal Huawei vendor certificate. This is done to resolve the issue that a base station cannot access a customer's network due to the abnormal certificate.

Note

  • Before updating a vendor certificate, ensure that the new certificate file has been uploaded to the FTP server of the MAE.

  • You can update vendor certificates of all boards (with Scope set to ALL(All)) or update the vendor certificate of a specified board (with cabinet number, subrack number, and slot number set). The command output displays the update result by board.

  • The certificate update is not performed in the following scenarios even if this command is executed:

    - A board cannot be detected.

    - The vendor certificate of a board is normal or does not exist.

    - The new certificate is abnormal.

  • In active/standby HA scenarios, if the vendor certificate update of the active board succeeds but that of the standby board fails, run this command to update the vendor certificates again.

  • Do not repeatedly update a vendor certificate before it is successfully updated. Otherwise, an exception will occur in the current certificate update process.

Example

To update vendor certificate with the parameters as follows: Certificate Type: DEVCERT, FTP Server IP: 192.168.58.118, User Name: admin, Password: *****, Certificate Replacement Scope: ALL, run the following command:
UPD VENDORCERT: MODE=IPV4, IP="192.168.58.118", USR="admin", PWD="*****", SCOPE=ALL;
