List SSL Cipher Suite in Use (DSP SSLCS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the names and security levels of all SSL cipher suites that have taken effect.

Note

None.

Parameters

None.

Example

To query the names and security levels of all SSL cipher suites that have taken effect, run the following command:
DSP SSLCS:;
The result is shown as follows:

Output Description

Field Description

Cipher Suite Name

Indicates the name of the SSL cipher suite.

Cipher Suite Level

Indicates the security level of an SSL cipher suite. Raising the level of cipher suites may increase system security risks. Set this parameter to a proper value.
