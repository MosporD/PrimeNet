Add Ping Filter IP/Mask (ADD PINGFILTER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a ping filter. After a ping filter is added, operators can ping only the host IP address or IP addresses of network segments that meet the ping filtering conditions on the BS if the ping filtering mode is set to whitelist. If the ping filtering mode is set to blacklist, operators cannot ping the host IP address or IP addresses of network segments that meet the ping filtering conditions on the BS.

Note

  • The IP addresses in different ping filter entries must be on different network segments.

  • In the same routing domain, when no ping filter entry is configured, the ping filtering function is disabled by default. After a ping filter entry is added, the ping filtering function is enabled automatically.

  • Adding a ping filter entry may affect the object (such as an IP path or a remote maintenance channel) that uses the ping function. It is recommended that the impact on these objects be eliminated when this command is used together with the SET PINGFILTERMODE command.

  • System specifications: If the WMPT/UMPT/UMDU/LMPT/GTMUc is the main control board, a maximum of 8 ping filter entries can be configured.

  • Board specifications: A maximum of 8 ping filter entries can be configured on a WMPT/UMPT/UMDU/LMPT/GTMUc/UTRPc/UTRP (subboard type: UEOC/UQEC/UIEC)/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

Parameters

ID Name Description
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
IP IP Address

Meaning: Indicates the IP address in a ping filter entry. This address must be a valid IP address of class A, B, or C. It can also be a network segment address.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]IP in a PINGFILTER MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
MASK Mask

Meaning: Indicates the subnet mask corresponding to the IP address in a ping filter entry. The subnet mask cannot be 0.0.0.0.

GUI Value Range: Valid subnet mask

Unit: None

Actual Value Range: Valid subnet mask

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the binary value into which MASK in a PINGFILTER MO is converted, 0 cannot precede 1. In addition, MASK can be 255.255.255.255, but cannot be 0.0.0.0.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a ping filter with the parameters as follows: IP Address: "10.10.10.10", Mask: "255.255.255.0", run the following command: 
ADD PINGFILTER: IP="10.10.10.10", MASK="255.255.255.0";
