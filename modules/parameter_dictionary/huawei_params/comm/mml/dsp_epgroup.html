Display End Point Group User-plane Links Information (DSP EPGROUP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to display the information of user-plane links in an end point group.

Note

  • [Co-MPT,eNodeB,gNodeB]In a GTP-U static detection period, the user-plane path detection results are not accurate in the following cases, and therefore you are advised to query the results later:

    1. The GTP-U static detection configuration of a user-plane path is modified. The GTP-U static detection configuration, for example, can be Static Check Mode in the GEPMODELPARA MO or Static Check Switch in the GTPU, USERPLANEPEER, or EPGROUP MO.

    2. Establishment of a user-plane path is triggered because, for example, another MO such as an S1 MO references the endpoint group, a user plane host is added to the endpoint group, or a user plane peer is added to the endpoint group.

    3. Modification of a user-plane path is triggered because, for example, a user-plane host is modified, a user-plane peer is modified, an EP2RSCGRP object is added, or an IPRT, IPROUTE4, or IPROUTE6 object is added, modified, or removed.

  • [NodeB,eGBTS]In a GTP-U static detection period, the user-plane path detection results are not accurate in the following cases, and therefore you are advised to query the results later:

    1. The GTP-U static detection configuration of a user-plane path is modified. The GTP-U static detection configuration, for example, can be Static Check Mode in the GEPMODELPARA MO or Static Check Switch in the GTPU, USERPLANEPEER, or EPGROUP MO.

    2. Establishment of a user-plane path is triggered because, for example, another MO such as an S1 MO references the endpoint group, a user plane host is added to the endpoint group, or a user plane peer is added to the endpoint group.

    3. Modification of a user-plane path is triggered because, for example, a user-plane host is modified, a user-plane peer is modified, an EP2RSCGRP object is added, or an IPRT or IPROUTE4 object is added, modified, or removed.

Parameters

ID Name Description
EPGROUPID End Point Group ID

Meaning: Indicates the ID of the end point group to which an end point belongs.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query end point group user-plane links Information with the parameters as follows: End Point Group ID: 0, run the following command:
DSP EPGROUP: EPGROUPID=0;

Output Description

Field Description

End Point Group ID

Indicates the ID of the end point group to which an end point belongs.

VRF Index

Indicates the index of an IPv4 VRF instance.

IPv6 VRF Index

Indicates the index of an IPv6 VRF instance. This parameter takes effect only in LTE and NR.

User Plane Host ID

Indicates the host ID used by the user-plane end point group.

Local IP Address

Indicates the IP Address of the user plane host.

Local IPv6 Address

Indicates the IPv6 Address of the user plane host. This parameter takes effect only in LTE and NR.

User Plane Peer ID

Indicates the peer ID used by the user-plane end point group.

Peer IP Address

Indicates the IP Address of the user plane peer.

Peer IPv6 Address

Indicates the IPv6 Address of the user plane peer. This parameter takes effect only in LTE and NR.

Check Result

Indicates the check results of GTP-U static detection for the user-plane links in the queried end point group. The parameter takes effect only in LTE and NR.

UDP Ping Check Result

Indicates the result of UDP ping detection. The parameter takes effect only in UMTS.

Fault Generation Time

Indicates the time when a user-plane link becomes faulty.
