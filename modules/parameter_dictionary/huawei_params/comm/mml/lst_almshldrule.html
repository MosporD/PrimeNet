List Alarm Shielding Rule (LST ALMSHLDRULE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query an alarm shielding rule.

Note

None.

Parameters

None.

Example

To query alarm shielding rules, run the following command:
LST ALMSHLDRULE:;
The result is as follows:
+++    0        2017-12-26 21:18:18
O&M    #529
%%LST ALMSHLDRULE:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Index

Indicates the ID of an alarm shielding rule.

Alarm ID

Indicates the ID of an alarm. An alarm ID uniquely identifies a type of alarms for specific faults or events.

Name of Parameter 1

Indicates the name of the first matching parameter. It can be the name of any parameter in alarm location information. The name must be complete. Otherwise, the alarm cannot be shielded.

Value of Parameter 1

Indicates the value of the first matching parameter. It can be the value of any parameter in alarm location information. The value must be complete. Otherwise, the alarm cannot be shielded.

Name of Parameter 2

Indicates the name of the second matching parameter. It can be the name of any parameter in alarm location information. The name must be complete. Otherwise, the alarm cannot be shielded.

Value of Parameter 2

Name of Parameter 3

Value of Parameter 3

Indicates the value of the third matching parameter. It can be the value of any parameter in alarm location information. The value must be complete. Otherwise, the alarm cannot be shielded.

Name of Parameter 4

Indicates the name of the fourth matching parameter. It can be the name of any parameter in alarm location information. The name must be complete. Otherwise, the alarm cannot be shielded.

Value of Parameter 4

Name of Parameter 5

Value of Parameter 5
