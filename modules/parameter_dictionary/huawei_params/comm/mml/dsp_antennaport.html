Display Antenna Port (DSP ANTENNAPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about an antenna port.

Note

[Co-MPT,NodeB,eNodeB,gNodeB]The MPRF does not support this command.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the RRU or RFU where the antenna port is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SRN Subrack No.

Meaning: Indicates the subrack number of the RRU or RFU where the antenna port is located.

GUI Value Range: 4~5,60~254

Unit: None

Actual Value Range: 4~5,60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CN in the ANTENNAPORT MO is set to a value in the range from 0 to 15, the value of SRN can be 4, 5, or a number ranging from 60 to 254. When the value of CN in the ANTENNAPORT MO ranges from 16 to 62, the value of SRN is 4 or 5.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SN Slot No.

Meaning: Indicates the slot number of the RRU or RFU where the antenna port is located.

GUI Value Range: 0~8

Unit: None

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]When SRN in the ANTENNAPORT MO is set to 4 or 5, the value of SN ranges from 0 to 8. When the value of SRN in an ANTENNAPORT MO ranges from 60 to 254 and RT in the RRU MO where the ANTENNAPORT MO is located is set to MPRF, the value of SN ranges from 1 to 3. When the value of SRN in an ANTENNAPORT MO is set to 60 and RT in the RRU MO where the ANTENNAPORT MO is located is not set to MPRF, SN ranges from 0 to 5. When the value of SRN in an ANTENNAPORT MO ranges from 61 to 254 and RT in the RRU MO where the ANTENNAPORT MO is located is not set to MPRF, SN must be set to 0.
  • [eGBTS]When SRN in the ANTENNAPORT MO is set to 4 or 5, the value of SN ranges from 0 to 8. When the value of SRN in the ANTENNAPORT MO is set to 60, SN ranges from 0 to 5. When the value of SRN in the ANTENNAPORT MO ranges from 61 to 254, SN is set 0.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
PN Antenna Port No.

Meaning: Indicates the number of the antenna port on the RRU or RFU. For the RRU that works in TDD or FDD mode and has eight channels to be connected to the antenna, the service channels are ANT1 to ANT8 and the corresponding ports on the antenna are R0A to R0H. For other RRUs/RFUs, the service channels are numbered from ANT0 and the corresponding port on the antenna is R0A.

GUI Value Range: R0A(R0A), R0B(R0B), R0C(R0C), R0D(R0D), R0E(R0E), R0F(R0F), R0G(R0G), R0H(R0H), R0I(R0I), R0J(R0J), R0K(R0K), R0L(R0L), R0M(R0M), R0N(R0N), R0O(R0O), R0P(R0P)

Unit: None

Actual Value Range: R0A, R0B, R0C, R0D, R0E, R0F, R0G, R0H, R0I, R0J, R0K, R0L, R0M, R0N, R0O, R0P

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

Example 1: To query the dynamic information about the antenna port with the parameters as follows: Cabinet No.: 0, Subrack No.: 63, Slot No.: 0, Antenna Port No.: R0A, run the following command:
DSP ANTENNAPORT: CN=0, SRN=63, SN=0, PN=R0A;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the RRU or RFU where the antenna port is located.

Subrack No.

Indicates the subrack number of the RRU or RFU where the antenna port is located.

Slot No.

Indicates the slot number of the RRU or RFU where the antenna port is located.

Antenna Port No.

Indicates the number of the antenna port on the RRU or RFU. For the RRU that works in TDD or FDD mode and has eight channels to be connected to the antenna, the service channels are ANT1 to ANT8 and the corresponding ports on the antenna are R0A to R0H. For other RRUs/RFUs, the service channels are numbered from ANT0 and the corresponding port on the antenna is R0A.

ALD Actual Power Switch

Indicates the actual status of the ALD power supply switch, which can be set to ON or OFF. ON indicates that this switch is set to on and OFF indicates that this switch is set to off.

ALD Current Value(mA)

Indicates the ALD current value. Value NULL indicates that this parameter fails to be queried or the ALD Actual Power Switch is OFF.
