Confirm TMA Connection (CFM TMACONNECTION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query whether an RRU/RFU is connected to a common tower mounted amplifier (TMA). You can run this command to check whether an RRU/RFU is connected to a common TMA that does not support the AISG protocol and run the SCN ALD command to check whether an RRU/RFU is connected to an intelligent TMA that supports the AISG protocol.

Before performing this operation, ensure that the base station has been commissioned and its cell data has been configured and activated.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • During the execution of this command, the base station attempts to turn on or off the ALD power switch of an antenna port on an RF module and set the receive channel attenuation of the RF module to 0. This changes the uplink coverage of the base station. However, the status of the ALD power switch restores after the command execution is complete. Therefore, it is recommended that you execute this command only during the base station deployment or when the traffic load of the base station is extremely light. If the common TMA is powered by another RF module or by a third-party power device instead of being powered by the connected RF module using feeders, this command cannot be used to determine whether the antenna port is connected to a common TMA.

  • This command cannot be executed when the crossed pair detection, intermodulation interference detection, or voltage standing wave ratio (VSWR) test is in process.

  • Do not add or remove a cell during the execution of this command. Otherwise, this command fails to be executed or the value of the CFMTMARESULT parameter in the command output is incorrect.

  • During the execution of this command, the RF module may report ALM-26530 RF Unit ALD Current Out of Range if the RF module is not connected to a TMA. After this command is executed, this alarm will be automatically cleared.

  • During the execution of this command, the RF module may report ALM-26541 ALD Maintenance Link Failure if the RF module has been configured with an ALD. After this command is executed, this alarm will be automatically cleared.

  • In a dual-mode base station, this command cannot be executed simultaneously on an RF module at both sides. Otherwise, this command fails to be executed or the value of the CFMTMARESULT parameter in the command output is incorrect.

  • If "With Normal TMA" is returned, the RRU/RFU may also be connected to an intelligent TMA.

  • If "Without Normal TMA" is returned, you need to check whether there is no TMA or a TMA is powered by a third party.

When the difference in the RTWP or RSSI is below this threshold, the antenna port is not connected to a common TMA.

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the RRU or RFU where the antenna port is located.

Subrack No.

Indicates the subrack number of the RRU or RFU where the antenna port is located.

Slot No.

Indicates the slot number of the RRU or RFU where the antenna port is located.

Antenna Port No.

Indicates the number of the antenna port on the RRU or RFU. For the RRU that works in TDD or FDD mode and has eight channels to be connected to the antenna, the service channels are ANT1 to ANT8 and the corresponding ports on the antenna are R0A to R0H. For other RRUs/RFUs, the service channels are numbered from ANT0 and the corresponding port on the antenna is R0A.

Confirm TMA Connection Result

Indicates the confirmation result of whether an antenna port is connected to a common TMA. If the confirmation fails for an RF module, you need to run the CFM TMACONNECTION command with the ALD Actual Power Switch, ALD Current Value(mA), ALD Current Out of Range, and Delta of RTWP parameters set to NULL on this RF module to obtain the reason for the confirmation failure.

ALD Actual Power Switch

Indicates the actual status of the ALD power supply switch, which can be set to ON or OFF. ON indicates that this switch is set to on and OFF indicates that this switch is set to off.

ALD Current Value(mA)

Indicates the ALD current value. Value NULL indicates that this parameter fails to be queried or the ALD Actual Power Switch is OFF.

ALD Current Out of Range Status

Indicates the status of the ALD current of an antenna port when the ALD power switch of the antenna port is set to on. If the status is No Alarm, the ALD power switch is set to on normally and the value of the CFMTMARESULT parameter is reliable. If the status is a value other than No Alarm, the ALD power switch is not set to on, the value of the CFMTMARESULT parameter is unreliable, and you need to determine whether the antenna port is connected to a common TMA based on the onsite conditions of the base station.

Delta of RTWP/RSSI(dB)

Indicates the difference in the RTWP/RSSI before and after the ALD power switch is set to on.
