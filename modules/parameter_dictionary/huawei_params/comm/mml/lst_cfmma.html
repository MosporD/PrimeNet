List CFM MA Configuration (LST CFMMA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of a CFM MA.

Note

None.

Parameters

None.

Example

To list the information about the CFM MA, run the following command: 
LST CFMMA:;
The result is shown as follows:
+++    0        2008-01-03 18:51:03
O&M    #186
%%LST CFMMA:;%%
RETCODE = 0  Operation succeeded. 

List CFM MA Configuration Data

        MD Name  =  CHINA
        MA Name  =  SHANGHAI

   Binding VLAN  =  Yes
        VLAN ID  =  3
  VLAN Priority  =  0

(Number of results = 1)


---    END

Output Description

Field Description

MD Name

Indicates the name of the MD to which the MA belongs.

MA Name

Indicates the name of the MA.

Cabinet No.

Indicates cabinet number of the board to which the MA belongs.

Subrack No.

Indicates subrack number of the board to which the MA belongs.

Slot No.

Indicates slot number of the board to which the MA belongs.

Binding VLAN

Indicates whether the MA is associated with the VLAN.

VLAN ID

Indicates the ID of the VLAN with which the MA is associated.

VLAN Priority

Indicates the priority of the VLAN with which the MA is associated.

CCM TX Interval

Indicates the interval at which the CFM MA transmits continuity check messages (CCMs).
