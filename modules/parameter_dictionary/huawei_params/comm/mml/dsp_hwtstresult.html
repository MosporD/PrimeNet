Display Board Hardware Test Result (DSP HWTSTRESULT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the result of the latest hardware test on a board.

Note

To ensure a successful query of the hardware test result of a board, the following conditions should be met:

1. The board has been configured.

2. At least one hardware test has been performed on the board.

3. No hardware test is being performed on the board.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the board is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the subrack number of the board.

GUI Value Range: 0~1,4~5,60~254

Unit: None

Actual Value Range: 0~1,4~5,60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the board.

GUI Value Range: 0~8

Unit: None

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the result of the hardware test on a board with the parameters as follows: Cabinet No.: 0, Subrack No.: 62, Slot No.: 0, run the following command:
DSP HWTSTRESULT: CN=0, SRN=62, SN=0;

Output Description

Field Description

BTS Name

Indicates the name of the BS.

Description

Indicates the description about the services and functions provided by the board or the cabinet.

Serial Number

Indicates the bar code of the board or the cabinet.

Software Version

Indicates the software version of the board.

Hardware Version

Indicates the hardware version of the board.

BootROM Version

Indicates the BootROM version of the board.

Test Time

Indicates the test time.

Test Result

Indicates the test result.
