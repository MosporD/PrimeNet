Display BFD Status (DSP BFD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of a BFD.

Note

When a BFD session is down, the displayed negotiation result of the BFD session is for reference only.

Parameters

ID Name Description
BFDSN Session ID

Meaning: Indicates the ID of a BFD.

GUI Value Range: 100~195

CLEAR Clear Statistic

GUI Value Range: NO(No), YES(Yes)

Unit: None

Example

To query the dynamic information about the BFD session with the parameters as follows: Session ID: 100, run the following command:
DSP BFD: BFDSN=100;

Output Description

Field Description

Session ID

Indicates the ID of a BFD.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Source IP

Indicates the source IP address of a BFD. The source IP address of a BFD must be a device IP address of a specified board (for example, the IP address of an Ethernet port or a port that carries a PPP link or MP group) or a logical IP address (for example, the IP address of a loopback port), but cannot be set to the same value as the IP address of a remote maintenance channel or a negotiated IP address. Note that a BFD cannot be configured as a single-hope session if its source IP address is a logical IP address.

Destination IP

Indicates the destination IP address of a BFD. The destination IP address must be a valid IP address, and cannot be set to 0.0.0.0 or any existing IP addresses in the system. If Virtual Router Redundancy Protocol (VRRP) is used in the network, two BFDs must be configured with the destination IP addresses set to the active and standby physical IP addresses of the virtual router, respectively.

My Discriminator

Indicates the local discriminator of a BFD session. The local discriminator must be the same as the peer discriminator.

Hop Type

Indicates the hop type of a BFD. The single-hop BFD is used to perform point-to-point detection at the data link layer, and often used in layer 2 networking scenarios. The multi-hop BFD is used to perform end-to-end connectivity checks at the transport layer, and often used in layer 3 networking scenarios.

Min TX Interval(ms)

Indicates the minimum interval at which a BFD transmits control packets.

Min RX Interval(ms)

Indicates the minimum interval at which a BFD receives control packets.

Detection Multiplier

Indicates the detection multiplier of a BFD.

Session Catalog

Indicates the type of a BFD. If this parameter is set to MAINTENANCE, this BFD is used only for continuity check (CC). If this parameter is set to RELIABILITY, the BFD is used to trigger route interlock. Route interlock enables the standby route to take over once the active route becomes faulty, and therefore prevents service interruption caused by route failures.

BFD Authentication Switch

Indicates whether a BFD supports BFD authentication. You are advised to enable the BFD Authentication Switch.

BFD Authentication Algorithm

Indicates the algorithm used during BFD authentication.

BFD Authentication Key Chain ID

Indicates the ID of a configured BFD key chain.

Cabinet No.

Indicates the cabinet No. to which a BFD belongs.

Subrack No.

Indicates the subrack No. to which a BFD belongs.

Slot No.

Indicates the slot No. to which a BFD belongs.

Session State

Indicates the state of a BFD.

Active Detecting Mode

Indicates the effective detection mode through negotiation.

Active Minimum Tx Interval(ms)

Indicates the effective minimum TX interval through negotiation.

Active Minimum Rx Interval(ms)

Indicates the effective minimum RX interval through negotiation.

Active Detection Time(ms)

Indicates the detection time when the negotiation takes effect.

Your Discriminator

Indicates the peer discriminator of a BFD.

Number of Transmit PDUs(packet)

Indicates the number of transmitted packets of a BFD.

Number of Receive PDUs(packet)

Indicates the number of received packets of a BFD.

Number of Up-to-Down Sessions

Indicates the number of times of up-to-down detected by a BFD.

Session Diagnosis

Indicates the diagnostic field of a BFD, that is, the cause of the latest failure.

Discard Pkt Qty for One-Way Authenticate(packet)

Indicates the number of packets discarded due to unidirectional BFD authentication.

Discard Pkt Qty for Authenticate Type Mismatch(packet)

Indicates the number of packets discarded due to authentication type inconsistency during BFD authentication.

Discard Pkt Qty for Invalid Packet Sequence No.(packet)

Indicates the number of packets discarded because the sequence number is invalid in BFD authentication packets.

Discard Pkt Qty for Packet Length Mismatch(packet)

Indicates the number of packets discarded due to key length inconsistency during BFD authentication.

Discard Pkt Qty for Key ID Mismatch(packet)

Indicates the number of packets discarded because the key indexes do not match between the two ends during BFD authentication.

Discard Pkt Qty for Abstract or Hash Fail(packet)

Indicates the number of packets discarded because the BFD authentication digest check or Hash algorithm execution fails.
