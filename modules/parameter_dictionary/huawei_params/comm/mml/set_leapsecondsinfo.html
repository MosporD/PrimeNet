Set the information of the leap second offset between the UTC and the GPS. (SET LEAPSECONDSINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the information of the leap second offset between the UTC and the GPS.

Note

None.

Parameters

ID Name Description
LEAPSECONDSCHGDATE Leap Seconds Change Date

Meaning: Indicates the date when the leap seconds changed. This parameter is set in compliance with the UTC. The format is as follows: YYYY-MM-DD. For example, 2006-09-08 indicates September 8th of 2006.

GUI Value Range: 1900-01-01~2099-12-31

Unit: None

Actual Value Range: 1900-01-01~2099-12-31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
LEAPSECONDSCHGTIME Leap Seconds Change Time

Meaning: Indicates the time when the leap seconds changed. This parameter is set in compliance with the UTC. The format is as follows: HH:MM:SS. For example, 10:20:05.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
CRTGPSTOUTCLEAPSECONDS Current Leap Second Offset Between UTC and GPS

Meaning: Indicates the current leap second offset between the UTC and the GPS.

GUI Value Range: -1000~1000

Unit: None

Actual Value Range: -1000~1000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
NEXTGPSTOUTCLEAPSECONDS Next Leap Second Offset Between UTC and GPS

Meaning: Indicates the next leap second offset between the UTC and the GPS.

GUI Value Range: -1000~1000

Unit: None

Actual Value Range: -1000~1000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set the information of the leap second offset between the UTC and the GPS with parameters as follows: Leap Seconds Change Date: 2017-1-7, Leap Seconds change Time: 07:59:59, Current LeapSeconds Offset between the UTC and the GPS: 17, Next LeapSeconds Offset between the UTC and the GPS: 18:
SET LEAPSECONDSINFO: LEAPSECONDSCHGDATE=2017&01&07, LEAPSECONDSCHGTIME=07&59&59, CRTGPSTOUTCLEAPSECONDS=17, NEXTGPSTOUTCLEAPSECONDS=18;
