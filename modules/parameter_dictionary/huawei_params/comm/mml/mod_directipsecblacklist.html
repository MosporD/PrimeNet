Modify Blacklist for Direct IPsec Tunnel (MOD DIRECTIPSECBLACKLIST)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify a direct IPsec blacklist.

Note

None.

Parameters

ID Name Description
DIRECTIPSECBLACKLISTID ID of Blacklist for Direct IPsec Tunnel

Meaning: Indicates the ID of a direct IPsec blacklist.

GUI Value Range: 0~383

Unit: None

Actual Value Range: 0~383

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
IPVERSION IP Version

Meaning: Indicates the IP version of a direct IPsec blacklist.

GUI Value Range: IPV4(IPv4), IPV6(IPv6)

Unit: None

Actual Value Range: IPV4, IPV6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
SECURITYPEERIPV4 Security Peer IPv4 Address

Meaning: Indicates the security peer IP address of a direct IPsec blacklist. This address must be a valid IP address of class A, B, or C.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]SECURITYPEERIPV4 in a DIRECTIPSECBLACKLIST MO must be set to a valid IP address of Class A, B, or C. In addition, it cannot be 127.x.x.x or 0.x.x.x.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
SECURITYPEERIPV6 Security Peer IPv6 Address

Meaning: Indicates the security peer IPv6 address of a direct IPsec blacklist. This IPv6 address must be set to a globally scoped unicast address.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]SECURITYPEERIPV6 in a DIRECTIPSECBLACKLIST MO must be set to a globally scoped unicast address.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To modify the configurations of the blacklist for direct IPSec tunnels with the parameters as follows: ID of Blacklist for Direct IPsec Tunnel: 0, IP Version: IPv4, Security Peer IPv4 Address: 192.168.10.10, run the following command:
MOD DIRECTIPSECBLACKLIST: DIRECTIPSECBLACKLISTID=0, IPVERSION=IPV4, SECURITYPEERIPV4="192.168.10.10";
