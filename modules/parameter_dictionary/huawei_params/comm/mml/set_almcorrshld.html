Set Alarm Correlation Shield Flag (SET ALMCORRSHLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the correlative alarm report flag for a specified alarm. If an alarm is generated as a correlative alarm, this alarm is not reported when Report Flag of Son Alarm is set to NOT_REPORT(Not Report) but reported when Report Flag of Son Alarm is set to REPORT(Report). In most cases, Report Flag of Son Alarm can be set to NOT_REPORT(Not Report) to shield the correlative alarms that carry the serial numbers of their root alarms. For example, when ALM-26232 BBU Optical Module Transmit/Receive Fault and ALM-26235 RF Unit Maintenance Link Failure are generated at the same time, you can set Report Flag of Son Alarm to NOT_REPORT(Not Report) if the ALM-26232 alarm is the root alarm and the user want to ignore the ALM-26235 alarm.

This command is an advanced alarm management function and is used to reduce correlative alarms. You must assess impacts before running this command.

Note

  • If an alarm has no root alarm, Report Flag of Son Alarm fails to be set for the alarm.

  • If an alarm is suppressed as a correlative alarm, this alarm will be reported again after Report Flag of Son Alarm is set to REPORT(Report).

  • If an alarm is reported as a correlative alarm, this alarm remains unchanged after Report Flag of Son Alarm is set to NOT_REPORT(Not Report).

  • After running this command, you can run the LST ALMCORRSHLD command to query whether the setting has taken effect.

  • After running this command, you can run the RST ALMCORRSHLD command to restore the default setting.

Parameters

ID Name Description
AID Alarm ID

Meaning: Indicates the alarm ID. The alarm ID is the only index for alarms.

GUI Value Range: 1~65032

Unit: None

Actual Value Range: 1~65032

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
RPTFLAG Report Flag of Son Alarm

Meaning: Indicates whether a correlative alarm can be reported.

GUI Value Range: NOT_REPORT(Not Report), REPORT(Report)

Unit: None

Actual Value Range: NOT_REPORT, REPORT

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the correlation shield flag of a specified alarm with parameters as follows: Alarm ID: 26235, Report Flag of Son Alarm: NOT_REPORT(Not Report), run the following command:
SET ALMCORRSHLD: AID=26235, RPTFLAG=NOT_REPORT;
