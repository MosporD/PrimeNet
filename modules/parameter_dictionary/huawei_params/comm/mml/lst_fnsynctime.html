List CIoT Frame No. Parameters (LST FNSYNCTIME)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the Cellular Internet of Thing (CIoT) Frame No. parameters, including the time when the hyper system frame No. (HSFN) is 0 and the status of the frame No. synchronization switch.

Note

None.

Parameters

None.

Example

To list CIoT Frame No. Parameters, run the following command:
LST FNSYNCTIME:;
The result is shown as follows:
+++    0        2016-07-22 19:55:09
O&M    #1389
%%LST FNSYNCTIME:;%%
RETCODE = 0  Operation succeeded.

List CIoT Frame No. Parameters
------------------------------
CIoT Frame No. Synchronization Switch  =  ON
                                 Date  =  2016-7-22
                                 Time  =  19:55:09
(Number of results = 1)


---    END

Output Description

Field Description

CIoT Frame No. Synchronization Switch

Indicates whether to enable the CIoT frame No. synchronization function. The value ON indicates that this function is enabled. The value OFF indicates that this function is disabled. This parameter takes effect only when frequency synchronization is used.

Date

Indicates the date to be set for the CIoT Frame No. This parameter is set in compliance with the GPS. The format is as follows: YYYY-MM-DD. For example, 2006-09-08 indicates September 8th of 2006.

Time

Indicates the time to be set for the CIoT Frame No. This parameter is set in compliance with the GPS. The format is as follows: HH:MM:SS. For example, 10:20:05.
