List Latest Successful Time Synchronization Time (LST LATESTSUCCDATE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the last update time from an external reference time source.

Note

None.

Parameters

None.

Example

Query the last update time from time source:
LST LATESTSUCCDATE:;
The result is shown as follows:
                                                    
+++    0        2009-09-06 10:06:16                                       
O&M    #262                                                                     
%%LST LATESTSUCCDATE:;%%                                                        
RETCODE = 0  Operation succeeded.                                               
                                                                                
List Latest Success Date                                                        
------------------------                                                        
                           Time Source  =  NTP                               
Latest Successful Synchronization Time  =  2009-09-03 14:30:12                                 
(Number of results = 1)                                                         
                                                                                
                                                                                
---    END

Output Description

Field Description

Time Source

Indicates the external reference time source of the NE.

Latest Successful Synchronization Time

Indicates the date and time of the last successfully-synchronized time of the NE. The format is as follows: YYYY-MM-DD HH:MM:SS.
