Delete Transport HA Group (RMV HAGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an HA group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

After this command is executed, the BS will reset.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet housing the board where the HA group is established.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SRN Subrack No.

Meaning: Indicates the number of the subrack housing the board where the HA group is established.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SN Logic Slot No.

Meaning: Indicates the logical slot number of the HA group. The logical slot number of an HA group is the number of the physical slot housing one of the two boards constituting the HA group.

GUI Value Range: 6~7

Unit: None

Actual Value Range: 6~7

MML Default Value: 6

Recommended Value: 6

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To remove an HA group with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Logic Slot No.: 6, run the following command: 
RMV HAGRP: CN=0, SRN=0, SN=6;
