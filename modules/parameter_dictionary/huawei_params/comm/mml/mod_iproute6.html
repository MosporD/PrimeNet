Modify IPv6 Route (MOD IPROUTE6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the description of a static IPv6 route.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eNodeB,gNodeB]When changing the priority of an IP route on a BS, ensure that the relative priority of the IP route remains unchanged.

  • [Co-MPT,eNodeB,gNodeB]After this command is executed, services or the OM channel carried on the route is disconnected. It is recommended that you enable the automatic configuration data rollback function based on situations. For details, see the help description for the CFM CB command.

  • [Co-MPT,eNodeB,gNodeB]After an IPADDR6 MO is configured, the system automatically generates a direct gateway route. A direct gateway route takes precedence over other routes. Therefore, after an IPROUTE6 MO is configured, if the network address part of the destination IPv6 address of the IPROUTE6 MO is the same as that of the direct gateway route, the IPROUTE6 MO is invalid.

FORCEEXECUTE Support Forcible Execution

Meaning: Indicates whether a forcible change of an IPv6 route is made. When this parameter is set to NO(No), the system checks whether the change affects upper-layer services. If the change affects upper-layer services, the forcible change will fail. When this parameter is set to YES(Yes), the system does not check whether the change affects upper-layer services. Upper-layer services include the following: active OM channel (OMCH), DNS service (DNSSRV), security link (IKEPEER), certificate authority (CA), CRL update (CRLTSK), IP clock link (IPCLKLINK), NTP (NTPC), Abis CP/Iub CP/S1 CP/X2 CP/M2 CP/ECO CP/eX2 CP/SO CP/uX2 CP/Xw CP/gNBCUX2 CP/gNBCUNg CP/gNBCUXn CP (SCTPLNK/SCTPPEER), and Abis UP/IP path of an unknown service type/Iub UP/uX2 UP/S1 UP/X2 UP/eX2 UP/Xw UP/gNBCUX2 UP/gNBCUS1 UP/gNBCUNg UP/gNBCUXn UP (USERPLANEPEER).

Pay attention to the following when using this parameter:

1. The system checks whether a forcible change affects upper-layer services based on the configuration data instead of based on the actual running status of these services.

2. If an NE is configured with an SRCIPROUTE6 MO, the system does not check whether a forcible change of an IPv6 route affects upper-layer services.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To modify the parameter settings of an IPv6 static route with the parameters as follows: Route Index: 0, Destination IPv6 Address: 2001:DB8::, Prefix Length: 32, Route Type: NEXTHOP, Next Hop IPv6 Address: 2001:DB8::3, run the following command:
MOD IPROUTE6: RTIDX=0, DSTIP="2001:DB8::", PFXLEN=32, RTTYPE=NEXTHOP, NEXTHOP="2001:DB8::3";
