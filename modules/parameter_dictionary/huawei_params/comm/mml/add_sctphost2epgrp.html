Add SCTP Host to End Point Group (ADD SCTPHOST2EPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an SCTP host to an end point group.

Note

  • [Co-MPT,NodeB,eNodeB,gNodeB]Before adding an SCTP host to an endpoint group, ensure that the endpoint group added by using the ADD EPGROUP command and the SCTP host added by using the ADD SCTPHOST command have been configured.

  • [Co-MPT,NodeB,eNodeB,gNodeB]This command takes effect only for UMTS, LTE, and NR.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If a base station is not configured with an SCTP link that meets the following conditions, the base station will automatically create an SCTP link and a CP bearer:

    - The values of First Local IP Address, Second Local IP Address, and Local SCTP Port No. in the SCTPHOST object are the same as those of another SCTP link.

    - The values of First Peer IP Address, Second Peer IP Address, and Peer SCTP Port No. in the SCTPPEER object in the same end point group are the same as those of another SCTP link.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If a base station is not configured with an SCTP link that meets the following conditions, the base station will automatically create an SCTP peer, an SCTP link, and a CP bearer during automatic setup of the control plane:

    - The values of First Local IP Address, Second Local IP Address, and Local SCTP Port No. in the SCTPHOST object are the same as those of another SCTP link.

    - The values of First Peer IP Address, Second Peer IP Address, and Peer SCTP Port No. in the SCTPPEER object to be created are the same as those of another SCTP link.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the following conditions are met during setup of an SCTP link, the system will automatically configure the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects for the SCTP link and set up an IPsec tunnel:

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the SCTPPEER object in the same end point group and the SCTPHOST object.

    - SeGW Switch is set to ENABLE(Enable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met during setup of an SCTP link, the system will automatically configure the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects for the SCTP link and set up an IPsec tunnel:

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the SCTPPEER object in the same end point group and the SCTPHOST object.

    - SeGW Switch is set to DISABLE(Disable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured. If IPSec Auto Configure Switch is set to DISABLE(Disable) for the SCTPPEER object in the same end point group and the SCTPHOST object, an IPsec tunnel can be set up by manually configuring all the preceding IPsec-related objects.

  • [Co-MPT,eNodeB,gNodeB]If a base station is not configured with an IPv6 SCTP link that meets the following conditions, the base station will automatically create an IPv6 SCTP link and a CP bearer:

    - The values of First Local IPv6 Address, Second Local IPv6 Address, and Local SCTP Port No. in the SCTPHOST object are the same as those of another IPv6 SCTP link.

    - The values of First Peer IPv6 Address, Second Peer IPv6 Address, and Peer SCTP Port No. in the SCTPPEER object in the same end point group are the same as those of another IPv6 SCTP link.

  • [Co-MPT,eNodeB,gNodeB]If a base station is not configured with an IPv6 SCTP link that meets the following conditions, the base station will automatically create an SCTP peer, an SCTP link, and a CP bearer during automatic setup of the control plane:

    - The values of First Local IPv6 Address, Second Local IPv6 Address, and Local SCTP Port No. in the SCTPHOST object are the same as those of another IPv6 SCTP link.

    - The values of First Peer IPv6 Address, Second Peer IPv6 Address, and Peer SCTP Port No. in the SCTPPEER object to be created are the same as those of another IPv6 SCTP link.

  • [Co-MPT,eNodeB,gNodeB]An endpoint group can be added with only a maximum of two SCTP hosts. If two SCTP hosts are added, they must be of different IP protocol versions. A maximum of 64 SCTP hosts can be added to the endpoint groups.

  • [NodeB]The number of SCTP hosts added to an endpoint group must be equal to or less than 1. The total number of SCTP hosts added to all endpoint groups must be equal to or less than 64.

Parameters

ID Name Description
EPGROUPID End Point Group ID

Meaning: Indicates the ID of the end point group to which an end point belongs.

Meaning: Indicates the ID of the SCTP host.

Unit: None

Example

To add an SCTP host to an end point group with the parameters as follows: End Point Group ID: 0, SCTP Host ID: 0, run the following command:
ADD SCTPHOST2EPGRP: EPGROUPID=0, SCTPHOSTID=0;
