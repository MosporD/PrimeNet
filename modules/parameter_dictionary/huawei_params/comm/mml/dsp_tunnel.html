Display Tunnel Status (DSP TUNNEL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of a tunnel.

Note

None.

Parameters

ID Name Description
SCN Source Cabinet No.

Meaning: Indicates the number of the source cabinet where the tunnel is configured.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Source Cabinet No. parameter in the BACKTUNNEL MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Unit: None

-Configuration constraints:

Example

To query the status of a tunnel with Source Slot No. set to 7, run the following command: 
DSP TUNNEL: SSN=7;

Output Description

Field Description

Source Cabinet No.

Indicates the number of the source cabinet where the tunnel is configured.

Source Subrack No.

Indicates the number of the source subrack where the tunnel is configured.

Source Slot No.

Indicates the number of the source slot where the tunnel is configured.

Tunnel No.

Indicates the index of the tunnel.

Destination Cabinet No.

Indicates the number of the destination cabinet where the tunnel is located.

Destination Subrack No.

Indicates the number of the destination subrack where the tunnel is located.

Destination Slot No.

Indicates the number of the destination slot where the tunnel is located.

Number of RX Bytes(byte)

Indicates the number of bytes received through the tunnel.

Number of RX Packets(packet)

Indicates the actual number of packets received through a tunnel.

Number of TX Bytes(byte)

Indicates the actual number of bytes sent through the tunnel.

Number of TX Packets(packet)

Indicates the actual number of packets sent through the tunnel.
