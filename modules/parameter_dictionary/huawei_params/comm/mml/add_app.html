Add Application (ADD APP)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an application based on the specified application type and application ID. An application provides the operating environment for the functions of an NE of a certain RAT. If an MBTS needs to provide functions of a certain RAT, operators need to add an application for the RAT. For example, if LTE is added to an MBTS after evolution, operators need to add an application for the eNodeB. When adding an application, operators can set the maintenance mode of the application. If the maintenance mode of an application has been set, the information about the maintenance mode will be contained in alarms to be reported. When the maintenance mode of a co-MPT NE is NORMAL and one of its applications is also in the maintenance mode, the performance measurements of this application will be implausible.

Note

  • Each application type can be added to only one object.

  • After the MPT is restarted, the application will be in the same maintenance status as it is before the restart.

  • It is recommended that this command not be executed when a main control board is being activated. If this command is executed when a main control board is being activated, the added application is unavailable.

  • If the software for the application type has been activated, the application will be started immediately after being added. After the application is started, the status of the application becomes available. If the software for the application type has not been activated, the application will not be started. It is started only after the software for its application type is activated.

  • Extend Application Type List is case sensitive.

  • [Co-MPT,eNodeB,gNodeB]If Working Mode is set to NON-CONCURRENT, only one application can be configured, but multiple extended applications can be configured. Run the LST NODE command to check the node working mode.

  • [NodeB,eGBTS]Only one application is allowed when the node working mode is NON-CONCURRENT.

    Run the LST NODE command to check the node working mode.

  • [Co-MPT]In a base station where the GTMU supports SingleOM, this command cannot be executed.

  • [Co-MPT]With a UMPTa/b, UMDU, or MDUC in use, the configured gNodeB application cannot be started if Working Mode Extension is set to COMM. With a UMPTa/b, UMDU, or MDUC in use, no application can be started if Working Mode Extension is set to COMM2, which is not supported by these main control boards. With a UMPTe or UMPTga in use, the configured gNodeB application cannot be started if Working Mode Extension is set to COMM. With a UMPTe in use, the configured GBTS, NodeB, and RFA applications cannot be started if Working Mode Extension is set to COMM2.

Example

To add an application with the parameters as follows: Application ID: 6, Application Type: NodeB, Application Name: "NodeB", Application Maintenance Mode: NORMAL, run the following command:
ADD APP: AID=6, AT=NodeB, AN="NodeB", APPMNTMODE=NORMAL;
