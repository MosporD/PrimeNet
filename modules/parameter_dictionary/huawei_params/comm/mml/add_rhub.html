Add RHUB (ADD RHUB)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an RHUB before adding a branch chain/ring.

Note

  • [Co-MPT,NodeB,eNodeB,gNodeB]An RHUB must be added to the chain tail or any position behind the breakpoint.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Before an RHUB is added, an RRU chain must be added by running the ADD RRUCHAIN command.

  • [Co-MPT,NodeB,eNodeB,gNodeB]RHUBs support only the chain and load sharing topologies. In load sharing scenarios, a breakpoint must be set for adding an RHUB.

  • [Co-MPT,NodeB,eNodeB,gNodeB]After an RHUB is added to a chain, the original RHUB with a position equal to or greater than the position of the newly added RHUB is automatically moved backwards.

  • [Co-MPT,NodeB,eNodeB,gNodeB]After an RHUB is added, if links cannot be set up for the associated RHUBs or links cannot work at the highest CPRI line rate, you need to run the STR CPRILBRNEG command to initiate negotiation.

  • [Co-MPT,NodeB,eNodeB,gNodeB]An RRU chain supports a maximum of four RHUBs.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If an RHUB is configured on an RRU chain, all the other boards on this chain must be RHUBs.

  • [Co-MPT,NodeB,eNodeB,gNodeB]After the maintenance mode of the RHUB is specified, all RF modules connected to the RHUB branch port inherit the maintenance mode of the RHUB.

RHUBSPEC RHUB Specification

Meaning: Indicates the type of an RHUB. This parameter needs to be set only when the MAE-Deployment is used for offline configuration. If this parameter is not set, the operation of the entire base station is not affected. Set this parameter based on the actual RHUB hardware type. The MAE-Deployment verifies the configuration based on the actual RHUB type. The MAE-Deployment can identify configuration errors before delivering the configuration to the base station, and display the main chain and branch chain ports of the RHUB based on the configuration type on the device panel. The value of this parameter must be the same as the hardware type of the RHUB. For example, for the RHUB5921 module, the value of this parameter is RHUB5921; for the RHUB5961 module, the value of this parameter is RHUB5961.

Example

To add an RHUB with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, RRU Chain No.: 0, RHUB Position: 0, RHUB Name: NewRhub, run the following command:
ADD RHUB: CN=0, SRN=60, SN=0, RCN=0, PS=0, RN="NewRhub";
