Modify Subnet VLAN Mapping (MOD SUBNETVLAN)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the parameters related to a subnet VLAN mapping.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The execution of this command may interrupt the service that references the subnet VLAN. For details, see the "Service Interrupted After Modification" of each parameter in this command.

  • This operation may interrupt the services or OM channels that rely on this VLAN ID. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

Parameters

ID Name Description
IP IP Address

Meaning: Indicates the source IP address used for mapping the VLAN.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]IP in the SUBNETVLAN MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 127.x.x.x or 0.x.x.x.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
MASK Mask

Meaning: Indicates the subnet mask of the source IP address used for mapping the VLAN.

GUI Value Range: Valid subnet mask

Unit: None

Actual Value Range: Valid subnet mask

MML Default Value: None

Recommended Value: 255.255.255.255

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]MASK in the SUBNETVLAN MO must be 255.255.255.255.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
VLANID VLAN ID

Meaning: Indicates the VLAN ID in the VLAN tag.

GUI Value Range: 1~4094

Unit: None

Actual Value Range: 1~4094

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To modify a subnet VLAN mapping with the parameters as follows: IP Address: 192.168.1.24, Mask: 255.255.255.255, VLAN ID: 1024, run the following command:
MOD SUBNETVLAN: IP="192.168.1.24", MASK="255.255.255.255", VLANID=1024;
