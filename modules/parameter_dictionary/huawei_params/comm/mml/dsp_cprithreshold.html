Display CPRI Threshold (DSP CPRITHRESHOLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the bit error rate (BER) threshold for the CPRI BER Monitoring function.

Note

[Co-MPT,NodeB,eNodeB,gNodeB]If eCPRI protocols are used, the CPRI bit error rate monitoring function is not supported.

Parameters

None.

Example

1. To query the BER threshold for each CPRI line rate:
DSP CPRITHRESHOLD:;
+++    0        2006-11-06 15:18:30
O&M    #2441
%%DSP CPRITHRESHOLD:;%%
RETCODE = 0  Operation succeeded.
