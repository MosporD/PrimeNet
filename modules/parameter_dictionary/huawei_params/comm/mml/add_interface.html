Add Interface (ADD INTERFACE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an interface.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • System specifications: If a UMPTa/UMPTb/UMDU is used as the main control board, a maximum of 300 interfaces can be configured for a base station. If a UMPTe is used as the main control board, a maximum of 512 interfaces can be configured for a base station. If a UMPTg/UMPTga is used as the main control board, a maximum of 640 interfaces can be configured for a base station. If a UMPT/UMDU is used as the main control board, a maximum of 300 interfaces can be manually configured for a base station.

  • Only the LMPT/UMPTa/UMPTb/UMPTe/UMPTg/UMPTga/UMDU/UTRPc board supports VLAN subinterfaces, and each physical port supports a maximum of sixteen VLAN subinterfaces.

  • When the VLAN tagging switch is turned off for a normal interface configured on an Ethernet port or an Ethernet trunk, the normal interface can receive only the packets that do not carry the VLAN ID. When the VLAN tagging switch is turned on, the normal interface can receive all the packets that are not matched with VLAN subinterfaces.

  • When a normal interface is not configured on an Ethernet port or Ethernet trunk port, the value of VLAN Tagged Switch for the port is ENABLE by default.

  • The VLAN ID of the ARP request packet sent by the NE through a VLAN subinterface is the VLAN ID of the VLAN subinterface, and the VLAN priority of the packet is always 7.

  • The VLAN ID and VLAN priority of the ARP request packet sent by the NE through the normal interface are configured according to the configurations of the VLANMAP, VLANCLASS, SUBNETVLAN, and default DSCP2PCPMAP objects.

  • The VLAN ID and VLAN priority of the received ARP request packet are also carried in the ARP response packet sent by the NE.

  • When Port Type is set to ETH or ETHTRK, the ranges of the MTU4 sizes supported by the following boards are: 46 bytes to 1800 bytes for the UMPTa/b, UMDU, LMPT, UCCU, and UTRPc boards; 46 bytes to 1500 bytes for the WMPT, GTMUb, GTMUc, UQEC, and UEOC boards; 46 bytes to 2000 bytes for the UMPTe board, 46 bytes to 9000 bytes for the UMPTg and UMPTga board. When Port Type is set to ETHCI, the range of MTU4 size supported by the UMPT, UMDU, LMPT, UCCU, UTRPc, WMPT, GTMUb, GTMUc, UQEC, and UEOC boards is 46 bytes to 1500 bytes. When this parameter is set to a value greater than MTU4 size supported by a board, MTU4 size supported by the board takes effect. It is recommended that this parameter be set to a value greater than or equal to 776. If this parameter value is less than 776, broadcast packets such as DHCP packets may experience reception or transmission failures.

  • The UMPTa/UMPTb/UMDU supports the MTU6 value in the range of 1280 to 1800. The UMPTe supports the MTU6 value in the range of 1280 to 2000. The UMPTg/UMPTga supports the MTU6 value in the range of 1280 to 9000. When the MTU6 parameter is set to a value greater than that supported by a board, the MTU6 value supported by the board takes effect. The fragment is 8-byte-aligned.

  • Board specifications: On a UMPTa/UMPTb/UMDU, a maximum of 300 interfaces can be used. On a UMPTe, a maximum of 512 interfaces can be used. On a UMPTg/UMPTga, a maximum of 640 interfaces can be used.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]The IPv6 function is supported only when a UMPT/UMDU board functions as the active main control board. The IPv6 function can be enabled on an interface only after enable IPV6SW.

  • [Co-MPT,eNodeB,gNodeB]If the interface is a tunnel interface, the interface is bound to an IPSECBINDITF MO, and fragment before IPSec encryption is disabled for the IKE peer, the internal system resets the MTU to the board maximum capability. If fragment before IPSec encryption is enabled for the IKE peer, the values of MTU4 and MTU6 in the INTERFACE MO of the TUNNELITF type are used.

Parameters

ID Name Description
ITFID Interface ID

Meaning: Indicates the ID of an interface. The value of ITFID in the INTERFACE MOs configured by users ranges from 0 to 1499. The value of ITFID in the INTERFACE MOs configured by the system ranges from 10000 to 19999.

GUI Value Range: 0~1499,10000~19999

Unit: None

Actual Value Range: 0~1499,10000~19999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In an INTERFACE MO, if ITFID is within the range from 0 to 1499, CTRLMODE must be set to MANUAL_MODE. In an INTERFACE MO, if ITFID is within the range from 10000 to 19999, CTRLMODE must be set to AUTO_MODE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
ITFTYPE Interface Type

Meaning: Indicates the type of an interface, which can be normal or VLAN.

GUI Value Range: NORMAL(Normal), VLAN(VLAN)

Unit: None

Actual Value Range: NORMAL, VLAN

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In an INTERFACE MO, when ITFTYPE is set to NORMAL, the DSCP2QUEMAPID must be set to 0.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In an INTERFACE MO, when ITFTYPE is set to NORMAL and PT is not set to LOOPINT, ETH, ETHTRK or TUNNELITF, the VRFIDX must be set to 0.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In an INTERFACE MO, when PT is set to ETHCI and ITFTYPE is set to NORMAL, TAGGED must be set to ENABLE.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Recommended Value: None

  • [Co-MPT, NodeB, eNodeB, gNodeB]In an INTERFACE MO, when ITFTYPE is set to NORMAL, the DSCP2QUEMAPID must be set to 0.

  • [Co-MPT, NodeB, eNodeB, gNodeB]In an INTERFACE MO, when PT is set to ETHCI and ITFTYPE is set to NORMAL, TAGGED must be set to ENABLE.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In an INTERFACE MO, when PT is set to ETHTRK, IPV6SW must be set to DISABLE.

MTU4 IPv4 Maximum Transmission Unit

Meaning: Indicates the maximum IPv4 transmission unit supported by an interface.

GUI Value Range: 46~9000

Unit: byte

Actual Value Range: 46~9000

MML Default Value: None

Recommended Value: If PT is set to ETH, ETHTRK or ETHCI, it is recommended that MTU4 be set to 1500.

If PT is set to TUNNELITF, it is recommended that MTU4 be set to 1380.

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: An excessive large parameter value leads to packet loss or excessively fragmented data packets on the transport network, resulting in a long delay and deteriorated performance. An excessive small parameter value leads to reduced available payloads for transmission, resulting in decreased transport bandwidth efficiency and deteriorated performance.

Applicable Mode: G, U, L, N, R

MTU6 IPv6 Maximum Transmission Unit

Meaning: Indicates the maximum IPv6 transmission unit supported by an interface.

GUI Value Range: 1280~9000

Unit: byte

Actual Value Range: 1280~9000

MML Default Value: None

Recommended Value: If PT is set to ETH or ETHTRK, it is recommended that MTU6 be set to 1500.

If PT is set to TUNNELITF, it is recommended that MTU6 be set to 1380.

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to a large value, packet loss may occur on the transport network before the base station detects and adjusts the value to the actual Path MTU size. If this parameter is set to a small value, the valid payload of the transmission decreases and the bandwidth of the transmission network cannot be effectively used. As a result, the transmission delay increases and the transmission performance deteriorates.

Applicable Mode: G, U, L, N, R
ARPPROXY ARP Proxy

Meaning: Indicates whether to enable the ARP proxy function. If the ARP proxy function is enabled, the base station serves as an ARP proxy for a loopback interface address included in the interface address segment of the base station or for an interface IP address of a lower-level base station. If this function is disabled, the base station does not serve as an ARP proxy for the loopback interface IP address of the base station or for the interface IP address of a lower-level base station. To access either IP address in this case, an external device on the same subnet must be configured with a route.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(Disable)

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Example

To add an Interface with the parameters as follows: Interface ID: 0, Interface Type: NORMAL, Port Type: ETH, Port ID: 10, IPv6 Switch: DISABLE, run the following command:
ADD INTERFACE: ITFID=0, ITFTYPE=NORMAL, PT=ETH, PORTID=10, IPV6SW=DISABLE;
