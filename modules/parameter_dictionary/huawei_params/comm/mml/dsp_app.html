Display Application (DSP APP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query information about applications running on the NE.

Note

  • If the added application is unavailable, run the LST VER command to check whether the software for the mode is activated.

  • When the running mode of the application doesn't match the running mode of the software, the application will be unavailable

  • [Co-MPT]If an application is unavailable, run the RST APP command to reset the application.

Parameters

None.

Example

To query the current application, run the following command:
DSP APP:;
The result is as follows:

Output Description

Field Description

Application ID

Indicates the application ID.

Application Name

Indicates the application name.

Application State

Indicates the application status.

Application Type

Indicates the application type.

Extended Application Type

Indicates the extended application type.

Software Version

Indicates the application software version.

Hot Patch Version

Indicates the hot patch version of the software for the application.

Application Version

Indicates the application version.

Application Hot Patch Version

Indicates the hot patch version of the application.

Current Application Maintenance Mode

Indicates the current maintenance mode of the application.

Running Mode

Indicates the running mode of the application.
