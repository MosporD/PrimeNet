Add BFD Key (ADD BFDKEY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a key to the BFD key chain.

Note

  • This command is only used to configure a BFD authentication key.

  • A maximum of three keys can be configured.

  • The local BFD keys and key indexes must be the same as the peer BFD keys and key indexes. The number of keys must also be consistent between the local and peer ends. Otherwise, the BFD authentication may fail.

  • If the base station is interconnected with a router provided by Cisco to establish a BFD session, it is recommended that the local key length not exceed 15 characters. Otherwise, the BFD session negotiation may fail.

  • If the new key index is smaller than the existing key index, the BFD session may experience renegotiation.

Parameters

ID Name Description
KEYCHAINID BFD Authentication Key Chain ID

Meaning: Indicates the ID of a configured BFD key chain.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
KEYID KEY Identity

Meaning: Indicates the index of a key in a BFD key chain, which must be consistent with the index of the key at the peer end.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
KEY KEY String

Meaning: Indicates the key settings in a BFD key chain, which must be consistent with the key settings at the peer end.

GUI Value Range: 1~20 characters

Unit: None

Actual Value Range: 1~20 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a BFD key with the parameters as follows:BFD Authentication Key Chain ID: 0, KEY Identity: 0, KEY String: *****:
ADD BFDKEY: KEYCHAINID=0, KEYID=0, KEY="*****";
