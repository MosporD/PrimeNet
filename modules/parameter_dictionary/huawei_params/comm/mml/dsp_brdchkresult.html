Display Board Running historical status (DSP BRDCHKRESULT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the historical running status of base station boards.

Note

  • Before querying the history running data of the boards in the BBU, ensure that the base station runs stably for more than one week and the running data is updated once a week.

  • The USCU board does not have a CPU. Therefore, the value of Cpu Usage for Busy Hour (%) for the USCU board is NULL.

Example

To query the historical running status of the board with Cabinet No. set to 0, Subrack No. set to 0, and Slot No. set to 1, run the following command:
DSP BRDCHKRESULT: CN=0, SRN=0, SN=1;
The result is shown as follows:
+++    0        2016-04-13 11:22:55
O&M    #523
%%DSP BRDCHKRESULT: CN=0, SRN=0, SN=1;%%

Output Description

Field Description

Total Number of Cold Resets

Indicates the number of times the board is powered off and reset by running MML commands or using the GUI mode.

Total Running Time(h)

Indicates the total running time of the board.

Cpu Usage for Busy Hour(%)

Indicates the average usage of the master CPU in busy hours within four weeks.

Board Mean Temperature[degree Celsius(degree Fahrenheit)]

Indicates the mean temperature of the board within four weeks.

Board Mean Difference in Temperature[degree Celsius(degree Fahrenheit)]

Indicates the mean temperature difference of the board within four weeks.
