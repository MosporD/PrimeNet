Add Quick Sector (ADD QUICKSECTOR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to quickly create sectors and sector equipment.

Note

  • When Sector Mode is set to SINGLE_SECTOR(Single Sector), all sector equipment belongs to one sector. When Sector Mode is set to MULTI_SECTOR(Multi Sectors), each set of sector equipment belongs to one sector.

  • If RRUMODE is set to CONTINUE, only RRUs in slot 0 of cabinet 0 can be used. The value CONTINUE indicates that the RRU subrack numbers are arranged in sequential order. If RRUMODE is set to UNCONTINUE, there is no special limitation on the cabinet No., subrack No., and slot No. of RRUs used.

  • Each RRU belongs to one set of sector equipment. RRU antennas are added to a set of sector equipment based on the numbers of TX and RX RRU antennas in each sector equipment set. The antenna channel is numbered from R0A.

  • After the command is executed, you can run the LST SECTOR and LST SECTOREQM commands to query the configuration information of sectors and sector equipment, run the MOD SECTOR and MOD SECTOREQM commands to modify the configuration of sectors and sector equipment, and run the RMV SECTOR and RMV SECTOREQM commands to remove the configuration of sectors and sector equipment.

  • Sector equipment cannot be added with ANTCFGMODE set to BEAM.

Example

To quickly add sectors and sector equipment with the parameters as follows: Sector Mode: MULTI_SECTOR, Sector ID (Begin): 0, RRU Mode: CONTINUE, Sector Equipment ID (Begin): 0, Sector Equipment ID (End): 1, Subrack No. of RRU (Begin): 60, Subrack No. of RRU (End): 61, RRU TX Antenna Number: 1, and RRU RX Antenna Number: 2, run the following command:
ADD QUICKSECTOR: SECMODE=MULTI_SECTOR, SECTORIDBEGIN=0, RRUMODE=CONTINUE, SECTOREQMIDBEGIN=0, SECTOREQMIDEND=1, SRNB=60, SRNE=61, RRUTXANTNUM=1, RRURXANTNUM=2;
