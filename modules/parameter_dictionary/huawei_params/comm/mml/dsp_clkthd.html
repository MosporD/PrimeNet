Display Clock Tracing Threshold (DSP CLKTHD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the clock tracing mode of a specified main control board.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the system clock is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the system clock is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the system clock is located.

GUI Value Range: 6~7

Unit: None

Actual Value Range: 6~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the clock tracing mode of a board in slot 7, run the following command:
DSP CLKTHD: SN=7;
The result is shown as follows:
+++    0        2013-11-08 16:26:24
O&M    #537922613
%%DSP CLKTHD: SN=7;%%
RETCODE = 0  Operation succeeded.

Display Clock Tracing Threshold
-------------------------------
Cabinet No.  Subrack No.  Slot No.  Clock Tracing Threshold

0            0            7         Enable                 
(Number of results = 1)


---    END

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the system clock is located.

Subrack No.

Indicates the number of the subrack where the system clock is located.

Slot No.

Indicates the number of the slot where the system clock is located.

Clock Tracing Threshold

Indicates whether the system is not allowed to trace the reference clock when its offset exceeds the clock tracing threshold.
