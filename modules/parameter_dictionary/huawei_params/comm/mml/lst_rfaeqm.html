List RF Access Equipment (LST RFAEQM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of RF access equipment.

Note

None.

Parameters

ID Name Description
RFAEQMID RFA Equipment ID

Meaning: Indicates the RF access equipment ID.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To list the configuration of RFA Equipment, run the following command:
LST RFAEQM:;
The result is as follows:
+++    0        2017-11-30 12:15:25
O&M    #10612
%%LST RFAEQM:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

RFA Equipment ID

Indicates the RF access equipment ID.

Port Num

Indicates the number of the port used the RF access equipment.

Cabinet No. of Port 1

Indicates the number of the cabinet housing the board which provides port 1 in the RF access equipment.

Subrack No. of Port 1

Indicates the number of the subrack housing the board which provides port 1 in the RF access equipment.

Slot No. of Port 1

Indicates the number of the slot housing the board which provides port 1 in the RF access equipment.

Port No. of Port 1

Indicates the number of the port which serves as port 1 in the RF access equipment.

Transmission Mode of Port 1
