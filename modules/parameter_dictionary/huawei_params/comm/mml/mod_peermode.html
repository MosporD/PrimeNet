Mod PeerMode (MOD PEERMODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the working mode of the main control board at the peer end. If the local subrack is selected, the working mode of the peer main control board in the local subrack will be modified. Otherwise, the working mode of the peer main control board in the peer subrack will be modified.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Running this command will reset the main control board at the peer end and cause the loss of all services carried on the main control board at the peer end.

  • If the peer board is a UMPT, its working mode can be changed to UMTS, LTE, COMM, LTE TDD, or COMM2. If the peer UMPT is not a UMPTa or UMPTb, its working mode can also be set to NR. If the peer board is an LMPT, its working standard can be changed to LTE, LTE TDD, COMM, or COMM2. If the peer board is a WMPT, its working standard can be changed to UMTS, COMM, or COMM2. If the peer board is a GTMUb/GTMUc used in SingleOM scenarios, its working standard can be changed to GSM or COMM. If the local board is a GTMUb/GTMUc used in SingleOM scenarios and the peer board is an LMPT, the working standard of the LMPT can be changed to LTE, LTE TDD, or COMM. If the local board is a GTMUb/GTMUc used in SingleOM scenarios and the peer board is a WMPT, the working standard of the WMPT can be changed to UMTS or COMM.

  • If the Type parameter is set to LOCAL and the target is to configure active and standby boards, two main control boards must be configured. If the Type parameter is set to LOCAL and the target is multiple modes, a maximum of one main control board must be configured.

  • If the Type parameter is set to PEER and the target is to configure primary and secondary boards, the specified main control board must be configured. If the Type parameter is set to PEER and the target is multiple modes, the specified main control board cannot be configured.

  • This command fails to be executed if the main control board at the peer end is being reset.

  • After this command is successfully executed, you need to wait for 5 minutes and run the DSP BSSTATUS command to check whether the working mode of the main control board at the peer end is changed.

  • If the main control board at the peer end resets or the link between two main control boards is faulty, the execution of this command will fail. Run this command 5 minutes after the execution fails.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]SN must meet the following conditions: 1. When SRN is set to 0 or 1, SN must be set to a value within the range of 0 to 7, 16, 18, or 19. When SRN is set to 4 or 5 and TYPE in the CABINET MO is set to BTS3900AL, the value of SN ranges from 0 to 8; When SRN is set to 4 or 5 and TYPE in the CABINET MO is not set to BTS3900AL, the value of SN ranges from 0 to 5; 3. Example

To modify the working mode of the main control board at the peer end in the local subrack to UMTS, run the following command:
MOD PEERMODE: TYPE=LOCAL, RAT=UMTS;
