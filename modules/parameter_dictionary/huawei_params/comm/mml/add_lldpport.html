Add LLDP Port Info (ADD LLDPPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a Link Layer Discovery Protocol (LLDP) port. When this command is executed, the system automatically configures local LLDP information using the default values. For details about the default settings, see Note of this command.

Note

  • System specifications: If the WMPT/UMPT/LMPT/GTMUb/GTMUc is the main control board, a maximum of 48 LLDP ports can be configured. If the UMDU is the main control board, a maximum of 2 LLDP ports can be configured.

  • Board specifications: A maximum of 2 LLDP Ports can be configured on a WMPT/UMPTa/UMPTb/UMDU/LMPT/GTMUc. A maximum of 4 LLDP Ports can be configured on a UMPTe/UMPTg/UMPTga. A maximum of 6 LLDP Ports can be configured on a UTRPc. A maximum of 2 LLDP Ports can be configured on a UTRP (subboard type: UEOC). A maximum of 4 LLDP Ports can be configured on a UTRP (subboard type: UQEC)/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

Example

To add the configuration of LLDP port as follows: Slot No.: 7, Subboard Type: Base Board, Port No.: 1, Binding VLAN: YES, VLAN ID: 3, VLAN Priority: 4, run the following command:  
ADD LLDPPORT: SN=7, SBT=BASE_BOARD, PN=1, BNDVLAN=YES, VLANID=3, VLANPRI=4;
