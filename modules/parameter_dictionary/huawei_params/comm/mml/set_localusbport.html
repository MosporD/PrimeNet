Set USB Port Status (SET LOCALUSBPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of the USB Port. This command applies only to the main control boards and UMDUs.

Note

  • For the NE that has just been initialized, EVT-26843 USB Port State Changed is not reported. This event can be reported only after it is unmasked by running the SET ALMSHLD command.

  • The actual status of a USB port is controlled by the USB ACCESS SECURITY POLICY parameter. If this parameter is set to DISABLE for a USB port, this port is disabled.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the USB port is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the subrack number of the board where the USB port is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the board where the USB port is located.

GUI Value Range: 6~7

Unit: None

Actual Value Range: 6~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
PN Port No.

Meaning: Indicates the port number of the board where the USB port is located.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SWITCH Enable Flag

Meaning: Indicates whether to enable the USB port. When this parameter is set to DISABLE, the USB port is disabled. When this parameter is set to ENABLE, the USB port is enabled.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To modify the configuration of the USB Port as follows: Cabinet NO.: 0, Subrack No.: 0, Slot No.: 6, Enable Flag: "DISABLE", run the following command:
SET LOCALUSBPORT: CN=0, SRN=0, SN=6, SWITCH=DISABLE;
