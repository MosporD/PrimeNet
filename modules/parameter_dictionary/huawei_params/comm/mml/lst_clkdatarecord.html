List Data Record Of IP Clock (LST CLKDATARECORD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of an IP clock.

Note

  • This command takes effect only if the IP clock source is activated.

  • A maximum of 100 records are displayed. A displayed delay value is the shortest delay in a filtering period.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the system clock is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Meaning: Indicates the number of the subrack where the system clock is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the system clock is located.

GUI Value Range: 6~7

Unit: None

MML Default Value: None

Impact on Radio Network Performance: None

Example

To list the configuration of an IP clock in slot 7, run the following command:
LST CLKDATARECORD: SN=7; 
The result is shown as follows:

Output Description

Field Description

Time

Indicates the time corresponding to each record.

DIFF(ns)

Indicates the delay recorded in the IP clock data.

Server Time

Indicates the time when the packets are sent from the IP clock server over the IP clock link.

ProtType of IpclkData

Indicates the protocol type recorded in the IP clock data.
