Modify TCPACK Limit Algorithm (MOD TCPACKLIMITALG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of the TCP ACK limit algorithm.

Note

[Co-MPT,eNodeB]This command applies only to LTE, but in co-MPT scenarios, this command applies to both LTE and NR.

Parameters

ID Name Description
TCPACKLIMITSWITCH TCP ACK Limit Switch

Meaning: Indicates whether to enable the TCP ACK limit algorithm. When this switch is set to on, the base station limits the ACK data rate of downlink TCP services based on the value of DL Throughput Threshold. In this case, the ACK burst of downlink TCP services is prevented and the KPIs related to the downlink throughput rate are improved, but the packet forwarding capability of boards is affected. When this switch is set to off, the base station does not limit the ACK data rate of downlink TCP services.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect. Therefore, avoid using this parameter.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this switch is set to on, the ACK burst of downlink TCP services is prevented.

Applicable Mode: L
DLTHROUGHPUTTHRESHOLD DL Throughput Threshold

Meaning: Indicates the maximum downlink service throughput that can be set by the TCP ACK limit algorithm. When this switch is set to on, the ACK burst of downlink TCP services is prevented and the KPIs related to the downlink throughput are improved.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect. Therefore, avoid using this parameter.

GUI Value Range: 1~4194304

Unit: kbit/s

Actual Value Range: 1~4194304

MML Default Value: None

Recommended Value: 153600

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the value of this parameter is less than the actual data rate over the air interface, the downlink throughput decreases.

When the value of this parameter is much greater than the actual data rate over the air interface, the TCP ACK buffer transmit function becomes invalid.

Applicable Mode: L

Example

To modify the configuration of the TCP ACK limit algorithm with the parameters as follows: TCP ACK Limit Switch: ON, DL Throughput Threshold: 714kbit/s:
MOD TCPACKLIMITALG: TCPACKLIMITSWITCH=ON, DLTHROUGHPUTTHRESHOLD=714;
