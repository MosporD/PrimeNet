Add IPSec Proposal (ADD IPSECPROPOSAL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an IP Security (IPSec) proposal.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • System specifications: If the WMPT/UMPT/UMDU/LMPT/GTMUb/GTMUc is the main control board, a maximum of 99 IPSec proposals can be configured.

  • Board specifications: A maximum of 99 IPSec proposals can be configured on a UMPT/UMDU/LMPT/UTRPc/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • The IPSECPROPOSAL MO takes effect on the board together with the IPSECBIND and IPSECBINDITF bearer objects. That is, the IPSECPROPOSAL MO does not take effect on any board when being configured, and takes effect on the board when the bearer MO (IPSECBIND or IPSECBINDITF) is configured.

  • If TRANMODE in the IPSECPROPOSAL MO is ESP and ESPAUTHALG is NULL, the anti-replay function does not take effect.

ENCAPMODE Encapsulation Mode

Meaning: Indicates the encapsulation mode of an IPSec proposal, which can be set to TUNNEL or TRANSPORT. In TRANSPORT mode, only data is encrypted. In TUNNEL mode, the whole IP packet is protected, and a new IP header is added to the original IP packet. The source IP address and the destination IP address of the new IP header are the IP addresses of two ends of the security tunnel. Both the TRANSPORT mode and the TUNNEL mode are used for end-to-end IPSec protection. The TUNNEL mode, however, is also applied to the protection of a certain segment.

GUI Value Range: TUNNEL(Tunnel), TRANSPORT(Transport)

Unit: None

Actual Value Range: TUNNEL, TRANSPORT

MML Default Value: TUNNEL(Tunnel)

Recommended Value: TUNNEL(Tunnel)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
TRANMODE Transform

Meaning: Indicates the security protocol used in an IPSec proposal. The value AH indicates the Authentication Header (AH) protocol specified in RFC2402. The value ESP indicates the Encapsulating Security Payload (ESP) protocol specified in RFC2406. The value AH_ESP indicates that the ESP protocol is preferentially used to protect packets, but not the AH protocol.

GUI Value Range: AH(AH Protocol), ESP(ESP Protocol), AH_ESP(AH/ESP Protocol)

Unit: None

Actual Value Range: AH, ESP, AH_ESP

MML Default Value: ESP(ESP Protocol)

Recommended Value: ESP(ESP Protocol)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
AHAUTHALG AH Authentication Algorithm

Meaning: Indicates the AH authentication algorithm used by an IPSec proposal. IPSec can use hashed message authentication code (HMAC) or cipher block chaining-message authentication code (CBC-MAC) for identity authentication and data integrity check. For details about HMAC, see RFC4306. HMAC currently supports three hash functions: message digest algorithm 5 (MD5), secure hash algorithm 1 (SHA1), and secure hash algorithm 256 (SHA256). The three hash functions verify data by means of integrity protection. Among them, SHA256 provides the highest security level and MD5 provides the lowest security level. For details about the hash functions, see RFC2409. CBC-MAC currently supports AES-XCBC-MAC-96, which is an enhancement to CBC-MAC. For details about AES-XCBC-MAC-96, see RFC3566.

Disuse statement: In later versions, the value MD5(MD5) will be removed from the value range of this parameter. In the current version, this value can still be configured and take effect.Therefore, you are not advised to use the value MD5(MD5).

GUI Value Range: MD5(MD5), SHA1(SHA1), AES-XCBC-MAC-96(AES-XCBC-MAC-96), SHA256(SHA256)

Unit: None

Actual Value Range: MD5, SHA1, AES-XCBC-MAC-96, SHA256

MML Default Value: SHA256(SHA256)

Recommended Value: SHA256(SHA256)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
ESPENCALG ESP Encryption Algorithm

Meaning: Indicates the encryption algorithm used in ESP. The Data Encryption Standard (DES) is an internationally used data encryption algorithm, which uses a 64-bit key. The 3DES is also an internationally used encryption algorithm, which uses a 192-bit key. The Advanced Encryption Standard (AES) is an advanced encryption algorithm, which can use three types of keys of different lengths: 128, 192, and 256 bits. Therefore, different protection levels are available. For details, see RFC2401. AES_GCM_128 and AES_GCM_256 are AEAD encryption algorithms that provide both authentication and confidentiality protection. NULL_AUTH_GMAC_128 and NULL_AUTH_GMAC_256 are NULL encryption algorithms that provide only authentication but not confidentiality protection. For details, see RFC 4543. AES_GCM and AES_GMAC are supported to meet the Suite B algorithm requirements. For details, see RFC 6379. The values AES_GCM_128 and AES_GCM_256 are supported only by the UMPTe, UMPTg, UMPTga, UBBPe(excluding UBBP15), UBBPem, UBBPep, UBBPei, UBBPex2, UBBPf1, UBBPf0, UBBPg1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 and UBBPg9 boards. The values NULL_AUTH_GMAC_128 and NULL_AUTH_GMAC_256 are supported only by the UMPTg and UMPTga boards.

Disuse statement: In later versions, the values DES(DES) and 3DES(3DES) will be removed from the value range of this parameter. In the current version, these values can still be configured and take effect. Therefore, you are not advised to use the values DES (DES) and 3DES (3DES).

GUI Value Range: NULL(NULL), DES(DES), 3DES(3DES), AES128(AES128), AES192(AES192), AES256(AES256), AES_GCM_128(AES_GCM_128), AES_GCM_256(AES_GCM_256), NULL_AUTH_GMAC_128(NULL_AUTH_GMAC_128), NULL_AUTH_GMAC_256(NULL_AUTH_GMAC_256)

Unit: None

Actual Value Range: NULL, DES, 3DES, AES128, AES192, AES256, AES_GCM_128, AES_GCM_256, NULL_AUTH_GMAC_128, NULL_AUTH_GMAC_256

MML Default Value: AES128(AES128)

Recommended Value: AES128(AES128)

Example

To add an IP security proposal with the parameters as follows: IPSec Proposal Name: prop1, Transform: ESP, ESP Encryption Algorithm: AES128, run the following command:
ADD IPSECPROPOSAL: PROPNAME="prop1", TRANMODE=ESP, ESPENCALG=AES128;
