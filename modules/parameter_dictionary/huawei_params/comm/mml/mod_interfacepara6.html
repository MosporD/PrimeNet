Modify IPv6 parameters of interface (MOD INTERFACEPARA6)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify IPv6 parameters of interface.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
ITFID Interface ID

Meaning: Indicates the ID of an interface.

GUI Value Range: 0~1499

Unit: None

Actual Value Range: 0~1499

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
SENDSW SEND Switch

Meaning: Indicates whether the interface opens the Send protocol and currently only supports the Nonce and Timestamp mechanisms.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
SENDDELTA SEND Delta

Meaning: Indicates the maximum difference between the moment when the ND message is received by the local side and the time at which the ND message is sent to the peer.

GUI Value Range: 0~1000

Unit: s

Actual Value Range: 0~1000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
SENDDRIFT SEND Drift

Meaning: Indicates the percentage of the maximum value of the receiver-to-sender system time difference value.

GUI Value Range: 0~100

Unit: None

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
SENDFUZZFACTOR SEND Fuzz-Factor

Meaning: Indicates the maximum time to live for a message.if the time at which the ND message is received by the local side is greater than delta-value, but within the Fuzz-value time range, it can still be received by the interface.

GUI Value Range: 0~1000

Unit: s

Actual Value Range: 0~1000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
DHCPRELAYSW DHCPv6 Relay Switch

Meaning: Indicates whether to enable the DHCPv6 relay function on an interface. If this parameter is set to ON, the interface can receive multicast packets of DHCPv6 requests sent by lower-level base stations.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

Example 1: To modify IPv6 parameters of interface with the parameters as follows: Interface ID: 0, SEND Switch: DISABLE, DHCPv6 Relay Switch: DISABLE, run the following command:
MOD INTERFACEPARA6: ITFID=0, SENDSW=DISABLE, DHCPRELAYSW=DISABLE;

Example 2: To modify IPv6 parameters of interface with the parameters as follows: Interface ID: 0, SEND Switch: ENABLE, SEND Delta(s): 400, SEND Drift: 2, SEND Fuzz-Factor(s): 2, DHCPv6 Relay Switch: ENABLE, run the following command:
MOD INTERFACEPARA6: ITFID=0, SENDSW=ENABLE, SENDDELTA=400, SENDDRIFT=2, SENDFUZZFACTOR=2, DHCPRELAYSW=ENABLE;
