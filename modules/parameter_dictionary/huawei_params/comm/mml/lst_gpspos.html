List GPS Position (LST GPSPOS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the location information of the GPS.

Note

None.

Parameters

None.

Example

1.To list the location information of the GPS, run the following command:
LST GPSPOS:;
The result is shown as follows:

Output Description

Field Description

Way to Get Position

Indicates the method of obtaining the position of the GPS satellite.

Antenna Longitude(1e-6 degree)

Indicates the longitude of the GPS antenna. A negative value indicates the west longitude, and a positive value indicates the east longitude.

Antenna Latitude(1e-6 degree)

Indicates the latitude of the GPS antenna. A negative value indicates the south latitude, and a positive value indicates the north latitude.

Antenna Altitude[m(ft)]

Indicates the altitude of the GPS antenna. A negative value indicates that the GPS antenna is below the sea level, and a positive value indicates that the GPS antenna is above the sea level.

Duration(min)

Indicates the duration for tracing the position of the GPS satellite.

Precision[m(ft)]

Indicates the precision requirement for tracing the position of the GPS satellite.

Antenna Angle(degree)

Indicates the antenna angle, which is the angle with the horizontal line. If the clock source has not been activated, the value NULL will be displayed. If the clock source has been activated, the value NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.

Position Check Switch

Indicates the position check switch of a satellite card. If this switch is turned on, the NE records the position where a satellite card is locked as the initial position and calculates the deviation between this initial position and the current position. If the deviation is excessively large, the NE regards the output signals of the satellite card unreliable and reports ALM-26120 GPS Clock Output Unavailable. The position check is applicable only when the NE position is fixed and the satellite card in the BBU supports this check.
