Restore RAE Files (RST RAEFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to restore Remote eAntenna Extension (RAE) files to default configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Executing this command will restore the weighting factor files stored on the RAE to default configurations. As a result, all the original weighting factor files will be lost.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the RAE.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SUBUNITNO Subunit No.

Meaning: Indicates the number of the RAE subunit, which starts from 1.

GUI Value Range: 1~6

Unit: None

Actual Value Range: 1~6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To restore RAE files with parameters as follows: Device No.: 1, Subunit No.: 1, run the following command:
RST RAEFILE: DEVICENO=1, SUBUNITNO=1;
The result is shown as follows: 
+++    0        2007-01-22 11:12:00
O&M    #560
