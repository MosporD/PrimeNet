List User Plane Peer Configuration (LST USERPLANEPEER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of user-plane peers and whether the object is created by the system. When AUTOCFGFLAG is set to MANUAL_CREATED, the object is configured by the user manually. When AUTOCFGFLAG is set to AUTO_CREATED, the object is created by the system.

Note

None.

Parameters

ID Name Description
UPPEERID User Plane Peer ID

Meaning: Indicates the ID of the user-plane peer. The value of UPPEERID in the user-plane peer configured by users ranges from 0 to 65535. The value of UPPEERID in the USERPLANEPEER MOs configured by the system ranges from 70000 to 79999.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If UPPEERID is set to a value in the range of 0 to 65535, CTRLMODE must be set to MANUAL_MODE, and AUTOCFGFLAG must be set to MANUAL_CREATED. If UPPEERID is set to a value in the range of 70000 to 79999, CTRLMODE must be set to AUTO_MODE, and AUTOCFGFLAG must be set to AUTO_CREATED.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To list the configuration of user-plane peers, run the following command:
LST USERPLANEPEER:;

Output Description

Field Description

User Plane Peer ID

Indicates the ID of the user-plane peer. The value of UPPEERID in the user-plane peer configured by users ranges from 0 to 65535. The value of UPPEERID in the USERPLANEPEER MOs configured by the system ranges from 70000 to 79999.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

IP Version

Indicates the version of the user-plane peer IP address.

Peer IP Address

Indicates the IPv4 Address of the user plane peer.

Peer IPv6 Address

Indicates the IPv6 Address of the user plane peer. This parameter takes effect only in LTE and NR.

IPSec Auto Configure Switch

Indicates whether to enable automatic user-plane IPsec tunnel setup based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. If this parameter is set to ENABLE, an IPsec tunnel is automatically set up to encrypt transmitted data. If this parameter is set to DISABLE, no IPsec tunnel is automatically set up. If the value of this parameter is changed from ENABLE to DISABLE using the MOD USERPLANEPEER command, the system deletes the automatically set up IPsec tunnel.

Security Peer ID

Indicates the security peer ID used by the user-plane peer.

Remote ID

Indicates the remote ID. This parameter is used by the system during the automatic configuration of this MO. If this parameter is manually configured, the system may fail to automatically modify or delete the MO.

Control Mode

Indicates whether the object can be automatically modified or removed by the system. If this parameter is set to MANUAL_MODE, only users can operate this object. If this parameter is set to AUTO_MODE, the system can modify or remove this object and users can only remove this object.

Auto Config Flag

Indicates whether the object is created by the system. The value MANUAL_CREATED means that the object is configured by the user. The value AUTO_CREATED means that the object is created by the system.

Static Check Switch

Indicates whether to enable the GTP-U static detection function for a link. When this parameter is set to ENABLE, the GTP-U static detection function is enabled for a link. When this parameter is set to DISABLE, the GTP-U static detection function is disabled for a link. When this parameter is set to FOLLOW_GLOBAL, the setting of the switch for the GTP-U static detection function is the same as that of the base station-level GTP-U detection switch. This parameter is valid only when STATICCHKMODE is set to UPPEERSTATICCHK(User-Plane Peer Static Check) in the GEPMODELPARA MO. This parameter takes effect only in LTE and NR.

User Label

Indicates the information about a user-plane peer.
