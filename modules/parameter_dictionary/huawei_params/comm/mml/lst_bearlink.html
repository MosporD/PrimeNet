List Bearer Link and Bandwidth of Current Physical Port (LST BEARLINK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the links carried on a physical port and the bandwidth occupied by each link.

Note

None.

Parameters

ID Name Description

Meaning: Indicates the cabinet number of the board where the port is located.

MML Default Value: 0

Recommended Value: None

Meaning: Indicates the subrack number of the board where the port is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
SN Slot No.

Meaning: Indicates the slot number of the board where the port is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

SBT Subboard Type

Meaning: Indicates the type of sub-board.

GUI Value Range: E1_COVERBOARD(E1 Cover Board), UNCHANNELLED_COVERBOARD(Unchannelled Cover Board), BASE_BOARD(Base Board), BACK_BOARD(Back Board)

MML Default Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB]In the BEARLINK MO, if SN is within the range from 0 to 5, this parameter can be set to E1_COVERBOARD or UNCHANNELLED_COVERBOARD.

Unit: None

MML Default Value: None

PN Port No.

Meaning: Indicates the port number.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB]In the BEARLINK MO, if SBT is set to BASE_BOARD and PT is set to IMA, this parameter can be set to 0 or 1.
  • In the BEARLINK MO, if SBT is set to E1_COVERBOARD and PT is set to IMA, the value range of this parameter is from 0 to 3.
  • In the BEARLINK MO, if SBT is set to BASE_BOARD or BACK_BOARD and PT is set to UNI, the value range of this parameter is from 0 to 3.
  • In the BEARLINK MO, if SBT is set to E1_COVERBOARD and PT is set to UNI, the value range of this parameter is from 0 to 7.
  • In the BEARLINK MO, if SBT is set to BASE_BOARD or BACK_BOARD and PT is set to FRAATM, the value range of this parameter is from 0 to 3.
  • In the BEARLINK MO, if SBT is set to E1_COVERBOARD and PT is set to FRAATM, the value range of this parameter is from 0 to 7.
  • In the BEARLINK MO, if SBT is set to UNCHANNELLED_COVERBOARD and PT is set to STM1, this parameter must be set to 0.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Example

To list the links carried on a physical port and the bandwidth occupied by each link with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: Base Board, Port Type: IMA, Port No.: 0, run the following command: 
LST BEARLINK: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=IMA, PN=0;
