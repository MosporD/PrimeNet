Display Cabinet Manufacturing Information (DSP CABMFRINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the manufacturing information about a cabinet.

Note

  • When querying the manufacturing information about a cabinet, ensure that the TCU, FMU, or CCU installed in the cabinet is operational.

  • This command may conflict with periodic electronic label tasks. If a conflict occurs, the system displays the following error message: "The e-label query process included in this operation conflicts with an existing e-label query process. Please try later." In this case, run this command one minute later.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the manufacturing information about the cabinet with the parameters as follows: Cabinet No.: 0, run the following command:
DSP CABMFRINFO:CN=0;
The result is shown as follows:
+++    0        2013-11-26 11:10:49
O&M    #537919904

Output Description

Field Description

Model

Indicates the physical type of cabinet.

Serial Number

Indicates the bar code of the board or the cabinet.

Description

Indicates the description about the services and functions provided by the board or the cabinet.

Date of Manufacture

Indicates the manufacturing date of the board or the cabinet.

Vendor

Indicates the manufacturer of the board or the cabinet.
