Display Trust Certificate (DSP TRUSTCERT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of trust certificates.

Note

If the queried trust certificate is in the P7B format, this command displays information of all certificates in the certificate chain.

Parameters

ID Name Description
CERTNAME Certificate File Name

Meaning: Indicates the file name of a trust certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]CERTNAME in a TRUSTCERT MO is recommended to enter ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When a TRUSTCERT MO is being added, the CERTNAME is case insensitive; but when a TRUSTCERT MO is referenced, the CERTNAME is case sensitive.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The system must be configured with TRUSTCERT MO with CERTNAME set to caroot.pem.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the detailed information about all trusted certificates, run the following command:
DSP TRUSTCERT:;

Output Description

Field Description

Certificate File Name

Indicates the file name of a trust certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

Serial Number

Indicates the serial number of a trust certificate.

Common Name

Indicates the common name of a trust certificate.

Issuer Name

Indicates the issuer of a trust certificate.

Effective Date

Indicates the date when a trust certificate begins to take effect.

Expiring Date

Indicates the expiration date of a trust certificate.

Key Type

Indicates type of key of one certificate, which can be RSA or ECDSA.

Key Size

Indicates the key length, which can be 1024 bits, 2048 bits, 3072 bits or 4096 bits. The key length of 1024 bits is not recommended. Otherwise, the security is undermined. If this parameter is set to KEYSIZE1024, the RRU still uses the value KEYSIZE2048 as the key length.

ECC Curve

Indicates the name of the elliptic curve used by the key when the certificate key type is ECDSA. The elliptic curve allows P256 (secp256r1), P384 (secp384r1), ED25519 and P521(secp521r1). ED25519 indicates the EdDSA signature scheme using SHA-512 and Curve25519.

Status

Indicates the loading status of a trust certificate.
