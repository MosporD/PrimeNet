Start E1/T1 Online Performance Test (STR E1T1ONLTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to start an E1/T1 online performance test.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]A maximum of three users can start the online performance test simultaneously on each port.

  • [Co-MPT,NodeB,eGBTS,eNodeB]You cannot start an online performance test at the port where an offline performance test is already started. Conversely, you cannot start an offline performance test at the port where an online performance test is already started.

  • [Co-MPT,NodeB,eGBTS,eNodeB]You can start the online performance test on multiple ports on the same board.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If the online performance test encounters a turnover, the number of error bits after the turnover is reported.

  • [Co-MPT,NodeB,eGBTS,eNodeB]An online performance test is applicable to a transmission link working properly and having error bits. You are advised to check the E1/T1 link status before starting an online test. If the link is faulty, you are not advised to start an online performance test. In this case, you can start an E1/T1 offline performance test and rectify the E1/T1 link fault.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When Period Report Switch is set to ON, the test result within a second is reported every other second. When Period Report Switch is set to OFF, you can run the STP E1T1ONLTST command to obtain the test result.

  • [eNodeB]An E1/T1 online performance test can be started in slot 6 or 7 only when the main control board is a UMTPa/UMPTb. An E1/T1 online performance test can be started in slot 6 only when the main control board is a UMDU.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the port is located.

Subrack No.

Indicates the number of the subrack where the port is located.

Slot No.

Indicates the slot number of the board where the port is located.

Subboard Type

Indicates the type of sub-board on the board where a port is located.

Port No.

Indicates the port number.

Duration

Indicates how long the test has been conducted.

Line Conflicting Error Rate

Indicates the error rate of type violation of channel coding in the test result.

Line Conflicting Error Number

Indicates the number of type violations of channel coding in the test result.

CRC Error Rate

Indicates the CRC error rate in the test result.

CRC Error Number

Indicates the number of CRC error frames in the test result.

EBit Error Rate(E1)/Error Block Rate(T1)

Indicates the error rate of E bit on E1 links or the error rate of block on T1 links in the test result.

EBit Error Number(E1)/Error Block Number(T1)

Indicates the number of E bit errors on E1 links or the number of block errors on T1 links in the test result.

Framing Error Rate

Indicates the FAS error rate in the test result.

Framing Error Number

Indicates the number of FAS errors in the test result.

Receive Direction Error Second(s)

Indicates the number of seconds for which error bits are received. For details, see G.826.

Receive Direction Severely Error Second(s)

Indicates the number of seconds for which severe error bits exist in the RX direction. For details, see G.826.

Receive Direction Unusable Second(s)

Indicates the number of seconds for which the received bits are unavailable. If severe error bits are received for 10 consecutive seconds, the system starts to measure this counter. If no severe error bits are received for 10 consecutive seconds, the original statistics are cleared. For details, see G.826.

Transmission Direction Error Second(s)

Indicates the number of seconds for which error bits exist in the TX direction. For details, see G.826.

Transmission Direction Severely Error Second(s)

Indicates the number of seconds in which severe error bits are transmitted. For details, see G.826.

Transmission Direction Unusable Second(s)

Indicates the number of seconds for which the transmitted bits are unavailable. If severe error bits are transmitted for 10 consecutive seconds, the system starts to measure this counter. If no severe error bits are transmitted for 10 consecutive seconds, the original statistics are cleared. For details, see G.826.
