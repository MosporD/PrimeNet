Display Local Ethernet Port Status (DSP LOCALETHPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of the local maintenance Ethernet port.

Note

None.

Parameters

ID Name Description
CLEAR Clear Statistic

Meaning: Indicates whether to delete the historical statistics. If this parameter is set to YES, the historical statistics are deleted and a new round of statistics collecting starts upon completion of the query.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: NO(No)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To query the status of the local maintenance Ethernet port with Clear Statistic set to NO, run the following command:
DSP LOCALETHPORT: CLEAR=NO;
The result is as follows:
+++    0        2011-04-02 06:15:37
O&M    #27

Output Description

Field Description

Actual Effect Status

Indicates whether to enable the local maintenance Ethernet port.

Port Status

Indicates the status of the local maintenance Ethernet port. When this parameter is set to Down, the port cannot be maintained.

Port Mode

Indicates the physical load mode of the near-end maintenance network port.

Number of RX Packets(packet)

Indicates the number of packets received at the local maintenance Ethernet port.

Number of RX Discarded Packets(packet)

Indicates the number of discarded packets that are received at the local maintenance Ethernet port.

Number of TX Packets(packet)

Indicates the number of packets transmitted at the local maintenance Ethernet port.

Number of TX Discarded Packets(packet)

Indicates the number of discarded packets that are transmitted at the local maintenance Ethernet port.
