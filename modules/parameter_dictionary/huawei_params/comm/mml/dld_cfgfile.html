Download Backup Configuration File (DLD CFGFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to download a configuration file from the FTP server to an NE.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that the following conditions are met:

    The FTP server is functioning properly.

    No firewall is set between the FTP server and the NE, or the firewall is disabled.

    The specified user name and password of the FTP server are valid, and the user has the read access to the specified directory.

  • The file to be downloaded must exist in the specified directory on the FTP server. If no file exists, the command fails.

  • The extension of a file to be downloaded must be .xml, .ecf, or .gz. Otherwise, execution of this command will fail.

  • If a configuration file downloaded by using this command is not activated within 24 hours, it will be automatically deleted.

  • Files downloaded using the DLD CFGFILE command and backed up using the BKP CFGFILE command are saved in the same directory on an NE. An existing file will be overwritten by a new file with the same file name.

  • Execution of this command will increase the CPU usage, and CPU overload may affect UE access. Therefore, it is recommended that you run this command when the system has a light load.

  • When you run this command with ENCRYPTMODE set to UNENCRYPTED to download an encrypted file, the downloaded file is not decrypted. As a result, the downloaded file cannot be activated.

  • When you run this command with ENCRYPTMODE set to PWD_ENCRYPTED to download a file that is not encrypted, the system fails to perform the decryption. As a result, the command fails.

  • When you run this command with CF set to UNCOMPRESSED to download a compressed file, the downloaded file is not decompressed. As a result, the downloaded file cannot be activated.

  • When you run this command with CF set to COMPRESSED to download a file that is not compressed, the system fails to perform the decompression. As a result, the command fails.

  • If there is insufficient disk space, it is recommended that you run related remove commands or the CLR FILE command to delete files that are no longer in use.

  • When the size of a file exceeds the maximum file download capability of the hardware (UMPTg/UMPTga: 100 MB; UMDU/LMPT/UMPTa/UMPTb/UMPTe: 50 MB; WMPT: 5 MB), the download will fail. Use a file compression tool such as gzip to compress the file into a .gz file and then download the file.

  • [Co-MPT,eGBTS]If an XML configuration file is downloaded through the MAE or LMT and the file name is CFGDATA.XML, you do not need to specify FT or FN. If the file name is not CFGDATA.XML, FN cannot be the default value. Instead, the file name must be specified. After the file is downloaded, it is automatically renamed CFGDATA.XML.

  • [NodeB]If an XML configuration file is downloaded through the MAE or LMT and the file name is NodeBCfg.xml, you do not need to specify FT or FN. If the file name is not NodeBCfg.xml, FN cannot be the default value. Instead, the file name must be specified. After the file is downloaded, it is automatically renamed NodeBCfg.xml.

  • [eNodeB]If an XML configuration file is downloaded through the MAE or LMT and the file name is ENBCFG.XML, you do not need to specify FT or FN. If the file name is not ENBCFG.XML, FN cannot be the default value. Instead, the file name must be specified. After the file is downloaded, it is automatically renamed ENBCFG.XML.

  • [gNodeB]If an XML configuration file is downloaded through the MAE or LMT and the file name is GNBCFG.XML, you do not need to specify FT or FN. If the file name is not GNBCFG.XML, FN cannot be the default value. Instead, the file name must be specified. After the file is downloaded, it is automatically renamed GNBCFG.XML.

Example

Example 1: To download the backup configuration file (IP Mode = IPV4; FTP Server IP = 192.168.60.35; User Name = admin; Password = *****; File Name = CFGDATA.XML; File Type = XML; Directory Name = default directory; Encrypted Mode = UNENCRYPTED), run the following command: 
DLD CFGFILE: MODE=IPV4, IP="192.168.60.35", USR="admin", PWD="*****", FN="CFGDATA.XML", FT=XML, ENCRYPTMODE=UNENCRYPTED;

Example 2: To download the backup configuration file (IP Mode = IPV4; FTP Server IP = 192.168.60.35; User Name = admin; Password = *****; File Name = CFGDATA.XML; File Type = XML; Directory Name = \files; Encrypted Mode = UNENCRYPTED), run the following command: 
DLD CFGFILE: MODE=IPV4, IP="192.168.60.35", USR="admin", PWD="*****", DIR="\files", FN="CFGDATA.XML", FT=XML, ENCRYPTMODE=UNENCRYPTED;

Example 3: To download the backup configuration file (IP Mode = IPV4; FTP Server IP = 192.168.60.35; User Name = admin; Password = *****; File Name = CFGDATA.XML; File Type = XML; Directory Name = ftproot/; Encrypted Mode = UNENCRYPTED), run the following command: 
DLD CFGFILE: MODE=IPV4, IP="192.168.60.35", USR="admin", PWD="*****", DIR="ftproot/", FN="CFGDATA.XML", FT=XML, ENCRYPTMODE=UNENCRYPTED;

Example 4: To download the backup configuration file (IP Mode = IPV4; FTP Server IP = 192.168.60.35; User Name = admin; Password = *****; File Name = CFGDATA.XML.ecf; File Type = XML; Directory Name = default directory; Encrypted Mode = PWD_ENCRYPTED; File Encryption Password = *****), run the following command: 
DLD CFGFILE: MODE=IPV4, IP="192.168.60.35", USR="admin", PWD="*****", FN="CFGDATA.XML.ecf", FT=XML, ENCRYPTMODE=PWD_ENCRYPTED, FILEPWD="*****";
