List the bind relation of the Mains Input Out of Range alarm (LST NMSABIND)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the bind relation of the Mains Input Out of Range alarm.

Note

None.

Parameters

None.

Example

To list the bind relation of the Mains Input Out of Range alarm, run the following command:
LST NMSABIND:;
The result is shown as follows:
+++    0        2010-10-19 13:55:36
O&M    #43
%%LST NMSABIND:;%%
RETCODE = 0  Operation succeeded.

List the bind relation of the Mains Input Out of Range alarm
------------------------------------------------------------
Base Station Almport Switch  =  ENABLE
        Almport Cabinet No.  =  0
        Almport Subrack No.  =  0
           Almport Slot No.  =  18
           Almport Port No.  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Base Station Almport Switch

Indicates the Base Station Almport Switch.

Almport Cabinet No.

Indicates the cabinet number of the dry contact that reports ALM-25622 Mains Input Out of Range.

Almport Subrack No.

Indicates the subrack number of the dry contact that reports ALM-25622 Mains Input Out of Range.

Almport Slot No.

Indicates the slot number of the dry contact that reports ALM-25622 Mains Input Out of Range.

Almport Port No.

Indicates the port number of the dry contact that reports ALM-25622 Mains Input Out of Range.
