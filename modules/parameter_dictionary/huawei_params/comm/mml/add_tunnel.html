Add Tunnel (ADD TUNNEL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a tunnel that is for backplane communication when co-transmission is implemented between radio access technologies.

Note

  • Board specifications: A maximum of 15 tunnels can be configured on a WMPT/UMPT/UMDU/LMPT/GTMUb/GTMUc/UTRPc.

  • System specifications: If the WMPT/UMPT/UMDU/LMPT/GTMUb/GTMUc is the main control board, a maximum of 15 tunnels can be configured.

  • A tunnel is used for backplane communications. A maximum of two uplink tunnels can be configured for a UMPT/UMDU/UTRPc/GTMUc; only one can be configured for a WMPT and an LMPT. If the number of tunnels configured for the uplink exceeds the preceding specifications, the tunnels beyond the specifications take effect on the downlink and cannot automatically take effect on the uplink unless the user reconfigures them.

  • When an uplink TUNNEL MO is added to slot 6 or 7 on the MAE-Deployment, its adaptive port transmission resource group is automatically created. The bandwidth-related parameters of the transmission resource group take effect based on default values of the board capability.

  • It is not recommended that TUNNEL and HAGRP be both configured in inter-BBU scenarios.

  • [Co-MPT,NodeB,eNodeB,gNodeB]When the board identified by the source cabinet number, subrack number, and slot number is a main control board, it is recommended that only one tunnel be configured on the main control board.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If two BBUs of the same mode are interconnected, the uplink tunnel configured on the UMPT in the leaf BBU is invalid and transmission resource groups and IP paths cannot be configured on such an uplink tunnel.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The board identified by the target cabinet number, subrack number, and slot number must not be a main control board of the local standard.

  • [Co-MPT,NodeB,eNodeB,gNodeB]It is recommended that a maximum of two tunnels be configured for each mode to communicate with the other modes.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the board identified by the source cabinet number, subrack number, and slot number is a UTRPc, the board identified by the target cabinet number, subrack number, and slot number must be a main control board.

  • [Co-MPT,NodeB,eGBTS]The GTMUb/GTMUc backplane supports a maximum MTU with 1450 bytes. A packet with more than 1450 bytes will be discarded.

Parameters

ID Name Description
SCN Source Cabinet No.

Meaning: Indicates the number of the source cabinet where the tunnel is configured.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Source Cabinet No. parameter in the BACKTUNNEL MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.
