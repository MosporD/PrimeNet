Add SCTP Peer to End Point Group (ADD SCTPPEER2EPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an SCTP peer to an end point group.

Note

  • [Co-MPT,NodeB,eNodeB,gNodeB]Before adding an SCTP peer to an endpoint group, ensure that the endpoint group added by using the ADD EPGROUP command and the SCTP peer added by using the ADD SCTPPEER command have been configured.

  • [Co-MPT,NodeB,eNodeB,gNodeB]A maximum of 1024 SCTP peers can be added in all endpoint group objects. A maximum of 512 SCTP peers can be added in a single endpoint group object.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If there are SCTP hosts configured in different endpoint groups which PNs are the same, and one's SIGIP1V4 or SIGIP2V4 is the same as the other's SIGIP1V4 or SIGIP2V4, the same SCTP peer is only allowed to be configured in one of these endpoint groups.

  • [Co-MPT,NodeB,eNodeB,gNodeB]This command takes effect only for UMTS, LTE, and NR.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If a base station is not configured with an SCTP link that meets the following conditions, the base station will automatically create an SCTP link and a CP bearer:

    - The values of First Local IP Address, Second Local IP Address, and Local SCTP Port No. in the SCTPHOST object in the same end point group are the same as those of another SCTP link.

    - The values of First Peer IP Address, Second Peer IP Address, and Peer SCTP Port No. in the SCTPPEER object are the same as those of another SCTP link.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the following conditions are met during setup of an SCTP link, the system will automatically configure the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects for the SCTP link and set up an IPsec tunnel:

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the SCTPHOST object in the same end point group and the SCTPPEER object.

    - SeGW Switch is set to ENABLE(Enable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met during setup of an SCTP link, the system will automatically configure the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects for the SCTP link and set up an IPsec tunnel:

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the SCTPHOST object in the same end point group and the SCTPPEER object.

    - SeGW Switch is set to DISABLE(Disable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

    If IPSec Auto Configure Switch is set to DISABLE(Disable) for the SCTPHOST object in the same end point group and the SCTPPEER object, an IPsec tunnel can be set up by manually configuring all the preceding IPsec-related objects.

  • [Co-MPT,eNodeB,gNodeB]If a base station is not configured with an IPv6 SCTP link that meets the following conditions, the base station will automatically set up an IPv6 SCTP link and a CP bearer:

    - The values of First Local IPv6 Address, Second Local IPv6 Address, and Local SCTP Port No. in the SCTPHOST object in the same end point group are the same as those of another IPv6 SCTP link.

    - The values of First Peer IPv6 Address, Second Peer IPv6 Address, and Peer SCTP Port No. in the SCTPPEER object are the same as those of another IPv6 SCTP link.

  • [Co-MPT,eNodeB,gNodeB]If there are SCTP hosts configured in different endpoint groups which PNs are the same, and one's SIGIP1V6 or SIGIP2V6 is the same as the other's SIGIP1V6 or SIGIP2V6, the same SCTP peer is only allowed to be configured in one of these endpoint groups.

Parameters

ID Name Description
EPGROUPID End Point Group ID

Meaning: Indicates the ID of the end point group to which an end point belongs.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SCTPPEERID SCTP Peer ID

Meaning: Indicates the ID of the SCTP peer.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add an SCTP peer to an end point group with the parameters as follows: End Point Group ID: 0, SCTP Peer ID: 0, run the following command:
ADD SCTPPEER2EPGRP: EPGROUPID=0, SCTPPEERID=0;
