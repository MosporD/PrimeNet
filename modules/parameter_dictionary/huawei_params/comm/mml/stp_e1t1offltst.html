Stop E1/T1 Offline Performance Test (STP E1T1OFFLTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to stop the E1/T1 offline performance test, summarize the E1/T1 test data, and report the data to the maintenance terminal.

Note

[Co-MPT,NodeB,eGBTS,eNodeB]You cannot handle the E1/T1 offline performance test started by any other user.

Example

To stop the E1/T1 offline performance test with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port No.: 0, run the following command:
STP E1T1OFFLTST: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PN=0;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the port is located.

Subrack No.

Indicates the number of the subrack where the port is located.

Slot No.

Indicates the slot number of the board where the port is located.

Subboard Type

Indicates the type of sub-board on the board where a port is located.

Port No.

Indicates the port number.

Remain Time

Indicates the remaining time.

Duration

Indicates how long the test has been conducted.

Bit Error Rate(E1)/Error Block Rate(T1)

Indicates the bit error rate in the test result.

Bit Error Number (E1)/Error Block Number (T1)

Indicates the number of bit errors in the test result.
