Display Backplane Tunnel Status (DSP BACKTUNNEL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of a backplane tunnel.

Note

None.

Parameters

ID Name Description
PORTID Port ID

Meaning: Indicates the ID of a backplane tunnel port.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CLEAR Clear Statistic

Meaning: Indicates whether to clear current statistics. If this parameter is set to YES, the historical statistics are deleted and a new round of statistics collecting starts upon completion of the query.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the status of a backplane tunnel with Port ID set to 0, run the following command: 
DSP BACKTUNNEL: PORTID=0;
The result is shown as follows:

Output Description

Field Description

Port ID

Indicates the ID of a backplane tunnel port.

Source Cabinet No.

Indicates the source cabinet number of the backplane tunnel.

Source Subrack No.

Indicates the source subrack number of the backplane tunnel.

Source Slot No.

Indicates the source slot number of the backplane tunnel.

Destination Cabinet No.

Indicates the destination cabinet number of the backplane tunnel.

Destination Subrack No.

Indicates the destination subrack number of the backplane tunnel.

Destination Slot No.

Indicates the destination slot number of the backplane tunnel.

Number of RX Bytes(byte)

Indicates the number of bytes received by the backplane tunnel.

Number of RX Packets(packet)

Indicates the number of packets received by the backplane tunnel.

Number of TX Bytes(byte)

Indicates the number of bytes transmitted by the backplane tunnel.

Number of TX Packets(packet)

Indicates the number of packets transmitted by the backplane tunnel.
