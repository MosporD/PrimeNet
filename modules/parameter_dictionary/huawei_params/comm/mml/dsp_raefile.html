Display RAE File (DSP RAEFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information about the Remote eAntenna Extension (RAE) files.

Note

If you query information about the weighting factor file when it is being uploaded or downloaded, the system will return a failure message or an incorrect result.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the RAE.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SUBUNITNO Subunit No.

Meaning: Indicates the number of the RAE subunit, which starts from 1.

GUI Value Range: 1~6

Unit: None

Actual Value Range: 1~6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

Example 1:To query the information about the remote eantenna extension (RAE) files with the parameters as follows: Device No.: 1, Subunit No.: 1, run the following command:
DSP RAEFILE: DEVICENO=1, SUBUNITNO=1:;
The result is shown as follows:

Output Description

Field Description

Device No.

Indicates the device number of the RAE.

Subunit No.

Indicates the number of the RAE subunit, which starts from 1.

Subunit Name

Indicates the name of the RAE subunit. The name of the RAE subunit is optional, but the name configured for each RAE subunit must be unique.

File Index

Indicates the index of the file saved on the RAE. NULL indicates that the file index fails to be obtained.

File Type

Indicates the type of the file saved on the RAE.

File Information

Indicates the information field of the file saved on the RAE.

File Name

Indicates the name of the file saved on the RAE.
