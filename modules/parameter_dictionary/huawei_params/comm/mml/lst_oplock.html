List Locking Status of Non-default Local Account (LST OPLOCK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the locking status of all the non-default local accounts.

Note

None.

Parameters

None.

Example

To query the locking status of non-default local accounts, run the following command:
LST OPLOCK:;
The result is as follows:
+++    0        2008-05-26 15:41:26
O&M    #11721
%%LST OPLOCK:;%%
RETCODE = 0  Operation succeeded.

Local Account Locked State
--------------------------
Non-default Local Users Lock Policy  =  On
(Number of results = 1)


---    END

Output Description

Field Description

Non-default Local Users Lock Policy

Indicates the status of the local non-default account switch.
