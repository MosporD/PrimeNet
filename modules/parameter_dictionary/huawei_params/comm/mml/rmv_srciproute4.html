Remove Source IPv4 Route (RMV SRCIPROUTE4)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a source IPv4 route.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Removing a source IPv4 route will invalidate the services or disconnect the O&M channel that is carried on this source IPv4 route.

Parameters

ID Name Description
SRCRTIDX Source Route Index

Meaning: Indicates the index of a source IPv4 route.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove a Source IPv4 Route with the parameters as follows: SRCRTIDX:0, run the following command:
RMV SRCIPROUTE4: SRCRTIDX=0;
