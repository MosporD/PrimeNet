List L2 LAN Switch Port (LST LSWPORT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list all configured layer 2 LAN switch ports.

Note

None.

Parameters

None.

Example

To list the information of L2 LAN switch port in the database, run the following command: 
LST LSWPORT:;
The result is shown as follows:

Output Description

Field Description

Port Index

Indicates the index of a layer 2 LAN switch port on a layer 2 LAN switch of an NE.

Port Type

Indicates the port type used by a layer 2 LAN switch port on a layer 2 LAN switch of an NE.

Ethernet Port ID

Indicates the ID of the Ethernet port corresponding to an Ethernet-type layer 2 switching port controlled by a layer 2 LAN switch.

User Label

Indicates the object descriptions of a layer 2 LAN switch port on a layer 2 LAN switch of an NE.
