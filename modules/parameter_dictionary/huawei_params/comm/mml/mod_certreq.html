Modify Certificate Request Configuration (MOD CERTREQ)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the registration information used to create the certificate request.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • When you run the REQ DEVCERT command to apply for a certificate and the file name of the certificate is empty, the additional information about the common name will be a part of the file name of the certificate. Therefore, the following special characters must not be in the additional information about the common name, otherwise, the certificate fails to be applied for: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks (""), left angle bracket (<), right angle bracket (>), bar (|).

  • Mandatory critical key usage: At least DIGITAL_SIGNATURE and KEY_ENCIPHERMENT shall be set.

Parameters

ID Name Description
COMMNAME Common Name

Meaning: Indicates the common name of the certificate request file, which can be the electronic serial number (ESN), media access control (MAC) address, or IP address of a board. If this parameter is set to MAC or IP, the RRU still uses the ESN as the common name of the certificate request file.

GUI Value Range: ESN(ESN), MAC(MAC), IP(IP)

Unit: None

Actual Value Range: ESN, MAC, IP

MML Default Value: None

Recommended Value: ESN(ESN)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
USERADDINFO Common Name Additional Info.

Meaning: Indicates the additional information about a certificate common name. The information will be added behind the value of the COMMNAME parameter to compose a complete common name for a certificate request file. The default value is .huawei.com. A space is not supported before the value of this parameter, that is, a space is not supported before the character string. However, to meet requirements of consistency checks performed by some CA servers to the certificate common name in a certificate request packet and that in a Huawei device certificate, the certificate common name in a certificate request packet is displayed as "Board ESN"+space+"Common Name Additional Info" only when the certificate common name in a Huawei device certificate is "Board ESN"+space+"Common Name Additional Info". For example, when the value of this parameter is "eNodeB" and the certificate common name in a Huawei device certificate is "ESN eNodeB", a space is automatically added before "eNodeB", that is, the certificate common name in a certificate request packet is displayed as "ESN eNodeB".

GUI Value Range: 0~32 characters

Unit: None

Actual Value Range: 0~32 characters

MML Default Value: None

Recommended Value: None

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of the USERADDINFO parameter in the CERTREQ MO must be composed of printable ASCII characters, such as upper-case letters (A to Z), lower-case letters (a to z), digits (0 to 9), left bracket ((), right bracket ()), plus sign (+), hyphens (-), full stops (.), slash (/), colon (:), and question mark (?).

FORCEEXECUTE Support Forcible Execution

Meaning: Indicates whether forcible changes to CERTREQ objects are made. When this parameter is set to YES, forcible changes to CERTREQ objects are made. When this parameter is set to NO, forcible changes to the CERTREQ objects that affect associated objects are not allowed. When forcible changes are not allowed, only the local IP address is checked.

The associated object is IKEPEER. This parameter is invalid when a WMPT, LMPT, GTMUb, or GTMUc serves as the main control board.

Pay attention to the following when setting this parameter:

1. The system checks whether forcible changes to CERTREQ objects affect associated objects based on the object configuration data instead of the actual object running status.

2. If an NE is configured with an SRCIPRT, SRCIPROUTE4, PPPLNK, or MPGRP object, the system will not check whether forcible changes to CERTREQ objects affect associated objects.

GUI Value Range: NO(No), YES(Yes)

Unit: None

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Example

To modify a certificate request file with parameters as follows: Common Name: ESN, Common Name Additional Info.: .huawei.com, Country: cn, Organization: ITEF, Organizational Unit: hw, State or Province: sc, Locality: cd, Key Usage: DATA_ENCIPHERMENT-1&DIGITAL_SIGNATURE-1&KEY_AGREEMENT-1&KEY_ENCIPHERMENT-1, Signature Algorithm: SHA256, Key Type: RSA, Key Size: KEYSIZE1024, Local Name: test, Local IP: 10.110.24.243, Local IPv6: 2001::1, Support Forcible Execution: NO, run the following command:
MOD CERTREQ: COMMNAME=ESN, USERADDINFO=".huawei.com", COUNTRY="cn", ORG="ITEF", ORGUNIT="hw", STATEPROVINCENAME="sc", LOCALITY="cd", KEYUSAGE=DATA_ENCIPHERMENT-1&DIGITAL_SIGNATURE-1&KEY_AGREEMENT-1&KEY_ENCIPHERMENT-1, SIGNALG=SHA256, KEYTYPE=RSA, KEYSIZE=KEYSIZE1024, LOCALNAME="test", LOCALIP="10.110.24.243", LOCALIP6="2001::1";
