Add UNI Link (ADD UNILNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add a UNI link.

Note

  • [Co-MPT,NodeB]Before running this command, ensure that the associated E1/T1 port does not carry links of any other type.

  • [Co-MPT,NodeB]Set the UNI link number to the number of the E1/T1 port that carries the UNI link.

  • [Co-MPT,NodeB]If an E1/T1 port uses the AMI line coding mode, the UNI link carried on the port must be scrambled.

  • [Co-MPT,NodeB]The parameter settings of the UNI link, including timeslot 16 and scrambling flags, must be identical on the BS and the BSC.

  • [Co-MPT,NodeB]The total number of IMA groups, UNI links, and fractional ATM links on a board must be smaller than or equal to the number of E1/T1 ports supported on the board.

  • [Co-MPT,NodeB]The total number of IMA links, UNI links, and fractional ATM links on a board must be smaller than or equal to the number of E1/T1 ports supported on the board.

  • [Co-MPT,NodeB]The E1/T1 timeslots used by IMA links, UNI links, fractional ATM links, and timeslot cross connections must not collide with each other.

  • [Co-MPT,NodeB]The E1/T1 port that carries a UNI link must not be associated with any port security, or SWITCH of the associated port security must be set to ENABLE.

  • [Co-MPT,NodeB]System specifications: If the WMPT/UMPT is the main control board, a maximum of 64 UNI links can be configured. If the UMDU is the main control board, a maximum of 4 UNI links can be configured.

  • [Co-MPT,NodeB]Board specifications: A maximum of 4 UNI links can be configured on a WMPT/UMPTa/UMPTb/UMDU. A maximum of 8 UNI links can be configured on a UTRP (subboard type: UAEC).

  • [Co-MPT,NodeB]When local loopback is set for the underlying bearer link, the IMA group, IMA link, UNI link, and FRAATM link succeed in the self-negotiation based on related protocols.

Example

To add a UNI link with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Link No.: 1, Scramble Mode: ENABLE, 16th Time Slot Support: DISABLE, run the following command: 
ADD UNILNK: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, UNILNKN=1, SCRAM=ENABLE, TS16=DISABLE;
