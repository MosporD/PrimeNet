Modify SASU Subunit (MOD SASUSUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to modify the configuration of a same-band antenna sharing unit (SASU) subunit.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB,eGBTS]If the system is busy, the configuration may take effect beyond the specified time, and the configuration data will be sent to the SASU later. The execution result can be checked by running the DSP SASUSUBUNIT command and querying the device running status.

  • [Co-MPT,NodeB,eGBTS]The value range of the gain supported by the SASU varies according to the SASU model. Run the DSP SASUDEVICEDATA command to query the value range of the gain supported by the SASU before configuration. If the gain supported by the SASU is a fixed value and the gain cannot be set, the gain setting fails to take effect.

  • [Co-MPT,NodeB,eGBTS]This command applies only to UMTS.

  • [Co-MPT,NodeB,eGBTS]The values of the Work Mode, GSM Gain, and UMTS Gain parameters must be consistent with the configuration plan. If inconsistent, the call drop rate will increase and the access success rate will decrease for users at the cell edge.

Example

To modify the configuration of an SASU subunit with the parameters as follows: Device No.: 0, Subunit No.: 1, Connect Port Cabinet No.: 0, Connect Port Subrack No.: 60, Connect Port Slot No.: 0, Connect Port No.: R0A, Mode: Normal, run the following command:
MOD SASUSUBUNIT: DEVICENO=0, SUBUNITNO=1, CONNCN=0, CONNSRN=60, CONNSN=0, CONNPN=R0A, MODE=NORMAL;
