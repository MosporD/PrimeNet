Remove Uplink Flow Control Para (RMV ULFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to remove the user-defined configuration of an uplink flow control algorithm. The execution of this command restores the default configuration of the algorithm.

Note

[Co-MPT,NodeB,eGBTS]This command takes effect only for UMTS.

BEAR Bear Type

Meaning: Indicates the bearer type of the physical port on which the UL flow control algorithm is configured. This parameter can be set to ATM or IP.

Disuse statement: In later versions, the value IP of this parameter will be deleted. In the current version, this value can be set and take effect when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD, and cannot be set when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: ATM(ATM), IP(IP)

Unit: None

Actual Value Range: ATM, IP

Recommended Value: If SBT is set to E1_COVERBOARD, BACK_BOARD, BASE_BOARD, or UNCHANNELLED_COVERBOARD, you are advised to set BEAR to ATM.

If SBT is set to ETH_COVERBOARD, you are advised to set to BEAR to IP.

Parameter Relationship:

-Others:

  • In the ULFLOWCTRLPARA MO, if SBT is set to E1_COVERBOARD, this parameter can be set to ATM or IP.
  • In the ULFLOWCTRLPARA MO, if SBT is set to UNCHANNELLED_COVERBOARD, this parameter must be set to ATM.
  • In the ULFLOWCTRLPARA MO, if SBT is set to ETH_COVERBOARD, this parameter must be set to IP.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U
PT Port Type

Meaning: Indicates the type of port where the UL flow control algorithm is configured.

Disuse statement: In later versions, the values LOOPINT, PPP, MPGRP, ETH, ETHTRK, and TUNNEL of this parameter will be deleted. In the current version, these values can be set and take effect when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD, and cannot be set when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: IMA(IMAGRP), UNI(UNILNK), FRAATM(FRAATM), PPP(PPP Link), MPGRP(Multi-link PPP Group), ETH(Ethernet Port), LOOPINT(Loop Interface), ETHTRK(Ethernet Trunk), TUNNEL(Tunnel), STM1(STM1)

  • In the ULFLOWCTRLPARA MO, if SBT and BEAR are set to BASE_BOARD and IP, respectively, this parameter can be set to PPP, MPGRP, ETH, LOOPINT, or ETHTRK.
  • In the ULFLOWCTRLPARA MO, if SBT and BEAR are set to BACK_BOARD and ATM, respectively, this parameter can be set to UNI or FRAATM.
  • In the ULFLOWCTRLPARA MO, if SBT and BEAR are set to BACK_BOARD and IP, respectively, this parameter can be set to PPP or TUNNEL.
  • In the ULFLOWCTRLPARA MO, if SBT and BEAR are set to E1_COVERBOARD and ATM, respectively, this parameter can be set to IMA, UNI, or FRAATM.
  • In the ULFLOWCTRLPARA MO, if SBT and BEAR are set to E1_COVERBOARD and IP, respectively, this parameter can be set to PPP or MPGRP.
  • In the ULFLOWCTRLPARA MO, if SBT and BEAR are set to UNCHANNELLED_COVERBOARD and ATM, respectively, this parameter must be set to STM1.
  • In the ULFLOWCTRLPARA MO, if SBT and BEAR are set to ETH_COVERBOARD and IP, respectively, this parameter can be set to ETH, ETHTRK, or LOOPINT.

Example

To remove the user-defined configuration of the uplink flow control algorithm with the parameters as follows: Slot No.: 0, Subboard Type: E1_COVERBOARD, Bear Type: ATM, Port Type: IMA, Port No.: 0, run the following command:
RMV ULFLOWCTRLPARA: SN=0, SBT=E1_COVERBOARD, BEAR=ATM, PT=IMA, PN=0;
