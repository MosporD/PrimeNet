Add CRL (ADD CRL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a CRL.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that the corresponding CRL file has been downloaded to the BS by running the DLD CERTFILE command.

  • System specifications: If the WMPT/UMPT/UMDU/LMPT/GTMUc is the main control board, a maximum of 20 CRLs can be configured.

  • Board specifications: A UMPT/UMDU/LMPT/GTMUc/UTRPc/UCCU/UBBPe series (except UBBPe15)/LCOP/UBBPf series/UBBPF series/UBBPg series board supports a maximum of 20 CRLs.

  • The total size of all CRL files that have been loaded must be less than 2 MB. The size of a CRL in PEM format must be less than 256 KB.

  • If the number of CRL files reaches 30, this command execution will fail. In this case, run the RMV CERTFILE command to delete the unused CRL files.

Parameters

ID Name Description
CERTNAME CRL File Name

Meaning: Indicates the file name of a CRL. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]CERTNAME in a CRL MO is recommended to enter ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: \ / : * ? " < > |.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When a CRL MO is being added, the CERTNAME is case-insensitive; but when a CRL MO is referenced, the CERTNAME is case-sensitive.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a CRL with CRL File Name: basestation.crl, run the following command:
ADD CRL: CERTNAME="basestation.crl";
