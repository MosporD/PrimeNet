Add User Plane Host to End Point Group (ADD UPHOST2EPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a user-plane host to an end point group.

Note

  • Before adding a user plane host to an endpoint group, ensure that the endpoint group added by using the ADD EPGROUP command and the user plane host added by using the ADD USERPLANEHOST command have been configured.

  • The number of user plane hosts added to an endpoint group must be equal to or less than 12, the total number of user plane hosts added to all endpoint groups must be equal to or less than 384.

  • If this command is executed, a base station will automatically set up a user-plane link with Path Type set to ANY(Any QoS).

  • During automatic setup of the user plane, a base station automatically creates a user-plane peer and a user-plane link with Path Type set to ANY(Any QoS).

  • If the following conditions are met during setup of an IPv4 user-plane link, the system will automatically configure the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects for the IPv4 user-plane link and set up an IPsec tunnel:

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the USERPLANEPEER object in the same end point group and the USERPLANEHOST object.

    - SeGW Switch is set to ENABLE(Enable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met during setup of an IPv4 user-plane link, the system will automatically configure the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects for the IPv4 user-plane link and set up an IPsec tunnel:

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the USERPLANEPEER object in the same end point group and the USERPLANEHOST object.

    - SeGW Switch is set to DISABLE(Disable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

    If IPSec Auto Configure Switch is set to DISABLE(Disable) for the USERPLANEPEER object in the same end point group and the USERPLANEHOST object, an IPsec tunnel can be set up by manually configuring all the preceding IPsec-related objects.

Example

To add a user-plane host to an end point group with the parameters as follows: End Point Group ID: 0, User Plane Host ID: 0, run the following command:
ADD UPHOST2EPGRP: EPGROUPID=0, UPHOSTID=0;
