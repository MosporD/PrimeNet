Remove Line Rate (RMV LR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove the data rate of a physical port.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the port is located.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Port Type and Port ID parameter in the PORTLR MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

  • In the LR MO, this parameter can be set to a value within the range of 0 to 5 if PT is set to ETH and SBT is set to ETH_COVERBOARD.
  • In the LR MO, this parameter can be set to a value within the range of 0 to 2 if PT is set to ETHTRK and SBT is set to ETH_COVERBOARD.
  • In the LR MO, this parameter can be set to 0 to 3 if PT is set to ETH and SBT is set to BASE_BOARD.
  • In the LR MO, this parameter can be set to 0 or 1 if PT is set to ETHTRK and SBT is set to BASE_BOARD.

Example

To remove the Line Rate with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: Base Board, Port Type: Ethernet Port, Port No.: 0, run the following command:
RMV LR: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=ETH, PN=0;
