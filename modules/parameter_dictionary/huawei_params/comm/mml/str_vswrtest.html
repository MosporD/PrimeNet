Start VSWR Test (STR VSWRTEST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to start the VSWR test on the TX channel to check whether the antenna system is properly installed. If the numbers of the cabinet, subrack, slot, and antenna port are not specified, the VSWR information of all the RRUs or RFUs are queried in batch.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Different types of RF module operate within different frequency bands. Therefore, use the frequency specified during the configuration of the cell as the frequency for the VSWR test.

  • Ensure that no operation is performed on the RRU or RFU during the test.

  • If the VSWR is greater than the value required by the engineering quality, the connection of the antenna is abnormal. In this case, you need to check the antenna connection and the ALD.

  • The VSWR queried by the DSP VSWR command is the result of the test that uses the current power of the RF module as the test power, and the VSWR test started by the STR VSWRTEST command is based on single tone and uses the maximum power of the RF unit as the test power. The precision of the two kinds of VSWR tests is different and so the test results are different.

  • The VSWR is displayed in the result of this command instead of the DSP VSWR command. The RF module uses the VSWR to determine whether to light the VSWR indicator, not to report a VSWR alarm.

  • If the start frequency and end frequency for a frequency segment are specified, the NE selects the frequencies that are supported by the TRX board from the frequency segment to perform a test. If the start frequency and end frequency are not specified, the NE selects frequencies that are supported by the TRX board from the predefined authorized downlink frequency band (which can be configured using the ADD AUTHDLFREQRANGE command) to perform a test. Specifically, the NE selects the specified frequency and frequencies with the step of 2 MHz. If the frequency is not configured, the NE selects frequencies with the step (specified in the MML interface) from the frequency band supported by the TRX board. If the authorized downlink frequency band is not configured, the NE selects frequencies that are supported by the TRX board to perform a test. However, this may cause the NE to select an unauthorized frequency to perform a test.

  • If a frequency or frequency band is not specified for the test and the message "Invalid parameter." or "Not exist usable frequency." is returned, run the LST AUTHDLFREQRANGE command to check whether the preconfigured granted downlink frequency band intersects with the frequency band supported by the TRX board.

  • After running the STP VSWRTEST command, wait for about 30 seconds, and then run the STR VSWRTEST command. Otherwise, the STR VSWRTEST command output may be displayed as NULL.

  • If Test Mode is set to SINGLE_ARFCN, only one VSWR test can be conducted at the same time. If Test Mode is set to MULTI_ARFCN, six VSWR tests can be conducted at the same time.

  • If the frequency range supported by the RF unit is greater than that supported by the antenna system componens, it is advised to configure the authorized downlink frequency band before starting the VSWR test. Otherwise, the VSWR test result may be abnormal. The components of the antenna system include antennas, feeders, jumpers, combiner-dividers, filters, tower-mounted amplifiers (TMAs) and POIs.

  • The MRIU supports only single-frequency VSWR tests and does not support multi-frequency VSWR tests.

  • [NodeB,eNodeB,gNodeB]This command is executed on the TX channels one by one, and the actual duration of the test is in direct ratio to the number of TX channels.

  • [eNodeB,gNodeB]In a multimode base station, starting a VSWR test on a multimode RF unit or on RF units of different modes that share the antenna system interrupts services of both modes. In a bases station involving the TDD mode, starting a VSWR test on certain types of RRUs does not interrupt any services. For details about these types of RRUs, see section "Checking the Voltage Standing Wave Ratio" in eNodeB Routine Maintenance Guide.

  • [NodeB]For the UMTS, if the queried RRU software version by DSP BRDVER is XX.XXX.01.XXX, you must specify the test frequency and relative power for the VSWR test.

  • [NodeB]In a multi-mode base station, starting a VSWR test on a multi-mode RF unit or on RF units of different modes that share the antenna system interrupts services of both modes.

Output Description

Field Description

BS Name

Indicates the name of the site.

Sector No.

Indicates the number of the sector. If sectors are not configured, the value of this parameter is NULL.

Cabinet No.

Indicates the cabinet number of the RRU or RFU where the TX channel is located.

Subrack No.

Indicates the subrack number of the RRU or RFU where the TX channel is located.

Slot No.

Indicates the slot number of the RRU or RFU where the TX channel is located.

TX Channel No.

Indicates the number of the TX channel of the RRU or RFU.

Txbranch Frequency(0.1MHz)

Indicates the test frequency. Different types of RRUs or RFUs support different frequency ranges. Therefore, the frequency of the cell is used as the VSWR test frequency. The default test frequency of an RRU is 65535.

VSWR(0.01)

Indicates the current VSWR of the TX channel. When the TX power is relatively low , the S/N of the reflected signal passing through the detector channel is relatively low, which leads to the inaccuracy of the VSWR calculation, the value of this field will be displayed as NULL.

Test Result

Indicates whether the voltage standing wave ratio (VSWR) test succeeds or fails. If the VSWR test fails, a failure cause is displayed.
