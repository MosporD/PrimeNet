Add IP General Performance Management (ADD IPGPM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add the IP general performance management (GPM) detection.

Note

  • [Co-MPT,NodeB]If the delay detection method is set to FPDT for the IPGPM detection, the transmission resource group enabled with the uplink IPGPM detection requires that HSUPA interactive or background services be performed, and the transmission resource group enabled with the downlink IPGPM detection requires that any one of the following HSDPA services be performed: interactive, background, and streaming services.

  • [Co-MPT,NodeB]If IPGPM is enabled for a base station, PPPMUX cannot be enabled on the base station side or controller side.

  • [Co-MPT,NodeB]If IPGPM is enabled for a base station, the timer for IPMUX must be less than or equal to 1 ms on the base station side and controller side.

  • [Co-MPT,NodeB]The port type of the transmission resource group detected by the IPGPM must be set to the same port type with the user-plane bearer.

  • [Co-MPT,NodeB]When the port type is loopback, the IP transmission resource group detected by the IPGPM is the default transmission resource group on the actual physical port corresponding to the loopback port.

  • [Co-MPT,NodeB]System specifications: When a WMPT/UMPT/UMDU serves as the main control board, a maximum of 20 IPGPM objects can be configured on the base station.

  • [Co-MPT,NodeB]Board specifications: A maximum of 20 IPGPM objects can be configured on a WMPT/UMPT/UMDU/UTRPc/UTRP (subboard type: UEOC/UQEC/UIEC/UAEC).

Example

To add an IP General Performance Management with the parameters as follows: IP GPM Detection ID: 0, Detection Direction: UP, Delay Detection Method: FPDT, Detection Object: IPRSCGRP, Port Type: OTHER, IP Transmission Resource Group ID: 0, run the following command:
ADD IPGPM: IPGPMID=0, DIR=UP, DDM=FPDT, DETECTOBJECT=IPRSCGRP, PT=OTHER, IPRSCGRPID=0;
