Modify DTLS Configuration Policy (MOD DTLSPOLICY)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify a DTLS configuration policy.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eGBTS,gNodeB]This command applies only to the UMPTe/UMPTg/UMPTga board.

  • [Co-MPT,eGBTS,gNodeB]Before changing the cipher suite, ensure that the peer end supports the desired cipher suite. Otherwise, the negotiation may fail.

Parameters

ID Name Description
DTLSPOLICYID DTLS Policy ID

Meaning: Indicates the sequence number of a DTLS configuration policy.

GUI Value Range: 0(0)

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, N
CIPHERSUITE Cipher Suite

Meaning: Indicates a DTLS cipher suite.

GUI Value Range: ECDHE_ECDSA_GCM256_SHA384(ECDHE_ECDSA_AES_256_GCM_SHA384), ECDHE_RSA_GCM256_SHA384(ECDHE_RSA_AES_256_GCM_SHA384), DHE_RSA_GCM256_SHA384(DHE_RSA_AES_256_GCM_SHA384), ECDHE_ECDSA_CHACHA20_SHA256(ECDHE_ECDSA_CHACHA20_POLY1305_SHA256), ECDHE_RSA_CHACHA20_SHA256(ECDHE_RSA_CHACHA20_POLY1305_SHA256), DHE_RSA_CHACHA20_SHA256(DHE_RSA_CHACHA20_POLY1305_SHA256), ECDHE_ECDSA_GCM128_SHA256(ECDHE_ECDSA_AES_128_GCM_SHA256), ECDHE_RSA_GCM128_SHA256(ECDHE_RSA_AES_128_GCM_SHA256), DHE_RSA_GCM128_SHA256(DHE_RSA_AES_128_GCM_SHA256)

Unit: None

Actual Value Range: ECDHE_ECDSA_GCM256_SHA384, ECDHE_RSA_GCM256_SHA384, DHE_RSA_GCM256_SHA384, ECDHE_ECDSA_CHACHA20_SHA256, ECDHE_RSA_CHACHA20_SHA256, DHE_RSA_CHACHA20_SHA256, ECDHE_ECDSA_GCM128_SHA256, ECDHE_RSA_GCM128_SHA256, DHE_RSA_GCM128_SHA256

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, gNodeB]ECDHE_RSA_AES_256_GCM_SHA384 of CIPHERSUITE in a DTLSPOLICY MO must not be disabled.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, N

Example

To modify a DTLS configuration policy with the parameters as follows: DTLS Policy ID: 0, Cipher Suite: the encryption algorithm set only supports ECDHE_RSA_AES_256_GCM_SHA384, run the following command:
MOD DTLSPOLICY: DTLSPOLICYID=0, CIPHERSUITE=ECDHE_ECDSA_GCM256_SHA384-0&ECDHE_RSA_GCM256_SHA384-1&DHE_RSA_GCM256_SHA384-0&ECDHE_ECDSA_CHACHA20_SHA256-0&ECDHE_RSA_CHACHA20_SHA256-0&DHE_RSA_CHACHA20_SHA256-0&ECDHE_ECDSA_GCM128_SHA256-0&ECDHE_RSA_GCM128_SHA256-0&DHE_RSA_GCM128_SHA256-0;
