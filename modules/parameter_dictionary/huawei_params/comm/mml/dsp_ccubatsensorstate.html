Display CCU Battery Sensor Information (DSP CCUBATSENSORSTATE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about the battery sensor to which a CCU is connected.

Note

Dynamic information updating of a battery sensor takes about 10 minutes.

Example

To query the information about the battery sensor to which a CCU is connected in cabinet 0, run the following command:
DSP CCUBATSENSORSTATE: CN=0;         
The result is shown as follows:

Output Description

Field Description

Logical No.

Indicates the logical number of the battery sensor to which a CCU is connected.

Type

Indicates the type of the battery sensor to which a CCU is connected. eBAT is a cell status monitoring unit. eBOX is a radio access unit.

Bar Code

Indicates the bar code of the battery sensor to which a CCU is connected.

Inner Resistance(0.1mΩ)

Indicates the internal resistance of the battery monitored by the eBAT to which a CCU is connected. This parameter is invalid for the eBOX.

Voltage(0.1V)

Indicates the voltage of the battery monitored by the eBAT to which a CCU is connected. This parameter is invalid for the eBOX.
