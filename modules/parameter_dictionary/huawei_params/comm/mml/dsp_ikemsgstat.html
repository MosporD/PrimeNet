Display IKE Message Statistics (DSP IKEMSGSTAT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query statistics on Internet Key Exchange (IKE) messages.

Note

[NodeB]The WMPT does not support this function.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where an IKE SA is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SRN Subrack No.

Meaning: Indicates the subrack number of the board where an IKE SA is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SN Slot No.

Meaning: Indicates the slot number of the board where an IKE SA is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query statistics on IKE messages with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, run the following command: 
DSP IKEMSGSTAT: CN=0, SRN=0, SN=6;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where an IKE SA is located.

Subrack No.

Indicates the subrack number of the board where an IKE SA is located.

Slot No.

Indicates the slot number of the board where an IKE SA is located.

Number of Received IKE Messages

Indicates the number of received IKE messages.

Number of Sent IKE Messages

Indicates the number of sent IKE messages.

Number of Successful Rekeys in IKEv1 Phase 1

Indicates the number of keys that are successfully reapplied for in IKEv1 phase 1.

Number of Successful Rekeys in IKEv1 Phase 2

Indicates the number of keys that are successfully reapplied for in IKEv1 phase 2.

Number of Exchange Timeouts in IKEv1 Phase 1

Indicates the number of exchange timeouts in IKEv1 phase 1.

Number of Exchange Timeouts in IKEv1 Phase 2

Indicates the number of exchange timeouts in IKEv1 phase 2.

Number of Soft Timeouts in IKEv1 Phase 2

Indicates the number of soft timeouts in IKEv1 phase 2. Soft timeout indicates the key that is re-applied for is not completely configured.

Number of Hard Timeouts in IKEv1 Phase 2

Indicates the number of hard timeouts in IKEv1 phase 2. Hard timeout indicates that the new key has been configured but renegotiation is not completed when the life cycle of an SA ends.

Number of Soft Timeouts in IKEv1 Phase 2 Without SA

Indicates the number of soft timeouts in IKEv1 phase 2 because the corresponding SA cannot be found locally.

Number of Hard Timeouts in IKEv1 Phase 2 Without SA

Indicates the number of hard timeouts in IKEv1 phase 2 because the corresponding SA cannot be found locally.

Number of Keys Successfully Re-applied for by IKEv2 SA

Indicates the number of keys that are successfully re-applied for by an IKEv2 SA.

Number of Keys Successfully Re-applied for by IKEv2 Child SA

Indicates the number of keys successfully re-applied for by an IKEv2 child SA.

Number of Failures in Re-applying for Keys by IKEv2 SA

Indicates the number of failures in re-applying for keys by an IKEv2 SA.

Number of Failures in Re-applying for Keys by IKEv2 Child SA

Indicates the number of failures in re-applying for keys by an IKEv2 child SA.

Number of IKEv2 Authentication Timeouts

Indicates the number of child IKEv2 authentication timeouts.

Number of IPSec Packets Allowed to Be Received by IKE

Indicates the number of IPSec packets allowed to be received by IKE.

Number of IPSec Packets Allowed to Be Discarded by IKE

Indicates the number of IPSec packets allowed to be discarded by IKE.

Number of Expired IPSec Packets Received by IKE

Indicates the number of expired IPSec packets received by IKE.

Number of Expired IPSec Packets Discarded by IKE

Indicates the number of expired IPSec packets discarded by IKE.

Number of Replaced SAs

Indicates the number of replaced SAs.

Number of Half-Opened IKEv2 Request Connections

Indicates the number of half-opened IKEv2 connections requested.

Number of Half-Opened IKEv2 Response Connections

Indicates the number of half-opened IKEv2 response connections.

Number of Requested IKEv2 Re-authentications

Indicates the number of requested IKEv2 re-authentications.

Number of Successful IKEv2 Re-authentications

Indicates the number of successful IKEv2 re-authentications.

Number of IKEv2 Re-authentications Discarded due to Invalid SA

Indicates the number of IKEv2 re-authentications discarded due to invalid SA.

Number of IKEv2 Re-authentications Discarded due to Absence of Child SA

Indicates the number of IKEv2 re-authentications discarded due to absence of child SA.

Number of IKEv2 Hard Re-authentications

Indicates the number of IKEv2 hard re-authentications.

Number of Remote Authentication Mismatches

Indicates the number of remote authentication mismatches.

Number of IKEv2 SA Soft Timeouts

Indicates the number of IKEv2 SA soft timeouts.

Number of IKEv2 SA Hard Timeouts

Indicates the number of IKEv2 SA hard timeouts.

Number of Soft Timeouts in IKEv2 Phase 2 Without SA

Indicates the number of soft timeouts in IKEv2 phase 2 because the corresponding SA cannot be found locally.

Number of Hard Timeouts in IKEv2 Phase 2 Without SA

Indicates the number of hard timeouts in IKEv2 phase 2 because the corresponding SA cannot be found locally.

Number of Temporary SAs Removed by IKEv1

Indicates the number of temporary SAs removed by IKEv1.

Number of IKEv1 DPD Triggers

Indicates the number of timeouts experienced by a dead peer detection (DPD) when the IKEv1 SA negotiation succeeds in the first phase and fails in the second phase.

Number of IKEv2 DPD Triggers

Indicates the number of timeouts experienced by a dead peer detection (DPD) when the IKEv2 SA negotiation succeeds in the first phase and fails in the second phase.

Number of Incoming Keys Removed by IKE

Indicates the number of incoming keys removed by IKE.

Number of Outgoing Keys Removed by IKE

Indicates the number of outgoing keys removed by IKE.

Number of IKE DPD Failed Session

Indicates the number of timeouts experienced by a DPD when the IKE SA negotiation succeeds in the second phase.

Number of Failures in IKEv2 Redirects

Indicates the number of failed IKEv2 redirections. When the peer end sends incorrect redirection packets, or when the base station fails the SA negotiation with the new redirection peer end in the first phase even though the peer end sends correct redirection packets, the redirection fails.

Number of Successful IKEv2 Redirects

Indicates the number of successful IKEv2 redirections. When the peer end sends redirection packets to the base station and the base station succeeds in the SA negotiation with the new redirection peer end in the first phase, the redirection succeeds.

Number of Denied IKEv2 Redirects

Indicates the number of IKEv2 redirections without response. When the number of redirections received by an IKEPEER MO in 300 consecutive seconds exceeds the allowed maximum number (can be set by running the SET IPGUARD command), the IKEPEER MO discards the received redirection packets without response.
