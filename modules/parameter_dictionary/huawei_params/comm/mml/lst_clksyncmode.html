List Clock Synchronization Mode (LST CLKSYNCMODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the clock synchronization mode of a BS, the GSM frame bit offset, the GSM Frame Sync Switch, the frame synchronization switch, the locked system clock source, the Enhanced SYSCLK Failure Check Switch, the low-precision frame No. synchronization switch and the Major Standard Change Optimization Switch.

Note

None.

Parameters

None.

Example

To list the clock synchronization mode, run the following command:
LST CLKSYNCMODE:;
The result is shown as follows:
+++    huawei        2019-10-22 12:41:13
O&M    #806358737
%%LST CLKSYNCMODE:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Clock Synchronization Mode

Indicates the clock synchronization mode of a BS, which can be frequency synchronization or time synchronization.

Loose Time Synchronization

Indicates whether to enable the loose time synchronization function. This function provides low-precision time synchronization for a base station. If this function is enabled, loose time synchronization is supported. If this function is disabled, loose time synchronization is not supported.

GSM Frame Bit Offset(1/8bit)

Indicates GSM frame bit offset. This parameter applies to GSM only.

Frame Sync Switch

Indicates the frame synchronization switch. This switch applies to the Cloud BB that works in frequency synchronization mode. In addition, it can be set to on only for an NE that connects to the clock source indirectly to realize frame synchronization between this NE and the upper-level NE.

Locked System Clock Source

Indicates the locked system clock source, which is obtained from the local standard clock or interconnection system clock. The local standard clock is a clock synchronized with the reference clock of the local NE or multimode base station. The interconnection system clock is the standard clock obtained from the interconnection port.

GSM Frame Sync Switch

Indicates the GSM frame synchronization switch. This parameter controls the GSM adjustment frame number and frame phase. In addition, this parameter is valid only for GSM NEs.

Enhanced SYSCLK Failure Check Switch

Indicates whether the enhanced system clock failure check is enabled. If this parameter is set to ON, the enhanced system clock failure check is enabled.

Low Precision Frame No. Synchronization Switch

Indicates the switch of low-precision frame No. synchronization. When this switch is turned on, the frame No. synchronization function is enabled, and the SFN and HSFN are automatically aligned after the system clock is locked. When this switch is turned off, the frame No. synchronization function is disabled. This switch applies to NB-IoT and eDRX.

Major Standard Change Optimization Switch

Indicates whether to optimize the major standard change mechanism. The major standard change mechanism is optimized only if this parameter is set to ON. The parameter is valid if a GL separate-MPT base station uses time synchronization and GSM and LTE are deployed in the same BBU.

Holding Duration

Indicates the holding duration of the system clock of the base station. This parameter is valid only when the reference source is SYNCETH+IPCLK and the synchronization mode is time synchronization. Only NR and LTE TDD support this function.

Phase Deviation Alarm Threshold(ns)

Indicates the alarm reporting threshold for multi-source phase difference detection. If this parameter is set to a small value, alarms may be reported frequently.
