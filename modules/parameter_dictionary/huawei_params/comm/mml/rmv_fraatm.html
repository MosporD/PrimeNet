Remove FRAATM Link (RMV FRAATM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to remove a fractional ATM link.

Note

[Co-MPT,NodeB]Running this command interrupts services carried on the fractional ATM link.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the FRAATM link is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
SRN Subrack No.

Meaning: Indicates the subrack number of the board where the FRAATM link is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
SN Slot No.

Meaning: Indicates the slot number of the board where the FRAATM link is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
SBT Subboard Type

Meaning: Indicates the type of sub-board on the board where the FRAATM link is located.

GUI Value Range: E1_COVERBOARD(E1 Cover Board), BASE_BOARD(Base Board), BACK_BOARD(Back Board)

Unit: None

Actual Value Range: E1_COVERBOARD, BASE_BOARD, BACK_BOARD

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB]In the FRAATM MO, if SN is within the range from 0 to 5, this parameter must be set to E1_COVERBOARD.
  • In the FRAATM MO, if SN is set to 6 or 7, this parameter can be set to BASE_BOARD or BACK_BOARD.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
FRAATM Link No.

Meaning: Indicates the number of the fractional ATM link.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB]In the FRAATM MO, if SBT is set to E1_COVERBOARD, the value range of this parameter is from 0 to 7.
  • In the FRAATM MO, if SBT is set to BASE_BOARD or BACK_BOARD, the value range of this parameter is from 0 to 3.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To remove a fractional ATM link with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Link No.: 3, run the following command: 
RMV FRAATM: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, FRAATM=3;
