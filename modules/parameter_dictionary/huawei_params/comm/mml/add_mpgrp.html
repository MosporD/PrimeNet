Add MLPPP Group (ADD MPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to add a Multi-link PPP (MLPPP) group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB,eGBTS,eNodeB]If an error message indicating an IP address conflict is displayed, query the existing IP address that conflicts with the IP address by running the following commands as required: LST DEVIP, DSP DEVIP, LST IPADDR4, DSP IPADDR4, LST OMCH, DSP OMCH, LST PPPLNK, DSP PPPLNK, LST LOCALIP, DSP LOCALIP, LST MPGRP, and DSP MPGRP. Then, manually resolve the IP address conflict. The conflicting IP address might be a device IP address, an IPv4 address, local IP address of the remote maintenance channel, local IP address of a PPP link, local IP address, and local IP address of an MLPPP group.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If the locally configured PEERIP parameter is inconsistent with LOCALIP configured at the peer end, the MLPPP negotiation fails.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If both the local and peer IP addresses of the MLPPP group are set to 0.0.0.0 at the local BS, ensure that neither of the local and peer IP addresses is set to 0.0.0.0 at the peer end. Otherwise, negotiation fails.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If the local IP address of the MLPPP group is set to 0.0.0.0 at the local BS, ensure that in the same routing domain the peer IP address of the MLPPP group at the peer end is different from any device IP address or IPv4 address on the board where the local MLPPP group is located. Otherwise, the negotiation will fail.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If AUTH for the MLPPP group is set to PAP or CHAP, the BS can be regarded only as the authenticated party.

  • [Co-MPT,NodeB,eGBTS,eNodeB]System specifications: If the LMPT/UMPT/WMPT/UMDU/GTMUb/GTMUc is the main control board, a maximum of 32 MLPPP groups can be configured.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Board specifications: WMPT/UMPTa/UMPTb/UMDU/UTRP board (subboard type: UIEC/UAEC) supports a maximum of four MLPPP groups. The GTMUb/GTMUc board supports a maximum of two MLPPP groups, and the group number of the MLPPP group on the GTMUb/GTMUc board can only be 0 or 1.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When an MPGRP MO is added on the MAE-Deployment, its adaptive port transmission resource group is automatically created. The bandwidth-related parameters of the transmission resource group follow the default values.

  • [Co-MPT,eGBTS]In the GTMUb, IP packet fragmentation and reassembly are not supported. Ensure that the MRU value is correctly configured.

  • [Co-MPT,eGBTS]In the GTMUb/GTMUc evolution scenario, the MLPPP group that contains cross-board MP links must be configured on the UMPT board.

  • [Co-MPT,eGBTS]In the GTMUb/GTMUc, PPPMUX is not supported.

  • [eNodeB]If the main control board is an LMPT, an MLPPP link can be successfully configured but cannot take effect.

LOCALIP Local IP

Meaning: Indicates the local IP address. If this parameter is set to 0.0.0.0, this IP address needs to be negotiated. If this parameter is not set to 0.0.0.0, it must be set to a valid IP address of class A, B, or C but must not be the reserved address 0.x.x.x or 127.x.x.x.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: 0.0.0.0

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]LOCALIP in an MPGRP MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to the reserved IP addresses 0.x.x.x or 127.x.x.x but can be set to 0.0.0.0.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In the MPGRP MO, IPMASK cannot be all 0 if LOCALIP is not all 0.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In the MPGRP MO, IPMASK must be all 0 if LOCALIP is all 0.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In an MPGRP MO, neither the network ID nor the host ID can be all 0 or 1 in the logical operation result of LOCALIP and IPMASK.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In an MPGRP MO, LOCALIP must be different from PEERIP.

Impact on Radio Network Performance: None

Example

To add an MLPPP group with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Subboard Type: BASE_BOARD, Port ID: 0, Authentication Type: NONAUTH, Local IP: 10.10.10.10, Mask: 255.255.255.0, PPPMUX: DISABLE, Multi-Class PPP: ENABLE, MP/MC Header Option: LONG, run the following command: 
ADD MPGRP: CN=0, SRN=0, SN=7, SBT=BASE_BOARD, PORTID=0, AUTH=NONAUTH, LOCALIP="10.10.10.10", IPMASK="255.255.255.0", MUXCP=DISABLE, MCPPP=ENABLE, MHO=LONG;
