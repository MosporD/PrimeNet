List SNMP Community (LST SNMPCOMMUNITY)

Network Element: BTS3900, BTS5900

Function

Use this command to query an SNMP community name.

Note

[Co-MPT]This command is supported only when the subrack type is DCU3911 or DCU5900.

Parameters

ID Name Description
COMMUNITYINDEX Community Index

Meaning: Indicates the index of an SNMP community.

GUI Value Range: 0~3

Unit: None

Actual Value Range: 0~3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To query SNMP community name configuration in the database, run the following command:
LST SNMPCOMMUNITY:;
The result is shown as follows:
+++    0        2019-07-05 09:36:16
TRAFFIC    #1746
%%LST SNMPCOMMUNITY:;%%
RETCODE = 0  Operation succeeded.

List SNMP Community
-------------------
Community Index  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Community Index

Indicates the index of an SNMP community.
