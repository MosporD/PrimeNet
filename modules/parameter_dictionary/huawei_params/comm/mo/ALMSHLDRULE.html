ALMSHLDRULE

Description

The alarm shielding rule model is used to manage configurations of an alarm shielding rule. An NE can shield alarms according to the rule.

Effective Scenario

Immediately

Relations Between MOs

None

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD ALMSHLDRULE

Use this command to add an alarm shielding rule to shield specified alarms.
LST ALMSHLDRULE

Use this command to query an alarm shielding rule.
MOD ALMSHLDRULE

Use this command to modify an alarm shielding rule.
RMV ALMSHLDRULE

Use this command to remove an alarm shielding rule.
