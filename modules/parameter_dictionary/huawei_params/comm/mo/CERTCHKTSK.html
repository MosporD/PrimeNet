CERTCHKTSK

TRANSPORT
  +-CERTCHKTSK

Description

The CERTCHKTSK MO defines a certificate validity checking task, in which a BS periodically checks whether activated device certificates are valid. If an activated device certificate has expired or is about to expire, the BS automatically updates the certificate by using proxy or Certificate Management Protocol (CMP).

Effective Scenario

Not involved

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Certificate Validity Period Checking

Indicates whether a task of certificate validity checking is started.
Checking Period

Indicates the interval between certificate validity checking tasks.
Alarm Threshold

Indicates the threshold for a certificate expiration alarm. If the base station detects that the interval between its current time and the expiration date of an activated device certificate is shorter than the threshold, an Imminent Certificate Expiry alarm is reported.
Update Method

Indicates the method for updating a certificate that has expired or is about to expire. There are three methods: PROXY, CMP and MANUAL. If the PROXY method is used, the BS uses the MAE as the proxy to update the certificate from the Certificate Authority (CA). If the CMP method is used, the BS directly updates the certificate from the CA. If the MANUAL method is used, the certificate needs to be updated manually instead of automatically.
Automatic Certificate Reapplication Switch

Indicates whether automatic certificate application is supported during a certificate server switchover. If this switch is turned on, the base station automatically applies for a certificate when detecting a certificate server switchover in the case of site deployment or IKE negotiation failure.
Preconfigured Certificate Expire Threshold

Indicates the threshold for the preconfigured certificate to expire. When the interval between the expiration time of a preconfigured device certificate in use and the current time of the base station is less than the threshold, the base station reports an alarm indicating that the certificate is about to expire.
Preconfigured Certificate Verification Switch

Indicates whether to perform a validity check on a Huawei preconfigured certificate. For example, check whether a preconfigured certificate is about to expire, has expired, is damaged, or is lost, and whether the certificate on an RRU is about to expire. When this parameter is set to OFF, the system does not check the validity of a preconfigured certificate. The system does not report an alarm indicating that a preconfigured certificate is about to expire or has expired even if the preconfigured certificate is about to expire or has expire. If an alarm indicating that a preconfigured certificate is about to expire or has expired already exists, the system automatically clears the alarm. When this parameter is set to ON, verification is required. When the threshold is reached, an alarm indicating that a preconfigured certificate is about to expire or has expired is reported.
