ACL6

TRANSPORT
  +-ACL6
    +-ACLRULE6[0~584]

Description

An access control list 6 (ACL6) is an instruction list for ports on routers and switches in IPv6 networks. The list is used to control packets received or transmitted on ports. Applicable to all router protocols, an ACL contains matching relationships, conditions, and query commands. The ACL framework is aimed at access control.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT

  • Possible children:

    ACLRULE6[0~584]
  • Relation with the MDU MO:
    • [Co-MPT, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, the ACL6 MO cannot be configured.
  • Relation with the IPSECPOLICY and ACL MOs:
    • [Co-MPT, eNodeB, gNodeB]If ACLTYPE in an IPSECPOLICY MO is set to IPV4+IPV6, the ACL and ACL6 MOs referenced by the IPSECPOLICY MO must have been configured.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the ACL6 MO cannot be configured.
  • Relation with the IPSECPOLICY MO:
    • [Co-MPT, eNodeB, gNodeB]The ACL6 MO corresponding to an IPSECPOLICY MO with ACLTYPE set to IPV6 must have been configured.
    • [Co-MPT, eNodeB, gNodeB]CTRLMODE in the IPSECPOLICY MO must be set to the same value as CTRLMODE in the corresponding ACL6 MO.
  • Relation with the ACL6 MO:
    • [Co-MPT, eNodeB, gNodeB]On a BS, the total number of ACL MOs and ACL6 MOs must be less than or equal to 584.
    • [Co-MPT, eNodeB, gNodeB]The number of ACL6 MOs with CTRLMODE set to MANUAL_MODE cannot exceed 188.
  • Relation with the PACKETFILTERING MO:
    • [Co-MPT, eNodeB, gNodeB]If FM in a PACKETFILTERING MO is set to ADV_ACL, and ACLTYPE in a PACKETFILTERING MO is set to IPV6, the ACL6 MO corresponding to ACLID must have been configured.
    • [Co-MPT, eNodeB, gNodeB]The ACL6 MOs corresponding to ACLID in the PACKETFILTERING MO must be configured manually.
  • Relation with the IPSECPOLICY and ACLRULE6 MOs:
    • [Co-MPT, eNodeB, gNodeB]If an ACL6 MO is referenced by an IPSECPOLICY MO with ACLTYPE set to IPV6, the ACL6 MO does not allow two ACLRULE6 MOs with the same SIP, SPFXLEN, DIP, and DPFXLEN values and with the protocol types being inclusive of each other. That is, if an ACLRULE6 MO with the protocol type being IPv6 has been configured, no ACLRULE6 MO with the protocol type being TCP, UDP, ICMP6, or SCTP can be configured.
    • [Co-MPT, eNodeB, gNodeB]If an ACL6 MO is referenced by an IPSECPOLICY MO with ACLTYPE set to IPV4+IPV6, the ACL6 MO does not allow two ACLRULE6 MOs with the same SIP, SPFXLEN, DIP, and DPFXLEN values and with the protocol types being inclusive of each other. That is, if an ACLRULE6 MO with the protocol type being IPv6 has been configured, no ACLRULE6 MO with the protocol type being TCP, UDP, ICMP6, or SCTP can be configured.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of ACL6 MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IPv6 ACL ID

Indicates the ID of the IPv6 ACL to which an IPv6 ACL rule belongs. An IPv6 ACL rule with an ACL ID ranging from 3000 to 3999 indicates a high-level rule based on the layer 3 and layer 4 information configured by users. An IPv6 ACL rule with an ACL ID ranging from 7000 to 7999 indicates a high-level rule based on the layer 3 and layer 4 information configured by the system.

Indicates the brief description of an IPv6 ACL.
Control Mode

Indicates whether an object can be modified or deleted by the system. The value MANUAL_MODE means that only users can modify or delete the object. The value AUTO_MODE means only the system can modify or delete the object.
Auto Config Flag

Indicates whether an object is created by the system. The value MANUAL_CREATED means that the object is manually configured by a user. The value AUTO_CREATED means that the object is created by the system.
