PORTPOLICY

EQUIPMENT
  +-PORTPOLICY

Description

This MO indicates the access security policy of a physical port. When the PORT ACCESS SECURITY POLICY parameter is set to DISABLE, all ports of the corresponding type are disabled but the flag configuration of each port remains unchanged. When the PORT ACCESS SECURITY POLICY parameter is set to ENABLE, the flag configuration of each port prevails.
