SECTOREQM

EQUIPMENT
  +-CARRIERRESOURCE
    +-SECTOREQM

Description

A SECTOREQM MO consists of parameters related to a set of RF antennas that can transmit or receive signals. This set of antennas must belong to the same sector.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CARRIERRESOURCE
  • Relation with the SECTOR MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The SECTOR MO corresponding to the SECTOREQM MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]An antenna in the sector equipment must exist in the sector that is quoted by the sector equipment.
  • Relation with the SECTOREQM MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the sector equipment is configured with a slave antenna, it must be configured with only one master antenna and one slave antenna.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The cabinet number, subrack number, slot number, and channel number of any two antennas in a set of sector equipment cannot be the same at the same time.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When ANTCFGMODE is set to ANTENNAPORT, at least one sector equipment antenna must be configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the ANTCFGMODE parameter in a SECTOREQM MO is set to BEAM, antennas cannot be configured in this SECTOREQM MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The total number of sector equipment antennas in all the sector equipment of a base station must be less than or equal to 1920.
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the antenna of pair of RRU/RFUs for RF intra interconnection is configured in sector equipment, the sector equipment can contain two antennas at most.
  • Relation with the RRU, RRUCHAIN, CXU, RFU, and AAMU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If sector equipment antennas are distributed on multiple radio frequency units, these radio frequency units can neither be configured on different branches of trunk chains, nor be configured in hybrid networking modes including the branches of trunk chain.
  • Relation with the MPT and NODE MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The base station can support a maximum of 480 sets of sector equipment when it is configured with the UMPTa/b board.
    • [Co-MPT, NodeB, eGBTS, eNodeB]The base station can support a maximum of 960 sector equipment antennas when it is configured with the UMPTa/b board.
  • Relation with the MPT, GTMU, and NODE MOs:
    • [Co-MPT, eGBTS]A DBS3900, BTS3900, BTS3900A, BTS3900L, or BTS3900AL working in non-concurrent multiple modes supports a maximum of 24 sets of sector equipment when it is configured with the GTMU board(the specification is configured as GTMUb) but not the UMPT board.
    • [Co-MPT, eGBTS]A DBS3900, BTS3900, BTS3900A, BTS3900L, or BTS3900AL working in non-concurrent multiple modes supports a maximum of 120 sector equipment antennas when it is configured with the GTMU board(the specification is configured as GTMUb) but not the UMPT board.
    • [Co-MPT, eGBTS]A DBS3900, BTS3900, BTS3900A, BTS3900L, or BTS3900AL working in non-concurrent multiple modes supports a maximum of 108 sets of sector equipment when it is configured with the GTMU board(the specification is not configured as GTMUb) but not the UMPT board.
    • [Co-MPT, eGBTS]A DBS3900, BTS3900, BTS3900A, BTS3900L, or BTS3900AL working in non-concurrent multiple modes supports a maximum of 288 sector equipment antennas when it is configured with the GTMU board(the specification is not configured as GTMUb) but not the UMPT board.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SECTOREQM

Use this command to add sector equipment and sector equipment antennas.
LST SECTOREQM

Use this command to list the configuration of sector equipment.
MOD SECTOREQM

Use this command to add or remove sector equipment antennas in sector equipment.
RMV SECTOREQM

Use this command to remove sector equipment.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Sector Equipment ID

Indicates the number of the sector equipment.
Sector ID

Indicates the number of the sector in which the sector equipment is located.
Sector Equipment Antenna

Indicates the information about the sector equipment antenna.
Antenna Config Mode

Indicates the antenna configuration mode of sector equipment. If this parameter is set to ANTENNAPORT, the antenna port list must be configured. If this parameter is set to BEAM, RRU and beamforming parameters must be configured.
RRU Cabinet No.

Indicates the cabinet number of the RRU corresponding to the sector equipment when ANTCFGMODE of the sector equipment is set to BEAM.
RRU Subrack No.

Indicates the subrack number of the RRU corresponding to the sector equipment when ANTCFGMODE of the sector equipment is set to BEAM.
RRU Slot No.

Indicates the slot number of the RRU corresponding to the sector equipment when ANTCFGMODE of the sector equipment is set to BEAM.
Beam Shape

Indicates the beam coverage shape of sector equipment, specified by the expanding angle of a sector.
Beam Layer Split

Indicates the vertical beam split. If this parameter is set to None, the vertical coverage area is not split. If this parameter is set to INNER_LAYER, the inner sector is covered after a beam layer split. If this parameter is set to OUTER_LAYER, the outer sector is covered after a beam layer split.
Beam Azimuth Offset

Indicates the azimuth offset of the main lobe direction of horizontal beam coverage and the RF module direction. If this parameter is set to None, the main lobe of beams and RF module are in the same direction. If this parameter is set to LEFT_HALF, the azimuth deflects 1/2 sector angle counterclockwise. If this parameter is set to RIGHT_HALF, the azimuth deflects 1/2 sector angle clockwise. For example, the horizontal azimuth deflects 60° counterclockwise with BEAMSHAPE set to SEC_120DEG and BEAMAZIMUTHOFFSET set to LEFT_HALF.
