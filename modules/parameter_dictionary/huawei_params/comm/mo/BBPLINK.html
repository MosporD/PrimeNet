BBPLINK

EQUIPMENT
  +-BBPLINK

Description

The BBPLINK MO manages the interconnection links between the interconnected baseband processing boards of BBUs. The bladebbu does not support this configuration.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT
  • Relation with the BBP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The BBP MO corresponding to HCN, HSRN, HSN, and HPN in the BBPLINK MO or the BBP MO corresponding to TCN, TSRN, TSN, and TPN in the BBPLINK MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Between two BBU subracks, there can be only one BBPLINK MO for which both the following BBP MOs are configured: the BBP MO corresponding to HCN, HSRN, HSN, and HPN, and the BBP MO corresponding to TCN, TSRN, TSN, and TPN.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the BBP MO that meets either of the following conditions, TYPE cannot be set to LCOP :
    • - Corresponds to the board specified by HCN, HSRN, HSN, and HPN in the BBPLINK MO.
    • - Corresponds to the board specified by TCN, TSRN, TSN, and TPN in the BBPLINK MO.
  • Relation with the BBPLINK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The combination of HCN, HSRN, HSN, and HPN in the BBPLINK MO cannot be the same as that of configured HCN, HSRN, HSN, and HPN in the BBPLINK MO. The combination of TCN, TSRN, TSN, and TPN in the BBPLINK MO cannot be the same as that of configured TCN, TSRN, TSN, and TPN in the BBPLINK MO.
  • Relation with the CASCADEPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of PM in a CASCADEPORT MO is 1*40GE or 4*10GE, the BBP MO specified by CN, SRN, and SN in the CASCADEPORT cannot be configured with a BBPLINK MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If a BBP MO is configured with a BBPLINK MO, the value of PM in the CASCADEPORT MO on the BBP MO cannot be 1*40GE or 4*10GE.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The BBPLINK MO cannot be configured under a MDU with TYPE is MDUC.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD BBPLNK

Use this command to add a configuration of a baseband processing link. The baseband processing link is a logical concept. The physical entity of the interconnection link is the topology between the interconnected baseband processing boards of BBUs.
DSP BBPLNK

Use this command to query the actual status of a baseband processing link.
LST BBPLNK

Use this command to list the configuration of a baseband processing link.
MOD BBPLNK

Use this command to modify the configuration of a baseband processing link.
RMV BBPLNK

Use this command to delete a baseband processing link.
