GPM

TRANSPORT
  +-GPM

Description

This MO is used to set parameters related to the GPM detection.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the GPM MO cannot be configured.
  • Relation with the GPM MO:
    • [Co-MPT, NodeB]In an RSCGRP MO, only one GPM MO with DDM set to FPDT and DIR set to DOWN and only one GPM MO with DDM set to FPDT and DIR set to UP can be configured.
    • [Co-MPT, NodeB]On a loopback port, only one GPM MO with DDM set to FPDT and DIR set to DOWN and only one GPM MO with DDM set to FPDT and DIR set to UP can be configured.
    • [Co-MPT, NodeB]The system supports a maximum of 20 GPM MOs.
  • Relation with the IPPATH MO:
    • [Co-MPT, NodeB]When PT and RSCGRPID in the GPM MO are not set to LOOPINT and DEFAULTPORT, respectively, if IPMUXSWITCH in the IPPATH MO corresponding to the GPM MO is set to ENABLE, TIMER in the IPPATH MO must be set to a value less than or equal to 1.
    • [Co-MPT, NodeB]When PT in the GPM MO is not set to LOOPINT and RSCGRPID in the GPM MO is set to DEFAULTPORT, if IPMUXSWITCH in the IPPATH MO corresponding to the GPM MO is set to ENABLE, TIMER in the IPPATH MO must be set to a value less than or equal to 1.
    • [Co-MPT, NodeB]When PT in the GPM MO is set to LOOPINT, if IPMUXSWITCH in the IPPATH MO corresponding to the GPM MO is set to ENABLE, TIMER in the IPPATH MO must be set to a value less than or equal to 1.
  • Relation with the RSCGRP MO:
    • [Co-MPT, NodeB]If RSCGRPID in a GPM MO is not set to DEFAULTPORT, the associated RSCGRP MO must have been configured.
  • Relation with the PPPLNK MO:
    • [Co-MPT, NodeB]If a GPM MO and a PPPLNK MO are configured on the same physical port, the MUXCP parameter must be set to DISABLE in the PPPLNK MO.
    • [Co-MPT, NodeB]If PT and RSCGRPID in a GPM MO are set to PPP and DEFAULTPORT, respectively, the associated PPPLNK MO must have been configured.
  • Relation with the MPGRP MO:
    • [Co-MPT, NodeB]If a GPM MO and a MPGRP MO are configured on the same physical port, the MUXCP parameter must be set to DISABLE in the MPGRP MO.
    • [Co-MPT, NodeB]If PT and RSCGRPID in a GPM MO are set to MPGRP and DEFAULTPORT, respectively, the associated MPGRP MO must have been configured.
  • Relation with the ETHTRK MO:
    • [Co-MPT, NodeB]If PT and RSCGRPID in a GPM MO are set to ETHTRK and DEFAULTPORT, respectively, the associated ETHTRK MO must have been configured.
  • Relation with the TUNNEL MO:
    • [Co-MPT, NodeB]If PT and RSCGRPID in a GPM MO are set to TUNNEL and DEFAULTPORT, respectively, the associated TUNNEL MO must have been configured.
  • Relation with the ETHTRKLNK MO:
    • [Co-MPT, NodeB]If PT and RSCGRPID in a GPM MO are set to ETH and DEFAULTPORT, respectively, ensure that the Ethernet port is not associated with an ETHTRKLNK MO.
  • Relation with the BBP and CASCADEPORT MOs:
    • [Co-MPT, NodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to SCPRI/SRIO or AUTO, this board cannot be configured with the GPM MO.
    • [Co-MPT, NodeB]On a UBBP or LCOP board, if the CASCADEPORT MO in which the PN parameter is set to 6 does not exist, this board cannot be configured with the GPM MO.
    • [Co-MPT, NodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to 1*40GE, and PT in the GPM MO for this board is set to ETH, PN can only be set to 0 in the GPM MO.
    • [Co-MPT, NodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to 4*10GE, and PT in the GPM MO for this board is set to ETH, PN can only be set to 0, 1, 2, or 3 in the GPM MO.
    • [Co-MPT, NodeB]On a UBBP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to 1*100GE, and PT in the GPM MO for this board is set to ETH, PN can only be set to 0 in the GPM MO.
  • Relation with the NODE MO:
    • [Co-MPT]An GPM MO cannot be configured on a PRODUCTTYPE MO with PRODUCTTYPE set to DBS3900 DCU or DBS5900 DCU.

Related MML Commands

Table 1 Related MML commands

MML Command

Function
ADD GPM

Use this command to add the general performance management (GPM) detection.

Use this command to modify a GPM detection.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
GPM ID

Indicates the No. of a GPM detection.
Detect Direction

Indicates the direction of a GPM detection.
Delay Detect Method

Indicates the delay detection method at the bottom layer used by the GPM detection.
Detect Object

Indicates the object to be detected by the GPM on the base station side. If the detection object is RSCGRP, the GPM detects congestion on transmission links of users in the transmission resource group.
Cabinet No.

Indicates the cabinet No. of the board where the transmission resource group detected by the GPM is located.
Subrack No.

Indicates the subrack No. of the board where the transmission resource group detected by the GPM is located.
Slot No.

Indicates the slot No. of the board where the transmission resource group detected by the GPM is located.
Subboard Type

Indicates the subboard type of the board where the transmission resource group detected by the GPM is located.
Port Type

Indicates the type of the port where a transmission resource group detected by the GPM is carried.
Port No.

Indicates the No. of the port where a transmission resource group detected by the GPM is carried.
Transmission Resource Group ID

Indicates the No. of the transmission resource group detected by the GPM.
Table 3 Dynamic parameters

Parameter

Description
Work State

Indicates the working state of a GPM detection. If the number of samples within a GPM detection period is 0, the working state of the GPM detection is "NO_MEASUREMENT". If the number of samples within a GPM detection period is greater than 0, the working state of the GPM detection is "IN_MEASUREMENT".
