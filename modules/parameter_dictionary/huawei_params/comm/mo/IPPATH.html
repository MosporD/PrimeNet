IPPATH

TRANSPORT
  +-IPPATH

Description

The IPPATH MO is used to differentiate service transmission through the service transmission channel between the BS and other NEs by configuring the IP address and service quality on both ends of the channel.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The TRANSCFGMODE of IPPATH must be the same with the TRANSCFGMODE of GTRANSPARA.
  • Relation with the BBP and CASCADEPORT MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to SCPRI/SRIO or AUTO, this board cannot be configured with the IPPATH MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB]On a UBBP or LCOP board, if the CASCADEPORT MO in which the PN parameter is set to 6 does not exist, this board cannot be configured with the IPPATH MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to 1*40GE, and PT in the IPPATH MO for this board is set to ETH, PN and SBT can only be set to 0 and ETH_COVERBOARD, respectively, in the IPPATH MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to 4*10GE, and PT in the IPPATH MO for this board is set to ETH, PN and SBT can only be set to 0, 1, 2, or 3 and ETH_COVERBOARD, respectively, in the IPPATH MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB]On a UBBP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to 1*100GE, and PT in the IPPATH MO for this board is set to ETH, PN and SBT can only be set to 0 and ETH_COVERBOARD, respectively, in the IPPATH MO.
  • Relation with the IPPMSESSION MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If BINDPATH in an IPPMSESSION MO is set to YES, the IPPATH MO specified by PATHID in the IPPMSESSION MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If BINDPATH and IPPMTYPE in an IPPMSESSION MO are set to YES and THREE_TUPLE, respectively, PATHTYPE in the IPPATH MO whose PATHID is the same as PATHID in the IPPMSESSION MO must be set to ANY.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If BINDPATH and IPPMTYPE in an IPPMSESSION MO are set to YES and THREE_TUPLE, respectively, SBT in the IPPATH MO whose PATHID is the same as PATHID in the IPPMSESSION MO must be set to BASE_BOARD or ETH_COVERBOARD.
  • Relation with the RSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If JNRSCGRP in an IPPATH MO is set to ENABLE, the associated RSCGRP MO must have been configured.
  • Relation with the PPPLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT and JNRSCGRP in an IPPATH MO are set to PPP and DISABLE, respectively, the associated PPPLNK MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If LOCALIP in an IPPATH MO is set to 0.0.0.0, the IPPATH MO must have been configured on a PPPLNK MO whose LOCALIP is set to 0.0.0.0.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to DISABLE, and BPT in an IPPATH MO is set to PPP respectively, the associated PPPLNK MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to DISABLE, LOCALIP in an IPPATH MO is set to 0.0.0.0, the IPPATH MO must have been configured on a PPPLNK MO whose LOCALIP is set to 0.0.0.0.
  • Relation with the MPGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT and JNRSCGRP in an IPPATH MO are set to MPGRP and DISABLE, respectively, the associated MPGRP MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If LOCALIP in an IPPATH MO is set to 0.0.0.0, the IPPATH MO must have been configured on an MPGRP MO whose LOCALIP is set to 0.0.0.0.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to DISABLE, and BPT in an IPPATH MO is set to MPGRP respectively, the associated MPGRP MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to DISABLE, LOCALIP in an IPPATH MO is set to 0.0.0.0, the IPPATH MO must have been configured on an MPGRP MO whose LOCALIP is set to 0.0.0.0.
  • Relation with the ETHTRK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT and JNRSCGRP in an IPPATH MO are set to ETHTRK and DISABLE, respectively, the associated ETHTRK MO must have been configured.
  • Relation with the ETHTRKLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT in an IPPATH MO is set to ETH, ensure that the Ethernet port is not associated with an ETHTRKLNK MO.
  • Relation with the IPPATH MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]Any two IPPATH MOs must have different DSCP values if all of the following conditions are met: (1) The two MOs are in the same routing domain. (2) PATHTYPE is set to FIXED in these two MOs. (3) The two MOs have the same combination of LOCALIP and PEERIP.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PATHTYPE is set to ANY in one or two IPPATH MOs in the same routing domain, the two MOs must have different address pairs. That is, the two MOs must have different combinations of LOCALIP and PEERIP.
    • [Co-MPT, eNodeB]On a BS, the sum of IPPATH MOs must be less than or equal to 320.
  • Relation with the DEVIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT in an IPPATH MO is set to LOOPINT, the corresponding DEVIP MO must have been configured, and VRFIDX, PT, and PN in the IPPATH MO must be the same as VRFIDX, PT, and PN in the DEVIP MO, respectively.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT in an IPPATH MO is set to TUNNEL, the DEVIP MO whose PT and BORROWIFIP are set to LOOPINT and NO respectively and that is in the same routing domain as the IPPATH MO must have been configured.
  • Relation with the DEVIP, PPPLNK, and MPGRP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]LOCALIP in an IPPATH MO must be the same as a DEVIP MO configured at a physical port or loopback port of the same board. If LOCALIP in an IPPATH MO is the same as a DEVIP MO configured at a physical port, PT and PN in the IPPATH MO must be the same as PT and PN in the DEVIP MO, respectively. Alternatively, LOCALIP in the IPPATH MO must be the same as LOCALIP in the associated PPPLNK MO or LOCALIP in the associated MPGRP MO.
  • Relation with the PORTSECURITY MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The ETHPORT MO that is associated with an IPPATH MO must meet either of the following conditions: (1) No PORTSECURITY MO is associated with the ETHPORT MO; (2) A PORTSECURITY MO is associated with the ETHPORT MO, but SWITCH in the PORTSECURITY MO is set to ENABLE.
  • Relation with the ETHTRUNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to DISABLE, and BPT in an IPPATH MO is set to ETHTRK respectively, the associated ETHTRUNK MO must have been configured.
  • Relation with the ETHTRUNKLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to DISABLE, and BPT in an IPPATH MO is set to ETHTRK respectively, the corresponding ETHTRUNKLNK MO of the associated ETHTRUNK MO must have been configured.
    • [Co-MPT, NodeB, eNodeB]If BPT in an IPPATH MO is set to ETH, ensure that the Ethernet port is not associated with an ETHTRUNKLNK MO.
  • Relation with the BACKTUNNEL MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to DISABLE, and BPT in an IPPATH MO is set to TUNNEL respectively, the associated BACKTUNNEL MO must have been configured.
  • Relation with the ETHPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to DISABLE, and BPT in an IPPATH MO is set to ETH respectively, the associated ETHPORT MO must have been configured.
  • Relation with the LOOPBACK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to DISABLE, and BPT in an IPPATH MO is set to LOOPINT respectively, the associated LOOPBACK MO must have been configured.
  • Relation with the IPADDR4, MPGRP, PPPLNK, LOOPBACK, and INTERFACE MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to DISABLE, the corresponding IPADDR4 MO of an IPPATH MO must have been configured on the INTERFACE MO, and VRFIDX, and LOCALIP in the IPPATH MO must be the same as VRFIDX, and IP in the IPADDR4 MO, respectively. Alternatively, LOCALIP in the IPPATH MO must be the same as LOCALIP in the associated PPPLNK MO or LOCALIP in the associated MPGRP MO. Alternatively, IPADDR4 for the corresponding LOCALIP in the IPPATH MO must be configured on the port of LOOPBACK MO.
  • Relation with the IPADDR4, MPGRP, PPPLNK, LOOPBACK, INTERFACE, and IPRSCGRP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to ENABLE, the corresponding IPADDR4 MO for LOCALIP must have been configured on the port of the IPRSCGRP MO which the IPPATH MO joins in, and VRFIDX, and LOCALIP in the IPPATH MO must be the same as VRFIDX, and IP in the IPADDR4 MO, respectively. Alternatively, LOCALIP in the IPPATH MO must be the same as LOCALIP in the associated PPPLNK MO or LOCALIP in the associated MPGRP MO. Alternatively, IPADDR4 for the corresponding LOCALIP in the IPPATH MO must be configured on the port of LOOPBACK MO.
  • Relation with the IPRSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]In an IPPATH MO, if TRANSCFGMODE is set to NEW, and JNIPRSCGRP is set to ENABLE and LOCALIP is set to 0.0.0.0, the corresponding PT of IPRSCGRP MO must be set to PPP or MPGRP.
    • [Co-MPT, NodeB, eNodeB]If JNIPRSCGRP in an IPPATH MO is set to ENABLE, the associated IPRSCGRP MO must have been configured and is not set to AUTOPORT and DEFAULTPORT.

  • Relation with the MPGRP and IPRSCGRP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]In an IPPATH MO, if TRANSCFGMODE is set to NEW, and JNIPRSCGRP is set to ENABLE and LOCALIP is set to 0.0.0.0, and the corresponding PT of IPRSCGRP MO is set to MPGRP, the corresponding MPGRP MO must have been configured whose LOCALIP is set to 0.0.0.0.
  • Relation with the IPADDR4, LOOPBACK, BACKTUNNEL, and INTERFACE MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW, and JNIPRSCGRP is set to DISABLE, and BPT in an IPPATH MO is set to TUNNEL, the IPADDR4 MO that is in the same routing domain as the IPPATH MO must have been configured, and also INTERFACE MO must have been configured on the LOOPBACK MO, which is on the same board with the corresponding BACKTUNNEL MO the IPPATH MO bears on.
  • Relation with the IPADDR4, LOOPBACK, BACKTUNNEL, IPRSCGRP, and INTERFACE MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW, and JNIPRSCGRP is set to ENABLE, and the PT in corresponding IPRSCGRP MO is set to TUNNEL, the IPADDR4 MO that is in the same routing domain as the IPPATH MO must have been configured, and also INTERFACE MO must have been configured on the LOOPBACK MO, which is on the same board with the corresponding BACKTUNNEL MO the IPPATH MO bears on.
  • Relation with the TUNNEL MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT and JNRSCGRP in an IPPATH MO are set to TUNNEL and DISABLE, respectively, the associated TUNNEL MO must have been configured.
  • Relation with the DEVIP and IFIP MOs:
    • [Co-MPT, NodeB, eNodeB]The DEVIP MO that is depended by an IPPATH MO cannot borrow an IFIP MO whose PT is ETHCI.
    • [Co-MPT, NodeB, eNodeB]If the DEVIP MO depended by an IPPATH MO borrows an IFIP MO and PT in the borrowed IFIP MO is SUBIF, PT and PN in the IPPATH MO must be the same as PT and PN in the corresponding SUBIF MO, respectively.
  • Relation with the GPM MO:
    • [Co-MPT, NodeB]When PT and RSCGRPID in the GPM MO are not set to LOOPINT and DEFAULTPORT, respectively, if IPMUXSWITCH in the IPPATH MO corresponding to the GPM MO is set to ENABLE, TIMER in the IPPATH MO must be set to a value less than or equal to 1.
    • [Co-MPT, NodeB]When PT in the GPM MO is not set to LOOPINT and RSCGRPID in the GPM MO is set to DEFAULTPORT, if IPMUXSWITCH in the IPPATH MO corresponding to the GPM MO is set to ENABLE, TIMER in the IPPATH MO must be set to a value less than or equal to 1.
    • [Co-MPT, NodeB]When PT in the GPM MO is set to LOOPINT, if IPMUXSWITCH in the IPPATH MO corresponding to the GPM MO is set to ENABLE, TIMER in the IPPATH MO must be set to a value less than or equal to 1.
  • Relation with the IPGPM MO:
    • [Co-MPT, NodeB]When PT in the IPGPM MO is not set to LOOPINT and RSCGRPNO in the associated IPRSCGRP MO is not set to DEFAULTPORT, if IPMUXSWITCH in the IPPATH MO corresponding to the IPGPM MO is set to ENABLE, TIMER in the IPPATH MO must be set to a value less than or equal to 1.
    • [Co-MPT, NodeB]When PT in the IPGPM MO is set to LOOPINT, if IPMUXSWITCH in the IPPATH MO corresponding to the IPGPM MO is set to ENABLE, TIMER in the IPPATH MO must be set to a value less than or equal to 1.
  • Relation with the IPGPM and IPRSCGRP MOs:

    • [Co-MPT, eGBTS]The number of IPPATH MOs must be less than or equal to 32 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
  • Relation with the NODE MO:

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Path ID

Indicates the ID of an IP path.
Cabinet No.

Indicates the cabinet number of the board where the IP path is located.
Subrack No.

Indicates the subrack number of the board where the IP path is located.
Slot No.

Indicates the slot number of the board where the IP path is located.
Port Type

Indicates the physical port type of the IP path.
Port No.

Indicates the number of the port where the IP path is configured.
Path Type

Indicates the type of the IP path. FIXED indicates that this IP path is used to carry the service with specified Quality of Service (QoS), that is, with a specified DSCP. ANY indicates that this IP path can be used to carry services of any QoS and hence is used to carry the service without a specified DSCP.
DSCP

Indicates the differentiated services code point (DSCP) of the services carried on an IP path.
Local IP Address

Indicates the local IP address of an IP path. The value 0.0.0.0 indicates that the local IP address needs to be negotiated.
Peer IP Address

Indicates the peer IP address of the IP path.
Transmission Resource Type

Indicates the type of transport resource for the IP path. The value HQ indicates high-quality transport resources, and the value LQ indicates low-quality transport resources. This parameter must be set in the hybrid transmission scenario. In other scenarios, the default value of this parameter is used. The parameter takes effect only in LTE.
IP MUX Switch

Indicates whether the IP MUX function is enabled on IP paths. LTE currently does not support this function.
MUX Timer

Indicates the length of the IP MUX timer, which defines the maximum buffer time for IP MUX packets. The LTE currently does not support the IP MUX function.
Maximum Length of IP MUX Multiframe

Indicates the maximum multiframe length of IP MUX. The LTE currently does not support the IP MUX function.
Maximum Length of IP MUX Subframe

Indicates the maximum subframe length of IP MUX. The LTE currently does not support the IP MUX function.
Transmission Resource Group ID

Indicates the ID of the transmission resource group established on an IP path.
Description

Indicates the description about the peer of the IP path.
Subboard Type

Indicates the type of sub-board on the board where the IP path is established.
VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).
Join Transmission Resource Group

Indicates whether the IP path joins a transmission resource group. If this parameter is set to DISABLE, the IP path is established on the default IP transmission resource group on a specific physical port.
Static Check Switch

Indicates whether to enable the GTP-U static detection function for a link. When this parameter is set to ENABLE, the GTP-U static detection function is enabled for a link. When this parameter is set to DISABLE, the GTP-U static detection function is disabled for a link. When this parameter is set to FOLLOW_GLOBAL, the setting of the switch for the GTP-U static detection function is the same as that of the base station-level GTP-U detection switch. This parameter takes effect only in LTE.
Transmission Configuration Mode

Indicates the configuration mode of the transmission model. The transmission model can be configured in old or new mode.

In old mode, the transmission model contains information such as cabinet, subrack, and slot numbers. Transmission configurations are bound to device boards.

In new mode, the transmission model has decoupled transmission and device models. That is, transmission configuration removes unnecessary cabinet, subrack, and slot configurations.
Join IP Transmission Resource Group

Indicates whether the IP path is added to an IP transmission resource group. When this parameter is set to DISABLE, the IP path is established on the default IP transmission resource group on a specified physical port.
IP Transmission Resource Group ID

Indicates the ID of the IP transmission resource group to which the IP path belongs.
Bearing Port Type

Indicates the physical port type of the IP path.
Port ID

Indicates the ID of the port to which the IP path belongs.
