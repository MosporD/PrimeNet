Description

An AlmPort MO is used to monitor the environment through external sensors. The alarm ports are classified into analog alarm ports and digital alarm ports. An analog alarm port is used to monitor the external environment factor in which the change is continuous, and it is supported only by an EMU. The analog port monitors the current environment factor and compares it with the configured measurement upper and lower limits and output signal upper and lower limits. A digital alarm port is used to monitor the external environment factor in which the change is indicated in Boolean or discrete values. It is contained in the EMU, PMU, TCU, FMU, RRU, CCU and power boards. The SC48200 PMU and the EPS4815 PMU do not support digital ports.

Relations Between MOs

  • Possible parents:

    CCU;EMU;FMU;MDU;MEB;PEU;PMU;RFU;RHUB;RRU;TCU;UEIU
  • Relation with the devices:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The board corresponding to CN, SRN, and SN in the ALMPORT MO must have been configured and must be one of following ones: PMU, EMU, TCU, FMU, RRU, PEU, UEIU, MDU, and CCU MOs.
  • Relation with the PMU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ALMPORT MOs configured on one PMU MO must be greater than or equal to 0 and smaller than or equal to 5.
  • Relation with the TCU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ALMPORT MOs configured on one TCU MO must be greater than or equal to 0 and smaller than or equal to 32.
  • Relation with the FMU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ALMPORT MOs configured on one FMU MO must be greater than or equal to 0 and smaller than or equal to 4.
  • Relation with the EMU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ALMPORT MOs configured on one EMU MO must be 36.
  • Relation with the CCU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ALMPORT MOs configured on one CCU MO must be 32.
  • Relation with the RFU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ALMPORT MOs configured on one RFU MO must be 0.
  • Relation with the UEIU and SUBRACK MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE of SUBRACK is not set to BBU5900A, the number of ALMPORT MOs configured on one UEIU MO must be 8.
  • Relation with the PEU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ALMPORT MOs configured on one PEU MO must be 8.
  • Relation with the MEB MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ALMPORT MOs configured on one MEB MO must be 6.
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]When RT in the RRU MO is not set to MPMU or MPRF, the number of ALMPORT MOs must range from 2 to 4.
    • [Co-MPT, NodeB, eNodeB, gNodeB]When RT in the RRU MO is set to MPMU or MPRF, the number of ALMPORT MOs must be 0.
    • [eGBTS]The number of ALMPORT MOs configured on one RRU MO must be greater than or equal to 2 and smaller than or equal to 4.
  • Relation with the ALMPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The number of ALMPORT MOs configured on one MDU MO with TYPE is UMDU must be 6.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the board where the port is located.
Subrack No.

Indicates the subrack number of the board where the port is located.
Slot No.

Indicates the slot number of the board where the port is located.
Port No.

Indicates the port number.
Switch

Indicates the enabled/disabled state of the port. Alarms can be detected and reported through the port only when the state of the port is ON.
Alarm ID

Indicates the alarm ID bound to the alarm port. This parameter is reported as the ID of the alarm detected at the port. This parameter is valid only if the port switch is turned on.
Port Type

Indicates the alarm port types: analog alarm port and digital alarm port. This parameter is valid only if the port switch is turned on. An analog alarm port is used to monitor the external environment that changes continuously. The port is supported only by the EMU. A digital alarm port is used to monitor the external environment of which the change is indicated by Boolean or discrete values. It is contained in the EMU, PMU, TCU, FMU, RRU, UMDU, CCU, and power boards. The SC48200 PMU and the EPS4815 PMU do not support digital ports.
Alarm Voltage

Indicates the alarm level. This parameter specifies whether alarms generated by the sensor over the port are in high or low voltage. The alarm level is set according to the type of external sensor. This parameter is valid only if the port switch is turned on.
Alarm Upper Limit

Indicates the alarm upper limit. If the environment measurement value is greater than the alarm upper limit configured for the sensor, the alarm is reported. Environment measurement value = Measurement lower limit + (Measurement upper limit - Measurement lower limit) x (Observed electric current or voltage - Output lower limit)/(Output upper limit - Output lower limit). Temperature is measured in the unit of degree Celsius, voltage is measured in the unit of volts, and current is measured in the unit of milliampere.
Alarm Lower Limit

Indicates the alarm lower limit. If the environment measurement value is smaller than the alarm lower limit configured for the sensor, the alarm is reported. Environment measurement value = Measurement lower limit + (Measurement upper limit - Measurement lower limit) x (Observed electric current or voltage - Output lower limit)/(Output upper limit - Output lower limit). Temperature is measured in the unit of degree Celsius, voltage is measured in the unit of volts, and current is measured in the unit of milliampere.
Sensor Type

Indicates the sensor type. The user can set the sensor type to current type or voltage type according to the actual external sensor.
Sensor Measurement Upper Limit

Indicates the measurement upper limit of the analog port. The range is set based on the actual situations such as the temperature and humidity. The temperature is measured in the unit of degree Celsius, the voltage is measured in the unit of volt, and the current is measured in the unit of milliampere.
Sensor Measurement Lower Limit

Indicates the measurement lower limit of the analog port. The range is set based on the actual situations such as the temperature and humidity. The temperature is measured in the unit of degree Celsius, the voltage is measured in the unit of volt, and the current is measured in the unit of milliampere.
Sensor Output Upper Limit

Indicates the upper limit of the output signals from the analog port. For sensors of either the current type or voltage type, the upper limit should be set according to the specifications of the sensor.
Sensor Output Lower Limit

Indicates the lower limit of the output signals from the analog port. For sensors of either the current type or voltage type, the lower limit should be set according to the specifications of the sensor.
Detection Period

Indicates the alarm detecting period of an environment signal input port. When this parameter is set to 255, the default alarm detecting period is used.
User Label

Indicates the user-defined information about an environment signal input port.
