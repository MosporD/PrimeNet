SnmpNms

TRANSPORT
  +-SnmpNms

Description

This MO is used to add an SNMP NMS.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SNMPNMS

Use this command to add an SNMP NMS.
DSP SNMPNMS

Use this command to collect statistics on the number of messages sent and received between the DCU and the SNMP NMS.
LST SNMPNMS

Use this command to query SNMP NMS information.
MOD SNMPNMS

Use this command to modify the SNMP NMS.
RMV SNMPNMS

Use this command to delete an SNMP NMS.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IP Address

Indicates the IP address of the SNMP NMS.
Port

Indicates the port number of the SNMP NMS.
Version

Indicates the SNMP version.You are not advised to use V2C(V2C) because it has security risks.
Community Index

Indicates the index of an SNMP community.
Security Name

Indicates the user name displayed on the SNMP NMS.
