STM1

TRANSPORT
  +-STM1

Description

The STM1 MO is used to set the STM-1 parameters, including the work mode of the STM-1 and the transmission clock source.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS]When TYPE in the MDU MO is set to MDUC, the STM1 MO cannot be configured.
  • Relation with the SDHJ0J1 MO:
    • [Co-MPT, NodeB]When adding an STM1 MO, the system automatically adds the associated SDHJ0J1 MO. When removing an STM1 MO, the system automatically removes the SDHJ0J1 MO that depends on the STM1 MO.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of STM1 MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
