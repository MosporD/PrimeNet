DFU

Description

A DFU MO defines a distributed function unit. This MO is added if a distributed function needs to be deployed for a specific RAT on the base station and the DFU is managed by the central function unit.

Effective Scenario

Immediately

Relations Between MOs

  • Relation with the DFUMLCLIENT MO:
    • [Co-MPT, eNodeB, gNodeB]The DFU MO specified by UID in the DFUMLCLIENT MO must exist.
  • Relation with the EPGROUP MO:
    • [Co-MPT, eNodeB, gNodeB]When APPTYPE in the EPGROUP MO is set to eNodeB or gNodeB, APPTYPE in the DFU MO must have been set to the corresponding value.
  • Relation with the APPLICATION MO:
    • [Co-MPT, eNodeB, gNodeB]APPREF in a DFU MO must be set to a configured value of AID in an APPLICATION MO, and the value of AT in the APPLICATION MO must be the same as that of APPTYPE in the DFU MO. In addition, RUNMODE in this APPLICATION MO must be set to SPLIT.

Use this command to remove a DFU.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Unit ID

Indicates the ID of a DFU.
NetWork ID

Indicates the network ID of a DFU. The network ID is unique for each application type on the entire network.
Application Type

Indicates the type of the application referenced by a DFU. The application provides the running environment for the DFU.
Application Reference

Indicates the ID of the application referenced by a DFU. The application provides the running environment for the DFU.
Unit Name

Indicates the name of a DFU.
Table 3 Dynamic parameters

Parameter

Description

Indicates the status of the link between a DFU and its central function unit.
Local IP

Indicates the local IP address of the link between a DFU and its central function unit.
Peer IP

Indicates the peer IP address of the link between a DFU and its central function unit.
