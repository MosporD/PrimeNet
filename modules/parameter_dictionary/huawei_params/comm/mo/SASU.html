SASU

EQUIPMENT
  +-SASU
    +-SASUSUBUNIT[2~2]

Description

The SASU MO consists of the configuration of a same-band antenna sharing unit. The SASU enables same-band antenna sharing between the GSM and UMTS networks. It is applicable to the co-site scenario where the newly established 3G system shares sites with the 2G system, for example, co-site of GSM 900 MHz and UMTS 900 MHz. In this scenario, a set of antenna is shared by the UMTS and GSM systems to reduce investment. The SASU enables signals on the same band from different systems to be transmitted in a TX channel, and causes a low insertion loss. This MO applies only to UMTS.

Effective Scenario

Immediately

Relations Between MOs

  • Base class:

    ALD

  • Possible parents:

    EQUIPMENT

  • Possible children:

    SASUSUBUNIT[2~2]
  • Relation with the RRU and RFU MOs:
    • [Co-MPT, NodeB, eGBTS]The RRU or RFU MO corresponding to CTRLCN, CTRLSRN, and CTRLSN in the SASU MO must have been configured.
  • Relation with the SASUSUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS]The number of SASUSUBUNIT MOs configured on one SASU MO must be 2.
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eGBTS]The RRU MO specified by CTRLCN, CTRLSRN, and CTRLSN in the SASU MO cannot be an MRIU.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SASU

Use this command to add a same-band antenna sharing unit (SASU). The SASU subunit is added at the same time.
DSP SASU

Use this command to query the dynamic information about one or all same-band antenna sharing units (SASUs).
LST SASU

Use this command to list the configuration of one or all same-band antenna sharing units (SASUs).
MOD SASU

Use this command to modify the configuration of a same-band antenna sharing unit (SASU).
RMV SASU

Use this command to remove a same-band antenna sharing unit (SASU). The contained subunits and device data are removed at the same time.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
DC Switch

Indicates the status of the DC power supply switch for the antenna port. The value range of this parameter is BS (GSM antenna power supply), UMTS (UMTS antenna power supply), OFF (Off), or DEVICE_DEFAULT_VALUE (Device default value). If this parameter is set to DEVICE_DEFAULT_VALUE, it is invalid and the actual DC Load switch is not changed. When the SASU is connected to a TMA, this parameter must be set to BS or UMTS for powering the TMA. Otherwise, this parameter is set to OFF.
Device No.(from ALD)

Indicates the device number of the ALD. The device number of the ALD must be unique.
Device Name(from ALD)

Indicates the device name of the ALD, which identifies the ALD. It is recommended that you set the device name in the following format: sector_device type_network type. The meanings of the parts are as follows: Sector indicates the number of the sector. Device type indicates the type of currently connected device. The device type can be SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), TMA (Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit). Network type indicates whether the current ALD is used for a 2G network or 3G/LTE network. The device name is optional, but the device name configured for each ALD must be unique.
Control Port Cabinet No.(from ALD)

Indicates the cabinet number of the RRU or RFU that controls the ALD.
Control Port Subrack No.(from ALD)

Indicates the subrack number of the RRU or RFU that controls the ALD.
Control Port Slot No.(from ALD)

Indicates the slot number of the RRU or RFU that controls the ALD.
Vendor Code(from ALD)

Indicates the vendor code.
Serial No.(from ALD)

Indicates the serial number of the ALD. The vendor code and the serial number uniquely identify an ALD.
