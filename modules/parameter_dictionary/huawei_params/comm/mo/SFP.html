Description

The SFP MO consists of optical modules and electrical modules. The optical and electrical modules are used to transmit signals through optical fibers or cables between the BBU and other equipment. The information about the optical or electrical module is not configurable. This information can only be queried.

Effective Scenario

Immediately

Table 3 Dynamic parameters

Parameter

Description
Installed status

Indicates whether the optical or electrical module is in position.
SFP Module Type

Indicates the type of optical or electrical modules, including SFP optical port, ESFP optical port, SFP electrical port, QSFP optical port, QSFP electrical port, CPRI electrical port, DWDM fixed wavelength optical port, DWDM tunable wavelength optical port, and DSFP optical port. These types of optical modules are different in the supported transmission rates, transmission distance, and the number of channels. SFP_ELECTRIC indicates the module at either end of an SFP electrical cable. QSFP_ELECTRIC indicates the module at either end of a QSFP electrical cable. Electrical modules support a short transmission distance and therefore are used for connecting BBUs and RFUs. The SFP module is a small hot-swappable module, which can be connected to an optical or electrical module. The module indicated by ESFP_OPTICAL is different from that indicated by SFP_OPTICAL in the supported rate set. The QSFP module provides four bi-directional channels and the SFP module provides one bi-directional channel. CPRI_ELECTRIC indicates a module in an RJ45 connector and the module is used to connect the RHUB and MPMU, transmitting data through Ethernet cables. The DWDM fixed wavelength optical port uses the wavelength division multiplexing (WDM) and the wavelength after multiplexing is fixed. The DWDM tunable wavelength optical port uses the WDM and supports multiple wavelengths, with wavelengths dynamically switched. The DSFP optical port supports two SFP channels. Each channel can be connected to a single-fiber bidirectional optical module through a single-fiber bidirectional optical fiber. NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.
Manufacturer name

Indicates the manufacturer of the optical or electrical module.
Transmission Mode

Indicates the transmission mode of the optical module, that is, single-mode or multi-mode.
Wavelength

Indicates the wavelength of the optical module.
Transmission code rate

Indicates the transmission code rate of the optical or electrical module. Generally, the value of this parameter equals the maximum rate supported by an optical module. However, some optical modules support rates higher than this parameter value. This parameter under "Channels Carried over the Port" indicates the rate of a single channel.
Transmission distance of single-mode fiber (9-micrometer core diameter)

Indicates the maximum distance that signals from the optical module can travel along a single-mode optical fiber with a 9-micrometer core diameter. The value 0 indicates that the optical module does not support this type of optical fiber.
Transmission distance of single-mode fiber

Indicates the transmission distance of the single-mode fiber optic cable. The value NULL indicates that the optical module does not support this type of fiber optic cable.
Transmission distance of OM2 multi-mode fiber

Indicates the transmission distance of the multi-mode fiber optic cable supporting OM2. The value NULL indicates that the optical module does not support this type of fiber optic cable.
Transmission distance of OM1 multi-mode fiber

Indicates the transmission distance of the multi-mode fiber optic cable supporting OM1. The value NULL indicates that the optical module does not support this type of fiber optic cable.
Temperature

Indicates the observed temperature of the optical module.
Voltage

Indicates the observed voltage of the optical module.
Current

Indicates the observed current of the optical module or channel.
TX optical power

Indicates the TX optical power of the optical module or channel. If the command output for an optical module includes Channels Carried over the Port, the value of this parameter under Display SFP Module Dynamic Information is NULL and the actual value is displayed under Channels Carried over the Port.
RX optical power

Indicates the RX optical power of the optical module or channel. If the command output for an optical module includes Channels Carried over the Port, the value of this parameter under Display SFP Module Dynamic Information is NULL and the actual value is displayed under Channels Carried over the Port.
Receive Power Upper Threshold

Indicates the upper threshold for the receive power of an optical module.
Receive Power Lower Threshold

Indicates the lower threshold for the receive power of an optical module.
Transmit Power Upper Threshold

Indicates the upper threshold for the transmit power of an optical module.
Transmit Power Lower Threshold

Indicates the lower threshold for the transmit power of an optical module.
Version

Indicates the version of the optical module.
ITU Grid Channel

Indicates the ID of the ITU channel corresponding to the wavelength of the optical module.It is the channel number defined by the International Telecommunication Union (ITU) for wavelength.
Transmission distance of OM3 multi-mode fiber

Indicates the transmission distance of the multi-mode fiber optic cable supporting OM3. The value NULL indicates that the optical module does not support this type of fiber optic cable.
Transmission distance of OM4 multi-mode fiber

Indicates the transmission distance of the multi-mode fiber optic cable supporting OM4. The value NULL indicates that the optical module does not support this type of fiber optic cable.
