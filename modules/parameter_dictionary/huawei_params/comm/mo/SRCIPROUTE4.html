SRCIPROUTE4

TRANSPORT
  +-SRCIPROUTE4

Description

The SRCIPROUTE4 MO defines a source IPv4 route, which is used for data forwarding by configuring a source IP routing table.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the OMCH and SRCIPRT MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an OMCH MO, if CHECKTYPE is set to AUTO_UDPSESSION, IP must be configured with the corresponding SRCIPRT or SRCIPROUTE4 MO.
  • Relation with the VRF MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The VRF MO associated with an SRCIPROUTE4 MO must have been configured.
  • Relation with the SRCIPROUTE4 MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Any one of the following parameters under one SRCIPROUTE4 MO cannot be set to the same value as that of the same parameter under another SRCIPROUTE4 MO: VRFIDX, SRCIP, RTTYPE, PT, PORTID, and NEXTHOP.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the VRFIDX, SRCIP parameters under two SRCIPROUTE4 MOs are set to the same value, the PREF parameters under these MOs must be set to different values.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an SRCIPROUTE4 MO, NEXTHOP must be different from SRCIP.
  • Relation with the IPADDR4 MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the same routing domain, NEXTHOP in an SRCIPROUTE4 MO cannot be set to a broadcast IP address of the network segment where the IPADDR4 MO on the egress port is located, and Network ID and Host ID cannot be all 0 or all 1.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If an IPADDR4 MO and an SRCIPROUTE4 MO are in the same routing domain, IP in the IPADDR4 MO must be different from NEXTHOP in the SRCIPROUTE4 MO.
  • Relation with the OMCH MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the same routing domain, IP in an OMCH MO must be different from NEXTHOP in an SRCIPROUTE4 MO.
  • Relation with the BACKTUNNEL MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the RTTYPE and PT parameters under the SRCIPROUTE4 MO are set to IF and TUNNEL, respectively, the PORTID parameter under the SRCIPROUTE4 MO must be set to the same value as that of the PORTID parameter under the BACKTUNNEL MO.
  • Relation with the IPADDR4 and INTERFACE MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the same routing domain, the IP address specified by NEXTHOP in the SRCIPROUTE4 MO must be on the same network segment as the IP address specified by IP in the IPADDR4 MO that is configured on the INTERFACE MO with PT set to ETH, ETHTRK, or ETHCI.
  • Relation with the PPPLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If the RTTYPE and PT parameters under the SRCIPROUTE4 MO are set to IF and PPP, respectively, the PORTID parameter under the SRCIPROUTE4 MO must be set to the same value as that of the PORTID parameter under the PPPLNK MO.
  • Relation with the MPGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If the RTTYPE and PT parameters under the SRCIPROUTE4 MO are set to IF and MPGRP, respectively, the PORTID parameter under the SRCIPROUTE4 MO must be set to the same value as that of the PORTID parameter under the MPGRP MO.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the SRCIPROUTE4 MO cannot be configured.
  • Relation with the INTERFACE MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, if RTTYPE and PT in an SRCIPROUTE4 MO are set to IF and INTERFACE, respectively, the INTERFACE MO corresponding to PORTID in the SRCIPROUTE4 MO must have been configured.
  • Relation with the IPSECBINDITF, IPSECPOLICY, and IKEPEER MOs:
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE is set to IF and PT is set to INTERFACE in an SRCIPROUTE4 MO, the INTERFACE MO specified by PORTID cannot be bound to the IPSECPOLICY MO that references an IKEPEER MO with REDUNDANCYFLAG set to SLAVE and IPVERSION set to IPV6.
    • [Co-MPT, eNodeB, gNodeB]In an IKEPEER MO referenced by an IPSECBINDITF MO, if REDUNDANCYFLAG is set to SLAVE and IPVERSION is set to IPV6, and if an SRCIPROUTE4 MO with RTTYPE set to IF and PT set to INTERFACE has been configured on the master IPSECBINDITF MO, the total number of configured SRCIPROUTE4 MOs and all slave IPSECBINDITF MOs (with active IPSECBINDITF MOs configured with SRCIPROUTE4 MOs in the same IPSec redundancy group) cannot exceed 32.
  • Relation with the IPSECBINDITF MO:
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an SRCIPROUTE4 MO is set to IF, the INTERFACE MO corresponding to PORTID in the SRCIPROUTE4 MO must be configured with an IPSECBINDITF MO.
  • Relation with the IPSECBINDITF and IPSECPOLICY MOs:
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE is set to IF and PT is set to INTERFACE in an SRCIPROUTE4 MO, ACLTYPE in the IPSECPOLICY MO that is bound to the same IPSECBINDITF MO as this interface must be set to IPV4 or IPV4+IPV6.
  • Relation with the IPPATHRT MO:
    • [Co-MPT, eNodeB]An SRCIPROUTE4 MO and an IPPATHRT MO cannot both be configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SRCIPROUTE4

Use this command to add a source IPv4 route.
DSP SRCIPROUTE4

Use this command to query the information about effective source IPv4 routes.
LST SRCIPROUTE4

Use this command to list the configuration of source IPv4 routes.
MOD SRCIPROUTE4

Use this command to modify a source IPv4 route.
RMV SRCIPROUTE4

Use this command to remove a source IPv4 route.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Source Route Index

Indicates the index of a source IPv4 route.
VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).
Source IP Address

Indicates the source IPv4 address of a source IPv4 route.
Route Type

Indicates the type of a source IPv4 route. The value NEXTHOP indicates that IP packets transmitted through the route are forwarded to a specified next-hop IP address. The value IF indicates that IP packets transmitted through the route are forwarded to a specified outbound interface.
Next Hop IP

Indicates the next-hop IP address of a source IPv4 route.
Port Type

Indicates the port type of a source IPv4 route.
Port ID

Indicates the port ID of a source IPv4 route.
Priority

Indicates the priority of the source IPv4 routing entry. A smaller parameter value indicates a higher priority.
User Label

Indicates the user-defined information of a source IPv4 route.
Table 3 Dynamic parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the board to which a source IPv4 route belongs.
Subrack No.

Indicates the subrack number of the board to which a source IPv4 route belongs.
Slot No.

Indicates the slot number of the board to which a source IPv4 route belongs.
Actual Port Type

Indicates the type of the actual port.
Actual Port No.

Indicates the number of the actual port. When the actual port type is Ethernet trunk, the actual port number indicates the port ID of the Ethernet trunk. When the actual port type is tunnel, the actual port number indicates the port ID of the backplane tunnel.
Valid State

Indicates the validity state of a source IPv4 route.
TX Packets

Indicates the number of transmitted packets. When enhanced ping connectivity check is enabled, ping packets are directly forwarded without matching routes and the number of transmitted packets cannot be measured.
