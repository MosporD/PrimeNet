FRAATM

TRANSPORT
  +-FRAATM

Description

The FRAATM MO indicates a transmission mode of the TC sub-layer of the ATM physical layer. In fractional ATM mode, some of the 32 timeslots on an E1/T1 link are used to transmit ATM cells. The timeslots correspond to the fractional ATM link carried on the E1/T1 link.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the TSCROSS MO:
    • [Co-MPT, NodeB, eGBTS]If SBT in an FRAATM MO is set to BACK_BOARD, the combination of CN, SRN, SN, SBT, and PN in the FRAATM MO must be different from the following combinations in the TSCROSS MO: (1) the combination of CN, SRN, SRCSN, SRCSBT, and SRCPN; (2) the combination of CN, SRN, DSTSN, DSTSBT, and DSTPN.
    • [Co-MPT, NodeB]A TSCROSS MO whose SRCTSN and DSTTSN have been used by an FRAATM MO on the same port cannot be configured.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS]When TYPE in the MDU MO is set to MDUC, the FRAATM MO cannot be configured.
  • Relation with the E1T1 MO:
    • [Co-MPT, NodeB]When an FRAATM MO is configured for the E1T1 MO whose LNCODE is set to AMI, SCRAM in the FRAATM MO must be set to ENABLE.
    • [Co-MPT, NodeB]If SBT in an FRAATM MO is set to BACK_BOARD, an E1T1 MO that meets the following conditions must have been configured: CN, SRN, SN, SBT, and PN in the E1T1 MO are the same as CN, SRN, SN, SBT, and PN in the FRAATM MO, respectively.
  • Relation with the TREELNKPVC MO:
    • [Co-MPT, NodeB]The FRAATM MO associated with a TREELNKPVC MO that is not added to any RSCGRP MO must have been configured.
  • Relation with the SAALLNK MO:
    • [Co-MPT, NodeB]The FRAATM MO associated with an SAALLNK MO that is not added to any RSCGRP MO must have been configured.
  • Relation with the AAL2PATH MO:
    • [Co-MPT, NodeB]The FRAATM MO associated with an AAL2PATH MO that is not added to any RSCGRP MO must have been configured.
  • Relation with the DLFLOWCTRLPARA MO:
    • [Co-MPT, NodeB]If PT in a DLFLOWCTRLPARA MO is set to FRAATM, the associated FRAATM MO must have been configured.
  • Relation with the ULFLOWCTRLPARA MO:
    • [Co-MPT, NodeB]If PT in a ULFLOWCTRLPARA MO is set to FRAATM, the associated FRAATM MO must have been configured.
  • Relation with the RSCGRP MO:
    • [Co-MPT, NodeB]If PT in an RSCGRP MO is set to FRAATM, the associated FRAATM MO must have been configured.
  • Relation with the OMCH MO:
    • [Co-MPT, NodeB]If BEAR, JNRSCGRP, and PT are set to ATM, DISABLE, and FRAATM, respectively in an OMCH MO, the FRAATM MO whose FRAATM is the same as PN in the OMCH MO must have been configured.
  • Relation with the DLFLOWCTRLPARA and ULFLOWCTRLPARA MOs:
    • [Co-MPT, NodeB]When removing an FRAATM MO, the system automatically removes the DLFLOWCTRLPARA and ULFLOWCTRLPARA MOs that depend on the FRAATM MO.
  • Relation with the UNILNK MO:
    • [Co-MPT, NodeB]PN in an FRAATM MO must be different from UNILNKN in a UNILNK MO on the same board.
  • Relation with the IMALNK MO:
    • [Co-MPT, NodeB]On the same board, IMALNKN in an IMALNK MO must be different from PN in an FRAATM MO.
  • Relation with the FRAATM MO:
    • [Co-MPT, NodeB]The FRAATM MOs of different subboards on the same board must have different PN values.
    • [Co-MPT, NodeB]The FRAATM MOs configured on one port must use different timeslots.
    • [Co-MPT, NodeB]The FRAATM MOs of different subboards on the same board must have different FRAATM values.
  • Relation with the E1T1BEAR MO:
    • [Co-MPT, NodeB]The E1T1BEAR MO in an FRAATM MO must have been configured.
    • [Co-MPT, NodeB]MODE in the E1T1BEAR MO associated with an FRAATM MO must be set to ATM.
  • Relation with the PORTSECURITY MO:
    • [Co-MPT, NodeB]The E1T1 MO that is associated with an FRAATM MO must meet either of the following conditions: (1) No PORTSECURITY MO is associated with the E1T1 MO; (2) A PORTSECURITY MO is associated with the E1T1 MO, but SWITCH in the PORTSECURITY MO is set to ENABLE.
  • Relation with the MPT MO:
    • [Co-MPT, NodeB]In the MPT MO, if the TYPE parameter is set to UMPT and the BRDSPEC parameter is set to "UMPTe" or "UMPTg" or "UMPTga" (case insensitive), the number of FRAATM MOs configured on this board must be 0.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of FRAATM MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
