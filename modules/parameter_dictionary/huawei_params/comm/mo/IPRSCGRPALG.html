IPRSCGRPALG

TRANSPORT
  +-IPRSCGRP
    +-IPRSCGRPALG

Description

The IPRSCGRPALG MO consists of parameters related to the algorithm for an IP transmission resource group. Each IP transmission resource group corresponds to a type of algorithm. According to the corresponding algorithm, each IP transmission resource group performs operations such as traffic control.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    IPRSCGRP
  • Relation with the IPRSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When an IPRSCGRP MO whose RSCGRPNO is not AUTOPORT is being added, the system automatically adds the associated IPRSCGRPALG MO. Before an IPRSCGRP MO is removed, the system automatically removes the IPRSCGRPALG MO associated with the IPRSCGRP MO.
    • [Co-MPT, NodeB, eNodeB, gNodeB]Before modifying an IPRSCGRPALG MO, ensure that the associated IPRSCGRP MO is configured. An IPRSCGRP MO is associated with an IPRSCGRPALG MO when IPRSCGRPID in the IPRSCGRP MO are the same as that in the IPRSCGRPALG MO.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the IPRSCGRPALG MO cannot be configured.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TYPE in an MDU MO is set to MDUC, the IPRSCGRPALG MO must meet the following conditions: TXBWAMIN and RXBWAMIN are set to values within the range of 64 to 1000000; TXRSVBW and RXRSVBW are set to value within the range of 0 to 1000000.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of IPRSCGRPALG MOs must be less than or equal to 16 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IP Transmission Resource Group ID

Indicates the ID of an IP transmission resource group. When you add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, a tunnel, or a PPPoE link, the system automatically creates an algorithm for the IP transmission resource group with IP Transmission Resource Group ID set to DEFAULTPORT(Default Port). When you remove any of the preceding objects, the system automatically removes the algorithm for the IP transmission resource group.
TX Traffic Shaping Switch

Indicates whether to enable traffic shaping for an IP transmission resource group. If this parameter is set to ON, traffic shaping is performed according to the TX bandwidth so that the transmit traffic would not exceed the capability of downstream routers, therefore avoiding unnecessary packet loss and congestion. If this parameter is set to OFF, traffic shaping is not performed during data transmission.
TX Bandwidth Adjustment Switch

Indicates whether to enable the dynamic adjustment of the TX bandwidth of an IP transmission resource group. If this parameter is set to ON, the TX bandwidth is adjusted according to the network performance and dynamic bandwidth adjustment parameters (Packet Loss Ratio Down Threshold and Delay Variation Down Threshold). The network performance is monitored through IP PM sessions, which can be enabled at the local end or at the peer end. If this parameter is set to OFF, the TX bandwidth is not adjusted. If mapping between the transmission resource group and a NodeB IP path or an IP path for no RAT is configured, this parameter does not take effect on the IP transmission resource group even though the parameter is set to ON. This parameter does not take effect in UMTS.
RX Bandwidth Adjustment Switch

Indicates whether to enable the dynamic adjustment of the RX bandwidth of an IP transmission resource group. If this parameter is set to ON, the RX bandwidth is adjusted according to the network performance and dynamic bandwidth adjustment parameters (Packet Loss Ratio Down Threshold and Delay Variation Down Threshold). The network performance is monitored through IP PM sessions, which can be enabled at the local end or at the peer end. If this parameter is set to OFF, the RX bandwidth is not adjusted. This parameter does not take effect in UMTS.
Packet Loss Ratio Down Threshold

Indicates the rate downsizing packet loss rate threshold for bandwidth adjustment. When RXBWASW or TXBWASW is set to ON, the estimated available transport bandwidth is reduced if the packet loss rate detected through IP Performance Monitoring (IP PM) is higher than this threshold. If the packet loss rate detected through IP PM is lower than this threshold, the estimated available transport bandwidth is increased.
Delay Variation Down Threshold

Indicates the rate downsizing packet loss rate threshold for bandwidth adjustment. When RXBWASW or TXBWASW is set to ON, the estimated available transport bandwidth will be reduced if the packet loss rate detected by an IP PM session is higher than this threshold; the estimated available transport bandwidth will be increased if the packet loss rate detected by an IP PM session is lower than this threshold.
TX Bandwidth Adjust Minimum

Indicates the minimum amount of adjusted TX bandwidth. If TXBWASW is set to ON, the adjusted bandwidth should be at least greater than this minimum. This parameter does not take effect in UMTS.
RX Bandwidth Adjust Minimum

Indicates the minimum amount of adjusted RX bandwidth. If RXBWASW is set to ON, the adjusted bandwidth must be at least greater than this minimum. This parameter does not take effect in UMTS.
Traffic Control Switch

Indicates whether to enable the backpressure algorithm of an IP transmission resource group.

The BS monitors the data buffered in the queues of each IP transmission resource group, determines whether the IP transmission resource group is congested, and transmits the backpressure signals (the ID and congestion status of the IP transmission resource group) to each flow control service.

If the size of buffered data packets in any backpressure queue exceeds 75% of the queue capacity, the BS regards this IP transmission resource group as congested and transmits congestion signals.

If the size of buffered data packets in each backpressure queue is less than 50% of the corresponding buffer capacity, the BS decides that the IP transmission resource group is not congested. In this situation, no congestion signal or congestion release signal is transmitted.

When this parameter is set to ENABLE, both intra-mode traffic control and inter-mode traffic control are supported.

The inter-mode traffic control for IP transmission resource groups applies only to separate-MPT base stations with co-transmission implemented through backplane interconnection. However, it does not apply to cascaded base stations, base stations with co-transmission implemented through panel interconnection, or base stations enabled with route load sharing.

When the inter-mode traffic control function is enabled for a separate-MPT base station with co-transmission implemented through backplane interconnection, the Tunnel Type parameter must be set to DL(DL) for the tunnel of the mode providing transmission ports and must be set to UL(UL) for the tunnel of the mode providing no transmission port.
PQ Number

Indicates the number of PQs in an IP transmission resource group. The queues in an IP transmission resource group are classified into PQs and non-PQs. The scheduling priority of any PQ is higher than that of any non-PQ. The queues numbered from 0 to the result after this parameter value minus 1 are PQs. PQ scheduling is used between PQs. A smaller PQ number indicates a higher scheduling priority. The queues numbered from this parameter value to 6 are non-PQs. WPR scheduling is used between non-PQs.
Congestion Time Threshold

Indicates the congestion time threshold of an IP transmission resource group. When TCSW is set to ENABLE, if the buffer time of non-real-time service data in an IP transmission resource group exceeds the threshold, the IP transmission resource group is congested, and backpressure signals are transmitted.
Congestion Clear Time Threshold

Indicates the congestion clear time threshold of an IP transmission resource group. When TCSW is set to ENABLE, if the buffer time of non-real-time service data in an IP transmission resource group is less than the threshold, the IP transmission resource group is not congested, and congestion clear signals are transmitted.
TX Reserved Bandwidth

Indicates the TX bandwidth reserved for signaling data, OM data, or real-time services. This parameter should be set to a value less than the TX bandwidth of an IP transmission resource group. It is recommended that the reserved TX bandwidth be set to a value less than or equal to 3% of the TX bandwidth of an IP transmission resource group. The UMTS currently does not support this function.
RX Reserved Bandwidth

Indicates the reserved RX bandwidth, which should be set to a value less than or equal to the RX bandwidth of an IP transmission resource group. This parameter does not take effect in UMTS.
Drop Packet Number Threshold

Indicates the threshold for the number of discarded packets. This parameter indicates the capability of the queue in an IP transmission resource group to buffer packets. A greater parameter value indicates a stronger capability. If this parameter is set to 0, the queue in an IP transmission resource group cannot buffer packets, and therefore all the delayed packets on the TX channel are discarded. The threshold for the number of discarded packets determines the maximum amount of data that can be buffered in an IP transmission resource group. The congestion time threshold of a transmission resource group determines the amount of data that is buffered when the IP transmission resource group is congested. Ensure that the maximum amount of data that can be buffered is not less than the amount of data that is buffered during congestion.
