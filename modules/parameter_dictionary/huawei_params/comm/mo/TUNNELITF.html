TUNNELITF

TRANSPORT
  +-TUNNELITF

Description

This object is used to configure the tunnel interface.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the TUNNELITF MO cannot be configured.
  • Relation with the TUNNELITF MO:
    • [Co-MPT, eNodeB, gNodeB]REMOTEIP6 in a TUNNELITF MO with CTRLMODE set to MANUAL_MODE must be different from REMOTEIP6 of any existing TUNNELITF MO in the same routing domain.
    • [Co-MPT, eNodeB, gNodeB]The number of TUNNELITF MOs with CTRLMODE set to MANUAL_MODE cannot exceed 128.
  • Relation with the SCTPHOST MO:
    • [Co-MPT, eNodeB, gNodeB]LOCALIP6 in a TUNNELITF MO with CTRLMODE set to MANUAL_MODE must be different from SIGIP1V6 and SIGIP2V6 in an SCTPHOST MO with IPVERSION set to IPv6 in the same routing domain.
  • Relation with the SCTPLNK MO:
    • [Co-MPT, eNodeB, gNodeB]LOCALIP6 in a TUNNELITF MO with CTRLMODE set to MANUAL_MODE must be different from LOCIP6 and SECLOCIP6 in an SCTPLNK MO with IPVERSION set to IPv6 in the same routing domain.
  • Relation with the USERPLANEHOST MO:
    • [Co-MPT, eNodeB, gNodeB]LOCALIP6 in a TUNNELITF MO with CTRLMODE set to MANUAL_MODE must be different from LOCIPV6 in a USERPLANEHOST MO with IPVERSION set to IPv6 in the same routing domain.
  • Relation with the VRF MO:
    • [Co-MPT, eNodeB, gNodeB]VRFIDX in a TUNNELITF MO with CTRLMODE set to MANUAL_MODE must be set to a configured VRF MO.
  • Relation with the IPADDR6 and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]The value of LOCALIP6 in a TUNNELITF MO with CTRLMODE set to MANUAL_MODE must be the same as that of IPV6 in an IPADDR6 MO that has been configured in the same routing domain on the base station, and the IPADDR6 MO must be configured on the INTERFACE MO with PT set to ETH or LOOPINT.
  • Relation with the IPADDR6 MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, REMOTEIP6 in a TUNNELITF MO with CTRLMODE set to MANUAL_MODE must be different from IPV6 in an IPADDR6 MO.
  • Relation with the OMCH MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, REMOTEIP6 in a TUNNELITF MO with CTRLMODE set to MANUAL_MODE must be different from IP6 in an OMCH MO with BEAR set to IPV6.
  • Relation with the INTERFACE MO:
    • [Co-MPT, eNodeB, gNodeB]If PT in an INTERFACE MO is set to TUNNELITF, the TUNNELITF MO referenced by the INTERFACE MO must exist.
    • [Co-MPT, eNodeB, gNodeB]If PT and CTRLMODE in an INTERFACE MO are set to TUNNELITF and MANUAL_MODE, respectively, CTRLMODE in the TUNNELITF MO cannot be set to AUTO_MODE.
    • [Co-MPT, eNodeB, gNodeB]If PT in the INTERFACE MO is TUNNELITF, VRFIDX in the INTERFACE MO must be different from VRFIDX in the INTERFACE MO of the ETH or ETHTRK type referenced by the LOCALIP6 of the TUNNELITF MO on which the INTERFACE MO of the TUNNELITF type depends.
  • Relation with the SRCIPROUTE6 MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, if SRCIP of an SRCIPROUTE6 MO is the same as LOCALIP6 of a TUNNELITF MO, RTTYPE of the SRCIPROUTE6 MO is set to NEXTHOP.
  • Relation with the SECURITYPEER MO:
    • [Co-MPT, eNodeB, gNodeB]If SEGWSWITCH in a SECURITYPEER MO is set to DISABLE and IPVERSION is set to IPv6, PEERIKEIPV6 must be different from REMOTEIP6 in the TUNNELITF MO with CTRLMODE set to MANUAL_MODE.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD TUNNELITF

Use this command to add a tunnel interface.
LST TUNNELITF

Use this command to list the configuration information of tunnel interfaces.
MOD TUNNELITF

Use this command to modify a tunnel interface.
RMV TUNNELITF

Use this command to remove a tunnel interface.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Port ID

Indicates the port ID of a tunnel interface. The value of PORTID in the TUNNELITF MOs configured by users ranges from 0 to 127. The value of PORTID in the TUNNELITF MOs configured by the system ranges from 10000 to 19999.
Mode

Indicates the mode of the tunnel interface.
VRF Index

Indicates the index of a VRF instance.
Local IPv6 Address

Indicates the local IPv6 address of the tunnel interface.
Remote IPv6 Address

Indicates the remote IPv6 address of the tunnel interface.
Control Mode

Indicates whether the object can be automatically modified or removed by the system. When this parameter is set to MANUAL_MODE, only users can perform operations on the object. When this parameter is set to AUTO_MODE, only the system can perform operations on the object.
