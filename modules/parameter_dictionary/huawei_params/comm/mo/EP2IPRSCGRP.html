EP2IPRSCGRP

TRANSPORT
  +-EP2IPRSCGRP

Description

The EP2IPRSCGRP MO is used to configure the mapping between end points and IP transmission resource groups. Based on the mapping, data flows are assigned to corresponding IP transmission resource groups.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the IPRSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The IPRSCGRP MO to which an EP2IPRSCGRP MO depends must exist and RSCGRPNO in the IPRSCGRP MO cannot be set to AUTOPORT or DEFAULTPORT.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The EP2IPRSCGRP MOs that reference an EPGROUP or USERPLANEPEER MO cannot correspond to different IP transmission resource groups on the same physical port.
  • Relation with the EP2IPRSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Two EP2IPRSCGRP MOs with the same combination of MT, ENDPOINTID, and IPRSCGRPID cannot coexist.
  • Relation with the USERPLANEPEER and IPRSCGRP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the EP2IPRSCGRP MO cannot be used to map the USERPLANEPEER MO of the IPv6 type and the AUTOCFGFLAG which is MANUAL_CREATED to the IPRSCGRP MO with PT set to PPP, MPGRP or TUNNEL.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the EP2IPRSCGRP MO cannot be used to map the USERPLANEPEER MO of the IPv6 type and the AUTOCFGFLAG which is MANUAL_CREATED to the IPRSCGRP MO with PT set to ETHTRK.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]A maximum of 64 EP2IPRSCGRP MOs can be configured when the following conditions are met: an Application MO with AT set to GBTS exists; a GTMU MO with TYPE set to GTMU exists, and an MPT MO with TYPE set to UMPT does not exist.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mapping ID

Indicates the ID of a mapping between end points and IP transmission resource groups.
Mapping Type

Indicates the mapping mode between the service and the IP transmission resource group. Two mapping modes are supported: endpoint group mode and endpoint mode. If this parameter is set to ENDPOINT_GROUP, all user-plane peer endpoints in the endpoint group can be added to the specified IP transmission resource group. If this parameter is set to ENDPOINT_NODE, the specified user-plane peer endpoints can be added to the specified IP transmission resource group. When both the endpoint group mode and the endpoint mode are available for mapping all service flows of the same EPPATH to the IP transmission resource group, the endpoint mode is preferentially used for the mapping.
End Point ID

Indicates the ID of the end point group or user plane peer to be added to the specified IP transmission resource group.
IP Transmission Resource Group ID

Indicates the ID of the IP transmission resource group to which a node maps.
User Label

Indicates the description of the end point mapping to IP resource group. This parameter takes effect only in LTE and NR.
