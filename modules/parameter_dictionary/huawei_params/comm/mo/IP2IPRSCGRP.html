IP2IPRSCGRP

TRANSPORT
  +-IP2IPRSCGRP

Description

The IP2IPRSCGRP MO indicates a mapping between the destination IP address of the passing-by data or local OM data (over IP transmission)/signaling data and the IP transmission resource group. This MO is used to guarantee the Quality of Service (QoS) of bound service streams in the target network segment by binding these service streams to an IP transmission resource group.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the IP2IPRSCGRP MO cannot be configured.
  • Relation with the IP2IPRSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If IPVERSION are set to IPV4, IPRSCGRPID, VRFIDX, DSTIPV4 and DSTMASK of IP2IPRSCGRP MOs must be different.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A maximum of 128 IPV6 type IP2IPRSCGRP MOs can be configured for an NE.
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION are set to IPV6, IPRSCGRPID, VRFIDX, DSTIPV6 and PFXLEN of IP2IPRSCGRP MOs must be different.
    • [Co-MPT, eNodeB, gNodeB]A maximum of 128 IPV4 type IP2IPRSCGRP MOs can be configured for an NE.
    • [NodeB]A maximum of 16 IP2IPRSCGRP Mos this IPVERSION are set to IPV4 can be configured for an IPRSCGRP MO.
  • Relation with the IPRSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A maximum of two resource groups can be bound to the same destination network segment on one board. That is, a maximum of two IP2IPRSCGRP MOs whose DSTIPV4 values are on the same network segment can be configured if the two MOs IPVERSION are set to IPV4 and the associated IPRSCGRP MO have the same combination of PT and PT.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The IPRSCGRP MO corresponding to an IP2IPRSCGRP MO must have been configured and the RSCGRPNO cannot set to DEFAULTPORT and AUTOPORT.
    • [Co-MPT, eNodeB, gNodeB]A maximum of two resource groups can be bound to the same destination network segment on one board. That is, a maximum of two IP2IPRSCGRP MOs whose DSTIPV6 values are on the same network segment can be configured if the two MOs IPVERSION are set to IPV6 and the associated IPRSCGRP MO have the same combination of PT and PT.
    • [Co-MPT, eNodeB, gNodeB]An IP2IPRSCGRP MO cannot be used to map an IPv6 address to an IPRSCGRP MO with PT set to PPP, ETHTRK, MPGRP, or TUNNEL.
  • Relation with the VRF MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The VRF instance used by an IP2IPRSCGRP MO must have been configured.
  • Relation with the IPRSCGRP and BACKTUNNEL MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]A maximum of two IP2IPRSCGRP MOs with IPVERSION set to IPV4 and DSTIPV4 located on the same network segment can be bound to the same destination network segment in the same routing domain of the same board.
    • [Co-MPT, NodeB, eGBTS, eNodeB]A board can be configured with a maximum of 32 IP2IPRSCGRP MOs with IPVERSION set to IPV4 on condition that the corresponding IPRSCGRP MOs are on the same board.
    • [Co-MPT, eNodeB]A maximum of two IP2IPRSCGRP MOs with IPVERSION set to IPV6 and DSTIPV6 located on the same network segment can be bound to the same destination network segment in the same routing domain of the same board.
    • [Co-MPT, eNodeB]A board can be configured with a maximum of 32 IP2IPRSCGRP MOs with IPVERSION set to IPV6 on condition that the corresponding IPRSCGRP MOs are on the same board.
    • [gNodeB]A maximum of two IP2IPRSCGRP MOs with IPVERSION set to IPV4 and DSTIPV4 located on the same network segment can be bound to the same destination network segment in the same routing domain of the same board.
    • [gNodeB]A maximum of two IP2IPRSCGRP MOs with IPVERSION set to IPV6 and DSTIPV6 located on the same network segment can be bound to the same destination network segment in the same routing domain of the same board.
    • [gNodeB]A maximum of 32 IP2IPRSCGRP MOs this IPVERSION are set to IPV4.
    • [gNodeB]A maximum of 32 IP2IPRSCGRP MOs this IPVERSION are set to IPV6.
  • Relation with the MDU MO:
    • [Co-MPT, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, the IP2IPRSCGRP MOs this IPVERSION are set to IPV6 cannot be configured.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of IP2IPRSCGRP MOs this IPVERSION are set to IPV6 is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD IP2IPRSCGRP

Use this command to add mapping between an IP address and an IP transmission resource group. The mapping between an IP address and an IP transmission resource group is the mapping between the destination IP address of the passing-by data or local OM data (over IP transmission)/signaling data and an IP transmission resource group.
LST IP2IPRSCGRP

Use this command to list the configuration of the mapping between the IP address and the IP transmission resource group.
RMV IP2IPRSCGRP

Use this command to remove a mapping between the IP address and the IP transmission resource group.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IP to IP Transmission Resource Group ID

Indicates the ID of the mapping between an IP address and an IP transmission resource group.
IP Transmission Resource Group ID

Indicates the ID of the IP transmission resource group.
VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).
IP Version

Indicates the destination IP protocol version of the service flow that is bound to an IP transmission resource group.
Destination IPv4 Address

Indicates the destination IPv4 address of the service flow that is bound to an IP transmission resource group.
Subnet Mask

Indicates the subnet mask of the destination IPv4 address of the service traffic bound to an IP transmission resource group.
Destination IPv6 Address

Indicates the destination IPv6 address of the service flow that is bound to an IP transmission resource group.
Prefix Length

Indicates the prefix length of the destination IPv6 address of the service flow that is bound to an IP transmission resource group.
