TREELNKPVC

TRANSPORT
  +-TREELNKPVC

Description

The treelink permanent virtual channel (PVC) is preestablished by the network management system (NMS). Regardless of service admission and terminal access, the PVC exists until it is released by the NMS. In this way, the PVC is similar to the leased line in the telephone network. Users connected over PVCs can communicate even if network resources are insufficient.

Effective Scenario

Immediately

  • Relation with the RSCGRP MO:
    • [Co-MPT, NodeB]The RSCGRP MO that is associated with a TREELNKPVC MO must have been configured.
    • [Co-MPT, NodeB]If JNRSCGRP in a TREELNKPVC MO is set to ENABLE, the transmit bandwidth for the TREELNKPVC MO cannot exceed the transmit bandwidth for an RSCGRP MO.
  • Relation with the IMAGRP, IMALNK, and E1T1 MOs:
    • [Co-MPT, NodeB]If JNRSCGRP in a TREELNKPVC MO is set to DISABLE, the transmit bandwidth for the TREELNKPVC MO cannot exceed the transmit bandwidth for an IMAGRP MO.
  • Relation with the E1T1 MO:
    • [Co-MPT, NodeB]If JNRSCGRP in a TREELNKPVC MO is set to DISABLE, the transmit bandwidth for the TREELNKPVC MO cannot exceed the transmit bandwidth for a UNILNK MO.
    • [Co-MPT, NodeB]If JNRSCGRP in a TREELNKPVC MO is set to DISABLE, the transmit bandwidth for the TREELNKPVC MO cannot exceed the transmit bandwidth for an FRAATM MO.
  • Relation with the TREELNKPVC MO:
    • [Co-MPT, NodeB]TREELNKPVC MOs cannot use the same path with the same combination of SRCVPI and SRCVCI on one link.
  • Relation with the SAALLNK MO:
    • [Co-MPT, NodeB]A TREELNKPVC MO and an SAALLNK MO cannot use the same path with the same combination of VPI and VCI on one link.
  • Relation with the OMCH MO:
    • [Co-MPT, NodeB]A TREELNKPVC MO and an OMCH MO cannot use the same path with the same combination of VPI and VCI on one link.
  • Relation with the AAL2PATH MO:
    • [Co-MPT, NodeB]A TREELNKPVC MO and an AAL2PATH MO cannot use the same path with the same combination of VPI and VCI on one link.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of TREELNKPVC MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
