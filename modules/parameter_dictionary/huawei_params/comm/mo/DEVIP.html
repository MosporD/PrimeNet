DEVIP

TRANSPORT
  +-DEVIP

Description

A DEVIP MO consists of the parameters related to a device IP address of an IP port. An IP port can be an Ethernet port, Ethernet CI port, Sub-interface, loopback port, or a port that carries a PPP link, MP group, or Ethernet trunk. A device IP address of a loopback port is also called a loopback IP address or logical IP address. Unlike other types of IP port, a loopback port is a virtual port. A loopback IP address mainly serves as the destination IP address of an active/standby route or as the IP address at the internal layer of an IPSec tunnel. The device IP addresses of IP ports of other types are called interface IP addresses. The IP address takes effect immediately upon the completion of configuration.

Effective Scenario

Immediately

  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If MODELSELECT in the GTRANSPARA MO is set to TRADITION, BORROWIFIP in the DEVIP MO must be NO.
    • [Co-MPT, NodeB, eNodeB, gNodeB]If MODELSELECT in the GTRANSPARA MO is set to HOSTGW, the PT in the DEVIP MO must be LOOPINT.
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the DEVIP MO cannot be configured.
  • Relation with the IPPATH, PPPLNK, and MPGRP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]LOCALIP in an IPPATH MO must be the same as a DEVIP MO configured at a physical port or loopback port of the same board. If LOCALIP in an IPPATH MO is the same as a DEVIP MO configured at a physical port, PT and PN in the IPPATH MO must be the same as PT and PN in the DEVIP MO, respectively. Alternatively, LOCALIP in the IPPATH MO must be the same as LOCALIP in the associated PPPLNK MO or LOCALIP in the associated MPGRP MO.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TYPE in an MDU MO is set to MDUC, the DEVIP MO must meet the following conditions: Cabinet No., Subrack No., and Slot No. are set to the same values as those in the MDU MO; SBT is set to BASE_BOARD; PT is set to ETH or LOOPINT; PN is set to a value within the range 0 to 2.
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, a maximum of 16 DEVIP MOs can be configured.
  • Relation with the SCTPLNK, PPPLNK, MPGRP, and GTRANSPARA MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TRANSCFGMODE in the GTRANSPARA MO is set to OLD, before adding an SCTPLNK MO with CTRLMODE set to MANUAL_MODE, ensure that the MPGRP or PPPLNK MO that has the same VRF Index as the SCTPLNK MO has been configured. Alternatively, ensure that the DEVIP MO, MPGRP MO, or PPPLNK MO that meets both of the following conditions has been configured: (1) The DEVIP MO, MPGRP MO, or PPPLNK MO is in the same routing domain as the SCTPLNK MO. (2) LOCIP or SECLOCIP in the SCTPLNK MO is the same as IP in the DEVIP MO, LOCALIP in the MPGRP MO, or LOCALIP in the PPPLNK MO. The first and the second local IP addresses of an SCTP link must be configured on the same subrack, if the two IP addresses are not on the same board, the subboard type of the host IP addresses must be BASE_BOARD, and the bearing port type must be ETH, ETHTRK, or LOOPINT.
  • Relation with the IPPMSESSION, PPPLNK, MPGRP, IPADDR4, and GTRANSPARA MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, and BINDPATH in an IPPMSESSION MO is set to NO, the IP address corresponding to LOCALIP in the IPPMSESSION MO must have been configured. That is, for the IPPMSESSION MO, if TRANSCFGMODE in the GTRANSPARA MO is set to OLD, DEVIP MO in the same routing domain, PPPLNK MO, and MPGRP MO configured on the same board, LOCALIP in the IPPMSESSION MO must be the same as any of the following: IP in the DEVIP MO; LOCALIP in the PPPLNK MO; or LOCALIP in the MPGRP MO. When TRANSCFGMODE in the GTRANSPARA MO is set to NEW, IPADDR4 MO in the same routing domain, PPPLNK MO, and MPGRP MO configured on the same board, LOCALIP in the IPPMSESSION MO must be the same as any of the following: IP in the IPADDR4 MO; LOCALIP in the PPPLNK MO; or LOCALIP in the MPGRP MO.
  • Relation with the DNSSRV and GTRANSPARA MOs:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD and IPVER is set to IPv4, DNSCIP4 in a DNSSRV MO must be the same as IP in an existing DEVIP MO, and PT in a DEVIP MO is not set to PPP or MPGRP or ETHCI.
  • Relation with the DNSSRV MO:
    • [Co-MPT, eNodeB, gNodeB]The DNSCIP4 parameter in all DNSSRV MOs must be configured on the same board.
    • [Co-MPT, eNodeB, gNodeB]The DNSSIP4 parameter in the DNSSRV MO must be different from the IP parameter in the DEVIP MO in the same routing domain.
  • Relation with the DFUMLCLIENT and OMCH MOs:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE is set to OLD, and IPVERSION in a DFUMLCLIENT MO is set to IPV4, IPVERSION in the DFUMLCLIENT MO must be set to the same value as IP in the OMCH MO or as IP in an DEVIP MO in the same routing domain.
  • Relation with the IPPATHRT, IFIP, and GTRANSPARA MOs:
    • [Co-MPT, eGBTS, eNodeB]If MODELSELECT of GTRANSPARA is set to TRADITION, the value of SRCIP in an IPPATHRT MO must be the same as the IP address in a configured DEVIP MO that meets both of the following conditions: (1) The DEVIP MO is in the same routing domain as the IPPATHRT MO. (2) The port type in the DEVIP MO is set to ETH, ETHTRK, LOOPINT, or SUBIF. If MODELSELECT of GTRANSPARA is set to HOSTGW, the value of SRCIP in an IPPATHRT MO must be the same as the IP address in a configured DEVIP MO that meets both of the following conditions: (1) The DEVIP MO is in the same routing domain as the IPPATHRT MO. (2)The IFIP MO is in the same routing domain as the IPPATHRT MO, the port type in the IFIP MO is set to ETH, ETHTRK, or SUBIF.
    • [Co-MPT, eGBTS, eNodeB]On the board to which the IP address specified by SRCIP in an IPPATHRT MO belongs, there must be an IP address that is on the same network segment and in the same routing domain as the IP address specified by NEXTHOPIP and these two IP addresses cannot be the same.
  • Relation with the IPPATHRT MO:
    • [Co-MPT, eGBTS, eNodeB]NEXTHOPIP in an IPPATHRT MO cannot be set to a broadcast IP address of the network segment where the DEVIP MO on the egress port is located, and Network ID and Host ID cannot be all 0 or all 1.
    • [Co-MPT, eGBTS, eNodeB]If a DEVIP MO and an IPPATHRT MO are in the same routing domain, IP in the DEVIP MO must be different from NEXTHOPIP in the IPPATHRT MO.
  • Relation with the IFIP and GTRANSPARA MOs:
    • [Co-MPT, eNodeB, gNodeB]On a BS, if MODELSELECT of GTRANSPARA MO is set to TRADITION, the sum of IPADDR6 and DEVIP MOs must be less than or equal to 128. If MODELSELECT of GTRANSPARA MO is set to HOSTGW, the sum of IPADDR6, DEVIP and IFIP MOs must be less than or equal to 128.
  • Relation with the IPPATH and IFIP MOs:
    • [Co-MPT, NodeB, eNodeB]The DEVIP MO that is depended by an IPPATH MO cannot borrow an IFIP MO whose PT is ETHCI.
    • [Co-MPT, NodeB, eNodeB]If the DEVIP MO depended by an IPPATH MO borrows an IFIP MO and PT in the borrowed IFIP MO is SUBIF, PT and PN in the IPPATH MO must be the same as PT and PN in the corresponding SUBIF MO, respectively.
  • Relation with the DIRECTIPSECWHITELIST, IFIP, and LOCALIP MOs:
    • [Co-MPT, eNodeB, gNodeB]When the value of MASK in a DIRECTIPSECWHITELIST MO is 255.255.255.255, the value of SECURITYPEERIPV4 in the DIRECTIPSECWHITELIST MO cannot be the same as the value of IP in the DEVIP MO, the value of IP in the IFIP MO or the value of IP in the LOCALIP MO.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of DEVIP MOs must be less than or equal to 64 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
  • Relation with the SCTPPEER, MPGRP, and PPPLNK MOs:

    • [NodeB]In the same routing domain, SIGIP2V4 in an SCTPPEER MO must be different from IP, LOCALIP, or LOCALIP in a configured DEVIP MO, MPGRP MO, and PPPLNK MO, respectively.
  • Relation with the SINGLEIPSWITCH, IFIP, and GTRANSPARA MOs:
    • [NodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, and MODELSELECT of GTRANSPARA is set to TRADITION, SINGLEIPSW and CM in a SINGLEIPSWITCH MO are set to ENABLE and PANEL_INTERCONNECT, respectively, ensure that a DEVIP MO corresponding to UIIP in the SINGLEIPSWITCH MO is configured and that PT in the DEVIP MO is set to ETH. If MODELSELECT of GTRANSPARA is set to HOSTGW, SINGLEIPSW and CM in a SINGLEIPSWITCH MO are set to ENABLE and PANEL_INTERCONNECT, respectively, ensure that an IFIP MO corresponding to UIIP in the SINGLEIPSWITCH MO is configured and that PT in the IFIP MO is set to ETH.
    • [NodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, and MODELSELECT of GTRANSPARA is set to TRADITION and SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, ensure that a DEVIP MO corresponding to UOIP in the SINGLEIPSWITCH MO is configured and that PT in the DEVIP MO is set to ETH or ETHTRK. If MODELSELECT of GTRANSPARA is set to HOSTGW and SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, ensure that an IFIP MO corresponding to UOIP in the SINGLEIPSWITCH MO is configured and that PT in the IFIP MO is set to ETH or ETHTRK.
  • Relation with the SINGLEIPSWITCH MO:
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GPEERIP in the SINGLEIPSWITCH MO must be different from IP in any DEVIP MO.
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GIIP in the SINGLEIPSWITCH MO must be different from IP in any DEVIP MO.
  • Relation with the BFDSESSION, IFIP, and GTRANSPARA MOs:
    • [gNodeB]SRCIP in a BFDSESSION MO to be added must have been configured. That is: (1) If MODELSELECT of GTRANSPARA is set to TRADITION, for the BFDSESSION MO and DEVIP MO configured on the same board, SRCIP in the BFDSESSION MO must be the same as any of the following: IP in the IFIP MO in the same routing domain. (2) If MODELSELECT of GTRANSPARA is set to HOSTGW, for the BFDSESSION MO and IFIP MO configured on the same board, SRCIP in the BFDSESSION MO must be the same as any of the following: IP in the IFIP MO in the same routing domain.
  • Relation with the SCTPLNK and GTRANSPARA MOs:
    • [gNodeB]When TRANSCFGMODE in a GTRANSPARA MO is set to OLD, before adding an SCTPLNK MO with CTRLMODE set to MANUAL_MODE, ensure that the DEVIP MO that meets both of the following conditions has been configured: (1) The DEVIP MO is in the same routing domain as the SCTPLNK MO. (2) LOCIP or SECLOCIP in the SCTPLNK MO is the same as IP in the DEVIP MO.
  • Relation with the IPPMSESSION and GTRANSPARA MOs:
