AAL2PATH

TRANSPORT
  +-AAL2PATH

Description

An AAL2 path is used to carry service data between AAL2 nodes.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS]When TYPE in the MDU MO is set to MDUC, the AAL2PATH MO cannot be configured.
  • Relation with the TREELNKPVC MO:
    • [Co-MPT, NodeB]A TREELNKPVC MO and an AAL2PATH MO cannot use the same path with the same combination of VPI and VCI on one link.
  • Relation with the SAALLNK MO:
    • [Co-MPT, NodeB]An SAALLNK MO and an AAL2PATH MO cannot use the same path with the same combination of VPI and VCI on one link.
  • Relation with the AAL2PATH MO:
    • [Co-MPT, NodeB]A maximum of 32 AAL2PATH MOs can be configured on a board.
    • [Co-MPT, NodeB]Two AAL2PATH MOs cannot use the same path with the same combination of VPI and VCI on one link.
    • [Co-MPT, NodeB]A maximum of 16 AAL2PATH MOs can be configured on a physical port or for a resource group.
  • Relation with the OMCH MO:
    • [Co-MPT, NodeB]An AAL2PATH MO and an OMCH MO cannot use the same path with the same combination of VPI and VCI on one link.
  • Relation with the UNILNK MO:
    • [Co-MPT, NodeB]The UNILNK MO associated with an AAL2PATH MO that is not added to any RSCGRP MO must have been configured.
  • Relation with the IMAGRP MO:
    • [Co-MPT, NodeB]The IMAGRP MO associated with an AAL2PATH MO that is not added to any RSCGRP MO must have been configured.
  • Relation with the FRAATM MO:
    • [Co-MPT, NodeB]The FRAATM MO associated with an AAL2PATH MO that is not added to any RSCGRP MO must have been configured.
  • Relation with the AAL2NODE MO:
    • [Co-MPT, NodeB]If NT in an AAL2PATH MO is set to LOCAL, the AAL2NODE MO that meets the following conditions must have been configured: (1) BELONG and FLAG are both set to MASTER and MASTER; (2) NT is set to LOCAL.
    • [Co-MPT, NodeB]If NT in an AAL2PATH MO is set to HUB, the AAL2NODE MO whose NT is set to HUB must have been configured.
  • Relation with the AAL2ADJNODE MO:
    • [Co-MPT, NodeB]If NT in an AAL2PATH MO is set to ADJNODE, the AAL2ADJNODE MO whose ANI is the same as ANI in the AAL2PATH MO must have been configured.
  • Relation with the RSCGRP MO:
    • [Co-MPT, NodeB]The RSCGRP MO to which an AAL2PATH MO will be added must have been configured.
    • [Co-MPT, NodeB]If JNRSCGRP in an AAL2PATH MO is set to DISABLE, an RSCGRP MO whose BEAR is set to ATM cannot be configured on the link that carries the AAL2 path.
    • [Co-MPT, NodeB]If JNRSCGRP in an AAL2PATH MO is set to ENABLE, the transmit bandwidth for the AAL2PATH MO cannot exceed the transmit bandwidth for an RSCGRP MO.
    • [Co-MPT, NodeB]If JNRSCGRP in an AAL2PATH MO is set to ENABLE, the receive bandwidth for the AAL2PATH MO cannot exceed the receive bandwidth for an RSCGRP MO.
  • Relation with the IMAGRP, IMALNK, and E1T1 MOs:
    • [Co-MPT, NodeB]If JNRSCGRP in an AAL2PATH MO is set to DISABLE, the transmit bandwidth for the AAL2PATH MO cannot exceed the transmit bandwidth for an IMAGRP MO.
  • Relation with the E1T1 MO:
    • [Co-MPT, NodeB]If JNRSCGRP in an AAL2PATH MO is set to DISABLE, the transmit bandwidth for the AAL2PATH MO cannot exceed the transmit bandwidth for a UNILNK MO.
    • [Co-MPT, NodeB]If JNRSCGRP in an AAL2PATH MO is set to DISABLE, the transmit bandwidth for the AAL2PATH MO cannot exceed the transmit bandwidth for an FRAATM MO.
    • [Co-MPT, NodeB]If JNRSCGRP in an AAL2PATH MO is set to DISABLE, the receive bandwidth for the AAL2PATH MO cannot exceed the receive bandwidth for a UNILNK MO.
    • [Co-MPT, NodeB]If JNRSCGRP in an AAL2PATH MO is set to DISABLE, the receive bandwidth for the AAL2PATH MO cannot exceed the receive bandwidth for an FRAATM MO.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of AAL2PATH MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Path ID

Indicates the number of an AAL2 path.
Cabinet No.

Indicates the number of the cabinet where an AAL2 path is located.
Subrack No.

Indicates the number of the subrack where an AAL2 path is located.
Slot No.

Indicates the number of the slot where an AAL2 path is located.
Bearer Service Type

Indicates the type of the service carried on an AAL2 path. From the perspective of flow control, services carried by an AAL2 path are classified into five categories: the constant bit rate (CBR) service, real-time variable bit rate (RTVBR) service, non-real-time variable bit rate (NRTVBR) service, unspecified bit rate plus (UBR+) service, and unspecified bit rate (UBR) service.
Join Transmission Resource Group

Indicates whether an AAL2 path joins a transmission resource group.
Transmission Resource Group ID

Indicates the number of the transmission resource group to which an AAL2 path is added.
Bearer Port Type

Indicates the type of port on which an AAL2 path is carried.
Bearer Port No.

Indicates the number of the port on which an AAL2 path is carried.
VPI

Indicates the virtual path identifier (VPI) of an AAL2 path.
VCI

Indicates the virtual channel identifier (VCI) of an AAL2 path.
Peak Cell Rate

Indicates the peak cell rate (PCR) of an AAL2 path, which is the maximum cell burst rate supported by the AAL2 path. The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality.
Sustain Cell Rate

Indicates the Sustainable Cell Rate (SCR) of the AAL2 path. The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality.

The SCR value determines the average rate at which cells are sent over a Variable Bit Rate (VBR) connection.
Min Cell Rate

Indicates the minimum cell rate (MCR) of an AAL2 path. The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality. The MCR is the minimum cell transmission rate acceptable by the user.
Max Burst Size

Indicates the maximum burst size (MBS). The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality.
Receive Cell Rate

Indicates the rate at which cells are received. This parameter must be consistent with the TX bandwidth configured on the controller. Otherwise, the RX bandwidth in the flow control algorithm will be inaccurate, affecting flow control.
Cell Delay Variation Tolerance

Indicates the cell delay variation tolerance. The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality.
Subboard Type

Indicates the type of sub-board on the board where an AAL2 path is established.
Node Type

Indicates the type of an AAL2 path. If the local end node is selected, the AAL2 path is used by local services. If the switching node is selected, the AAL2 path is used to connect to the controller through the hub BS. If the adjacent node is selected, the AAL2 path is used to connect to the lower-level BS through the hub BS.
Adjacent Node ID

Indicates the adjacent node ID of an AAL2 path.
Rate Unit

Indicates the unit of the peak cell rate (PCR), minimum cell rate (MCR), sustainable cell rate (SCR), and receive cell rate (RCR). 1 cell/s is equal to 0.424 kbit/s. If the rate is converted from cell/s to kbit/s, the result value must be rounded down to the nearest integer. For example, 73 cell/s is converted to 30 kbit/s.
User Label

Indicates the user-defined information about an AAL2 path.
