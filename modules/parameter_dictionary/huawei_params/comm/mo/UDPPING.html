UDPPING

TRANSPORT
  +-UDPPING

Description

A UDPPING MO is used to configures the parameters related to UDP Ping detection of control frames.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    TRANSPORT

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST UDPPING

Use this command to query the parameter configuration for UDP Ping detection of echo packets.
SET UDPPING

This command is used to set the parameters for UDP Ping detection of echo packets.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Timeout Duration of Echo Frames

Indicates the timeout duration of waiting for echo responses in the UDP Ping detection mechanism. If no echo response is received after the duration specified by this parameter, echo response times out.
Number of Echo Frame Timeouts

Indicates the maximum number of echo response timeouts during UDP Ping detection. When the number of times that echo responses time out reaches the value of this parameter, the UDP Ping detection path is considered faulty.
DSCP

Indicates the differentiated services code point (DSCP) for UDP Ping control packets.
