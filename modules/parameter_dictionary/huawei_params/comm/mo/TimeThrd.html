TIMETHRD

+-NE
  +-NODE
    +-SYSTEMOM
      +-TIMETHRD

Description

The TIMETHRD MO is used to manage the time threshold between the NE and the external clock source. When the time difference between the current time of the NE and that of the external clock source exceeds the threshold, a notification is sent to the management module for alarm reporting.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    SYSTEMOM

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST TIMETHRD

Use this command to list the parameter settings related to the threshold value.
SET TIMETHRD

Use this command to set parameters related to the threshold value for an NE. EVT-26360 Time Source Switchover is reported, when Time Hopping Detection Switch is set to On, time synchronization succeeds, and the difference between the NE time and the time provided by the time source is greater than the threshold.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Threshold Value

Indicates the threshold value for the difference between the NE time and the time provided by the time source.
Time Hopping Detection Switch

Indicates whether to detect time hopping on the NE.
