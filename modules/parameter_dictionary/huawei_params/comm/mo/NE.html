NE

NE
  +-NODE[1~1]

Description

The root of NE model.

Effective Scenario

Not involved

Relations Between MOs

  • Possible children:

    NODE[1~1]
  • Relation with the LOCATION MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATION in the NE MO is not left blank, POSITIONINGMETHOD in the LOCATION MO corresponding to this character string cannot be set to POSITIONING_BY_UE.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NE

Use this command to list network element configuration.
SET NE

Use this command to set Network Element Name, Site Location, Deployment Identifier, Site Name, User Label and Cloud BB identifier.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Site Location

Indicates the location of the base station.
Software Version

Indicates the software version of the NE.
User Label

Indicates the user-defined information of the NE.
NeRM Version

Indicates the version of the NE resource model which includes the MOC, attributes, and configuration rules.
Product InterfaceID

Indicates the ID of the product interface.
Product Version

Indicates the product software version of the base station.
LMT Version

Indicates the LMT version.
Deployment Identifier

Indicates the deployment identifier that specifies the site of the NE. When multiple NEs are deployed at the same site, these NEs have the same deployment identifier.
Site Name

Indicates the site name. When multiple NEs are at the same site, these NEs are configured with the same site name.
Network Element Name

Indicates the NE name.
Hot Patch Version

Indicates the software hot patch version of the NE.
Cloud BB Identifier

Indicates the Cloud BB identifier that specifies the Cloud BB to which the NE belongs. When multiple NEs are deployed under the same Cloud BB, these NEs have the same Cloud BB identifier. The default value 0 cannot be used as a Cloud BB identifier.
