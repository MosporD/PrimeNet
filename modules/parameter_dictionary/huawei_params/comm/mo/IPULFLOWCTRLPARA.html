IPULFLOWCTRLPARA

TRANSPORT
  +-IPULFLOWCTRLPARA

Description

The IPULFLOWCTRLPARA MO is used to set the parameters related to the algorithm for uplink flow control of a physical port. The IPULFLOWCTRLPARA MO takes effect only in UMTS.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the ETHTRUNK MO:
    • [Co-MPT, NodeB, eGBTS]If PT in a IPULFLOWCTRLPARA MO is set to ETHTRK, the associated ETHTRUNK MO must have been configured.
  • Relation with the ETHTRUNKLNK MO:
    • [Co-MPT, NodeB, eGBTS]If PT in an IPULFLOWCTRLPARA MO is set to ETHTRK, at least one member ETHTRUNKLNK MO must have been configured in the associated ETHTRUNK MO.
    • [Co-MPT, NodeB, eGBTS]If an ETHPORT MO has been added to an ETHTRUNK MO, an IPULFLOWCTRLPARA MO that meets all the following conditions cannot be configured: (1) PT in the IPULFLOWCTRLPARA MO is set to ETH. (2) PORTID is the same as ETHPORTID in the ETHTRUNKLNK MO.
  • Relation with the PPPLNK MO:
    • [Co-MPT, NodeB, eGBTS]If PT in a IPULFLOWCTRLPARA MO is set to PPP, the associated PPPLNK MO must have been configured.
  • Relation with the MPGRP MO:
    • [Co-MPT, NodeB, eGBTS]If PT in a IPULFLOWCTRLPARA MO is set to MPGRP, the associated MPGRP MO must have been configured.
  • Relation with the BACKTUNNEL MO:
    • [Co-MPT, NodeB, eGBTS]If PT in a IPULFLOWCTRLPARA MO is set to TUNNEL, the associated BACKTUNNEL MO must have been configured.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eGBTS]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the IPULFLOWCTRLPARA MO cannot be configured.
  • Relation with the IPULFLOWCTRLPARA MO:
    • [Co-MPT, NodeB, eGBTS]Each IPULFLOWCTRLPARA MO must have a unique combination of PT, and PORTID.
    • [Co-MPT, NodeB, eGBTS]On a BS, the sum of IPULFLOWCTRLPARA and ULFLOWCTRLPARA MOs must be less than or equal to 144.
  • Relation with the ETHPORT MO:
    • [Co-MPT, NodeB, eGBTS]If PT in a IPULFLOWCTRLPARA MO is set to ETH, the associated ETHPORT MO must have been configured.
  • Relation with the LOOPBACK MO:
    • [Co-MPT, NodeB, eGBTS]If PT in a IPULFLOWCTRLPARA MO is set to LOOPINT, the associated LOOPBACK MO must have been configured.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of IPULFLOWCTRLPARA MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IP Uplink Flow Control Algorithm ID

Indicates the ID of the IP UL flow control algorithm.
Port Type

Indicates the type of port where the IP UL flow control algorithm is configured.
Port ID

Indicates the ID of the port where the IP UL flow control algorithm is configured.
Bandwidth Adjustment Protection Switch

Indicates whether to adjust the IP available UL bandwidth. When this parameter is set to ON, the BS stops adjusting the available UL bandwidth of the physical port if the bit error rate (BER) on the transmission line exceeds the specified alarm threshold. This parameter does not take effect for loopback ports or tunnels because the error MAC frame reporting function is not implemented for loopback ports and tunnels.
Congestion Control Switch

Indicates whether to perform congestion control. When this switch is turned on, the BS lowers the TX rate if the BS detects that links experience transmission delay or packet loss.
Congestion Control Enhancement Switch

Indicates the switch for the enhanced congestion control. When the switch is set to ON, the enhanced congestion control prevents uplink available bandwidth from sharply decreasing and uplink throughput from abruptly deteriorating when bit-error packet loss occurs on the transport network. The packet loss rate may increase when the incoming port is congested. However, this seldom occurs.

This feature requires the uplink FPDT IP GPM detection result. Before using this feature, run the ADD IPGPM or MOD IPGPM command to enable the uplink FPDT IP GPM detection function for the NodeB.

This switch can be configured only when the flow control function is enabled.
Minimum UL Available Bandwidth of Logical Port

Indicates the minimum UL bandwidth of logic port.
