OMCH

TRANSPORT
  +-OMCH

Description

An OMCH MO consists of the parameters related to a remote maintenance channel through which the MAE manages and maintains the BS. The OMCH MO has one active channel and one standby channel. If the active channel is interrupted, the BS switches services to the other channel according to instructions from the MAE.

Effective Scenario

Immediately

  • Relation with the FRAATM MO:
    • [Co-MPT, NodeB]If BEAR, JNRSCGRP, and PT are set to ATM, DISABLE, and FRAATM, respectively in an OMCH MO, the FRAATM MO whose FRAATM is the same as PN in the OMCH MO must have been configured.
  • Relation with the IMAGRP, IMALNK, and E1T1 MOs:
    • [Co-MPT, NodeB]In an IMAGRP MO, the total transmit bandwidth for the SAALLNK MO with JNRSCGRP set to DISABLE and for the OMCH MO cannot exceed the transmit bandwidth for the IMAGRP MO.
  • Relation with the E1T1 MO:
    • [Co-MPT, NodeB]In a UNILNK MO, the total transmit bandwidth for the SAALLNK MO with JNRSCGRP set to DISABLE and for the OMCH MO cannot exceed the transmit bandwidth for the UNILNK MO.
    • [Co-MPT, NodeB]In an FRAATM MO, the total transmit bandwidth for the SAALLNK MO with JNRSCGRP set to DISABLE and for the OMCH MO cannot exceed the transmit bandwidth for the FRAATM MO.
  • Relation with the RSCGRP MO:
    • [Co-MPT, NodeB]In an RSCGRP MO, the total transmit bandwidth for the SAALLNK and OMCH MOs cannot exceed the transmit bandwidth for the RSCGRP MO.
    • [Co-MPT, NodeB]If BEAR and JNRSCGRP are set to ATM and ENABLE, respectively in an OMCH MO, the associated RSCGRP MO must have been configured.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of OMCH MOs with CHECKTYPE set to AUTO_UDPSESSION is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
    • [Co-MPT, eGBTS]The number of OMCH MOs whose bearer type is IPV6 is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
    • [Co-MPT, eGBTS]The number of OMCH MOs with BEAR set to ATM is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
  • Relation with the HAGRP MO:
    • [Co-MPT, NodeB]In one logical protection group, SN in an HAGRP MO must be the same as that in an OMCH MO.
  • Relation with the SINGLEIPSWITCH MO:
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GPEERIP in the SINGLEIPSWITCH MO must be different from IP in any OMCH MO in the same routing domain.
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GIIP in the SINGLEIPSWITCH MO must be different from IP in any OMCH MO in the same routing domain.
  • Relation with the DHCPSVRIP, IPADDR4, and GTRANSPARA MOs:
    • [gNodeB]When TRANSCFGMODE in a GTRANSPARA MO is set to NEW, DHCPRELAYIP parameter in the DHCPSVRIP MO must be set to a valid IP address, and this IP address must be equal to any one value of the following parameters: IP in OMCH MO in the same routing domain, IP in IPADDR4 MO in the same routing domain.
  • Relation with the IPRT and MPT MOs:
    • [gNodeB]When an MPT MO with TYPE set to UMPT exists, or an OMCH MO does not exist, for any two IPRT MOs of a base station in the same routing domain, if RTTYPE and IFT in any one of the IPRT MO are set to IF and TUNNEL, respectively, DSTIP in the two IPRT MOs must be set to different values.
  • Relation with the DHCPSVRIP, DEVIP, IFIP, and GTRANSPARA MOs:
    • [gNodeB]If MODELSELECT of GTRANSPARA is set to TRADITION, the DHCPRELAYIP parameter in the DHCPSVRIP MO must be set to a valid IP address, and this IP address must be equal to any one value of the following parameters: IP in OMCH MO, IP in DEVIP MO. If MODELSELECT of GTRANSPARA is set to HOSTGW, the DHCPRELAYIP parameter in the DHCPSVRIP MO must be set to a valid IP address, and this IP address must be equal to any one value of the following parameters: IP in OMCH MO, IP in IFIP MO.
  • Relation with the IPROUTE4 and MPT MOs:
    • [gNodeB]When an MPT MO with TYPE set to UMPT exists, or an OMCH MO does not exist, for any two IPROUTE4 MOs of a base station in the same routing domain, if RTTYPE and PT in any one of the IPROUTE4 MO are set to IF and TUNNEL, respectively, DSTIP in the two IPROUTE4 MOs must be set to different values.

Indicates whether a route is bound to the remote maintenance channel.
