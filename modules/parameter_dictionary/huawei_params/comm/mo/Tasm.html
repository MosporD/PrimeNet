TASM

EQUIPMENT
  +-TASM

Description

The Tasm MO is the system clock. It is created by the system automatically and can be changed to another reference clock source according to the priority and availability.

Effective Scenario

Not involved

Function

Use this command to query the Phase Lock status of soft synchronization over the Air interface.

Use this command to display the records of clock status. The main control board stores the latest 100 records. The board records the clock status when users change the clock source, current DA value, clock working mode, or center DA value or when the system automatically calibrates the clock that operates for a long time.

Use this command to display the clock quality test monitoring result. The result shows the frequency or phase offset of the current clock source. The offset indicates the quality of the clock.

DSP DARECORD

Use this command to display the records of center DA values. The main control board stores the latest 100 records. The board records the center DA value each time the value is changed by users or the system. The system changes the center DA to the average of current DA when system clock is in the locked state for 96 hours.

Use this command to query the information of the leap second offset between the UTC and the GPS.

Use this command to query the clock quality level of a BS.
MOD CENTERDA

Use this command to change the center DA value of an NE.
MOD CURRDA

Use this command to change the current DA value of the NE. When the clock of the NE works in free-running mode, the current DA value changes with the center DA value. When an external reference clock is available, the current DA value changes with the frequency of the reference clock, that is, the current DA value is adjusted on the basis of the frequency deviation during software phase-locking. If the reference clock is locked for 96 hours, it is an indication that the reference is stable. In this case, the average of current DA values in this period is used as the center DA value. Each time the NE or the main control board is reset, the current DA value is automatically overwritten by the center DA value.
SET AISS

Use this command to set parameters related to air interface soft synchronization.
SET CLKMODE

Use this command to set the working mode of the reference clock source.
SET CLKMUTUALLOCK

Use this command to set the major standard for clock mutual lock on a multimode base station. The clock on the major standard side is used as the standard clock.
SET CLKSRCBKPMODE

Use this command to set the backup mode of the GPS or TOD clock source whose signals are introduced by a main control board. The backup mode is controlled by the Clock Source Backup Mode parameter. When this parameter is set to BRDBKMODE, the primary main control board introduces clock signals from the clock source regardless of whether the GPS or TOD clock link is configured on the active or standby board. When this parameter is set to CLKSRCBRDCFG, the active and standby boards can be configured with both GPS clock links or both TOD clock links, and the standby board introduces clock signals from the clock source if it is configured with a GPS or TOD clock link.
SET CLKSYNCMODE

Use this command to set the clock synchronization mode of a BS, the GSM frame bit offset, the GSM Frame Sync Switch, the frame synchronization switch, the locked system clock source, the Enhanced SYSCLK failure check switch, the low-precision frame No. synchronization switch and the Major Standard Change Optimization Switch.
SET CLKTHD

Use this command to set the clock tracing mode of a specified main control board.
SET CLOUDSRC

Use this command to set whether the local NE serves as the reference clock source in the Cloud BB. When the NE is enabled, the other NEs in the Cloud BB can share the reference clock source of the local NE by adding an interconnection clock link.
SET FNSYNCTIME

Use this command to set the Cellular Internet of Thing (CIoT) Frame No. parameters, including the time when the hyper system frame No. (HSFN) is 0 and the status of the frame No. synchronization switch.
SET IPCLKALGO

Use this command to set the clock algorithm parameters for an IP clock link.
SET LEAPSECONDSINFO

Use this command to set the information of the leap second offset between the UTC and the GPS.
SET LOCALCLKQL

Use this command to set the clock quality level of a BS.
SET TSTCLKOUT

Use this command to set the types of test clocks to be outputted.
STP CLKTST

Use this command to stop the clock quality test monitoring.
STR CLKTST

Use this command to start a clock quality test monitoring. The test time, frequency offset, and phase offset are saved as test records. A maximum of 100 test records can be saved. If there are more than 100 test records, the historical records will be overwritten.
STR FREQDIFFCHK

Use this command to check the cause of an excessive frequency deviation when ALM-26262 External Clock Reference Problem is reported and the alarm cause is Excessive Frequency Difference Between Clock Reference and Local Crystal Oscillator.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Clock Source No.

Indicates the clock link number of the reference clock source. When the Selected Clock Source parameter is set to GPS+SYNCETH, this parameter indicates the number of the GPS clock link. When the Selected Clock Source parameter is set to SYNCETH+IPCLK, this parameter indicates the number of the IP clock link. When this parameter is set to AUTO, the system selects an available clock link from those of the specified reference clock source. If there is more than one clock link and the selected clock link fails, another available clock link will be used.
Selected Clock Source

Indicates the type of the user-selected clock source.
Clock Working Mode

Indicates the working mode of the system clock. Manual indicates that a clock source must be specified by the user. Auto indicates that the system automatically selects a clock source based on the priority and availability of the clock source. Free indicates that the system clock works in free-running mode, that is, the system clock does not trace any reference clock source.
Algorithm

Indicates the clock algorithm mode for the IP clock link. In DEFAULT mode that is also called the adaption mode, and the system adjusts the filtering period and sampling period based on the network quality in this mode. In CLASSA mode, the Free Count, Search Count, Hold Count, Lock Count, and Sample Time parameters are set to 4, 4, 4, 10, and 2400, respectively. In CLASSB mode, the Free Count, Search Count, Hold Count, Lock Count, and Sample Time parameters are set to 4, 4, 4, 10, and 4800, respectively. In CUSTOM mode, the filtering period and sampling period are set by the customer. The LTE currently does not support this function.
Free Count

Indicates the filtering period of the IP clock link when the IP clock works in free-running mode. The LTE currently does not support this function.
Search Count

Indicates the filtering period of the IP clock link when the IP clock works in fast-tracking mode. The LTE currently does not support this function.
Hold Count

Indicates the filtering period of the IP clock link when the IP clock works in hold mode. The LTE currently does not support this function.
Lock Count

Indicates the filtering period of the IP clock link when the IP clock works in locked mode. The LTE currently does not support this function.
Sample Time

Indicates the sampling period of the IP clock link. The LTE currently does not support this function.
IP Clock Time Synchronization Mode

Indicates the mode of scheduled synchronization for the IP clock link. In ABSOLUTE mode, the system clock obtains synchronization signals from the clock server at a fixed time every few days until the system clock is stable. In RELATIVE mode, the system clock obtains synchronization signals from the clock server at regular intervals until the system clock is stable. In OFF mode, the system clock obtains only messages from the clock server in real time. The LTE currently does not support this function.
Synchronization Period

Indicates the synchronization period of the IP clock link. The LTE currently does not support this function.
Synchronization Time

Indicates the start time of scheduled synchronization for the IP clock link. The LTE currently does not support this function.
Clock Synchronization Mode

Indicates the clock synchronization mode of a BS, which can be frequency synchronization or time synchronization.
Holding Duration

Indicates the holding duration of the system clock of the base station. This parameter is valid only when the reference source is SYNCETH+IPCLK and the synchronization mode is time synchronization. Only NR and LTE TDD support this function.
Clock Source Backup Mode

Indicates the backup mode of the reference clock sources. This parameter applies only to backup of GPS clock sources or TOD clock sources whose signals are introduced by a main control board. When this parameter is set to BRDBKMODE, only the primary main control board can introduce clock signals from the clock source. When this parameter is set to CLKSRCBRDCFG, the board in the specified slot introduces clock signals from the clock source.
Quality Level

Indicates the clock quality level of the BS. The values for this parameter are listed in quality descending order. QL-PRC indicates the highest quality level.
Adaptive Timing Recovery Switch

Indicates the adaptive scheduled recovery switch for an IP clock link. The function is used to make the BS and the IPCLK Server exchange handshake messages directly. The network between them transfers packages only and the packages will be filtered by the package delay vibrates which Adaptive Timing Recovery (ATR) of BS imported to the network. The time synchronization with the server will be realized.
Air Soft Syn Phase Adjustment Period

Indicates the adjustment period of the frame clock phase when the Air interface soft synchronization Phase Lock function is enabled on the NE.
Soft-Synchronized Network Adaption Mode

Indicates the adaption mode of the soft synchronous transport network. The value of this parameter depends on the synchronous status of the transport network.
Air Interface Soft Synchronization Switch

Indicates whether the Air interface Soft synchronization Phase Lock function is enabled on the NE, which can be set to ON or OFF. ON indicates that the switch for the Air interface soft synchronization phase lock function is set to on and OFF indicates that the Air interface soft synchronization phase lock function is set to off.
Day

Indicates the number of timing synchronization days of the IP clock. The LTE currently does not support this function.
GSM Frame Bit Offset

Indicates GSM frame bit offset. This parameter applies to GSM only.
Locked System Clock Source

Indicates the locked system clock source, which is obtained from the local standard clock or interconnection system clock. The local standard clock is a clock synchronized with the reference clock of the local NE or multimode base station. The interconnection system clock is the standard clock obtained from the interconnection port.
Cloud BB Clock Reference Source Flag

Indicates whether the local BBU serves as the clock reference source in the Cloud BB.
Frame Sync Switch

Indicates the frame synchronization switch. This switch applies to the Cloud BB that works in frequency synchronization mode. In addition, it can be set to on only for an NE that connects to the clock source indirectly to realize frame synchronization between this NE and the upper-level NE.
GSM Frame Sync Switch

Indicates the GSM frame synchronization switch. This parameter controls the GSM adjustment frame number and frame phase. In addition, this parameter is valid only for GSM NEs.
Air Interface Soft Synchronization Standard

Indicates the standard where the Air interface soft synchronization function is enabled.
Enhanced SYSCLK Failure Check Switch

Indicates whether the enhanced system clock failure check is enabled. If this parameter is set to ON, the enhanced system clock failure check is enabled.
CIoT Frame No. Synchronization Switch

Indicates whether to enable the CIoT frame No. synchronization function. The value ON indicates that this function is enabled. The value OFF indicates that this function is disabled. This parameter takes effect only when frequency synchronization is used.
Date

Indicates the date to be set for the CIoT Frame No. This parameter is set in compliance with the GPS. The format is as follows: YYYY-MM-DD. For example, 2006-09-08 indicates September 8th of 2006.
Time

Indicates the time to be set for the CIoT Frame No. This parameter is set in compliance with the GPS. The format is as follows: HH:MM:SS. For example, 10:20:05.
Leap Seconds Change Date

Indicates the date when the leap seconds changed. This parameter is set in compliance with the UTC. The format is as follows: YYYY-MM-DD. For example, 2006-09-08 indicates September 8th of 2006.
Leap Seconds Change Time

Indicates the time when the leap seconds changed. This parameter is set in compliance with the UTC. The format is as follows: HH:MM:SS. For example, 10:20:05.
Current Leap Second Offset Between UTC and GPS

Indicates the current leap second offset between the UTC and the GPS.
Next Leap Second Offset Between UTC and GPS

Indicates the next leap second offset between the UTC and the GPS.
Low Precision Frame No. Synchronization Switch

Indicates the switch of low-precision frame No. synchronization. When this switch is turned on, the frame No. synchronization function is enabled, and the SFN and HSFN are automatically aligned after the system clock is locked. When this switch is turned off, the frame No. synchronization function is disabled. This switch applies to NB-IoT and eDRX.
Major Standard Change Optimization Switch

Indicates whether to optimize the major standard change mechanism. The major standard change mechanism is optimized only if this parameter is set to ON. The parameter is valid if a GL separate-MPT base station uses time synchronization and GSM and LTE are deployed in the same BBU.
Phase Deviation Alarm Threshold

Indicates the alarm reporting threshold for multi-source phase difference detection. If this parameter is set to a small value, alarms may be reported frequently.
Loose Time Synchronization

Indicates whether to enable the loose time synchronization function. This function provides low-precision time synchronization for a base station. If this function is enabled, loose time synchronization is supported. If this function is disabled, loose time synchronization is not supported.

Indicates the duration in which the base station enters the holding state after the reference source is lost.The value of this parameter is NULL when PLL Status is not Holdover.
Suspicious State

Indicates the suspicious status of the reference clock source. Grouping is based on the phase offset between the current source and the backup source. If the phase offset between two sources is less than Phase Deviation Alarm Threshold, such sources form a group. If the number of reference sources in a group is the largest among all groups and no group with the same number exists, the reference sources in the group is regarded as non-suspicious. Otherwise, they are regarded as suspicious. If the phase value cannot be obtained, the status is regarded as unknown.
