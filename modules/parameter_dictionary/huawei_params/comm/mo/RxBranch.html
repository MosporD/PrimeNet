RXBRANCH

    +-AARU
      +-RXBRANCH

EQUIPMENT

      +-SUBRACK
        +-RFU

EQUIPMENT
  +-RRU
    +-RXBRANCH

Description

The RxBranch MO is used to manage the RX channel No., the logical switch, attenuation, physical status of the RX channel, and the initial correction value of the RTWP.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    AARU;RFU;RRU
  • Relation with the ANTENNAPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]One ANTENNAPORT MO maps to TXBRANCH MO and one RXBRANCH MO.
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When RT in the RRU MO is not set to AIRU or MRRU, the number of RXBRANCH MOs configured on one RRU MO must be greater than or equal to 0 and smaller than or equal to 8.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When RT in the RRU MO is set to MRRU, the number of RXBRANCH MOs configured on one RRU MO must be greater than or equal to 0 and smaller than or equal to 16.
  • Relation with the RFU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of RXBRANCH MOs configured on one RFU MO must be greater than or equal to 0 and smaller than or equal to 8.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP RXBRANCH

Use this command to query the dynamic attributes of the RX channel of the RRU or RFU. The dynamic attributes include information such as the attenuation, initial correction value of the Received Total Wideband Power (RTWP), frequency band, and bandwidth.
LST RXBRANCH

Use this command to list the RX channel configuration of an RRU or RFU.
MOD RXBRANCH

Use this command to modify the RX channel of an RRU or RFU. If the main antenna is responsible only for transmitting signals, you can run this command to set the switch of the RX channel of the main antenna to OFF.
SET RXLNASW

Use this command to modify the configuration of the switch and shutdown duration of the low noise amplifier (LNA) for the RRU receive channel.

Related Parameters

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the RRU or RFU where the RX channel is located.

Indicates the subrack number of the RRU or RFU where the RX channel is located.

Indicates the slot number of the RRU or RFU where the RX channel is located.
RX Channel No.

Indicates the number of the RX channel of the RRU or RFU.
Logical Switch of RX Channel

Indicates the logical switch of the RX channel of the RRU or RFU, which can be set to ON or OFF. ON indicates that the logical switch of the RX channel is set to on and OFF indicates that the logical switch of the RX channel is set to off. This parameter is set to ON by default. The switch can be set by running the MOD RXBRANCH command.

Indicates the attenuation of the RX channel of the RRU or RFU.
RTWP Initial0

Indicates the initial correction value of the Received Total Wideband Power (RTWP) for carrier 0. The big offset between the RTWP in empty load and the theoretical background noise can be adjusted through the setting of initial correction value of the RTWP.
