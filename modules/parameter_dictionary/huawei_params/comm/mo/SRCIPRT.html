SRCIPRT

TRANSPORT
  +-SRCIPRT

Description

The SRCIPRT MO enables data to be forwarded by configuring a source IP route table.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the OMCH and SRCIPROUTE4 MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an OMCH MO, if CHECKTYPE is set to AUTO_UDPSESSION, IP must be configured with the corresponding SRCIPRT or SRCIPROUTE4 MO.
  • Relation with the SRCIPRT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Any one of the following parameters under one SRCIPRT MO cannot be set to the same value as that of the same parameter under another SRCIPRT MO: CN, SRN, SN, SBT, SRCIP, RTTYPE, IFT, IFNO, and NEXTHOP.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the SRCIP parameters under two SRCIPRT MOs are set to the same value, the PREF parameters under these MOs must be set to different values.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A maximum of 32 SRCIPRT MOs can be configured on a board.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an SRCIPRT MO, NEXTHOP must be different from SRCIP.
  • Relation with the OMCH MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a default routing domain, IP in an OMCH MO must be different from NEXTHOP in an SRCIPRT MO.
  • Relation with the TUNNEL MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the RTTYPE and IFT parameters under the SRCIPRT MO are set to IF and TUNNEL, respectively, the IFNO parameter under the SRCIPRT MO must be set to the same value as that of the TUNNELID parameter under the TUNNEL MO.
  • Relation with the DEVIP, IFIP, and GTRANSPARA MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If MODELSELECT of GTRANSPARA is set to TRADITION and an SRCIPRT MO and a DEVIP MO whose PT is set to ETH, ETHTRK, SUBIF, or ETHCI are in the default routing domain, NEXTHOP in the SRCIPRT MO must be on the same network segment as IP in the DEVIP MO. In addition, CN, SRN, SN, and SBT in the DEVIP MO must be the same as CN, SRN, SN, and SBT in the SRCIPRT MO, respectively. If MODELSELECT of GTRANSPARA is set to HOSTGW and an SRCIPRT MO and an IFIP MO whose PT is set to ETH, ETHTRK, SUBIF, or ETHCI are in the default routing domain, NEXTHOP in the SRCIPRT MO must be on the same network segment as IP in the IFIP MO. In addition, CN, SRN, SN, and SBT in the IFIP MO must be the same as CN, SRN, SN, and SBT in the SRCIPRT MO, respectively.
  • Relation with the DEVIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If a DEVIP MO and an SRCIPRT MO are in the default routing domain, IP in the DEVIP MO must be different from NEXTHOP in the SRCIPRT MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]NEXTHOP in an SRCIPRT MO cannot be set to a broadcast IP address of the network segment where the DEVIP MO on the egress port is located, and Network ID and Host ID cannot be all 0 or all 1.
  • Relation with the IFIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If an IFIP MO and an SRCIPRT MO are in the default routing domain, IP in the IFIP MO must be different from NEXTHOP in the SRCIPRT MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]NEXTHOP in an SRCIPRT MO cannot be set to a broadcast IP address of the network segment where the IFIP MO on the egress port is located, and Network ID and Host ID cannot be all 0 or all 1.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the SRCIPRT MO cannot be configured.
  • Relation with the PPPLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If the RTTYPE and IFT parameters under the SRCIPRT MO are set to IF and PPP, respectively, the IFNO parameter under the SRCIPRT MO must be set to the same value as that of the PPPLNKN parameter under the PPPLNK MO.
  • Relation with the MPGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If the RTTYPE and IFT parameters under the SRCIPRT MO are set to IF and MPGRP, respectively, the IFNO parameter under the SRCIPRT MO must be set to the same value as that of the MPGRPN parameter under the MPGRP MO.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TYPE in an MDU MO is set to MDUC, RTTYPE in the SRCIPRT MO must be set to NEXTHOP.
  • Relation with the IPPATHRT MO:
    • [Co-MPT, eNodeB]An SRCIPRT MO and an IPPATHRT MO cannot both be configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SRCIPRT

Use this command to add a source IP route.
DSP SRCIPRT

Use this command to query the information about a source IP route.
LST SRCIPRT

Use this command to list the configuration of a source IP route.
MOD SRCIPRT

Use this command to modify the configuration of a source IP route.
RMV SRCIPRT

Use this command to remove a source IP route.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Source Route Index

Indicates the index of the source IP route.
Cabinet No.

Indicates the number of the cabinet that houses the board where the source IP route is configured.
Subrack No.

Indicates the number of the subrack that houses the board where the source IP route is configured.
Slot No.

Indicates the number of the slot that houses the board where the source IP route is configured.
Subboard Type

Indicates the subboard type of the board where the source IP route is configured.
Source IP Address

Indicates the source IP address of the source IP route.
Route Type

Indicates the type of the source IP route. NEXTHOP means that all IP packets that meet the route direction are first forwarded to the specified next hop IP address. IF means that all IP packets that meet the route direction are first forwarded to the specified egress port.
Next Hop IP

Indicates the next-hop IP address of the source IP route.
Interface Type

Indicates the type of the port that carries the source IP route.
Port No.

Indicates the number of the port that carries the source IP route.
Priority

Indicates the priority of the source IP routing entry. A smaller parameter value indicates a higher priority.
User Label

Indicates the user-defined information of the source IP route.
Table 3 Dynamic parameters

Parameter

Description
Actual Port Type

Indicates the type of a port.
Actual Port No.

Indicates the number of a port.
Valid State

Indicates whether the source IP route is valid.
TX Packets

Indicates the number of transmitted packets. During an enhanced connectivity ping test, ping packets are directly forwarded without matching routes, and therefore the number of transmitted packets cannot be measured.
