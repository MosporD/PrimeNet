ETHCIPORT

TRANSPORT
  +-ETHCIPORT

Description

This MO indicates an Ethernet port carried by a CI port on a panel.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the PACKETFILTERING MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT in a PACKETFILTERING MO is set to ETHCI, the corresponding ETHCIPORT MO must have been configured.
  • Relation with the PACKETFILTER MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT in a PACKETFILTER MO is set to ETHCI, the corresponding ETHCIPORT MO must have been configured.
  • Relation with the DEVIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT in a DEVIP MO is set to ETHCI, the associated ETHCIPORT MO must have been configured.
  • Relation with the IFIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT in an IFIP MO is set to ETHCI, the associated ETHCIPORT MO must have been configured.
  • Relation with the IPADDR4 and INTERFACE MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]A maximum of eight IPADDR4 MOs can be configured on an Ethernet CI port.
  • Relation with the IPADDR4, INTERFACE, and LOOPBACK MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]In the same routing domain, the IP address defined in the IPADDR4 MO on an INTERFACE MO with PT set to LOOPINT cannot be on the same network segment as the IP address defined in the IPADDR4 MO on another INTERFACE MO on a different board when PT in the latter INTERFACE MO is set to ETHCI.
  • Relation with the IPSECBIND MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]Before binding an IPSECPOLICY MO to an ETHCIPORT MO, ensure that the ETHCIPORT MO is configured.
  • Relation with the ETHCIPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]A maximum of 1 ETHCIPORT MOs can be configured on a board.
  • Relation with the HAGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]In one logical protection group, SN in an HAGRP MO must be the same as that in an ETHCIPORT MO.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, the ETHCIPORT MO cannot be configured.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the PORTID to any two ETHCIPORT MOs must be different and valid.
  • Relation with the INTERFACE MO:
    • [Co-MPT, NodeB, eNodeB]The ETHCIPORT MO corresponding to INTERFACE MO must have been configured.
  • Relation with the SCTPHOST, IPADDR4, INTERFACE, PPPLNK, MPGRP, ETHPORT, ETHTRUNKLNK, LOOPBACK, and GTRANSPARA MOs:
    • [Co-MPT, eNodeB]When TRANSCFGMODE in a GTRANSPARA MO is set to NEW and the SIGIP2V4 parameter in an SCTPHOST MO is valid, the IPADDR4 MOs to which SIGIP1V4 and SIGIP2V4 belongs must be configured on the same subrack, the subboard type of the host IP addresses must be BASE_BOARD, and the bearing port type must be ETH, ETHTRK, or LOOPINT.
  • Relation with the SCTPHOST, IPADDR6, INTERFACE, ETHPORT, PPPLNK, MPGRP, ETHTRUNKLNK, LOOPBACK, and GTRANSPARA MOs:
    • [Co-MPT, eNodeB]When SIGIP2V6 is valid in an SCTPHOST MO, the IPADDR6 MOs for SIGIP1V6 and SIGIP2V6 of this MO must be configured on the same board.
  • Relation with the SCTPHOST, IPADDR4, SECURITYHOST, INTERFACE, ETHPORT, ETHTRUNKLNK, LOOPBACK, and GTRANSPARA MOs:
    • [Co-MPT, eNodeB]In an SCTPHOST MO, if SIGIP1SECSWITCH is set to ENABLE, SIGIP1V4 must be configured on the same board as LOCIKEIPV4 in a referenced SCTPHOST MO.
    • [Co-MPT, eNodeB]In an SCTPHOST MO, if SIGIP2SECSWITCH is set to ENABLE, SIGIP2V4 must be configured on the same board as LOCIKEIPV4 in a referenced SCTPHOST MO.
  • Relation with the USERPLANEHOST, IPADDR4, SECURITYHOST, INTERFACE, ETHPORT, ETHTRUNKLNK, LOOPBACK, and GTRANSPARA MOs:
    • [Co-MPT, eNodeB]If IPSECSWITCH is set to ENABLE for a USERPLANEHOST MO, LOCIPV4 for the USERPLANEHOST MO must be configured on the same board as LOCIKEIPV4 for the referenced SECURITYHOST MO.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the board where the Ethernet CI port is located.
Subrack No.

Indicates the subrack number of the board where the Ethernet CI port is located.
Slot No.

Indicates the slot number of the board where the Ethernet CI port is located.
Subboard Type

Indicates the subboard type of the board where the Ethernet CI port is located.
Port No.

Indicates the number of the Ethernet CI port.
Port ID

Indicates the ID of an Ethernet CI port, which uniquely identifies the Ethernet CI port. When the system automatically creates an Ethernet CI port, the most significant bit to the least significant bit of this parameter value indicate the slot number, subrack number, slot number, and port number of the Ethernet CI port, respectively. When Transmission Configuration Mode in the GTRANSPARA MO is set to OLD, this parameter is optional. If this parameter is not set, the default value 4294967295 is used. When Transmission Configuration Mode in the GTRANSPARA MO is set to NEW, this parameter is mandatory and must be unique in the system. If the ETHCIPORT MO is not configured, the default value 4294967295 of PORTID is displayed.
Maximum Transmission Unit

Indicates the IPv4 maximum transmission unit on the Ethernet CI port. For the UMPT, the value of this parameter ranges from 46 to 1500. If this parameter is set to a value greater than the maximum allowed value, the maximum allowed value takes effect. A value greater than or equal to 776 is recommended, because broadcast packets, such as DHCP packets, may experience reception or transmission failures if the maximum transmission unit is smaller than 776.

This parameter is valid only when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD.

This parameter is invalid when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW.
ARP Proxy

Indicates whether to enable the proxy ARP function on the Ethernet CI port.

This parameter is valid only when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD.

This parameter is invalid when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW.
