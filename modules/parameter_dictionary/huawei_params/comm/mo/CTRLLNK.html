CTRLLNK

EQUIPMENT
  +-CTRLLNK

Description

The CTRLLNK MO defines the control link between baseband units (BBUs). The bladebbu does not support this configuration.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT
  • Relation with the SUBRACK MO:

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CTRLLNK

Use this command to add a control link. The control link is a logical concept. The physical entity of the control link is the topology between the interconnected BBUs.
DSP CTRLLNKSTAT

Use this command to query the statistics of control and clock signal links between BBUs. The statistics mainly include the number of received packets, number of error packets, total packet receiving time, and the loss of signal (LOS) duration, reflecting the link transmission quality. If the port supports MACsec, the MACsec negotiation statistics are displayed. For the UCIU, the rates of error packets on ports 0 to 4 and port 8 are displayed. For the UMPT, the rate of error packets on port 8 is displayed. For the UMDU, the rates of error packets on ports 6 and 7 are displayed.
LST CTRLLNK

Use this command to list the configuration of a control link.
MOD CTRLLNK

Use this command to modify the configuration of a control link.
RMV CTRLLNK

Use this command to remove a control link.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Link No.

Indicates the number of the control link at the local end.
Local Cabinet No.

Indicates the cabinet number of the local node at one end of the control link.
Local Subrack No.

Indicates the subrack number of the local node at one end of the control link.
Local Slot No.

Indicates the slot number of the local node at one end of the control link.
Upper Cabinet No.

Indicates the cabinet number of the upper-level node at the other end of the control link.
Upper Subrack No.

Indicates the subrack number of the upper-level node at the other end of the control link.
Upper Slot No.

Indicates the slot number of the upper-level node at the other end of the control link.
Upper Port No.

Indicates the port number of the upper-level node at the other end of the control link. Values 0 to 4 indicate the ports M0 to M4 on the UCIU, Values 6 to 7 indicate the HEI ports HEI0 to HEI1 on the UMDU, and value 8 indicates the CI port on the UMPT.
Table 3 Dynamic parameters

Parameter

Description
MACSec Negotiation Failure Times

Indicates the number of failed MACSec (MAC Security) negotiations. The number is counted from the time a link becomes normal. The number falls to zero after the link becomes abnormal but is counted again after the link becomes normal.
MACSec Negotiation Failure Phase

Indicates the phase in which the latest failed MACSec negotiation occurs. The values of this parameter include Identity Authentication, MKA Negotiation, and NULL. MKA is short for MACsec key agreement protocol. The value NULL indicates that a negotiation succeeds or no negotiation is performed.
MACSec Negotiation State

Indicates the states of MACSec (MAC Security) negotiations. The values of this parameter include Succeeded, Failed, and None.
MACSec Negotiation Success Times

Indicates the number of successful MACSec (MAC Security) negotiations. The number is counted from the time a link becomes normal. The number falls to zero after the link becomes abnormal but is counted again after the link becomes normal.
Local Port Rate

Indicates the port rate of the local node. NULL indicates that the link is disconnected over the port.
