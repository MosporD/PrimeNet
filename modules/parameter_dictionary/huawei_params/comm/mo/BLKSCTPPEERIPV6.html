BLKSCTPPEERIPV6

TRANSPORT
  +-BLKSCTPPEERIPV6

Description

A BLKSCTPPEERIPV6 MO is used to manage the blocking status SCTP peer IPv6 address.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the BLKSCTPPEERIPV6 MO cannot be configured.
  • Relation with the VRF MO:
    • [Co-MPT, eNodeB, gNodeB]The VRF instance used by a BLKSCTPPEERIPV6 MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD BLKSCTPPEERIPV6

Use this command to block SCTP links based on the peer IPv6 address.After a peer IPv6 address is blocked, all SCTP links associated with the peer IPv6 address are blocked accordingly.
LST BLKSCTPPEERIPV6

Use this command to list the SCTP peer IPv6 addresses that have been blocked.
RMV BLKSCTPPEERIPV6

Use this command to unblock SCTP links based on the peer IPv6 address. After a peer IPv6 address is unblocked, all SCTP links associated with the peer IPv6 address are unblocked.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
VRF Index

Indicates the index of a VRF instance.
Peer IPv6 Address

Indicates the peer IPv6 address of a blocked SCTP link.
