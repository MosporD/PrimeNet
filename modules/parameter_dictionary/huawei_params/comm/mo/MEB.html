MEB

EQUIPMENT
  +-CABINET
    +-SUBRACK
      +-MEB
        +-ALMPORT[6~6]

Description

The MEB MO is used to configure a monitoring extension box (MEB). The MEB helps increase the number of dry contact ports and monitoring ports on a power board to monitor electromechanical equipment such as the PMU, FMU, TCU, and EMU.

Effective Scenario

Immediately

Relations Between MOs

  • Base class:

    RU

  • Possible parents:

    SUBRACK

  • Possible children:

    ALMPORT[6~6]
  • Relation with the subrack that houses the MEB MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A subrack must be configured together with an MEB MO to house the MEB MO.
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The MO corresponding to MCN and MSRN in the MEB MO must have been configured and must be the RRU MO with SN set to 0.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The RRU MO specified by MCN and MSRN in the MEB MO cannot be configured as an MRIU.
  • Relation with the ALMPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ALMPORT MOs configured on one MEB MO must be 6.
  • Relation with the MEB, TCU, PMU, EMU,andFMU Mos:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The following cases are not allowed: 1. The combination of MCN, MSRN, and MPN in the MEB MO is same as the combination of those in other MEB MOs; 2. The combination of MCN, MSRN, and MPN in the TCU MO is same as the combination of those in the MEB MOs, and ADDR in the TCU MO is equal to 10; 3. The combination of MCN, MSRN, and MPN in the PMU MO is same as the combination of those in the MEB MOs, and ADDR in the PMU MO is equal to 10; 4. The combination of MCN, MSRN, and MPN in the EMU MO is same as the combination of those in the MEB MOs, and ADDR in the EMU MO is equal to 10; 5. The combination of MCN, MSRN, and MPN in the FMU MO is same as the combination of those in the MEB MOs, and ADDR in the FMU MO is equal to 10.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD MEB

Use this command to add a monitoring extension box (MEB). When an MEB is added, an MEB subrack and an MEB board are added at the same time.
DSP MEB

Use this command to query the effective information about a monitoring extension box (MEB).
LST MEB

Use this command to query the configuration of a monitoring extension box (MEB).
MOD MEB

Use this command to modify the configuration of a monitoring extension box (MEB).
RMV MEB

Use this command to remove a monitoring extension box (MEB). When an MEB is removed, the MEB subrack and the MEB board are removed at the same time.

Description

Alarm Status(from RU)

Indicates the alarm status of the board hardware, which can be set to Normal, Warning, Minor, Major, or Critical. The alarm status of the PSU, PDB, and BDU is in the alarm status of the PMU.
Operational State(from RU)

Indicates the operational state of the board, which can be set to Enabled or Disabled. Enabled indicates that services can be carried on the board. Disabled indicates that no service can be carried on the board.
Availability Status(from RU)

Indicates the physical status of a board, which can be Uninstalled, Starting up, Normal, Inconsistent, Unconfigured, Power off, Fault, Communication lost, In test, or the combination of multiple states. For example, if a board is not configured and fails to communicate with the main control and transmission board, the availability status of the board is "Unconfigured, Communication lost." If a board is under management of the peer end, the availability status of the board may be Starting up, Communication lost, or Fault.
Electronic Label(from RU)

Indicates the electronic label, which is a text file with a maximum of 2 KB used to record the manufacturing information about equipment such as the board, sub-board, and optical module. "BoardType" indicates the type of the board. "BarCode" indicates the bar code of the board and is the same as the code labeled on the board. "Item" indicates the BOM code. "Description" indicates the board description in English. "Manufactured" indicates the manufacturing date of the board. "VendorName" indicates the name of the vendor providing the board. "IssueNumber" indicates the board hardware version. "CLEICode" indicates the common language equipment indicator (CLEI) code of the board. "BOM" indicates the fine-grained item code of the board. "Model" indicates the model displayed on the customer interface, such as Bill of Quotation (BOQ) and paper labels.
