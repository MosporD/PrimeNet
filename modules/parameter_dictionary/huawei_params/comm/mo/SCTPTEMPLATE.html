SCTPTEMPLATE

TRANSPORT
  +-SCTPTEMPLATE

Description

The SCTPTEMPLATE MO is used to configure the parameters for automatically setting up an SCTP link. This MO can be referenced by multiple SCTP hosts.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the SCTPHOST MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]SCTPTEMPLATEID in an SCTPHOST MO must be the same as SCTPTEMPLATEID in a configured SCTPTEMPLATE MO.
  • Relation with the NODE MO:
    • [Co-MPT]An SCTPTEMPLATE MO cannot be configured on a PRODUCTTYPE MO with PRODUCTTYPE set to DBS3900 DCU or DBS5900 DCU.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
SCTP Parameters Template ID

Indicates the ID of the SCTP parameter template.
RTO Min Value

Indicates the minimum RTO value of an SCTP link. According to the SCTP protocol, if the calculated RTO is less than the value of this parameter, the round trip delay is set to the value of this parameter to reduce the probability of retransmission timeout.
RTO Max Value

Indicates the maximum RTO value of an SCTP link. According to the SCTP protocol, this parameter is the upper limit for the doubling operation of the retransmission timeout timer.
RTO Initial Value

Indicates the initial RTO value of an SCTP link. According to the SCTP protocol, this parameter is used to calculate the initial value of retransmission timeout.
RTO Alpha Value

Indicates the RTO alpha value of an SCTP link. A larger value indicates less sensitivity to the link delay. For details, see RFC4960. According to the SCTP protocol, this parameter is used as the smooth factor for calculating round-trip delay. In a new estimation, (RtoAlpha/100) is obtained based on a new measurement and 1-(RtoAlpha/100) is obtained based on the last estimation.
RTO Beta Value

Indicates the RTO beta value of an SCTP link. This parameter is used to calculate the round trip time variation (RTTVAR). A larger value indicates that the latest change is more important. For definitions of the beta value, see RFC4960.
Heart-beat Interval

Indicates the heartbeat interval, corresponding to the HBINTER parameter specified in RFC4960. SCTP periodically transmits heartbeat messages to an idle destination address to detect the reachability. According to RFC4960, the actual interval at which heartbeat messages are transmitted equals the value of this parameter plus RTO.
Max Association Retransmission

Indicates the maximum number of association retransmissions on an SCTP link. If the number of retransmissions exceeds the value of this parameter, the SCTP link is released and a link failure alarm is reported.
Max Path Retransmission

Indicates the maximum number of retransmissions over a path of an SCTP link. If no heartbeat response is received from the peer end when the number of retransmissions over a path exceeds the value of this parameter, the current path cannot be reached. If multiple paths are used on the SCTP link, path switching is automatically performed.
Switch Back Flag

Indicates whether the automatically established SCTP link switches back to the primary path when the primary path is restored and reachable. If the primary path is not reachable, the SCTP link switches to the secondary path. When this parameter is set to ENABLE, the SCTP link switches to the primary path if the primary path is restored and reachable. When this parameter is set to DISABLE and the primary path is restored and reachable, the SCTP link does not switch back to the primary path if the secondary path is also reachable, and the SCTP link switches back to the primary path if the secondary path is unreachable.
Heart-beat Times When Switch Back

Indicates the number of consecutive heartbeat messages that must be transmitted on the primary path before transmission can switch back to the primary path when SWITCHBACKFLAG is set to ENABLE.
SACK Timeout

Indicates the interval between time when one end of an SCTP link receives data and time when it can respond the other end with an SACK message. A larger value indicates a longer interval between receiving data and sending an SACK message.
Checksum Algorithm Type

Indicates the checksum algorithm. The checksum algorithms at both ends of an SCTP link must be the same.
Maximum Stream No.

Indicates the maximum stream number of an SCTP link.
Maximum SCTP PDU Size

Indicates the maximum size of of an IPv4 SCTP PDU (Protocol Data Unit). It specifies the maximum length of an SCTP PDU (excluding the IP header) transmitted on an SCTP link, which is set using the parameter template. If the value of this parameter is greater than the size of the IP layer MTU of the base station or intermediate transmission equipment, SCTP packets are fragmented at the IP layer. This causes a large number of fragments and affects the transmission efficiency of the intermediate transmission equipment.
