NEMNT

+-NE
  +-NODE
    +-SYSTEMOM
      +-NEMNT

Description

The NEMNT MO is used to query the maintenance mode information of NEs.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    SYSTEMOM

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP MNTMODE

Use this command to query the current maintenance status of an NE.
LST MNTMODE

Use this command to list the maintenance status of the NE.
SET MNTMODE

Use this command to set the maintenance status of the NE. When the NE is in the maintenance status, the way of alarm reporting is changed and the performance measurement is unbelievable.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Maintenance Mode

Indicates the maintenance mode of an NE. The normal state indicates that the NE is in the normal service operation state and does not carry out any engineering maintenance activities. The value INSTALL indicates device creation caused by network capability expansion, device reparenting, or access of a new device to the network. The value EXPAND indicates the subrack or carrier capacity expansion of a device. The value UPGRADE indicates a device upgrade. The value TESTING indicates that an installed device is being commissioned. The maintenance mode of a device is set to TESTING by default before delivery. ExpandStatus1 to ExpandStatus10 can be used by users to define maintenance modes.
Start Time of Status Setting

Indicates the start time of the NE maintenance mode. This time refers to the local time (including the DST offset) on the NE. If this parameter is not specified, the start time of the maintenance mode is 2000-01-01 00:00:00.
End Time of Status Setting

Indicates the end time of maintenance status of the NE. This time refers to the local time (including the DST offset) on the NE. If this parameter is not specified, the maintenance status ends at 2037-12-31 23:59:59.
Maintenance Mode Setting Remark

Indicates the remarks of the NE maintenance mode.
Table 3 Dynamic parameters

Parameter

Description
Current Maintenance Mode

Indicates the current maintenance mode of the network element (NE).
