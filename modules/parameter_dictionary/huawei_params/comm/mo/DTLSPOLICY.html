DTLSPOLICY

TRANSPORT
  +-DTLSPOLICY

Description

A DTLSPOLICY MO defines a configuration policy of the Datagram Transport Layer Security (DTLS) protocol. This MO applies only to NR.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]If AT is set to GBTS for an Application MO, TYPE is set to GTMU for a GTMU MO, and TYPE is not set to UMPT for any MPT MO, then the number of DTLSPOLICY MOs is 0.
  • Relation with the SCTPHOST MO:
    • [Co-MPT, gNodeB]An SCTPHOST MO can reference only a configured DTLSPOLICY MO.
