MAINSALARMBIND

EQUIPMENT
  +-MAINSALARMBIND

Description

The MAINSALARMBIND MO defines the binding relation between ALM-25622 Mains Input Out of Range and a specified port. When this alarm is reported, some or all cells are shut down to reduce the power consumption of a base station, prolonging the operating time of storage batteries.

Effective Scenario

Not involved

Use this command to list the bind relation of the Mains Input Out of Range alarm.

Use this command to modify the bind relation of the Mains Input Out of Range alarm. When the corresponding alarm is reported, some or all cells are shut down to reduce the power consumption of a base station, prolonging the operating time of storage batteries.
