DIRECTIPSECWHITELIST

TRANSPORT
  +-DIRECTIPSECWHITELIST

Description

A DIRECTIPSECWHITELIST MO is used to restrict the area in which direct IPsec tunnels for X2/Xn links can be automatically created between base stations. In direction connection scenarios of X2/Xn links, if direct IPsec tunnels need to be automatically established based on areas, a whitelist defined by this MO can be added to specify the area where direct IPsec tunnels can be automatically created between base stations. After a direct IPsec whitelist is specified, a base station automatically establishes a direct IPsec tunnel with only the IP addresses in the whitelist.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the DIRECTIPSECBLKLST MO:
    • [Co-MPT, eNodeB, gNodeB]A DIRECTIPSECBLKLST MO and a DIRECTIPSECWHITELIST MO cannot both be configured.
  • Relation with the DIRECTIPSECBLACKLIST MO:
    • [Co-MPT, eNodeB, gNodeB]A DIRECTIPSECBLACKLIST MO and a DIRECTIPSECWHITELIST MO cannot both be configured.
  • Relation with the GEPMODELPARA MO:
    • [Co-MPT, eNodeB, gNodeB]If DIRIPSECAUTODELSW in the GEPMODELPARA MO is set to ENABLE, the DIRECTIPSECWHITELIST MO cannot be configured.
  • Relation with the DIRECTIPSECWHITELIST MO:
    • [Co-MPT, eNodeB, gNodeB]SECURITYPEERIPV4 and MASK must be different in any two DIRECTIPSECWHITELIST MOs in the same routing domain. That is, SECURITYPEERIPV4 in two DIRECTIPSECWHITELIST MOs must be on different network segments.
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a DIRECTIPSECWHITELIST MO is set to IPv6, SECURITYPEERIPV6 in the DIRECTIPSECWHITELIST MO must be different from SECURITYPEERIPV6 in any existing DIRECTIPSECWHITELIST MO.
  • Relation with the DEVIP, IFIP, and LOCALIP MOs:
    • [Co-MPT, eNodeB, gNodeB]When the value of MASK in a DIRECTIPSECWHITELIST MO is 255.255.255.255, the value of SECURITYPEERIPV4 in the DIRECTIPSECWHITELIST MO cannot be the same as the value of IP in the DEVIP MO, the value of IP in the IFIP MO or the value of IP in the LOCALIP MO.
  • Relation with the IPADDR4 and LOCALIP MOs:
    • [Co-MPT, eNodeB, gNodeB]When the value of MASK in a DIRECTIPSECWHITELIST MO is 255.255.255.255, the value of SECURITYPEERIPV4 in the DIRECTIPSECWHITELIST MO cannot be the same as the value of IP in the IPADDR4 MO or the value of IP in the LOCALIP MO.
  • Relation with the MPGRP and PPPLNK MOs:
    • [Co-MPT, eNodeB]When the value of MASK in a DIRECTIPSECWHITELIST MO is 255.255.255.255, the value of SECURITYPEERIPV4 in the DIRECTIPSECWHITELIST MO cannot be the same as the value of LOCALIP in the MPGRP MO or the value of LOCALIP in the PPPLNK MO.

Table 1 Related MML commands

MML Command

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
ID of Whitelist for Direct IPsec Tunnel

Indicates the ID of a direct IPsec whitelist.
IP Version

Indicates the IP version of a direct IPsec whitelist.
Security Peer IPv4 Address

Indicates the security peer IP address of a direct IPsec whitelist. This address must be a valid IP address of class A, B, or C. It can also be a network segment address.
Mask

Indicates the subnet mask of the security peer IP address of a direct IPsec whitelist. The subnet mask cannot be 0.0.0.0.
Security Peer IPv6 Address

Indicates the security peer IPv6 address of a direct IPsec whitelist. This IPv6 address must be set to a globally scoped unicast address. It can also be a network segment address.
IPv6 Address Prefix Length

Indicates the security peer IPv6 address prefix length of a direct IPsec whitelist.
