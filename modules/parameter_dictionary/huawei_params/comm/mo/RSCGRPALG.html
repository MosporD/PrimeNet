RSCGRPALG

TRANSPORT
  +-RSCGRP
    +-RSCGRPALG

Description

The RSCGRPALG MO consists of parameters related to the algorithm for a transmission resource group. Each transmission resource group corresponds to a type of algorithm. According to the corresponding algorithm, each transmission resource group performs operations such as traffic control.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RSCGRP
  • Relation with the RSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before modifying an RSCGRPALG MO, ensure that the associated RSCGRP MO is configured. An RSCGRP MO is associated with an RSCGRPALG MO when both the following conditions are met: BEAR in the RSCGRP MO is set to IP; CN, SRN, SN, SBT, PT, and PN in the RSCGRP MO are the same as those in the RSCGRPALG MO, respectively.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When an RSCGRP MO whose RSCGRPID is not AUTOPORT is being added, the system automatically adds the associated RSCGRPALG MO. Before an RSCGRP MO is removed, the system automatically removes the RSCGRPALG MO associated with the RSCGRP MO.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the RSCGRPALG MO whose BEAR is set to IP cannot be configured.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TYPE in an MDU MO is set to MDUC, the RSCGRPALG MO must meet the following conditions: TXBWAMIN and RXBWAMIN are set to values within the range of 64 to 1000000; TXRSVBW and RXRSVBW are set to value within the range of 0 to 1000000.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of RSCGRPALG MOs must be less than or equal to 16 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Description
Cabinet No.

Indicates the number of the cabinet that houses the board where a transmission resource group is established.
Subrack No.

Indicates the number of the subrack that houses the board where a transmission resource group is established.
Slot No.

Indicates the number of the slot that houses the board where a transmission resource group is established.
Subboard Type

Indicates the subboard type of the board where a transmission group is established. This parameter cannot be set to UNCHANNELLED_COVERBOARD for LTE and NR.
Transmission Resource Group Bear Type

Indicates the bearer type of a transmission group. This parameter cannot be set to ATM for LTE and NR.
Bearing Port Type

Indicates the type of port where a transmission resource group is carried. This parameter cannot be set to STM1, IMA, UNI, or FRAATM for LTE and NR.
Bearing Port No.

Indicates the number of the port where the transmission resource group is configured.
Transmission Resource Group ID

Indicates the ID of a transmission resource group. When you add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, a tunnel, or a PPPoE link, the system automatically creates an algorithm for the transmission resource group with Transmission Resource Group ID set to DEFAULTPORT(Default Port). When you remove any of the preceding objects, the system automatically removes the algorithm for the transmission resource group.
TX Traffic Shaping Switch

Indicates whether to enable traffic shaping for a transmission resource group. If this parameter is set to ON, traffic shaping is performed according to the TX bandwidth so that the transmit traffic would not exceed the capability of downstream routers, therefore avoiding unnecessary packet loss and congestion. If this parameter is set to OFF, traffic shaping is not performed during data transmission.
TX Bandwidth Adjustment Switch

Indicates whether to enable the dynamic adjustment of the TX bandwidth of a transmission resource group. If this parameter is set to ON, the TX bandwidth is adjusted according to the network performance and dynamic bandwidth adjustment parameters (Packet Loss Ratio Down Threshold and Delay Variation Down Threshold). The network performance is monitored through IP PM sessions, which can be enabled at the local end or at the peer end. If this parameter is set to OFF, the TX bandwidth is not adjusted. If mapping between the transmission resource group and a NodeB IP path or an IP path for no RAT is configured, this parameter does not take effect on the transmission resource group even though the parameter is set to ON. This parameter does not take effect in UMTS and NR.
RX Bandwidth Adjustment Switch

Indicates whether to enable the dynamic adjustment of the RX bandwidth of a transmission resource group. If this parameter is set to ON, the RX bandwidth is adjusted according to the network performance and dynamic bandwidth adjustment parameters (Packet Loss Ratio Down Threshold and Delay Variation Down Threshold). The network performance is monitored through IP PM sessions, which can be enabled at the local end or at the peer end. If this parameter is set to OFF, the RX bandwidth is not adjusted. This parameter does not take effect in UMTS and NR.
Packet Loss Ratio Down Threshold

Indicates the rate downsizing packet loss rate threshold for bandwidth adjustment. When RXBWASW or TXBWASW is set to ON, the estimated available transport bandwidth is reduced if the packet loss rate detected through IP Performance Monitoring (IP PM) is higher than this threshold. If the packet loss rate detected through IP PM is lower than this threshold, the estimated available transport bandwidth is increased.
Delay Variation Down Threshold

Indicates the rate downsizing packet loss rate threshold for bandwidth adjustment. When RXBWASW or TXBWASW is set to ON, the estimated available transport bandwidth will be reduced if the packet loss rate detected by an IP PM session is higher than this threshold; the estimated available transport bandwidth will be increased if the packet loss rate detected by an IP PM session is lower than this threshold.
TX Bandwidth Adjust Minimum

Indicates the minimum amount of adjusted TX bandwidth. If TXBWASW is set to ON, the adjusted bandwidth should be at least greater than this minimum. This parameter does not take effect in UMTS and NR.
RX Bandwidth Adjust Minimum

Indicates the minimum amount of adjusted RX bandwidth. If RXBWASW is set to ON, the adjusted bandwidth must be at least greater than this minimum. This parameter does not take effect in UMTS and NR.
Traffic Control Switch

Indicates whether to enable the backpressure algorithm of a transmission resource group.

The BS monitors the data buffered in the queues of each transmission resource group, determines whether the transmission resource group is congested, and transmits the backpressure signals (number and congestion status of the transmission resource group) to each flow control service.

If the size of buffered data packets in any backpressure queue exceeds 75% of the queue capacity, the BS regards this transmission resource group as congested and transmits congestion signals.

If the size of buffered data packets in each backpressure queue is less than 50% of the corresponding buffer capacity, the BS decides that the transmission resource group is not congested. In this situation, no congestion signal or congestion release signal is transmitted.

When this parameter is set to ENABLE, both intra-mode traffic control and inter-mode traffic control are supported.

The inter-mode traffic control for transmission resource groups applies only to separate-MPT base stations with co-transmission implemented through backplane interconnection. However, it does not apply to cascaded base stations, base stations with co-transmission implemented through panel interconnection, or base stations enabled with route load sharing.

When the inter-mode traffic control function is enabled for a separate-MPT base station with co-transmission implemented through backplane interconnection, the Tunnel Type parameter must be set to DL(DL) for the tunnel of the mode providing transmission ports and must be set to UL(UL) for the tunnel of the mode providing no transmission port.
PQ Number

Indicates the number of PQs in a transmission resource group. The queues in a transmission resource group are classified into PQs and non-PQs. The scheduling priority of any PQ is higher than that of any non-PQ. The queues numbered from 0 to the result after this parameter value minus 1 are PQs. PQ scheduling is used between PQs. A smaller PQ number indicates a higher scheduling priority. The queues numbered from this parameter value to 6 are non-PQs. WPR scheduling is used between non-PQs.
Congestion Time Threshold

Indicates the congestion time threshold of a transmission resource group. When TCSW is set to ENABLE, if the buffer time of non-real-time service data in a transmission resource group exceeds the threshold, the transmission resource group is congested, and backpressure signals are transmitted.
Congestion Clear Time Threshold

Indicates the congestion clear time threshold of a transmission resource group. When TCSW is set to ENABLE, if the buffer time of non-real-time service data in a transmission resource group is less than the threshold, the transmission resource group is not congested, and congestion clear signals are transmitted.
TX Reserved Bandwidth

Indicates the TX bandwidth reserved for signaling data, OM data, or real-time services. This parameter should be set to a value less than the TX bandwidth of a transmission resource group. It is recommended that the reserved TX bandwidth be set to a value less than or equal to 3% of the TX bandwidth of a transmission resource group. The UMTS currently does not support this function.
RX Reserved Bandwidth

Indicates the reserved RX bandwidth, which should be set to a value less than or equal to the RX bandwidth of a transmission resource group. This parameter does not take effect in UMTS.
Drop Packet Number Threshold

Indicates the number threshold of discarded packets. This parameter indicates the capability of the queue in an enhanced transmission resource group to buffer packets. A greater parameter value indicates a stronger capability. If this parameter is set to 0, the queue in an enhanced transmission resource group cannot buffer packets, and therefore all the delayed packets on the TX channel are discarded. The number threshold of discarded packets determines the maximum amount of data that can be buffered in an enhanced transmission resource group. The congestion time threshold of an enhanced transmission resource group determines the amount of data that is buffered when the enhanced transmission resource group is congested. Ensure that the maximum amount of data that can be buffered is not less than the amount of data that is buffered during congestion. When the board type is UMPTg or UMPTga, the configuration is not effective. The capacity of the UMPTg and UMPTga queue cache packet is dynamically allocated by the system.
