CFMBNDIP

TRANSPORT
  +-CFMMD
    +-CFMMA
      +-CFMRMEP
        +-CFMBNDIP

Description

A CFMBNDIP MO indicates the binding between a Remote Maintenance association End Point (RMEP) and an IP address.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CFMRMEP
  • Relation with the CFMBNDIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A maximum of four IP addresses can be bound to a CFMRMEP MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The BNDIP to any two CFMRMEP MOs which are in the same routing domain in the same CFMMA MO must be different.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If MDNAME and MANAME in a CFMMEP MO are the same as MDNAME and MANAME in a CFMBNDIP MO, respectively, the port configured for the CFMMEP MO cannot be an ETHPORT MO in an ETHTRK MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If MDNAME and MANAME in a CFMLOCALMEP MO are the same as MDNAME and MANAME in a CFMBNDIP MO, respectively, the port configured for the CFMLOCALMEP MO cannot be an ETHPORT MO in an ETHTRUNK MO.
    • [Co-MPT, eGBTS, eNodeB, gNodeB]A maximum of 256 CFMBNDIP MOs can be configured on a board.
    • [NodeB]A maximum of 16 CFMBNDIP MOs can be configured on a board.
  • Relation with the IFIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]BNDIP in a CFMBNDIP MO must be different from IP in an IFIP MO in the same routing domain.
  • Relation with the DEVIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]BNDIP in a CFMBNDIP MO must be different from IP in a DEVIP MO in the same routing domain.
  • Relation with the IPADDR4 MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]BNDIP in a CFMBNDIP MO must be different from IP in an IPADDR4 MO in the same routing domain.
  • Relation with the VRF MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The VRF instance used by a CFMBNDIP MO must have been configured.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of CFMBNDIP MOs must be less than or equal to 32 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CFMBNDIP

Use this command to add a binding relationship between an RMEP and an IP address. The binding relationship between an RMEP and an IP address can be used for route interlock.
LST CFMBNDIP

Use this command to list the configurations of a binding relationship between an RMEP and an IP address.
RMV CFMBNDIP

Use this command to remove a binding relationship between an RMEP and an IP address.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
MD Name

Indicates the name of the MD to which the RMEP belongs.
MA Name

Indicates the name of the MA to which the RMEP belongs.
RMEP ID

Indicates the RMEP ID.
VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).
IP Address

Indicates the IP address of the Ethernet port or Ethernet trunk corresponding to an RMEP. The binding IP address must be different from the existing local IP address or the IP address of any effective port (including the physical port and loopback port). The binding IP address must be different from the local IP address dynamically negotiated on the PPP or MLPPP link. During the binding of an IP address, an error messaged indicating IP address conflicts may be displayed. In this case, list the existing IP address in the system that conflicts with the IP address to be bound by running the related MML commands. Then, manually resolve the IP address conflicts. To list the IP address, run the LST DEVIP, DSP DEVIP, LST IPADDR4, or DSP IPADDR4 command. To list the local IP address of the remote maintenance channel, run the LST OMCH or DSP OMCH command. To list the local IP address of the PPP link, run the LST PPPLNK or DSP PPPLNK command. To list the local IP address of the MLPPP group, run the LST MPGRP or DSP MPGRP command. To list the IP address of the local maintenance channel, run the LST LOCALIP or DSP LOCALIP command.
