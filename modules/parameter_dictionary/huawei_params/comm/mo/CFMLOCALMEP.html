CFMLOCALMEP

TRANSPORT
  +-CFMMD
    +-CFMMA
      +-CFMLOCALMEP

Description

The CFMMEP MO consists of the parameters related to the local maintenance association end point (MEP). Local MEPs and remote MEPs (RMEPs) determine the scope and boundaries of a maintenance domain (MD). The MD and MA to which MEPs belong determine the VLAN attributes and level for messages sent from the MEPs.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CFMMA
  • Relation with the CFMLOCALMEP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Only one CFMLOCALMEP MO can be configured in a CFMMA MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the parent CFMMA MO of a CFMLOCALMEP MO is bound to a VLAN, the LEVEL value in the CFMMD MO to which the CFMLOCALMEP MO belongs must be greater than that of the CFMMD MO containing any CFMLOCALMEP MO not bound to a VLAN.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before adding a CFMLOCALMEP MO to an ETHPORT MO in an ETHTRUNK MO, ensure that LEVEL in the CFMMD MO to which the CFMLOCALMEP MO belongs is less than or equal to that in the CFMMD MO to which the CFMLOCALMEP MO configured for the ETHTRUNK MO belongs.
  • Relation with the CFMRMEP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Under a CFMMA MO, MEPID in the CFMLOCALMEP MO and RMEPID in the CFMRMEP MO cannot be set to the same value.
  • Relation with the CFMMEP and CFMRMEP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the TRANSCFGMODE in the GTRANSPARA MO is set to OLD, CFMMEP MO must be configured when a CFMRMEP MO has been configured in a CFMMA MO.
    • When the TRANSCFGMODE in the GTRANSPARA MO is set to NEW, CFMLOCALMEP MO must be configured when a CFMRMEP MO has been configured in a CFMMA MO.
  • Relation with the ETHTRUNKLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before a CFMLOCALMEP MO is configured on an ETHTRUNK MO or on an ETHPORT MO that is not added to an ETHTRUNK MO, BNDVLAN in the parent CFMMA MO of the CFMLOCALMEP MO must be set to YES.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If an ETHPORT MO configured with a CFMLOCALMEP MO has joined an ETHTRUNK MO, the CFMMA MO to which the CFMLOCALMEP MO belongs cannot be associated with any VLAN.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before configuring a CFMLOCALMEP MO on an ETHTRUNK MO, ensure that the ETHTRUNKLNK MO has been configured in the ETHTRUNK MO.
  • Relation with the ETHTRUNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before configuring a CFMLOCALMEP MO on an ETHTRUNK MO, ensure that the ETHTRUNK MO has been configured.
  • Relation with the CFMMA MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When adding a CFMLOCALMEP MO to an ETHPORT MO that belongs to an ETHTRUNK MO, CCMINTL in the CFMMD MO containing the CFMLOCALMEP MO in the ETHTRUNK MO must be greater than CCMINTL in the CFMMD MO containing the CFMLOCALMEP MO in the ETHTRUNKLNK MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When setting the TRANSCFGMODE in the GTRANSPARA MO to NEW and adding a CFMLOCALMEP MO to an ETHTRUNK MO that an ETHPORT MO belongs to it, CCMINTL in the CFMMD MO containing the CFMLOCALMEP MO in the ETHTRUNK MO must be greater than CCMINTL in the CFMMD MO containing the CFMLOCALMEP MO in the ETHTRUNKLNK MO.
  • Relation with the PORTSECURITY MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The ETHPORT MO that is associated with a CFMLOCALMEP MO must meet either of the following conditions: (1) No PORTSECURITY MO is associated with the ETHPORT MO; (2) A PORTSECURITY MO is associated with the ETHPORT MO, but SWITCH in the PORTSECURITY MO is set to ENABLE.
  • Relation with the ETHDM and CFMMEP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the CFMMEP MO referenced by the ETHDM MO must have been configured.
    • If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the CFMLOCALMEP MO referenced by the ETHDM MO must have been configured.
  • Relation with the ETHLM and CFMMEP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the CFMMEP MO referenced by the ETHLM MO must have been configured.
    • If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the CFMLOCALMEP MO referenced by the ETHLM MO must have been configured.
  • Relation with the ETHLM and ETHTRUNKLNK MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the TRANSCFGMODE in the GTRANSPARA MO is set to NEW and the ETHLM MO is associated with the CFMLOCALMEP MO whose PT parameter is set to ETHTRK, the ETHLM MO cannot be activated. When the ETHLM MO is associated with the CFMLOCALMEP MO whose PT parameter is set to ETH and this port has been added to the ETHTRUNK MO, the ETHLM MO cannot be activated.
  • Relation with the ETHPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before configuring a CFMLOCALMEP MO on an ETHPORT MO, ensure that the ETHPORT MO has been configured.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the CFMLOCALMEP MO cannot be configured.
  • Relation with the INTERFACE MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]TAGGED in the INTERFACE MO associated with the CFMLOCALMEP MO must be set to ENABLE if the CFMLOCALMEP MO meets any of the following conditions: PORTID in the CFMLOCALMEP MO is equal to PORTID in the INTERFACE MO, PT is set to ETH, and ITFTYPE is set to NORMAL. PORTID in the CFMLOCALMEP MO is equal to ETHPORTID in the ETHTRUNKLNK MO, PORTID is equal to ETHTRKPORTID, PT is set to ETH, ITFTYPE is set to NORMAL, and PT is set to ETHTRK. PORTID in the CFMLOCALMEP MO is equal to PORTID in the INTERFACE MO, PT is set to ETHTRK, and ITFTYPE is set to NORMAL.

Function

Use this command to remove a local connectivity fault management (CFM) maintenance association end point (MEP).
