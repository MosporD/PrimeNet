LOCATION

EQUIPMENT
  +-LOCATION

Description

The LOCATION MO provides detailed information related to the physical location.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT
  • Relation with the SECTOR MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in the SECTOR MO is not left blank, POSITIONINGMETHOD in the LOCATION MO corresponding to this character string cannot be set to POSITIONING_BY_UE.
  • Relation with the CABINET MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in a CABINET MO is not set to NULL, the corresponding LOCATION must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in the CABINET MO is not left blank, POSITIONINGMETHOD in the LOCATION MO corresponding to this character string cannot be set to POSITIONING_BY_UE.
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in a RRU MO is not set to NULL, the corresponding LOCATION must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in a RRU MO is not set to NULL, the corresponding LOCATION with LOCATIONTYPE set to BTSSITE or RFSITE must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If POSITIONINGMETHOD in the LOCATION MO corresponding to LOCATIONNAME in the RRU MO is set to POSITIONING_BY_UE, LOCATIONNAME in other RRU MOs cannot correspond to the LOCATION MO.
  • Relation with the RHUB MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in the RHUB MO is not set to NULL, the corresponding LOCATION must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in the RHUB MO is not set to NULL, the corresponding LOCATION with LOCATIONTYPE set to BTSSITE or RFSITE must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in the RHUB MO is not left blank, POSITIONINGMETHOD in the LOCATION MO corresponding to this character string cannot be set to POSITIONING_BY_UE.
  • Relation with the CXU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in a CXU MO is not set to NULL, the corresponding LOCATION must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in a CXU MO is not set to NULL, the corresponding LOCATION with LOCATIONTYPE set to BTSSITE or RFSITE must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in the CXU MO is not left blank, POSITIONINGMETHOD in the LOCATION MO corresponding to this character string cannot be set to POSITIONING_BY_UE.
  • Relation with the RFU and CABINET MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME of a CABINET housing the RFU is not set to NULL, the corresponding LOCATION with LOCATIONTYPE set to BTSSITE or RFSITE must have been configured.
  • Relation with the NE MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATION in the NE MO is not left blank, POSITIONINGMETHOD in the LOCATION MO corresponding to this character string cannot be set to POSITIONING_BY_UE.

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
address

Indicates the address of the base station.
Altitude

Indicates the altitude of the base station.
City

Indicates the city where the base station is located.
Contact

Indicates the addresses related to this base station or telephone numbers of the personnel related to this base station.
Geo-coordinate Data Format

Indicates the format of geographical coordinates.
Latitude With Degree Format

Indicates the latitude of the base station. A negative value indicates the south and a positive value indicates the north.
Latitude With Second Format

Indicates the latitude of the base station in the WGS-84 coordinate system.
Location Id

Indicates the location ID of the base station.
Location Name

Indicates the location name of the base station.
Longitude With Degree Format

Indicates the longitude of the base station. A negative value indicates the west and a positive value indicates the east.
Longitude With Second Format

Indicates the longitude of the base station in the WGS-84 coordinate system.
Office

Indicates the site that the base station belongs to.
Range

Indicates the range of the base location.
Region

Indicates the block where the base station is located.
Telephone

Indicates the telephone number of the maintenance personnel of the base station.
User Label

Indicates the user-defined information of the location.
Precise

Indicates the positioning accuracy of the base station's geographical location.
Mode

Indicates the configuration mode of the base station longitude and altitude. This parameter can be set to AUTO or MANUAL. In automatic mode, the base station longitude and altitude are obtained from the GPS antenna or UE, and the configured longitude and latitude information is overwritten. In manual mode, the base station longitude and altitude are configured manually.
PosStandard

Indicates the RAT corresponding to the longitude and latitude. The default value is the local RAT.
Location Type

Indicates the location type. The value BTSSITE indicates a traditional site deployed with both BBUs and RF modules. The value RFSITE indicates an RF site deployed only with RF modules (including their auxiliary devices). The value BBSITE indicates a baseband site deployed only with BBUs.
Positioning Method

Indicates the automatic location mode of the physical equipment of the base station.
