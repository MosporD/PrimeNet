Description

The CascadePort MO, which can be either a basic interconnection port or an extended interconnection ports, is used to interconnect the BBU. The basic interconnection port transmits control-panel data and clock signals. The extended interconnection port transmits user-plane data. The BLADEBBU does not support this configuration.

  • Relation with the BBP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the BBP MO is not UBBP, LCOP or UBBP-W, the value of PM in the CASCADEPORT MO must be set to AUTO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the BBP MO is not UBBP, the value of PM in the CASCADEPORT MO cannot be set to 1*100GE.
    • [Co-MPT, NodeB, eNodeB, gNodeB]When the combination of CN, SRN and SN in the CASCADEPORT MO is same as the combination of CN, SRN and SN in the BBP MO, PT in the CASCADEPORT MO must be set to ExpandedCascadePort.
  • Relation with the BBPLINK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of PM in a CASCADEPORT MO is 1*40GE or 4*10GE, the BBP MO specified by CN, SRN, and SN in the CASCADEPORT cannot be configured with a BBPLINK MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If a BBP MO is configured with a BBPLINK MO, the value of PM in the CASCADEPORT MO on the BBP MO cannot be 1*40GE or 4*10GE.
  • Relation with the MPT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the combination of CN, SRN and SN in the CASCADEPORT MO is same as the combination of CN, SRN and SN in the MPT MO, PM in the CASCADEPORT must be set to AUTO.
