PPPLNK

TRANSPORT
  +-PPPLNK

Description

This MO is used to set the parameters of a PPP link.

The Point-to-Point Protocol (PPP) is a protocol at the data link layer that is used to carry network layer packets on a PPP link. The PPP supports both synchronous communication and asynchronous communication.

Authentication Type

Indicates the mode in which the local end of a PPP link authenticates the peer end. The authentication mode is classified into No authentication, Password Authentication Protocol(PAP) authentication, and Challenge and shake Authentication Protocol(CHAP) authentication. In PAP mode, user names and passwords are transmitted explicitly on the network. If they are intercepted during transmission, a great threat to network security is caused. Therefore, the PAP is applied only to the network environment with low security requirements. With three handshakes, the CHAP provides a more secure authentication. In CHAP mode, only user accounts rather than passwords are transmitted, enhancing security compared to the PAP.

Peer IP

Indicates the peer IP address. If the BS is connected to an upper-level node, this address is specified according to the upper-level node. If the BS is cascaded to a lower-level node, this address must be specified. This parameter can be set to 0.0.0.0.
