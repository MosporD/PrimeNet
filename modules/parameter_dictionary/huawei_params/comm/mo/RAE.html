RAE

EQUIPMENT
  +-RAE
    +-RAESUBUNIT[1~6]

Description

The Remote eAntenna Extension (RAE) is a device on the antenna and stores weighting factor and assistant information about the antenna. The base station can obtain this information from the RAE and overwrite this information stored on the RAE.

Effective Scenario

Immediately

Relations Between MOs

  • Base class:

    ALD

  • Possible parents:

    EQUIPMENT

  • Possible children:

    RAESUBUNIT[1~6]
  • Relation with the RAESUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of RAESUBUNIT MOs configured on one RAE MO must be greater than or equal to 1 and smaller than or equal to 6.
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The RRU MO specified by CTRLCN, CTRLSRN, and CTRLSN in the RAE MO cannot be an MRIU.
  • Relation with the RRU, RFU, and AAMU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The RRU, RFU, or AAMU MO corresponding to CTRLCN, CTRLSRN, and CTRLSN in the RAE MO must have been configured.
  • Relation with the RRU and RFU MOs:
    • [gNodeB]The RRU or RFU MO corresponding to CTRLCN, CTRLSRN, and CTRLSN in the RAE MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD RAE

Use this command to add a Remote eAntenna Extension (RAE). The subunits and device data are also added at the same time.
DSP RAE

Use this command to query the dynamic information about one or all Remote eAntenna Extension (RAE).
LST RAE

Use this command to list the configuration of one or all Remote eAntenna Extension (RAEs).
MOD RAE

Use this command to modify the configuration of a Remote eAntenna Extension (RAE).
RMV RAE

Use this command to remove a Remote eAntenna Extension (RAE). The subunits and device data are also removed at the same time.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Antenna Scenario

Indicates the connection scenario of the antenna. This parameter must be set based on the hardware installation. The vendor code and serial number of the device must be correctly configured in a non-regular scenario. This parameter can be set to REGULAR or DAISY_CHAIN.
Number of RAE Subunits

Indicates the number of configured RAE subunits.
Device No.(from ALD)

Indicates the device number of the ALD. The device number of the ALD must be unique.
Device Name(from ALD)

Indicates the device name of the ALD, which identifies the ALD. It is recommended that you set the device name in the following format: sector_device type_network type. The meanings of the parts are as follows: Sector indicates the number of the sector. Device type indicates the type of currently connected device. The device type can be SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), TMA (Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit). Network type indicates whether the current ALD is used for a 2G network or 3G/LTE network. The device name is optional, but the device name configured for each ALD must be unique.
Control Port Cabinet No.(from ALD)

Indicates the cabinet number of the RRU or RFU that controls the ALD.
Control Port Subrack No.(from ALD)

Indicates the subrack number of the RRU or RFU that controls the ALD.
Control Port Slot No.(from ALD)

Indicates the slot number of the RRU or RFU that controls the ALD.
Vendor Code(from ALD)

Indicates the vendor code.
Serial No.(from ALD)

Indicates the serial number of the ALD. The vendor code and the serial number uniquely identify an ALD.
