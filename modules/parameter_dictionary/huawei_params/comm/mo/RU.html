RU

Description

The replaceable unit (RU) MO is a virtual base class of a board, which provides keywords and status information of the cabinet, subrack, and slot.

Effective Scenario

Immediately

Relations Between MOs

  • Inherit children:

    RE;CXU;RHUB;GDU;EDC;MEB;BDU;UCCU;MDU;RFC;BRI;GTMU;TRP;PEU;BBP;MPT;PSU;PMU;UCIU;UEIU;USCU;TCU;BBUFAN;FMU;EMU

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD BRD

Use this command to add a board. Only the boards in the BBU can be added by running this command. When the type of the board to be added is FAN, the temperature control mode ID for fan speed adjustment can be configured.
BLK BRD

Use this command to block a specified board.
DSP BKPSTATUS

Use this command to query information about the backup status, including software packages, configuration data, and logs.
DSP BRD

Use this command to query the status of a board.
DSP BRDCERTMK

Use this command to query the certificate information of boards.
DSP BRDCHKRESULT

Use this command to query the historical running status of base station boards.
DSP BRDDORMANCY

Use this command to query the energy-saving status of a board.
DSP BRDMFRINFO

Use this command to query the manufacturing information about a board. Only one board can be queried at a time. Because there is only one backplane in the BBU subrack, the manufacturing information about the subrack can be obtained by the query of the manufacturing information about the backplane.
DSP BRDREMAINTIME

Use this command to query the remaining time of board.
DSP BRDTEMP

Use this command to query the temperature of a board. The temperature of the board includes the board temperature and power amplifier temperature.
DSP CPUUSAGE

Use this command to query the CPU/DSP usage of a board. After the execution of this command, the usage of the master CPU, slave CPU, and DSP (if any) is displayed.
DSP DEVCONFLICTINFO

Use this command to query the information of devices encountering configuration conflicts.
DSP ELABEL

Use this command to query the electronic label of the specified device. The command output includes the manufacturing information.
DSP FAN

Use this command to query the status of the BBU fan board, including the temperature, ratio of revolutions, and the temperature control mode ID that takes effect on the BBU fan board.
DSP FLASHUSAGE

Use this command to query the flash usage.
DSP HWOLTSTRESULT

Use this command to query the result of the latest hardware online test.
DSP HWTSTRESULT

Use this command to query the result of the latest hardware test on a board.
DSP MEMUSAGE

Use this command to query the memory usage.
DSP SWAPLOG

Use this command to query the recent swap records.
DSP UPEU

Use this command to query the UPEU status, including the UPEU spare power, the BBU spare power, and the input voltage.
DSP USERLABEL

Use this command to query user-defined labels.
LST BRDALMTHLD

Use this command to list the configurations of the thresholds for reporting and clearing the board overload alarm.
MOD PEERMODE

Use this command to modify the working mode of the main control board at the peer end. If the local subrack is selected, the working mode of the peer main control board in the local subrack will be modified. Otherwise, the working mode of the peer main control board in the peer subrack will be modified.
OPR BRDPWR

Use this command to perform power-on and power-off of a board. If a board in the BBU subrack is not carrying services, you can power off the board to save power. To use the board, you can power on it again. In a dual-mode BS, this command can be run to power on or off a board of the other mode. The service carried on the board is interrupted after the power-off.
RMV BRD

Use this command to remove a board.
RST BRD

Use this command to reset a specified board, except passive boards such as the UPEU and USCU.
RST BRDPWROFF

Use this command to power off a board. The board is automatically powered on and is reset. This helps to rectify some hardware faults of the board. Currently, only the boards (excluding the FAN unit, UPEU, and UEIU) in the BBU and the boards on the RRU chain/ring support such reset.
RST CANBUS

Use this command to reset the controller area network BUS (CANBUS) of a specified board.
SET BRDALMTHLD

Use this command to set the thresholds for reporting and clearing the board overload alarm.
SET USERLABEL

Use this command to set a user-defined label.
STR HWOLTST

Use this command to start a hardware online test on a board in order to locate or troubleshoot hardware faults.
STR HWTST

Use this command to start a hardware test on a board, which aims to locate or rectify the hardware faults on the board.
SWP BRD

Use this command to manually start the swap of the active and standby boards. When this command is executed successfully, the previous standby board becomes active and functions as the active board, while the previous active one becomes standby.
UBL BRD

Use this command to unblock a specified board.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Dynamic parameters

Parameter

Description
Alarm Status

Indicates the alarm status of the board hardware, which can be set to Normal, Warning, Minor, Major, or Critical. The alarm status of the PSU, PDB, and BDU is in the alarm status of the PMU.
Operational State

Indicates the operational state of the board, which can be set to Enabled or Disabled. Enabled indicates that services can be carried on the board. Disabled indicates that no service can be carried on the board.
Availability Status

Indicates the physical status of a board, which can be Uninstalled, Starting up, Normal, Inconsistent, Unconfigured, Power off, Fault, Communication lost, In test, or the combination of multiple states. For example, if a board is not configured and fails to communicate with the main control and transmission board, the availability status of the board is "Unconfigured, Communication lost." If a board is under management of the peer end, the availability status of the board may be Starting up, Communication lost, or Fault.
Electronic Label

Indicates the electronic label, which is a text file with a maximum of 2 KB used to record the manufacturing information about equipment such as the board, sub-board, and optical module. "BoardType" indicates the type of the board. "BarCode" indicates the bar code of the board and is the same as the code labeled on the board. "Item" indicates the BOM code. "Description" indicates the board description in English. "Manufactured" indicates the manufacturing date of the board. "VendorName" indicates the name of the vendor providing the board. "IssueNumber" indicates the board hardware version. "CLEICode" indicates the common language equipment indicator (CLEI) code of the board. "BOM" indicates the fine-grained item code of the board. "Model" indicates the model displayed on the customer interface, such as Bill of Quotation (BOQ) and paper labels.
Type

Indicates the type of the board or the cabinet.
Serial Number

Indicates the bar code of the board or the cabinet.
Description

Indicates the description about the services and functions provided by the board or the cabinet.
Date of Manufacture

Indicates the manufacturing date of the board or the cabinet.
Vendor

Indicates the manufacturer of the board or the cabinet.
Issue Number

Indicates the issue number of the board.
Config Type

Indicates the type of a board.
Board Temperature

Indicates the temperature of a board.
HPA Temperature

Indicates the temperature of the power amplifier. A power amplifier is a component on an RF module. If there is no power amplifier on an RF module, this parameter value is NULL.
DEVTYPE

Indicates the type of the device.
Software Version

Indicates the software version of the board.
Hardware Version

Indicates the hardware version of the board.
BootROM Version

Indicates the BootROM version of the board.
WorkMode

Indicates the working mode of the board. the value SINGLEOM indicates that the GTMU works as the main control board and provides the main control, transmission, and RF port functions. The value EVOLUTION indicates that the GTMU works as the evolved board and provides the transmission and RF port functions. NORMAL indicates that the main control and transmission board works in normal mode. TDS-EVOLUTION indicates that the main control and transmission board works in TDS evolution mode. NULL is displayed for boards other than GTMU or when the working mode cannot be queried.
