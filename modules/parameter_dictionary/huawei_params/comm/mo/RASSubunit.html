RASSUBUNIT

EQUIPMENT
  +-RAS
    +-RASSUBUNIT
      +-RASDEVICEDATA[1~1]

Description

The RASSUBUNIT MO is the managed object of a RAS subunit, which receives and transmits RF signals.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RAS

  • Possible children:

    RASDEVICEDATA[1~1]
  • Relation with the RASSUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]One of the following ANTENNAPORT MOs must have been configured: 1. An ANTENNAPORT MO corresponding to CONNCN1, CONNSRN1, CONNSN1, and CONNPN1 in the RASSUBUNIT MO. 2. An ANTENNAPORT MO corresponding to CONNCN2, CONNSRN2, CONNSN2, and CONNPN2 in the RASSUBUNIT MO.
  • Relation with the RAS MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of RASSUBUNIT MOs configured on one RAS MO must be greater than or equal to 1 and smaller than or equal to 8.
  • Relation with the RASDEVICEDATA MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of RASDEVICEDATA MOs configured on one RASSUBUNIT MO must be 1.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP RASSUBUNIT

Use this command to query the dynamic information about a remote azimuth steering (RAS) subunit.
LST RASSUBUNIT

Use this command to list the configuration of a remote azimuth steering (RAS) subunit.
MOD RASSUBUNIT

Use this command to modify a remote azimuth steering (RAS) subunit.

Description

Indicates the allowed maximum horizontal azimuth inconsistency. When the difference between the actual horizontal azimuth and configured tilt of an RAS subunit is larger than the value of this parameter; ALM-26757 RET Antenna Running Data and Configuration Mismatch is reported.

Subunit Name

Indicates the name of the RAS subunit. The name of the RAS subunit is optional, but the name configured for each RAS subunit must be unique.
