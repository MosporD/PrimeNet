LANSW

TRANSPORT
  +-LANSW
    +-LANSWITCHPORT[0~33]
    +-LSWPORT[0~33]
    +-STATICMACITEM[0~100]

Description

A layer 2 LAN switch controls a switching port of the Ethernet type (uplink port) and a switching port of the air-interface link type (downlink port). Addressing and switching are performed based on MAC addresses between the uplink and downlink ports for all packets to be forwarded. This MO is of the scalar class and is a subclass of the TPM MO. It can also be combined with the TPM MO.

Effective Scenario

Not involved

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Broadcast Packet Rate Threshold

Indicates the threshold limiting the data rate for forwarding broadcast packets by the layer 2 LAN switch of an NE.
MAC Aging Time

Indicates the aging time of entries in a MAC forwarding table that is learned by a layer 2 LAN switch of an NE.
Dynamic MAC Learn Switch

Indicates whether to enable the function of dynamically learning the MAC forwarding table by the layer 2 LAN switch of an NE.
Source MAC Attack Check Switch

Switch for checking the source MAC address attack to the layer 2 LAN switch of an NE. When this parameter is set to ENABLE, the related alarm is reported when a layer 2 LAN switch is attacked by the source MAC address. When this parameter is set to DISABLE, the related alarm is not reported when the layer 2 LAN switch is attacked by the source MAC address.
Source MAC Attack Alarm Threshold

Indicates the threshold for generating the source MAC attack-caused alarm on the layer 2 LAN switch of an NE. When this switch is turned on and a MAC forwarding table has been configured with the maximum number of entries, the Base Station Being Attacked alarm is reported if the number of the dynamic forwarding table update attempts exceeds a specified threshold within 1 minute, and the specific problem is source MAC address attack. If there is no dynamic update request within five consecutive minutes after the source MAC attack-caused alarm is reported, the alarm is cleared.
