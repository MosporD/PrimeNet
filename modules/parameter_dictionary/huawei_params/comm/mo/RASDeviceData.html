RASDEVICEDATA

EQUIPMENT
  +-RAS
    +-RASSUBUNIT
      +-RASDEVICEDATA

Description

The RASDeviceData MO refers to the configuration saved in the antenna and the capability supported by the antenna. For details, see 3GPP TS25.466 and AISG2.0.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RASSUBUNIT
  • Relation with the RASSUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of RASDEVICEDATA MOs configured on one RASSUBUNIT MO must be 1.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP RASDEVICEDATA

Use this command to query the dynamic information in the remote azimuth steering unit (RAS) device data.
LST RASDEVICEDATA

Use this command to list the configuration in the remote azimuth steering unit (RAS) device data.
MOD RASDEVICEDATA

Use this command to modify the configuration in the remote azimuth steering unit (RAS) device data.

Indicates the AISG sector ID. An AISG1.1-based RAS unit supports the longest sector ID of 4 characters. If the input sector ID has more than 4 characters, only the first 4 characters are saved on the RAS unit.
