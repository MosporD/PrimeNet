TWAMPRESPONDER

TRANSPORT
  +-TWAMPRESPONDER

Description

A TWAMPRESPONDER MO is used to respond to TWAMP negotiation packets and TWAMP measurement packets.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the DEVIP, PPPLNK, MPGRP, and GTRANSPARA MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD and IPVERSION in a TWAMPRESPONDER MO is set to IPv4, LOCALIP in the TWAMPRESPONDER MO must have been configured. That is, LOCALIP is from IP in a DEVIP MO, LOCALIP in a PPPLNK MO, or LOCALIP in a MPGRP MO in the same routing domain.
  • Relation with the IPADDR4, PPPLNK, MPGRP, and GTRANSPARA MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE in a GTRANSPARA MO is set to NEW and IPVERSION in a TWAMPRESPONDER MO is set to IPv4, LOCALIP in the TWAMPRESPONDER MO must have been configured. That is, LOCALIP of the TWAMPRESPONDER MO is from IP in an IPADDR4 MO, LOCALIP in a PPPLNK MO, or LOCALIP in an MPGRP MO in the same routing domain.
  • Relation with the TWAMPRESPONDER MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]In the same routing domain, if IPVERSION and TWAMPARCH in two TWAMPRESPONDER MOs are set to IPv4 and FULL respectively, their LOCALIP must be set to different values.
    • [Co-MPT, NodeB, eNodeB, gNodeB]In the same routing domain, if IPVERSION and TWAMPARCH in two TWAMPRESPONDER MOs are set to IPv4 and LIGHT respectively, their LOCALIP or LIGHTLOCALUDPPORT must be set to different values.
    • [Co-MPT, NodeB, eNodeB, gNodeB]In the same routing domain, if IPVERSION in two TWAMPRESPONDER MOs is set to IPv4, and TWAMPARCH of the two TWAMPRESPONDER MOs are set to FULL and LIGHT respectively, their LOCALIP must be set to different values.
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, if IPVERSION and TWAMPARCH in two TWAMPRESPONDER MOs are set to IPv6 and LIGHT respectively, their LOCALIP or LIGHTLOCALUDPPORT must be set to different values.
  • Relation with the IPADDR6 MO:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a TWAMPRESPONDER MO is set to IPv6, LOCALIPV6 in the TWAMPRESPONDER MO must have been configured. That is, LOCALIPV6 is IPV6 of an IPADDR6 MO in the same routing domain.
  • Relation with the DEVIP and GTRANSPARA MOs:
    • [gNodeB]If TRANSCFGMODE in a GTRANSPARA MO is set to OLD, LOCALIP in a TWAMPRESPONDER MO with IPVERSION set to IPv4 must have been configured. That is, LOCALIP is IP of a DEVIP MO in the same routing domain.
  • Relation with the IPADDR4 and GTRANSPARA MOs:
    • [gNodeB]If TRANSCFGMODE in a GTRANSPARA MO is set to NEW and IPVERSION in a TWAMPRESPONDER MO is set to IPv4, LOCALIP of the TWAMPRESPONDER MO must have been configured. That is, LOCALIP of the TWAMPRESPONDER MO is IP of an IPADDR4 MO in the same routing domain.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD TWAMPRESPONDER

Use this command to add a TWAMP responder.
DSP TWAMPRESPONDER

Use this command to query the negotiation results and statistics of measurement packets for TWAMP responders.
DSP TWAMPRESPONDERSTA

Use this command to query the statistics of negotiation packets for TWAMP responders. This command takes effect only when TWAMPARCH for TWAMP responders is set to FULL.
LST TWAMPRESPONDER

Use this command to query the configuration about a TWAMP responder.
MOD TWAMPRESPONDER

Use this command to modify the configuration of a TWAMP responder.
RMV TWAMPRESPONDER

Use this command to remove a TWAMP responder.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Responder Index

Indicates the index of a TWAMP responder.
TWAMP Architecture

Indicates the architecture of a TWAMP responder.
IP Version

Indicates the IP version of a TWAMP responder.
Local IP Address

Indicates the local IPv4 address of a TWAMP responder.
VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).
DSCP for TCP Packets

Indicates the DSCP of TCP negotiation packets sent by a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.
Measurement Wait Time

Indicates the measurement wait time of a TWAMP responder. The REFWAIT timer is started to monitor the status of a measurement session between the server and client. When this timer expires, the server releases the measurement session and returns to the link establishment state.
Negotiation Wait Time

Indicates the negotiation wait time of a TWAMP responder. The SERVWAIT timer is started to monitor the establishment status of a control connection between the server and client. When this timer expires, the server releases the control connection.
Local IPv6 Address

Indicates the local IPv6 address of a TWAMP responder.
Local TCP Port No.

Indicates the local TCP port number of a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.
Light Architecture Local UDP Port No.

Indicates the local UDP port number used when TWAMP responders work in light-architecture mode. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to LIGHT. This parameter is invalid when the parameter is set to 4294967295.
Light Architecture Mode

Indicates the working mode of a TWAMP responder deployed in the light architecture. The working mode of the TWAMP responder must be the same as that of the TWAMP sender. This parameter takes effect only when the TWAMP responder is deployed in the light architecture.
