EXTRRURES

EQUIPMENT
  +-EXTRRURES

Description

An EXTRRURES MO defines the RF resources that another NE provides for the local NE. When a distributed control unit (DCU) is connected with a BBU, the DCU shares its RRUs with the BBU. The RF resources provided by these RRUs are configured in this MO so that the BBU can use the RF resources.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT
  • Relation with the RCSSERVER MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The RCSSERVER MO where the EXTRRURES MO is located must have been configured.
  • Relation with the RRU, CXU, AAMU, and RHUB MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]Each of the following MOs must have a unique combination of cabinet number, subrack number, and slot number: EXTRRURES, RRU, AAMU, RHUB and CXU.
  • Relation with the EXTRRURES MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The value of SERVERRRUNAME in each EXTRRURES MO must be unique.
  • Relation with the RRU, CXU, and RHUB MOs:
    • [gNodeB]Each of the following MOs must have a unique combination of cabinet number, subrack number, and slot number: EXTRRURES, RRU, RHUB and CXU.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD EXTRRURES

Use this command to add shared external RRU resources that another NE provides for the local NE. When a DCU is connected with a BBU, the DCU shares its RRUs with the BBU. The RF resources provided by these RRUs are configured on the BBU so that the BBU can use the RF resources.
DSP EXTRRURES

Use this command to query the status of shared external RRU resources.
LST EXTRRURES

Use this command to list the configuration of shared external RRU resources.
MOD EXTRRURES

Use this command to modify the configuration of shared external RRU resources.
RMV EXTRRURES

Use this command to remove shared external RRU resources.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of shared external RRU resources.
Subrack No.

Indicates the subrack number of shared external RRU resources.
Slot No.

Indicates the slot number of shared external RRU resources.
RCS Server No.

Indicates the number of the RCS server where an RRU entity providing the shared external RRU resources is located.
Server RRU Name

Indicates the name of an RRU entity providing the shared external RRU resources. This parameter must be set to the name of this RRU entity configured on the RCS server that provides the RRU.
User Label

Indicates the user-defined information about shared external RRU resources.
Table 3 Dynamic parameters

Parameter

Description
