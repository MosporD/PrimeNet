RHUBRESQUOTA

EQUIPMENT
  +-RHUBRESQUOTA

Description

Indicates the quota of RHUB resources provided by the NE for a client NE.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT
  • Relation with the RHUB MO:
    • [Co-MPT]The RHUB MO in the RHUB list under the RHUBRESQUOTA MO must have been configured.
  • Relation with the RHUBRESQUOTA MO:
    • [Co-MPT]If the SCOPE parameter in the RHUBRESQUOTA MO is set to ALL, the RCSCLIENTNO parameter in this RHUBRESQUOTA MO cannot be set to the same value as those in other RHUBRESQUOTA MOs.
    • [Co-MPT]If the RCSCLIENTNO parameters of the RHUBRESQUOTA MOs are set to the same value, the RHUBs in the RHUBRESQUOTA MOs must be different.
  • Relation with the RCSCLIENT MO:
    • [Co-MPT]The RCSCLIENT MO corresponding to the RCSCLIENTNO parameter in the RHUBRESQUOTA MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD RHUBRESQUOTA

Use this command to add an RHUB resource quota. Each client NE can correspond to multiple quotas and each quota corresponds to different RHUBs.
LST RHUBRESQUOTA

Use this command to list configuration of RHUB resource quotas.
MOD RHUBRESQUOTA

Use this command to modify an RHUB resource quota. Each client NE can correspond to multiple quotas and each quota corresponds to different RHUBs.
RMV RHUBRESQUOTA

Use this command to remove an RHUB resource quota.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
RHUB Resource Quota ID

Indicates the quota ID of RHUB resources.
RCS Client No.

Indicates the number of the client NE to which the quota is allocated.
RF Combination Capacity

Indicates the number of cells that use RF combination.
Inter-RHUB RF Combination Capacity

Indicates the number of cells that use inter-RHUB RF combination.
RHUB Scope

Indicates the scope of RHUBs to which the quota is allocated.
RHUB List

Indicates the list of RHUBs to which the quota is allocated.
