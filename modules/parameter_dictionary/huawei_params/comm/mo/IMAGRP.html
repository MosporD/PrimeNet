IMAGRP

TRANSPORT
  +-IMAGRP

Description

This MO indicates a group of combined physical links that use Inverse Multiplexing over ATM (IMA) to obtain higher bandwidth for high-speed ATM cell stream transmission. The bandwidth of an IMA group is the total bandwidth of all the IMA links in the IMA group.

Effective Scenario

Immediately

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ACT VCLPM

Use this command to activate the virtual channel link (VCL) performance monitoring (PM) function. This function performs end-to-end detection of VCL quality, such as measuring the number of lost cells and the number of misinserted cells. You can run the DSP VCLPM command to query the PM result.
ADD IMAGRP

Use this command to add an inverse multiplexing over ATM (IMA) group.
DEA VCLPM

Use this command to deactivate the VCL PM function.
DSP IMAGRP

Use this command to query the status of an IMA group.
DSP IMATST

Use this command to query the status of an IMA group test.
DSP VCLPM

Use this command to list the VCL Performance Monitoring (PM) result, including information about the PM activation state, statistics about lost cells, statistics about miss-inserted cells, and VCL application information.
LST BEARLINK

Use this command to list the links carried on a physical port and the bandwidth occupied by each link.
LST IMAGRP

Use this command to list the IMA group configuration.
MOD IMAGRP

Use this command to modify the configuration of an IMA group.
RMV IMAGRP

Use this command to remove an IMA group. The execution of this command will lead to automatic removal of IMA links from the IMA group.
RST IMAGRP

Use this command to reset an IMA group having taken effect.
SET SCRAM

Use this command to set the scramble mode of the Inverse Multiplexing on ATM (IMA) group, User-Network Interface (UNI) link, or fractional ATM link.
STP IMATST

Use this command to stop an IMA group test.
STR IMATST

Use this command to start a test on an IMA group. The test is conducted to check whether an IMA group at the local end is connected to multiple IMA groups at the peer end. An IMA test is performed on an IMA group. That is, when an IMA test is started on an IMA link, the IMA test is actually started on the IMA group to which the IMA link belongs.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the board where the IMA group is located.
Subrack No.

Indicates the subrack number of the board where the IMA group is located.
Slot No.

Indicates the slot number of the board where the IMA group is located.
Group No.

Indicates the number of the IMA group.
IMA Protocol Version

Indicates the version of the IMA protocol. If this parameter is set to V1.0, the position of RX link information in an IMA Control Protocol (ICP) cell is determined by the TX Link ID (LID) transmitted by the local end. If this parameter is set to V1.1, the position of RX link information in an ICP cell is determined by the TX LID transmitted by the peer end.
Clock Mode

Indicates the clock mode of the IMA group. Links in an IMA group may pass through different transport networks. As a result, links in the IMA group may use different clock sources for synchronization. It is recommended that the IMA group work in Independent Transmit Clock (ITC) mode.
Tx Frame Length

Indicates the length of the frame used for data transmission on the IMA link in the IMA group. A larger value of this parameter results in higher efficiency but lower sensitivity to bit errors.
Min Number of Links Activated

Indicates the minimum number of active links that must be contained in an available IMA group. If the number of active links contained in the IMA group is smaller than the minimum number, the IMA group is unavailable.
Diff Max Delay

Indicates the allowed maximum differentiated delay of the IMA group.
Scramble Mode

Indicates whether scrambling is applied to the IMA group.
16th Time Slot Support

Indicates whether to enable E1 timeslot 16.
Subboard Type

Indicates the type of sub-board on the board where the IMA group is established.
Table 3 Dynamic parameters

Parameter

Description
NE State

Indicates the near end status of the IMA group. The near end inversely multiplexes one ATM cell stream (unit: cell) to enable the cells to be transmitted on multiple physical links.
FE State

Indicates the remote group status of the IMA group. The far end multiplexes the cell streams transmitted on multiple physical connections into a single cell stream.
Group Failure Status

Indicates the failure status of the IMA group.
Tx Available Bandwidth

Indicates the available TX bandwidth of the IMA group. The number of activated RX links may be greater than that of activated TX links only when IMA links are connected improperly or the TX or RX link is disconnected. At this time, available TX and RX bandwidths in the listed result of the IMA group status are calculated according to the number of activated TX links.
Rx Available Bandwidth

Indicates the RX bandwidth of the IMA group. The number of activated RX links will be greater than that of activated TX links only when IMA links are connected improperly or the TX or RX link is disconnected. At this time, available TX and RX bandwidths in the listed result of the IMA group status are calculated according to the number of activated TX links.
Number of Tx Links Configured

Indicates the configured TX link numbers of the IMA group.
Number of Rx Links Configured

Indicates the configured RX link numbers of the IMA group.
Number of Tx Links Activated

Indicates the activated TX link numbers of the IMA group. Generally, the number of activated TX links should be equal to the number of configured TX links. If the number of activated TX links is less than the number of configured TX links, you can infer that one or more links are faulty. The number of activated RX links may be greater than that of activated TX links only when IMA links are connected improperly or the TX or RX link is disconnected.
Number of Rx Links Activated

Indicates the activated RX link numbers of the IMA group.
IMA Link No.

Indicates the number of the IMA link under test.
Test Picture

Indicates the picture of the IMA test. If the system sends a test picture from an IMA link in an IMA group, it expects to receive the picture on another link in the same IMA group to check the connectivity of the IMA links in the IMA group. When this parameter is not specified, the user-defined IMA group number plus 1 is used as the test picture by default. You can set this parameter to any number from 1 to 254.
Test Result

Indicates the result of the IMA group test.
Number of Tx Cells

Indicates the number of cells sent by the IMA group.
Number of Rx Cells

Indicates the number of cells received by the IMA group.
Number of Tx Filler Cells

Indicates the number of filler cells transmitted by the IMA group.
Number of Rx Filler Cells

Indicates the number of filler cells received by the IMA group.
Number of Rx Dropped Cells

Indicates the number of user received cells that are discarded due to congestion at the ATM layer.
Number of Tx Discarded Cells

Indicates the number of user transmitted cells that are discarded due to congestion at the ATM layer.
IMA Group Subboard Type

Indicates the type of sub-board on the board where the IMA link is established.
Number of Deleted IMA Links Caused by Loopback

Indicates the number of IMA links that are removed due to loopbacks.
