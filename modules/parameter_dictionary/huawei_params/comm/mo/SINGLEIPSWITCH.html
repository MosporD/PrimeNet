SINGLEIPSWITCH

TRANSPORT
  +-SINGLEIPSWITCH

Description

The SINGLEIPSWITCH MO is the switch for single IP.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the DEVIP, IFIP, and GTRANSPARA MOs:
    • [NodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, and MODELSELECT of GTRANSPARA is set to TRADITION, SINGLEIPSW and CM in a SINGLEIPSWITCH MO are set to ENABLE and PANEL_INTERCONNECT, respectively, ensure that a DEVIP MO corresponding to UIIP in the SINGLEIPSWITCH MO is configured and that PT in the DEVIP MO is set to ETH. If MODELSELECT of GTRANSPARA is set to HOSTGW, SINGLEIPSW and CM in a SINGLEIPSWITCH MO are set to ENABLE and PANEL_INTERCONNECT, respectively, ensure that an IFIP MO corresponding to UIIP in the SINGLEIPSWITCH MO is configured and that PT in the IFIP MO is set to ETH.
    • [NodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, and MODELSELECT of GTRANSPARA is set to TRADITION and SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, ensure that a DEVIP MO corresponding to UOIP in the SINGLEIPSWITCH MO is configured and that PT in the DEVIP MO is set to ETH or ETHTRK. If MODELSELECT of GTRANSPARA is set to HOSTGW and SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, ensure that an IFIP MO corresponding to UOIP in the SINGLEIPSWITCH MO is configured and that PT in the IFIP MO is set to ETH or ETHTRK.
  • Relation with the DEVIP MO:
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GPEERIP in the SINGLEIPSWITCH MO must be different from IP in any DEVIP MO.
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GIIP in the SINGLEIPSWITCH MO must be different from IP in any DEVIP MO.
  • Relation with the LOCALIP MO:
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GPEERIP in the SINGLEIPSWITCH MO must be different from IP in any LOCALIP MO.
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GIIP in the SINGLEIPSWITCH MO must be different from IP in any LOCALIP MO.
  • Relation with the PPPLNK MO:
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GPEERIP in the SINGLEIPSWITCH MO must be different from LOCALIP in any PPPLNK MO.
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GIIP in the SINGLEIPSWITCH MO must be different from LOCALIP in any PPPLNK MO.
  • Relation with the MPGRP MO:
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GPEERIP in the SINGLEIPSWITCH MO must be different from LOCALIP in any MPGRP MO.
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GIIP in the SINGLEIPSWITCH MO must be different from LOCALIP in any PPPLNK MO.
  • Relation with the OMCH MO:
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GPEERIP in the SINGLEIPSWITCH MO must be different from IP in any OMCH MO in the same routing domain.
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GIIP in the SINGLEIPSWITCH MO must be different from IP in any OMCH MO in the same routing domain.
  • Relation with the WLOCALIP MO:
    • [NodeB]If SINGLEIPSW in the SINGLEIPSWITCH MO is set to ENABLE, GPEERIP in the SINGLEIPSWITCH MO must be different from IP in the WLOCALIP MO.
    • [NodeB]If SINGLEIPSW in the SINGLEIPSWITCH MO is set to ENABLE, GIIP in the SINGLEIPSWITCH MO must be different from IP in the WLOCALIP MO.
  • Relation with the IFIP MO:
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GPEERIP in the SINGLEIPSWITCH MO must be different from IP in any IFIP MO.
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GIIP in the SINGLEIPSWITCH MO must be different from IP in any IFIP MO.
  • Relation with the IPADDR4, INTERFACE, and GTRANSPARA MOs:
    • [NodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, and SINGLEIPSW is set to ENABLE and CM is set to PANEL_INTERCONNECT, the IPADDR4 MO corresponding to UIIP in the SINGLEIPSWITCH MO must exist and PT in the INTERFACE MO referenced by the IPADDR4 MO must be set to ETH.
    • [NodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW,
    • and SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, the IPADDR4 MO corresponding to UOIP in the SINGLEIPSWITCH MO must exist and PT in the INTERFACE MO referenced by the IPADDR4 MO must be set to ETH or ETHTRK.
  • Relation with the IPADDR4 MO:
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GPEERIP in the SINGLEIPSWITCH MO must be different from IP in any IPADDR4 MO.
    • [NodeB]If SINGLEIPSW in a SINGLEIPSWITCH MO is set to ENABLE, GIIP in the SINGLEIPSWITCH MO must be different from IP in any IPADDR4 MO.
