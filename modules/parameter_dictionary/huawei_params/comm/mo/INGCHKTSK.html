INGCHKTSK

+-NE
  +-NODE
    +-SYSTEMOM
      +-INGCHKTSK

Description

This MO defines the configuration for integrity check tasks, including the file integrity check switch, check time, and item. When the integrity check function is enabled, the system periodically checks whether the file specified by check items has been modified.

Effective Scenario

Not involved
