ETHDM

TRANSPORT
  +-ETHDM

Description

The ETHDM MO describes a task for detecting the delay and jitter between a specified local MEP and the RMEP in the same MA.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the CFMMEP and CFMLOCALMEP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the CFMMEP MO referenced by the ETHDM MO must have been configured.
    • If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the CFMLOCALMEP MO referenced by the ETHDM MO must have been configured.
  • Relation with the CFMRMEP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the DSTTYPE parameter is set to RMEP, the CFMRMEP MO reference by the ETHDM MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the DSTTYPE parameter is set to MAC, the CFMRMEP MO reference by the ETHDM MO must have been configured.
  • Relation with the ETHDM MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the ETHDM MO is activated, a CFMMEP MO cannot initiate measurement sessions with multiple peer ends at the same time.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ACT ETHDM

Use this command to activate the measurement of bidirectional delay and jitter on the Ethernet.
DEA ETHDM

Use this command to deactivate the measurement of bidirectional delay and jitter on the Ethernet.
DSP ETHDM

Use this command to query the bidirectional delay and jitter on the Ethernet.
LST ETHDM

Use this command to query the configuration of all measurement sessions for the Ethernet delay.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Session ID

Indicates the number of a performance detection session.
MD Name

Indicates the name of the MD to which the MEP belongs.
MA Name

Indicates the name of the MA to which the MEP belongs.
MEP ID

Indicates the MEP ID.
Destination Type

Indicates the ITU-T Y.1731 measurement destination type. The parameter value RMEP is the local MEP ID of the peer end. The parameter value MAC is the MAC address configured for the RMEP.
RMEP ID

Indicates the RMEP ID.
MAC Address

Indicates the configured destination MAC address in the format of XXXX-XXXX-XXXX.
TX Interval

Indicates the interval at which ITU-T Y.1731 performance detection packets (LMM/DMM) are transmitted.
Table 3 Dynamic parameters

Parameter

Description
Measurement State

Indicates the state of ITU-T Y.1731 performance measurement.
Tx DMM Frames

Indicates the number of transmitted delay measurement message (DMM) frames.
Rx DMR Frames

Indicates the number of received delay measurement reply (DMR) frames.
Jitter Std Deviation

Indicates the jitter standard deviation. This parameter measures the standard deviation of jitters sampled in the latest measurement period of 5s compared with the average jitter.
RTT Sum

Indicates the total round trip time (RTT) delay within the latest 5s sampling period.
RTT Average Delay

Indicates the average round trip time (RTT) delay within the latest 5s sampling period.
