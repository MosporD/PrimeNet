APPLICATION

+-NE
  +-NODE
    +-APPLICATION

Description

An application provides the operating environment for the functions of a base station. If an MBTS needs to provide functions of a certain standard, operators need to add an application for the standard. For example, if LTE is added to an MBTS after evolution, operators need to add an application for the eNodeB.

Immediately

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD APP

Use this command to add an application based on the specified application type and application ID. An application provides the operating environment for the functions of an NE of a certain RAT. If an MBTS needs to provide functions of a certain RAT, operators need to add an application for the RAT. For example, if LTE is added to an MBTS after evolution, operators need to add an application for the eNodeB. When adding an application, operators can set the maintenance mode of the application. If the maintenance mode of an application has been set, the information about the maintenance mode will be contained in alarms to be reported. When the maintenance mode of a co-MPT NE is NORMAL and one of its applications is also in the maintenance mode, the performance measurements of this application will be implausible.
DSP APP

Use this command to query information about applications running on the NE.
LST APP

Use this command to list the maintenance mode of the application.
MOD APP

Use this command to set the maintenance mode of the application. If the maintenance mode of an application has been set, an alarm to be reported will contain the information about the maintenance mode. When the maintenance mode of a co-MPT NE is NORMAL and one of its applications is also in the maintenance mode, the performance measurements of this application will be implausible.
RMV APP

Use this command to remove an application. An application provides the operating environment for the functions of an NE of a certain RAT. If an MBTS needs to stop providing the functions of a certain RAT, operators can delete the application for the RAT. The application does not exist after it is deleted. For example, if GSM is removed from an MBTS after evolution, operators need to remove the application for the GBTS.
RST APP

Use this command to restart an application based on a specified application ID. An application provides the operating environment for the functions of an NE of a certain RAT. When an application cannot work properly, the NE can reset the application to restore the functions provided by the application.
