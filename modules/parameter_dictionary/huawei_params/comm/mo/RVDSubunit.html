RVDSUBUNIT

EQUIPMENT
  +-RVD
    +-RVDSUBUNIT
      +-RVDDEVICEDATA[1~1]

Description

The RVD Subunit MO is the managed object of an RVD subunit, which receives and transmits RF signals.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RVD

  • Possible children:

    RVDDEVICEDATA[1~1]
  • Relation with the RVDSUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]One of the following ANTENNAPORT MOs must have been configured: 1. An ANTENNAPORT MO corresponding to CONNCN1, CONNSRN1, CONNSN1, and CONNPN1 in the RVDSUBUNIT MO. 2. An ANTENNAPORT MO corresponding to CONNCN2, CONNSRN2, CONNSN2, and CONNPN2 in the RVDSUBUNIT MO.
  • Relation with the RVD MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of RVDSUBUNIT MOs configured on one RVD MO must be greater than or equal to 1 and smaller than or equal to 8.
  • Relation with the RVDDEVICEDATA MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of RVDDEVICEDATA MOs configured on one RVDSUBUNIT MO must be 1.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP RVDSUBUNIT

Use this command to query the dynamic information about a remote vendor-defined antenna line device (RVD) subunit.
LST RVDSUBUNIT

Use this command to list the configuration of a remote vendor-defined antenna line device (RVD) subunit.
MOD RVDINFO

Use this command to modify the configuration of vertical beamwidth or Software-defined Antenna Mode for the remote vendor-defined antenna line device (RVD).
MOD RVDSUBUNIT

Use this command to modify a remote vendor-defined antenna line device (RVD) subunit.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Device No.

Indicates the device number of the RVD.
Subunit No.

Indicates the number of the RVD subunit, which starts from 1.
Connect Port 1 Cabinet No.

Indicates the cabinet number of the RRU or RFU that is connected to antenna port 1.
Connect Port 1 Subrack No.

Indicates the subrack number of the RRU or RFU that is connected to antenna port 1.
Connect Port 1 Slot No.

Indicates the slot number of the RRU or RFU that is connected to antenna port 1.
Connect Port 1 Port No.

Indicates the port number of the RRU or RFU that is connected to antenna port 1.
Connect Port 2 Cabinet No.

Indicates the cabinet number of the RRU or RFU that is connected to antenna port 2. This parameter is valid when a dual-polarized antenna is used.
Connect Port 2 Subrack No.

Indicates the subrack number of the RRU or RFU that is connected to antenna port 2. This parameter is valid when a dual-polarized antenna is used.
Connect Port 2 Slot No.

Indicates the slot number of the RRU or RFU that is connected to antenna port 2. This parameter is valid when a dual-polarized antenna is used.
Connect Port 2 Port No.

Indicates the port number of RRU or RFU that is connected to antenna port 2. This parameter is valid when a dual-polarized antenna is used.
Vertical BeamWidth

Indicates the vertical beamwidth of RVD subunit.
Software-defined Antenna Mode

Indicates the working mode of the programmable antenna.
Subunit Name

Indicates the name of the RVD subunit. The name of the RVD subunit is optional, but the name configured for each RVD subunit must be unique.
