BFDKEY

TRANSPORT
  +-BFDKEYCHAIN
    +-BFDKEY

Description

The BFDKEY MO is used to configure multiple keys in a key chain.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    BFDKEYCHAIN
  • Relation with the BFDKEYCHAIN MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A maximum of 3 BFDKEY MOs can be configured in one BFDKEYCHAIN MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The BFDKEYCHAIN MO instance used by a BFDKEY MO must have been configured.
  • Relation with the BFD MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When BFDAUTHSW in the BFD MO is set to ON, the BFDKEY MO instance used by a BFD MO must have been configured.
  • Relation with the BFDSESSION MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When BFDAUTHSW in the BFDSESSION MO is set to ON, the BFDKEY MO instance used by a BFDSESSION MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD BFDKEY

Use this command to add a key to the BFD key chain.
LST BFDKEY

Use this command to query keys in the BFD key chain.
MOD BFDKEY

Use this command to modify a key in the BFD key chain.
RMV BFDKEY

Use this command to remove a key from the BFD key chain.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
BFD Authentication Key Chain ID

Indicates the ID of a configured BFD key chain.
KEY Identity

Indicates the index of a key in a BFD key chain, which must be consistent with the index of the key at the peer end.
KEY String

Indicates the key settings in a BFD key chain, which must be consistent with the key settings at the peer end.
