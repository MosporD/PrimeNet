SAALLNK

TRANSPORT
  +-SAALLNK

Description

This MO indicates a Signaling ATM Adaptation Layer (SAAL) link used to carry signaling layer protocols in an ATM network, guaranting reliable signaling transmission.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS]When TYPE in the MDU MO is set to MDUC, the SAALLNK MO cannot be configured.
  • Relation with the TREELNKPVC MO:
    • [Co-MPT, NodeB]A TREELNKPVC MO and an SAALLNK MO cannot use the same path with the same combination of VPI and VCI on one link.
  • Relation with the SAALLNK MO:
    • [Co-MPT, NodeB]A maximum of 16 SAALLNK MOs can be configured on a board.
    • [Co-MPT, NodeB]SAALLNK MOs cannot use the same path with the same combination of VPI and VCI on one link.
  • Relation with the AAL2PATH MO:
    • [Co-MPT, NodeB]An SAALLNK MO and an AAL2PATH MO cannot use the same path with the same combination of VPI and VCI on one link.
  • Relation with the OMCH MO:
    • [Co-MPT, NodeB]An SAALLNK MO and an OMCH MO cannot use the same path with the same combination of VPI and VCI on one link.
  • Relation with the AAL2NODE MO:
    • [Co-MPT, NodeB]Before adding an AAL2NODE MO, ensure that SAALNO in an SAALLNK MO is the same as LN in the AAL2NODE MO under the same BS.
  • Relation with the UNILNK MO:
    • [Co-MPT, NodeB]The UNILNK MO associated with an SAALLNK MO that is not added to any RSCGRP MO must have been configured.
  • Relation with the IMAGRP MO:
    • [Co-MPT, NodeB]The IMAGRP MO associated with an SAALLNK MO that is not added to any RSCGRP MO must have been configured.
  • Relation with the FRAATM MO:
    • [Co-MPT, NodeB]The FRAATM MO associated with an SAALLNK MO that is not added to any RSCGRP MO must have been configured.
  • Relation with the RSCGRP MO:
    • [Co-MPT, NodeB]The RSCGRP MO that is associated with an SAALLNK MO must have been configured.
    • [Co-MPT, NodeB]In an RSCGRP MO, the total transmit bandwidth for the SAALLNK and OMCH MOs cannot exceed the transmit bandwidth for the RSCGRP MO.
  • Relation with the IMAGRP, IMALNK, and E1T1 MOs:
    • [Co-MPT, NodeB]In an IMAGRP MO, the total transmit bandwidth for the SAALLNK MO with JNRSCGRP set to DISABLE and for the OMCH MO cannot exceed the transmit bandwidth for the IMAGRP MO.
  • Relation with the E1T1 MO:
    • [Co-MPT, NodeB]In a UNILNK MO, the total transmit bandwidth for the SAALLNK MO with JNRSCGRP set to DISABLE and for the OMCH MO cannot exceed the transmit bandwidth for the UNILNK MO.
    • [Co-MPT, NodeB]In an FRAATM MO, the total transmit bandwidth for the SAALLNK MO with JNRSCGRP set to DISABLE and for the OMCH MO cannot exceed the transmit bandwidth for the FRAATM MO.
  • Relation with the AAL2ADJNODE MO:
    • [Co-MPT, NodeB]Before adding an AAL2ADJNODE MO, ensure that SAALNO in an SAALLNK MO is the same as LN in the AAL2ADJNODE MO under the same BS.
  • Relation with the CPBEARER MO:
    • [Co-MPT, NodeB]If BEARTYPE in a CPBEARER MO is set to SAAL, an SAALLNK MO whose SAALNO is the same as LINKNO in the CPBEARER MO must have been configured.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of SAALLNK MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Table 2 Configuration parameters

Parameter

Description

Indicates the number of the SAAL link.
Cabinet No.

Indicates the cabinet number of the SAAL link.
Subrack No.

Indicates the subrack number of the SAAL link.
Slot No.

Indicates the slot number of the SAAL link.
Bearer Port Type

Indicates the port type of the SAAL link.
Bearer Port No.

Indicates the number of the port that carries the SAAL link.
Join Transmission Resource Group

Indicates whether the SAAL link joins a transmission resource group.
Transmission Resource Group ID

Indicates the number of the transmission resource group to which the SAAL link is added.
VPI

Indicates the Virtual Path Identifier (VPI), which is used for VP routing. A virtual path contains multiple virtual channels.
VCI

Indicates the Virtual Channel Identifier (VCI), which is used for VC routing.
Bearer Service Type

Indicates the type of the service carried by the SAAL link. In flow control, services are classified into five categories: the Constant Bit Rate (CBR) service, Real-Time Variable Bit Rate (RTVBR) service, Non-Real-Time Variable Bit Rate (NRTVBR) service, Unspecified Bit Rate Plus (UBR+) service, and Unspecified Bit Rate (UBR) service.

If this parameter is set to CBR, the bandwidth is calculated based on the PCR.

If this parameter is set to VBR, the bandwidth is calculated based on the SCR.

If this parameter is set to UBR, the bandwidth is calculated based on the PCR.

If this parameter is set to UBR+, the bandwidth is calculated based on the MCR.
Peak Cell Rate

Indicates the Peak Cell Rate (PCR) of the SAAL link. The PCR is an ATM service-related parameter defined by the ATM forum for ATM communication management. In CBR transmission, the PCR value determines the frequency at which sampled data is transmitted. In ABR transmission, the PCR value determines the maximum value of Allowed Cell Rate (ACR).
Min Cell Rate

Indicates the Minimum Cell Rate (MCR) of the SAAL link. The MCR is the minimum cell transmission rate acceptable by the user.
Sustain Cell Rate

Indicates the Sustainable Cell Rate (SCR) of the SAAL link. The SCR value determines the average rate at which cells are transmitted over a Variable Bit Rate (VBR) connection.
Timer_CC

Indicates the length of the SSCOP timer Timer_Cc. This timer specifies the time interval between transmissions of an SAAL PDU during link establishment or connection release. An SAAL PDU is retransmitted if no ACK to the PDU is received.
Timer_Poll

Indicates the length of the SSCOP timer Timer_Poll. If this timer expires, the SAAL protocol stack must send a POLL PDU to the peer end. The POLL PDU is used to query the status information about the peer end through an SSCOP connection.
Timer_Idle

Indicates the duration of the SSCOP timer Timer_Idle based on the SAAL protocol. This timer is used to guarantee the duration during which the SAAL protocol is in IDLE mode.
Timer_No_Response

Indicates the length of the SSCOP timer Timer_No_Response. This timer specifies the maximum time interval for receiving STAT PDUs.
Timer_Keep_Alive

Indicates the length of the SSCOP timer Timer_Keep_Alive. This timer is used to guarantee the inactivity duration for the SAAL link.
Max Connection Control Count

Indicates the maximum number of SAAL PDUs that are sent during SAAL link establishment or release.
Max Poll Data Count

Indicates the maximum number of data transmissions during a polling period of the SAAL protocol.
Max STAT Count

Indicates the maximum number of elements in an STAT PDU. This parameter must be set to an odd number within the range of 3 to 65535. STAT PDUs are used to respond to POLL PDUs.
Subboard Type

Indicates the type of subboard where an SAAL link is established.
Rate Unit

Indicates the unit of the Peak Cell Rate (PCR), Minimum Cell Rate (MCR), and Sustainable Cell Rate (SCR). Rate units are converted according to the following principle: 1 cell/s is equal to 0.424 kbit/s. If the rate is converted from cell/s to kbit/s, the result value must be rounded down to the nearest integer. For example, 73 cell/s is converted into 30 kbit/s.
Table 3 Dynamic parameters

Parameter

Description
SAAl Link State

Indicates the status of the SAAL link. The status is either normal or abnormal. If the status is normal, this link can receive and transmit upper-layer user data properly. If the status is abnormal, this link cannot receive or transmit upper-layer user data.
