SSLCS

TRANSPORT
  +-SSLCS

Description

The SSLCS MO defines the security level of SSL cipher suite.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP SSLCS

Use this command to query the names and security levels of all SSL cipher suites that have taken effect.
LST SSLCS

Use this command to query the names and security levels of all SSL cipher suites the NE supports.
SET SSLCS

Use this command to set the security level of an SSL cipher suite.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cipher Suite Name

Indicates the name of the SSL cipher suite.
Cipher Suite Level

Indicates the security level of an SSL cipher suite. Raising the level of cipher suites may increase system security risks. Set this parameter to a proper value.
