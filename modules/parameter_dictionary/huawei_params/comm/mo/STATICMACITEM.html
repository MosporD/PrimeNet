STATICMACITEM

TRANSPORT
  +-LANSW
    +-STATICMACITEM

Description

The STATICMACITEM MO stores the mapping relationships between manually configured MAC addresses and switch ports.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    LANSW
  • Relation with the MDU MO:
    • [Co-MPT, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, the STATICMACITEM MO cannot be configured.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eNodeB]The number of STATICMACITEM MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD STATICMACITEM

Use this command to add an entry to a static MAC forwarding table.
CLR DYNAMICMAC

Use this command to clear one specific dynamic MAC entry, effective entries in the dynamic MAC forwarding table on a specified switch port, or effective entries in the dynamic MAC forwarding tables on all switch ports.
DSP MACTABLE

Use this command to query the entries in the MAC forwarding table that takes effect on one or all switch ports.
LST STATICMACITEM

Use this command to list all configured entries in static MAC forwarding tables.
RMV STATICMACITEM

Use this command to remove an entry from a static MAC forwarding table.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
MAC Entry Index

Indicates the index of an entry in a MAC forwarding table.
Switch Port Index

Indicates the index of the switch port corresponding to an entry in a MAC forwarding table.
Destination MAC Address

Indicates the destination MAC address of an entry in a MAC forwarding table. The format must be "XXXX-XXXX-XXXX".
Table 3 Dynamic parameters

Parameter

Description
MAC Type

Indicates the type of effective MAC addresses. The value of this parameter can be STATIC, DYNAMIC, or AUTO.
MAC Aging Time

Indicates the remaining aging time of an entry in a MAC forwarding table.
