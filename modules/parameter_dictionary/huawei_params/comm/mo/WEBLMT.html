WEBLMT

TRANSPORT
  +-WEBLMT

Description

The WEBLMT MO defines the policy for logging in to the Web LMT.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    TRANSPORT

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST WEBLOGINPOLICY

Use this command to query the policy for logging in to the Web LMT.
RST WEBLMT

Use this command to reset the Web LMT.
SET WEBLOGINPOLICY

Use this command to set the policy for logging in to the LMT.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
WebLMT Login Policy

Indicates the policy for logging in to the Web LMT.

The value COMPATIBLE indicates that if http is entered in the address bar of a browser, the HTTP is used for and after the login. If https is entered in the address bar of a browser, the HTTPS is used for and after the login.

The value HTTPS_ONLY indicates that no matter whether http or https is entered in the address bar of a browser, the HTTPS is used for and after the login.

The value LOGIN_HTTPS_ONLY indicates that no matter whether http or https is entered in the address bar of a browser, the HTTPS is used for login and the HTTP is used after the login.
TLS/SSL Version

Indicates the TLS/SSL version supported by the Web LMT. You are not advised to use SSL3.0, TLS1.0 and TLS1.1 because they have security risks.
Session Idle Timeout

Indicates the timeout duration of session idleness. When the idleness duration of a Web LMT session exceeds the value of this parameter, the Web LMT server automatically clears the session. If this parameter is set to 0, the timeout of session idleness is not allowed, which reduces the session security. You are not advised to set this parameter to 0.
Session Maximum Lifetime

Indicates the maximum lifetime of a session. When the lifetime of a Web LMT session exceeds the value of this parameter, the Web LMT server automatically clears the session in a forcible manner.If this parameter is set to 0, the session lifetime is infinitely long, which reduces the session security. You are not advised to set this parameter to 0.
Session Idle Force Timeout Switch

Indicates how the idle session detection mechanism on the Web LMT is implemented. If this switch is turned on, a session without any user operations enters the idle state. If this switch is turned off, a session enters the idle state only when no user is performing operations on the session and no tracing, monitoring, or batch processing task is running.
