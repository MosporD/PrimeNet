EP2RSCGRP

TRANSPORT
  +-EP2RSCGRP

Description

The EP2RSCGRP MO is used to configure the mapping between end points and transmission resource groups. Based on the mapping, data flows are assigned to corresponding transmission resource groups.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the RSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The RSCGRP MO on which an EP2RSCGRP MO depends must have been configured.
  • Relation with the USERPLANEPEER and RSCGRP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the EP2RSCGRP MO cannot be used to map the USERPLANEPEER MO of the IPv6 type and the AUTOCFGFLAG which is MANUAL_CREATED to the RSCGRP MO with PT set to PPP, MPGRP or TUNNEL.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the EP2RSCGRP MO cannot be used to map the USERPLANEPEER MO of the IPv6 type and the AUTOCFGFLAG which is MANUAL_CREATED to the RSCGRP MO with PT set to ETHTRK.
  • Relation with the EP2RSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The EPGROUP MO or USERPLANEPEER MO referenced by an EP2RSCGRP MO cannot be configured on different resource groups of the same physical port.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of EP2RSCGRP MOs must be less than or equal to 64 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mapping Type

Indicates the mapping mode between the service and the transmission resource group. Two mapping modes are supported: endpoint group mode and endpoint mode. If this parameter is set to ENDPOINT_GROUP, all user-plane peer endpoints in the endpoint group can be added to the specified transmission resource group. If this parameter is set to ENDPOINT_NODE, the specified user-plane peer endpoints can be added to the specified transmission resource group. When both the endpoint group mode and the endpoint mode are available for mapping all service flows of the same EPPATH to the transmission resource group, the endpoint mode is preferentially used for the mapping.
End Point ID

Indicates the ID of the end point group or user plane peer to be added to the specified transmission resource group.
Cabinet No.

Indicates the number of the cabinet where the transmission resource group to which a node maps is configured.
Subrack No.

Indicates the number of the subrack where the transmission resource group to which a node maps is configured.
Slot No.

Indicates the number of the slot where the transmission resource group to which a node maps is configured.
Subboard Type

Indicates the subboard type of the board where the transmission resource group to which a node maps is configured.
Bearing Port Type

Indicates the type of the port where the transmission resource group to which a node maps is configured.
Bearing Port No.

Indicates the number of the port where the transmission resource group to which a node maps is configured.
Transmission Resource Group Bear Type

Indicates the bearing type of the transmission resource group to which a node maps.
Transmission Resource Group ID

Indicates the ID of the transmission resource group to which a node maps.
User Label

Indicates the description of the end point mapping to resource group. This parameter takes effect only in LTE and NR.
