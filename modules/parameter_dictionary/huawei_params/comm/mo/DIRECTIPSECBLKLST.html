DIRECTIPSECBLKLST

TRANSPORT
  +-DIRECTIPSECBLKLST

Description

The DIRECTIPSECBLKLST MO is used to shield direct IPSec tunnels automatically set up over the X2/Xn interface. When automatically set up direct IPSec tunnels cannot function normally, the eNodeBs can shield the IPSec tunnels by adding the IP address of the security peer to the blacklist to mask alarms and prevent direct IPSec tunnels from frequent automatic setup.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the SECURITYPEER MO:
    • [Co-MPT, eNodeB, gNodeB]PEERIKEIPV4 in the SECURITYPEER MO must be different from SECURITYPEERIP in the DIRECTIPSECBLKLST MO.
  • Relation with the MDU MO:
    • [Co-MPT, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, a maximum of 256 DIRECTIPSECBLKLST MOs can be configured.
  • Relation with the DIRECTIPSECWHITELIST MO:
    • [Co-MPT, eNodeB, gNodeB]A DIRECTIPSECBLKLST MO and a DIRECTIPSECWHITELIST MO cannot both be configured.
  • Relation with the DIRECTIPSECBLACKLIST MO:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a DIRECTIPSECBLACKLIST MO is set to IPv4, SECURITYPEERIPV4 in the DIRECTIPSECBLACKLIST MO must be different from SECURITYPEERIP in the DIRECTIPSECBLKLST MO.
  • Relation with the DIRECTIPSECBLKLST MO:
    • [Co-MPT, gNodeB]The number of blacklists configured in the DIRECTIPSECBLKLST and DIRECTIPSECBLACKLIST MOs on a base station cannot exceed 384.
    • [eNodeB]The number of blacklists configured in the DIRECTIPSECBLKLST and DIRECTIPSECBLACKLIST MOs on a base station cannot exceed 128.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT]The number of DIRECTIPSECBLKLST MOs must be 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD DIRECTIPSECBLKLST

Use this command to add an IP address to the blacklist for direct IPSec tunnels.
LST DIRECTIPSECBLKLST

Use this command to list the configurations of the blacklist for direct IPSec tunnels.
MOD DIRECTIPSECBLKLST

Use this command to modify the configurations of the blacklist for direct IPSec tunnels.
RMV DIRECTIPSECBLKLST

Use this command to remove an IP address from the blacklist for direct IPSec tunnels.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Security Peer IP Address

Indicates the IP address of a security peer in the IPSec blacklist. When an IP address of a security peer is added to the blacklist, no more IPSec tunnels to the security peer are automatically set up.
User Label

Indicates the description of a security peer.
