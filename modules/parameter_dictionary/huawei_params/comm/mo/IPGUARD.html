IPGUARD

TRANSPORT
  +-IPGUARD

Description

The IPGUARD MO consists of the parameters related to attack defense policies used at the MAC and IP layers, attack alarm switches, and attack alarm thresholds.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    TRANSPORT

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function

Use this command to query the blacklist in an ARP table.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
ARP Spoofing Check Switch

Indicates whether to perform an ARP spoofing check. If this parameter is set to ENABLE, an alarm is reported when an ARP spoofing attack occurs. If this parameter is set to DISABLE, no alarm is reported when an ARP spoofing attack occurs.
ARP Spoofing Alarm Threshold

Indicates the ARP spoofing alarm threshold. When the ARP spoofing check switch is turned on, an ARP spoofing alarm is reported if the number of ARP update attempts reaches this threshold within one minute. Note that the number of ARP update attempts from trusted MAC addresses is not counted. This alarm is cleared if no request for updating the MAC address mapping to the IP address indicated by the alarm is received within one or two minutes.
ARP Learning Strict Switch

Indicates whether to enable ARP strict learning. ARP learning strict is a function that enables a BS to learn the acknowledgement packets in response to only ARP request packets sent by itself. With ARP strict learning, the BS can reject most ARP request and acknowledge packet attacks.
Invalid Packet Check Switch

Indicates whether to report an alarm when the number of invalid packets received by a BS exceeds a specified threshold. If this parameter is set to ENABLE, an alarm is reported when the number of invalid packets received by a BS exceeds the specified threshold. If this parameter is set to DISABLE, no alarm is reported when the number of invalid packets received by a BS exceeds the specified threshold. Invalid packets are those filtered according to the packet filter criteria.
Invalid Packet Alarm Threshold

Indicates the threshold for the excessive flood packet alarm. When Invalid Packet Check Switch is set to ENABLE, the system measures the RX rate of invalid packets every 10 seconds. If the measured value exceeds this threshold, an excessive invalid packet alarm is reported. The alarm is cleared if the RX rate of invalid packets keeps below the threshold for 5 consecutive minutes.
IPSec Replay Alarm Switch

Indicates whether to report an IPSec packet replay alarm.
IPSec Replay Alarm Threshold

Indicates the IPSec anti-replay alarm threshold.
IKEv2 Redirect DOS Check Switch

Indicates the switch for checking IKEv2 redirection DOS attacks. When this parameter is set to ENABLE, ALM-25950 Base Station Being Attacked is reported when the number of IKEv2 redirections received by the base station exceeds the IKEv2 redirection DOS attack threshold in 300 consecutive seconds, with Specific Problem set to DOS Attack. After the number of IKEv2 redirections received by the base station exceeds the IKEv2 redirection DOS attack threshold, the base station does not respond to IKEv2 redirection packets. When this parameter is set to DISABLE, DOS attacks are not processed.
Max Redirects Number

Indicates the IKEv2 redirection DOS attack threshold. ALM-25950 Base Station Being Attacked is reported when the number of IKEv2 redirections received by the base station exceeds the IKEv2 redirection DOS attack threshold in 300 consecutive seconds, with Specific Problem set to DOS Attack. After the number of IKEv2 redirections received by the base station exceeds the IKEv2 redirection DOS attack threshold, the base station does not respond to IKEv2 redirection packets. This alarm is cleared when the number of IKEv2 redirections received by the base station is less than or equal to the IKEv2 redirection DOS attack threshold in 300 consecutive seconds.
ND Spoofing Check Switch

Indicates whether to detect ND spoofing. If this parameter is set to ENABLE, an alarm is reported when ND spoofing occurs. If this parameter is set to DISABLE, no alarm is reported when ND spoofing occurs.
ND Spoofing Alarm Threshold

Indicates the threshold for reporting an ND spoofing alarm. When the number of ND spoofing times reaches the threshold, an alarm is reported. After ND spoofing detection is enabled, an ND spoofing alarm is reported if the number of ND update attempts exceeds the threshold within one minute. If any trusted MAC address exists, the update requests initiated by the trusted MAC address is not counted. This alarm is cleared when the IP address for which the alarm is generated does not receive any MAC address request within 1 minute to 2 minutes.
