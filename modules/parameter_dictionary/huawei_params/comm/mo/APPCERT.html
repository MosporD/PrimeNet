APPCERT

TRANSPORT
  +-APPCERT

Description

An APPCERT MO defines an activated device certificate in use. This device certificate identifies a BS during secure negotiation.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the APPCERT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]APPCERT in an APPCERT MO must be the same as APPCERT in the associated CERTMK MO.
  • Relation with the IKEPEER MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]IKEPEER MO instances cannot reference more than 6 certificates.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP APPCERT

Use this command to query the status of activated device certificates.
LST APPCERT

Use this command to list the configurations of activated device certificates.
LST CERTTYPE

Use this command to list all NE-supported application types of device certificates.
MOD APPCERT

Use this command to modify the device certificate used by a base station to negotiate with the peer end about security channels. When Application Type is set to SSL, this command can be used to specify whether an RRU needs to apply for an operator-issued device certificate.
TST APPCERT

Use this command to test a device certificate. When a test on a device certificate starts, the BS attempts to use this device certificate to set up a secure channel to a peer device through negotiation and then returns the negotiation result.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Application Type

Indicates the application type of activated device certificate. The application type of a device certificate can be IKE, SSL, or DTLS. When APPTYPE is set to IKE and CERTSOURCE in the IKEPEER object is set to Appcert, the device certificate being used during IKE negotiation is the certificate configured in the APPCERT object. When APPTYPE is set to SSL, the device certificate being used is the certificate used during SSL connection, 802.1x-based, or inter-BBU interconnection authentication. When APPTYPE is set to DTLS, the device certificate being used is the certificate used during DTLS connection authentication.
Certificate File Name

Indicates the file name of an activated device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).
RRU Certificate Request Switch

Indicates whether an RRU needs to apply for an operator-issued device certificate. When an operator-issued device certificate is used for SSL application type and this switch is turned on, the RRU with the eCPRI port applies for a certificate to the CA.
Table 3 Dynamic parameters

Parameter

Description
