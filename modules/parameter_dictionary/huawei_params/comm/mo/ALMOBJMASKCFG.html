ALMOBJMASKCFG

+-NE
  +-NODE
    +-SYSTEMOM
      +-ALMOBJMASKCFG

Description

This MO is used to add or delete alarm shielding conditions.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    SYSTEMOM

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD OBJALMSHLD

Use this command to add an alarm suppression condition by object.
RMV OBJALMSHLD

Use this command to remove an alarm shielding condition by object that has been configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Object Type

Indicates the type of an object according to which alarms are shielded.
Cabinet No.

Indicates the number of the cabinet shielded by physical location.
Subrack No.

Indicates the number of the subrack shielded by physical location.
Slot No.

Indicates the number of the slot shielded by physical location.

[NodeB]Bound of Slot No. is [0~8;16;18] in UMTS.
Port No.

Indicates the port number of the object.
Alarm ID Select Type

Indicates the selection mode of alarm IDs.
Object Alarm ID

Indicates the alarm ID. An alarm ID identifies a type of alarms, which indicates a specific fault or event. The alarm ID is the only index for alarms.
