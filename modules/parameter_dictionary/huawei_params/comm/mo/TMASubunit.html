TMASUBUNIT

EQUIPMENT
  +-TMA
    +-TMASUBUNIT
      +-TMADEVICEDATA[1~1]

Description

The TMASubunit MO is the managed object of a TMA subunit, which amplifies one-channel UL RF signals.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TMA

  • Possible children:

    TMADEVICEDATA[1~1]
  • Relation with the TMASUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The ANTENNAPORT MO corresponding to CONNCN, CONNSRN, CONNSN, and CONNPN in the TMASUBUNIT MO must have been configured.
  • Relation with the TMA MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of TMASUBUNIT MOs configured on one TMA MO must be greater than or equal to 1 and smaller than or equal to 8.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The ratio of TMA MOs to TMASUBUNIT MOs is 1:2. If the number of TMASUBUNIT MOs configured for one TMA MO is greater than 2, the system supports a less number of TMA MOs.
  • Relation with the TMADEVICEDATA MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of TMADEVICEDATA MOs configured on one TMASUBUNIT MO must be 1.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP TMASUBUNIT

Use this command to query the dynamic information about one or all tower mounted amplifier (TMA) subunit.
LST TMASUBUNIT

Use this command to list the configuration of one or all tower mounted amplifier (TMA) subunit.
MOD TMASUBUNIT

Use this command to modify a tower mounted amplifier (TMA) subunit.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Device No.

Indicates the device number of the TMA.
Subunit No.

Indicates the number of the TMA subunit, which starts from 1.
Connect Port No.

Indicates the number of the antenna port to which the TMA subunit is connected.
Connect Port Cabinet No.

Indicates the cabinet number of the RRU or RFU that provides the antenna port to which the TMA subunit is connected.
Connect Port Slot No.

Indicates the slot number of the RRU or RFU that provides the antenna port to which the TMA subunit is connected.
Connect Port Subrack No.

Indicates the subrack number of the RRU or RFU that provides the antenna port to which the TMA subunit is connected.
Gain

Indicates the gain of the TMA subunit. If this parameter is set to 255, it is invalid and the actual gain is not changed.
Work Mode

Indicates the working mode of the TMA subunit. The value NORMAL indicates that the TMA subunit works in normal mode and properly amplifies uplink signals. The value BYPASS indicates that the TMA subunit works in bypass mode and does not amplify uplink signals. The value DEVICE_DEFAULT_VALUE indicates that the TMA subunit works in default mode.
Table 3 Dynamic parameters

Parameter

Description
Actual Sector ID

Indicates the sector ID of the TMA subunit.
Actual Gain

Indicates the actual gain of the TMA subunit.
Actual Work Mode

Indicates the actual working mode of the TMA subunit.
Online Status

Indicates the online status of the TMA subunit.
