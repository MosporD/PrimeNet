IPADDR4

TRANSPORT
  +-INTERFACE
    +-IPADDR4

Description

An IPADDR4 MO defines the IPv4 address of an interface of which the port type can be PPP port, MP port, Ethernet port, Ethernet CI port,Ethernet trunk port, or loopback interface. If the port type of an interface configured with an IPv4 address is loopback interface, the IPv4 address is called a loopback IP address or a logical IP address. Unlike an Ethernet port and a PPP port, a loopback interface is a virtual interface. In most cases, a loopback IP address is used as the destination IP address of the active and standby routes or the inner IP address of an IPsec tunnel. IPv4 addresses which are configured on interfaces whose port type is physical port are collectively called interface IP addresses. An IPv4 address takes effect immediately after being configured.
