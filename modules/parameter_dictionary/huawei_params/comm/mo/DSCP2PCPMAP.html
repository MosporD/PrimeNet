DSCP2PCPMAP

TRANSPORT
  +-DSCP2PCPMAP

Description

A DSCP2PCPMAP MO defines the table of mappings between differentiated services code points (DSCPs) and virtual local area network (VLAN) priorities, which is used to encapsulate VLAN priorities.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the DSCP2PCPMAP MO cannot be configured.
  • Relation with the DSCP2PCPMAP MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]DSCP referenced by DSCP2PCPREFS in an DSCP2PCPMAP MO must be different from each other.
  • Relation with the INTERFACE MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]In the INTERFACE MO, if ITFTYPE is set to VLAN, the DSCP2PCPMAP MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD DSCP2PCPMAP

Use this command to add a table of mappings between DSCPs and VLAN priorities.
ADD DSCP2PCPREF

Use this command to add a mapping between a DSCP and a VLAN priority.
LST DSCP2PCPMAP

Use this command to list the configuration of mapping tables between DSCPs and VLAN priorities.
MOD DSCP2PCPMAP

Use this command to modify a table of mappings between DSCPs and VLAN priorities.
RMV DSCP2PCPMAP

Use this command to remove a table of mappings between DSCPs and VLAN priorities.
RMV DSCP2PCPREF

Use this command to remove a mapping between a DSCP and a VLAN priority.
