LOCALWAP

EQUIPMENT
  +-LOCALWAP

Description

This MO manages and maintains the local wireless access point (WAP) that complies with 802.11b/g/n and works at 2.4 GHz band. Users can use a terminal configured with a wireless NIC to access the local wireless access point and then maintain the base station over the wireless local maintenance IP address.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Switch

Indicates the switch for the LOCALWAP(Local Wireless Access Point). If the base station is equipped with a WLAN module before shipment, this parameter is set to on by default. If this parameter is set to off, both the remote maintenance function of the base station and the WLAN local maintenance function are unavailable once the OMCH between the base station and the MAE fails. When this happens, users can only adopt the local wired method to maintain the base station. When a BBU is installed at a high position (for example, on a pole), it is difficult to perform local maintenance using network cables. Therefore, you need to consider the impacts before setting this parameter to OFF.
SSID

Indicates the service set identifier (SSID) of the LOCALWAP(Local Wireless Access Point). The default SSID is in the format of HID_Last ten digits of the board ESN.This parameter can be set as required. If this parameter is set to HID_0000000000, the system restores the SSID to the default value. The default value is the combination of HID_ and the last ten characters of the ESN.
Show SSID

Indicates the switch for broadcasting the SSID of the LOCALWAP(Local Wireless Access Point). To prevent malicious attacks, you can set this parameter to OFF, which indicates that the SSID is hidden. The default value of this parameter is ON, which indicates that the SSID is displayed.
AP auto disable time

Indicates the length that the LOCALWAP(Local Wireless Access Point) is automatically disabled after the OMCH of a base station is recovered.
Region Code

Indicates the region code of the country where the base station is located. Channels available at the 2.4 GHz band vary with regions. The base station side supports five types of region codes. Value 0 indicates North America, where channels 1 through 11 are available. Value 1 indicates Europe, Japan, and China, where channels 1 through 13 are available. Value 2 indicates France, where channels 1 through 9 are available. Value 3 indicates Israel, where channels 5 through 13 are available. User-defined indicates all regions, where channels 1 through 14 are available. When the base station is located in a region other than the regions specified by values 0, 1, 2, and 3, set this parameter to User-defined.
Channel

Indicates the working channel of the LOCALWAP(Local Wireless Access Point) . Channels available at the 2.4 GHz band vary with regions. Different countries and regions may use different channel policies. For example, indoor and outdoor WLAN APs use different channels. When Region Code is set to 0, 1, 2, or 3, Channel can be set to Automatic. In this case, the WLAN module automatically selects the most appropriate channel, that is, the channel with the minimum interference. When Region Code is set to User-defined, Channel cannot be set to Automatic. This is because in this case the WLAN AP cannot select the most appropriate channel, and therefore Channel must be set to a specific value. The parameter value must meet the law, regulation, and industry standard requirements of the country or region where the base station is located. The typical data rate is 6 Mbit/s if there is neither obstacle nor obvious interference within a radius of five meters. If the actual data rate is lower than 6 Mbit/s, you can modify the value of this parameter to avoid intra-frequency interference. It is recommended that the selected channel be far away from the current channel or you can attempt other channels one by one. In addition, ensure that the distance between the terminal and the WLAN module is short and there are no obstacles between them. The weather and strong magnetic field also affect WLAN transmission rates.
