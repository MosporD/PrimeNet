UDPSESSION

TRANSPORT
  +-UDPSESSION

Description

A UDPSESSION MO is used to detect channel reachability.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the DEVIP, IFIP, PPPLNK, MPGRP, and GTRANSPARA MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If MODELSELECT of GTRANSPARA is set to TRADITION, LOCALIP in a UDPSESSION MO to be added must have been configured. That is, for the UDPSESSION MO, DEVIP MO, PPPLNK MO, and MPGRP MO configured on the same board (in the same slot and cabinet), LOCALIP in the UDPSESSION MO must be the same as any of the following: IP in the DEVIP MO in the same routing domain, LOCALIP in the PPPLNK MO, and LOCALIP in the MPGRP MO. If MODELSELECT of GTRANSPARA is set to HOSTGW, LOCALIP in a UDPSESSION MO to be added must have been configured. That is, for the UDPSESSION MO, IFIP MO, PPPLNK MO, and MPGRP MO configured on the same board (in the same slot and cabinet), LOCALIP in the UDPSESSION MO must be the same as any of the following: IP in the IFIP MO in the same routing domain, LOCALIP in the PPPLNK MO, and LOCALIP in the MPGRP MO.
  • Relation with the IPADDR4, PPPLNK, MPGRP, and GTRANSPARA MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]LOCALIP in a UDPSESSION MO to be added must have been configured, LOCALIP in the UDPSESSION MO must be the same as any of the following: IP in the IPADDR4 MO in the same routing domain, LOCALIP in the PPPLNK MO, and LOCALIP in the MPGRP MO.
  • Relation with the PPPLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]PEERIP in a UDPSESSION MO must be different from LOCALIP in a PPPLNK MO.
  • Relation with the MPGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]PEERIP in a UDPSESSION MO must be different from LOCALIP in a MPGRP MO.
  • Relation with the UDPSESSION MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]LOCALIP and PEERIP in a UDPSESSION MO must be different from LOCALIP and PEERIP in any other UDPSESSION MOs.
    • [Co-MPT, NodeB, eGBTS, eNodeB]The UDPSESSIONGRPID parameters can be set to the same value for at most two UDPSESSION MOs.
  • Relation with the OMCH MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]In the same routing domain, PEERIP in a UDPSESSION MO must be different from IP in an OMCH MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If CHECKTYPE in an OMCH MO is set to UDPSESSION, before configuring the UDPSN in this OMCH MO, ensure that the UDPSESSION MO for the OMCH MO have been configured. That is, the UDPSESSION MOs whose UDPSN is the same as UDPSN in the OMCH MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If the CHECKTYPE parameter is set to UDPSESSIONGRP, the UDPSESSIONGRPID parameter must be configured in the UDPSESSION MO.
  • Relation with the LOCALIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]PEERIP in a UDPSESSION MO must be different from IP in a LOCALIP MO in the same routing domain.
  • Relation with the DEVIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]PEERIP in a UDPSESSION MO must be different from IP in a DEVIP MO.
  • Relation with the IFIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]PEERIP in a UDPSESSION MO must be different from IP in an IFIP MO.
  • Relation with the IPADDR4 MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]PEERIP in a UDPSESSION MO must be different from IP in an IPADDR4 MO.
  • Relation with the WLOCALIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]IP in the WLOCALIP MO must be different from PEERIP in the UDPSESSION MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD UDPSESSION

Use this command to add a UDP session.
DSP UDPSESSION

Use this command to query the UDP session status.
LST UDPSESSION

Use this command to list the configuration of a UDP session.
MOD UDPSESSION

Use this command to modify the configuration of a UDP session.
RMV UDPSESSION

Use this command to remove the configuration of a UDP session.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
UDP Session ID

Indicates the UDP session number.
UDP Session Group ID

Indicates the UDP session group number.
Cabinet No.

Indicates the cabinet number of the board where UDP detection is performed.
Subrack No.

Indicates the subrack number of the board where UDP detection is performed.
Slot No.

Indicates the slot number of the board where UDP detection is performed.
Local IP Address

Indicates the local IP address. The local IP address must be the device IP address configured on the board such as the Ethernet port IP address, or logical IP address such as the IP address on the loopback port. The address of the local maintenance Ethernet port cannot be used.
Peer IP Address

Indicates the peer IP address. The IP address cannot be 0.0.0.0, broadcast IP address, multicast IP address, loopback IP address, or any existing IP address in the system.
DSCP

Indicates the differentiated services code point (DSCP) of a packet. The priority has a positive correlation with the value of this parameter.
Interval

Indicates the interval at which UDP session detection packets are sent.
Check Count

Indicates the number of times that UDP ping packets time out. If this number is greater than the number of times that detection packets time out, the UDP session detection is considered faulty.
Table 3 Dynamic parameters

Parameter

Description
Response Messages

Indicates the statistics of the UDPECHO response messages, including RTT information.
Check Status

Indicates the UDP session status. If the UDP session detection finds interruption, the status is abnormal.
