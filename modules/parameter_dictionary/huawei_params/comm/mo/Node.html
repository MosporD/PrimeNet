Description

This MO defines the root node for the device or transport model of an RAT.

Effective Scenario

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
EXP DEVFILE

Use this command to export a device file. You can export the device file containing one table or all tables.

Use this command to list node configuration.

Use this command to reset the configured in-position boards (excluding passive boards such as the UPEU and USCU) in a BS.

Use this command to set Working Mode, LTE Mode and Product Type of an NE.

Use this command to upload device files to an FTP server.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Product Type

Indicates the type of an NE.
User Label

Indicates the user-defined information of a node.
NeRM Version

Indicates the resource model version of the node.
Node Identifier

Indicates the unique identifier of a node within a base station.
Node Name

Indicates the node name.
Working Mode

Indicates the working mode of a base station. The value of this parameter can only be Non-ConCurrent when the product type of the NE is not DBS3900, BTS3900, BTS3900A, BTS3900L, BTS3900AL, DBS3900 LampSite, DBS5900, BTS5900, BTS5900A, BTS5900L, BTS5900AL, or DBS5900 LampSite.
Software Version

Indicates the software version of the node.
Hot Patch Version

Indicates the software hot patch version of the node.
Product Version

Indicates the product software version of the node.
Product InterfaceID

Indicates the ID of the product interface of the node.
LMT Version

Indicates the LMT version of the node.
Application Version

Indicates the application version of the node.
Application Hot Patch Version

Indicates the application hot patch version of the node.
LTE Mode

Indicates the LTE mode. This parameter can be set to LTE_TDD only in separate-MPT LTE FDD and LTE TDD dual-mode base stations. This parameter is valid when either of the following conditions is met: (1) Product Type is set to DBS3900, BTS3900, BTS3900A, BTS3900L, BTS3900AL, DBS3900_LampSite, DBS5900, BTS5900, BTS5900A, BTS5900L, BTS5900AL, or DBS5900_LampSite, Working Mode is set to NON-CONCURRENT, and Application Type is set to eNodeB. (2) Product Type is set to DBS3900_LTE, BTS3900_LTE, BTS3900A_LTE, BTS3900L_LTE, BTS3900AL_LTE, DBS3900_LampSite_LTE, DBS5900_LTE, BTS5900_LTE, BTS5900A_LTE, BTS5900L_LTE, BTS5900AL_LTE, or DBS5900_LampSite_LTE.
Working Mode Extension

Indicates the extended deployment type of an NE. COMM and COMM2 are used when two SingleRAN base stations form a separate-MPT base station. For example, if a GU co-MPT base station and an LNR co-MPT base station form a separate-MPT base station, set the NE deployment type to COMM and COMM2 respectively. For details about the mapping between extended deployment types and apps, see the note in the ADD APP command help.
