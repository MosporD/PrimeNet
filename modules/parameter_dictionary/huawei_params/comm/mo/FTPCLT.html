FTPCLT

+-NE
  +-NODE
    +-SYSTEMOM
      +-FTPCLT

Description

The FTPCLT MO contains the parameters related to the File Transfer Protocol (FTP) client, such as the encryption mode and the state firewall flag.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    SYSTEMOM
  • Relation with the TLSPOLICY MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If EncryMode is not set to Plaintext and the FTPCLT MO needs to reference an TLSPOLICY MO, the TLSPOLICY MO must exist.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Transport Encrypted Mode

Indicates the transmission encryption mode of the FTP client. If this parameter is set to Auto, the FTP client first attempts to transmit data in ciphertext. If the attempt fails, the FTP client automatically switches the encryption mode to retransmit data in plaintext. Therefore, setting this parameter to Auto may pose security risks. However, if there are faults in transmission equipment, the FTP client does not attempt to retransmit data in plaintext even if the FTP server supports encrypted transmission. In this case, the FTP connection setup fails.
Support State Firewall

Indicates whether FTP connections in encrypted mode can be established when there is a state firewall. In encrypted mode, if this parameter is set to Yes, the FTP client delivers a command to switch the transmission mode of the control connection channel to plaintext. In this way, the state firewall can identify and dynamically open the port required for FTP transmission; if this parameter is set to No, the FTP connection may fail to be set up due to port restrictions imposed by the state firewall. If security requirements are met, it is recommended that this parameter be set to Yes.
Support SSL Certificate Authentication

Indicates whether the certificate authentication mode is supported when data is transmitted in encrypted mode. This parameter takes effect only for TLS1.2 and earlier versions.
Minimum DH length of FTPS

Indicates the minimum Diffie-Hellman group length on the NE side during an FTPS negotiation. When the key exchange algorithm DH is used in FTPS negotiation algorithms, if the length of the DH key sent by the FTP server is less than the value of this parameter, the FTPS negotiation fails. A longer DH key provides higher security. When this parameter is set to DH_0, DH keys of any length can be used for SSL negotiations between the FTP client and FTP servers. This parameter takes effect only for TLS1.2 and earlier versions.
Policy ID

Indicates the ID of a TLS configuration policy.
TLS Secure Cipher Suite Switch

Indicates the TLS security algorithm switch. When this switch is turned off, weak security algorithm suites other than authenticated encryption with associated data (AEAD) or perfect forward secrecy (PFS) are supported, which poses security risks. When this switch is turned on, the TLS does not support weak security algorithm suites other than AEAD and PFS. Instead, the TLS negotiates only security algorithm suites.
