TRUSTCERT

TRANSPORT
  +-TRUSTCERT

Description

A TRUSTCERT MO defines a trust certificate that is used by a BS to verify the device certificate of a peer device.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD TRUSTCERT

Use this command to add a trust certificate.
DSP TRUSTCERT

Use this command to query the status of trust certificates.
LST TRUSTCERT

Use this command to list the configurations of all trusted certificates.
RMV TRUSTCERT

Use this command to remove a trust certificate and the corresponding certificate file.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Certificate File Name

Indicates the file name of a trust certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).
Table 3 Dynamic parameters

Parameter

Description
Serial Number

Indicates the serial number of a trust certificate.
Common Name

Indicates the common name of a trust certificate.
Issuer Name

Indicates the issuer of a trust certificate.
Expiring Date

Indicates the expiration date of a trust certificate.
Status

Indicates the loading status of a trust certificate.
Effective Date

Indicates the date when a trust certificate begins to take effect.
