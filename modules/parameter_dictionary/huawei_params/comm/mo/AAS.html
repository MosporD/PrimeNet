AAS

EQUIPMENT
  +-AAS
    +-AAMU[0~1]
    +-AARU[0~3]

Description

An AAS MO defines an active antenna system, which consists of one Active Antenna Management Unit (AAMU) and one to three Active Antenna Radio Units (AARUs).

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT

  • Possible children:

    AAMU[0~1];AARU[0~3]
  • Relation with the AARU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The AAS MO corresponding to CN and SRN in the AARU MO must have been configured.
  • Relation with the LOCATION MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If LOCATIONNAME in a AAS MO is not set to NULL, the corresponding LOCATION must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If LOCATIONNAME in a AAS MO is not set to NULL, the corresponding LOCATION with LOCATIONTYPE set to BTSSITE or RFSITE must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB]If LOCATIONNAME in the AAS MO is not left blank, POSITIONINGMETHOD in the LOCATION MO corresponding to this character string cannot be set to POSITIONING_BY_UE.

Function

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the number of the cabinet where the AAS is located.
Subrack No.

Indicates the number of the subrack where the AAS is located.
AAS Name

Indicates the AAS name.
AAU Specification

Indicates the type of an AAS. This parameter must be set to the hardware type of the AAS. After this parameter is specified, the MAE-Deployment checks the configurations of power, carrier, and receive and transmit capabilities based on the value of this parameter. This ensures that these configurations are correct before they take effect. If the user does not need to forcibly verify the AAS specifications using the MAE-Deployment, this parameter can be left unspecified. Leaving this parameter unspecified has no impact on the base station. For example, this parameter must be set to AAU3902 for AAU3902.
Location Name

Indicates the location information of an AAS. Set this parameter to the location name of the site. The location name of the site is configured in the Location object. LocationName must be set to the same value for RF modules serving the same sector.
