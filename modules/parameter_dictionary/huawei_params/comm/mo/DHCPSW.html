DHCPSW

TRANSPORT
  +-DHCPSW

Description

The DHCPSW MO is the switch for the automatic establishment function of the remote maintenance channel. The automatic establishment of the remote maintenance channel is implemented by setting up connections with the Network Management System (NMS) by using the Dynamic Host Configuration Protocol (DHCP) or Bootstrap Protocol (BootP) on all ports.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    TRANSPORT

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP DHCPDETECT

Use this command to query the delay for automatic establishment of the remote maintenance channel.
LST DHCPSW

Use this command to list configurations of parameters for automatic establishment of a remote maintenance channel.
SET DHCPDETECT

Use this command to set the delay for automatic detection of the remote maintenance channel and let the BS exit the steady state. During the detection, all the user-defined configurations are removed and the BS automatically attempts to restore the remote maintenance channel.
SET DHCPSW

Use this command to set parameters for automatic establishment of a remote maintenance channel.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
OMCH Auto-Establishment Switch

Indicates whether to enable DHCP detection during automatic establishment of the remote maintenance channel. If this parameter is set to DISABLE, DHCP listening is performed instead of DHCP detection.
Vlanscan Switch

Indicates whether to turn on the base station VLAN scan function, the VLAN scanning function is refers, when the network element enters the detect detection, on the Ethernet port, carries on the IPv4 DHCP detection to the VLAN identity range to 0~4094.
Delay Establishment Switch

Indicates whether to enable the function of reestablishing the base station's remote maintenance channel after a specified period.
