TLSPOLICY

TRANSPORT
  +-TLSPOLICY

Description

The TLSPOLICY MO configures the key negotiation, signature, and encryption algorithms, and other security-related parameters used by the Transport Layer Security (TLS) protocol. In each TLS scenario, a specific TLS configuration policy is referenced by the corresponding POLICYID. This MO does not apply to TLS1.2 or earlier versions.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the SSL MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If a TLSPOLICY MO does not exist, it cannot be referenced.
  • Relation with the FTPCLT MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If EncryMode is not set to Plaintext and the FTPCLT MO needs to reference an TLSPOLICY MO, the TLSPOLICY MO must exist.
