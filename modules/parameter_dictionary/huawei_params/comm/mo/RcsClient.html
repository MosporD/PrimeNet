RCSCLIENT

EQUIPMENT
  +-RCSCLIENT

Description

The RCSCLIENT MO defines a radio coverage service (RCS) client. The RCS client refers to an operator' base station that uses the shared external RRU resources provided by the local NE. The local NE functions as an RCS server and allows multiple RCS clients to access and use the shared external RRU resources.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT
  • Relation with the RCSSERVER MO:
    • [Co-MPT, eGBTS]RCSSERVER and RCSCLIENT cannot be configured at the same time.
  • Relation with the EXTCONNPORT and EDC MOs:
    • [Co-MPT, eGBTS]The ExtConnPort MO referenced by the RCSCLIENT MO must be configured on the EDC MO with TYPE set to MEDC.
  • Relation with the RCSCLIENT MO:
    • [Co-MPT, eGBTS]One EXTCONNPORT MO cannot be referenced by multiple RCSCLIENT MOs.
  • Relation with the NODE MO:
    • [Co-MPT, eGBTS]The RCSCLIENT MO can be configured only on the NODE MO with PRODUCTTYPE set to DBS3900 DCU or DBS5900 DCU.
  • Relation with the RFRESQUOTA MO:
    • [Co-MPT]The RCSCLIENT MO corresponding to the RCSCLIENTNO parameter in the RFRESQUOTA MO must have been configured.
  • Relation with the RHUBRESQUOTA MO:
    • [Co-MPT]The RCSCLIENT MO corresponding to the RCSCLIENTNO parameter in the RHUBRESQUOTA MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD RCSCLIENT

Use this command to add an RCS client and to add the local NE ports that are connected to the RCS client. The RCS client uses the shared external RRU resources provided by the local NE.
DSP RCSCLIENT

Use this command to list the information of RCS clients, which use the shared external RRU resources.
LST RCSCLIENT

Use this command to list the configuration of RCS clients, which use the shared external RRU resources.
MOD RCSCLIENT

Use this command to modify the configuration of an RCS client and to modify the configuration of the local NE ports that are connected to the RCS client. The RCS client uses the shared external RRU resources provided by the local NE.
RMV RCSCLIENT

Use this command to remove an RCS client, which uses the shared external RRU resources.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
RCS Client No.

Indicates the ID of an RCS client.
RCS Client Name

Indicates the name of an RCS client. When a DCU functions as an RCS server and a BBU functions as an RCS client, this parameter must be set to the NE name of the BBU.
RCS Connection Port List

Indicates the list of ports that are connected to external NEs.
Table 3 Dynamic parameters

Parameter

Description
Local Cell Index

Indicates the local cell ID, which uniquely identifies a cell within an RCS client.
ExConnport PortID

Indicates the ID of a port which an external NE is connected to. This parameter uniquely identifies a port. The parameter value is in the format of cabinet number-subrack number-slot number-port number-subport number. When no allocation results are returned, the parameter value is NULL.
Mode

Indicates the RAT of a cell.
DL Center Frequency

Indicates the downlink frequency channel number of a cell.
DL Bandwidth

Indicates the downlink bandwidth of a cell.
CPRI Band Width

Indicates the BBU-DCU interconnection port bandwidth occupied by a cell. When no allocation results are returned, the parameter value is 0.
Local Cell Resource Status

Indicates the status of bandwidth resources of interconnection ports for a cell. If resources are properly allocated, the parameter value is Available. In other cases, the parameter value is Unavailable.
