FTPCLTPORT

+-NE
  +-NODE
    +-SYSTEMOM
      +-FTPCLTPORT

Description

The FTPCLTPORT MO contains the parameters related to a destination port on the File Transfer Protocol (FTP) server that the FTP client accesses.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    SYSTEMOM

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD FTPSCLTDPORT

Use this command to add a record of the control connection port number and data connection port range of the FTP server. A record of the control connection port number and data connection port range corresponds to a target IP address.
LST FTPSCLTDPORT

Use this command to query the list of server ports and IP addresses configured for the FTP client.
MOD FTPSCLTDPORT

Use this command to modify a record of the control connection port number and data connection port range of the FTP server. A record of the control connection port number and data connection port range corresponds to a target IP address.
RMV FTPSCLTDPORT

Use this command to remove a record of the control connection port number and data connection port range of the FTP server. A record of the control connection port number and data connection port range corresponds to a target IP address.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
FTP Server IP Address

Indicates the IP address of the FTP server.
Destination Port

Indicates the port of the FTP server. If no port is added to an IP address using the ADD FTPSCLTDPORT command, port 21 is used for the IP address by default. If a port is added to an IP address using the ADD FTPSCLTDPORT command, the default port 21 is no longer valid for the IP address.
Start Number of the Data Port Range

Indicates the start number of data connection ports of the FTP server. The STARTDATAPORT and ENDDATAPORT parameters specify the range of data connection ports of the FTP server when ACL Rule Automatic Setup and Deletion Switch in the PACKETFILTER MO is set to ON. If the ADD FTPSCLTDPORT command is not executed to add the start number of a data port range for a new IP address, the default start port number 0 is used.
End Number of the Data Port Range

Indicates the end number of data connection ports of the FTP server. The STARTDATAPORT and ENDDATAPORT parameters specify the range of data connection ports of the FTP server when ACL Rule Automatic Setup and Deletion Switch in the PACKETFILTER MO is set to ON. If the ADD FTPSCLTDPORT command is not executed to add the end number of a data port range for a new IP address, the default end port number 65535 is used.
