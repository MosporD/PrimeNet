ALMCURCFG

+-NE
  +-NODE
    +-SYSTEMOM
      +-ALMCURCFG

Description

The ALMCURCFG MO defines the configuration information of alarms, including alarm severity, whether the alarm is shielded, and environmental alarm name. The configuration information of a specific alarm can be modified.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    SYSTEMOM

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
RST ALMCFG

Use this command to initialize the settings of parameters related to the alarm severity, alarm shield flag, duration-based alarm filtering rule, and times-based alarm filtering rule for a specified alarm (indicated by the alarm ID).
SET ALMLVL

Use this command to set the severity of an alarm based on the alarm ID.

After the alarm severity is set, alarms are reported based on the new alarm severity, and the severity of existing active alarms remains unchanged.
SET ALMSHLD

Use this command to set the Shield Flag for the specified alarm (identified by the alarm ID) so that the alarm is shielded or unshielded.
SET ENVALMPARA

Use this command to set the name, severity, and type of an environmental alarm.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Alarm ID

Indicates the alarm ID. An alarm ID identifies a type of alarms, which indicates a specific fault or event. The alarm ID is the only index for alarms.
Alarm Level

Indicates the alarm severity, that is the impact of the fault on services.
Event Type

Indicates the network management type.
Shield Flag

Indicates whether to shield the alarm.
Alarm Name

Indicates the alarm name, which is the unique name of an alarm in the same product. It corresponds to the alarm ID and clearly and accurately conveys the meaning of the alarm.
