IMALNK

TRANSPORT
  +-IMALNK

Description

An IMALNK MO consists of the parameters related to an IMA link. The multiple E1/T1 links contained in an IMA group logically are called IMA links.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the TSCROSS MO:
    • [Co-MPT, NodeB, eGBTS]If SBT in an IMALNK MO is set to BACK_BOARD, the combination of CN, SRN, SN, SBT, and IMALNKN in the IMALNK MO must be different from the following combinations in the TSCROSS MO: (1) the combination of CN, SRN, SRCSN, SRCSBT, and SRCPN; (2) the combination of CN, SRN, DSTSN, DSTSBT, and DSTPN.
    • [Co-MPT, NodeB]A TSCROSS MO whose SRCTSN and DSTTSN have been used by an IMALNK MO on the same port cannot be configured.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS]When TYPE in the MDU MO is set to MDUC, the IMALNK MO cannot be configured.
  • Relation with the IMAGRP and E1T1 MOs:
    • [Co-MPT, NodeB]When an IMALNK MO is configured for the E1T1 MO whose LNCODE is set to AMI, SCRAM in the associated IMAGRP MO must be set to ENABLE.
  • Relation with the E1T1 MO:
    • [Co-MPT, NodeB]If SBT in an IMALNK MO is set to BACK_BOARD, an E1T1 MO that meets the following condition must exist: CN, SRN, SN, SBT, and PN in the E1T1 MO are the same as CN, SRN, SN, SBT, and IMALNKN in the IMALNK MO, respectively.
  • Relation with the IMAGRP, SAALLNK, and E1T1 MOs:
    • [Co-MPT, NodeB]In an IMAGRP MO, the total transmit bandwidth for the SAALLNK MO with JNRSCGRP set to DISABLE and for the OMCH MO cannot exceed the transmit bandwidth for the IMAGRP MO.
  • Relation with the IMAGRP, OMCH, and E1T1 MOs:
    • [Co-MPT, NodeB]In an IMAGRP MO, the total transmit bandwidth for the SAALLNK MO with JNRSCGRP set to DISABLE and for the OMCH MO cannot exceed the transmit bandwidth for the IMAGRP MO.
  • Relation with the AAL2PATH, IMAGRP, and E1T1 MOs:
    • [Co-MPT, NodeB]If JNRSCGRP in an AAL2PATH MO is set to DISABLE, the transmit bandwidth for the AAL2PATH MO cannot exceed the transmit bandwidth for an IMAGRP MO.
  • Relation with the IMAGRP, TREELNKPVC, and E1T1 MOs:
    • [Co-MPT, NodeB]If JNRSCGRP in a TREELNKPVC MO is set to DISABLE, the transmit bandwidth for the TREELNKPVC MO cannot exceed the transmit bandwidth for an IMAGRP MO.
  • Relation with the UNILNK MO:
    • [Co-MPT, NodeB]IMALNKN in an IMALNK MO must be different from UNILNKN in a UNILNK MO on the same board.
  • Relation with the IMALNK MO:
    • [Co-MPT, NodeB]IMALNKN in the IMALNK MOs that are configured on the same slot but have different types of subboard must be different.
    • [Co-MPT, NodeB]The number of IMALNK MOs in an IMAGRP MO must be greater than or equal to MINLNK in the IMAGRP MO.
  • Relation with the IMAGRP MO:
    • [Co-MPT, NodeB]The IMAGRP MO associated with an IMALNK MO must have been configured.
    • [Co-MPT, NodeB]When removing an IMAGRP MO, the system automatically removes the IMALNK MO that depends on the IMAGRP MO.
  • Relation with the FRAATM MO:
    • [Co-MPT, NodeB]On the same board, IMALNKN in an IMALNK MO must be different from PN in an FRAATM MO.
  • Relation with the PORTSECURITY MO:
    • [Co-MPT, NodeB]The E1T1 MO that is associated with an IMALNK MO must meet either of the following conditions: (1) No PORTSECURITY MO is associated with the E1T1 MO; (2) A PORTSECURITY MO is associated with the E1T1 MO, but SWITCH in the PORTSECURITY MO is set to ENABLE.
  • Relation with the IMAGRP, RSCGRP, and E1T1 MOs:
    • [Co-MPT, NodeB]In an IMAGRP MO, the sum of the values of TXBW in each RSCGRP MO cannot exceed the bandwidth of the IMAGRP MO.
    • [Co-MPT, NodeB]In an IMAGRP MO, the sum of the values of RXBW in each RSCGRP MO cannot exceed the bandwidth of the IMAGRP MO.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of IMALNK MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD IMALNK

Use this command to add an Inverse Multiplexing on ATM (IMA) link to an IMA group.
DSP IMALNK

Use this command to query the status of an IMA link.
LST IMALNK

Use this command to list the IMA link configuration.
RMV IMALNK

Use this command to remove an IMA link from an IMA group.

Parameter

Description

Table 3 Dynamic parameters

Parameter

Description
NE TX Link State

Indicates the TX status of the IMA link at the near end. The near end inversely multiplexes one ATM cell stream (unit: cell) to enable the cells to be transmitted on multiple physical links.
NE RX Link State

Indicates the RX status of the IMA link at the near end.
FE TX Link State

Indicates the TX status of the IMA link at the far end. The far end multiplexes the cell streams transmitted on multiple physical connections into a single cell stream.
FE RX Link State

Indicates the RX status of the IMA link at the far end.
NE IMA RX Link Invalid State

Indicates the invalid RX status of the local IMA link at the near end.
FE IMA RX Link Invalid State

Indicates the invalid RX status of the IMA link at the far end.
Number of Tx User Cells

Indicates the number of user cells transmitted by the IMA link.
Number of Rx User Cells

Indicates the number of user cells received by the IMA link.
Number of Rx Filtered Cells

Indicates the number of incorrect user cells discarded by the IMA link.
Number of Rx Dropped Cells

Indicates the number of discarded idle cells received by the IMA link.
Number of Rx Abnormal Synchronized frame Cells

Indicates the number of cells with abnormal frame synchronization on the IMA link.
Number of Violation ICP Cells

Indicates the number of invalid IMA Control Protocol (ICP) cells received by the IMA link.
Number of Correct ICP Cells

Indicates the number of valid IMA Control Protocol (ICP) cells received by an IMA link.
Number of HEC Failure Cells

Indicates the number of Header Error Control (HEC) error cells received by the IMA link.
Number of Tx Stuff Cells

Indicates the number of stuff cells transmitted by the IMA link.
Number of Rx Stuff Cells

Indicates the number of stuff cells received by the IMA link.
Number of Rx Filler Cells

Indicates the number of filler cells received by the IMA link.
