RRUCHAIN

EQUIPMENT
  +-RRUCHAIN

Description

An RRUCHAIN MO manages an RRU topology in aspects of the RRU chain/ring number, the networking modes, the backup modes, the cabinet number, subrack number, and slot number of the head and tail of the chain/ring, the position of the breakpoints, the number of RRU levels on the chain/ring, and the number of boards.

Effective Scenario

Immediately

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD RRUCHAIN

Use this command to add an RRU chain/ring before adding an RRU to the chain/ring. There are two types of RRU chains/rings: TRUNK and BRANCH. TRUNK indicates that RRUs or RFUs are located on the main chain/ring connected to the optical port on the baseband processing board. BRANCH indicates that RRUs or RFUs are connected to an RHUB or RMU.
CMB RRUCHAIN

Use this command to combine two RRU chains into a cold backup RRU ring. The cold backup mode is described in the backup mode parameter of the MOD RRUCHAIN command.

To improve the reliability of RRU chains, use a fiber optic cable to connect two RRUs on the tails of two chains. Then, run this command to combine them into a ring.

When two RRU chains are combined successfully, the number of the first chain is used as the number of the newly created ring by default.

If the original two RRU chains have no breakpoints, the new ring has no breakpoint.

If only one RRU chain has breakpoints, breakpoints 1 and 2 of the new ring coincide.

If both the original RRU chains have breakpoints, the new ring has two breakpoints. The position of breakpoint 1 is that of the breakpoint on the first RRU chain. The position of breakpoint 2 is the level of the new ring minus the position of the breakpoint on the second RRU chain.
DSP CPRILBR

Use this command to query the current line rate of the specified chain/ring and the maximum line rates of the remote equipment controller (REC) and each remote equipment (RE).
DSP RRUCHAIN

Use this command to query running information about RRU chains/rings..
LST RRUCHAIN

Use this command to query the configurations of RRU chains/rings.
MOD RRUCHAIN

Use this command to modify the configuration of an RRU chain/ring.

To modify the number of ports, the positions of the optical ports at the RRU chain head/ring head/ring tail, or the networking mode of the RRU chain/ring, perform the following steps:

1. Run this command to set breakpoints at the optical port on the chain/ring to be modified.

Only one breakpoint (breakpoint 0) needs to be set for a chain or trunk chain.

Two breakpoints need to be set for a ring or load sharing topology. The position of the first breakpoint is 0, and the position of the second breakpoint is the level of the board.

2. Adjust cable connections, and modify the configurations. Ensure that physical cable connections are consistent with the data configurations.

3. Run this command to remove the breakpoints by setting the positions of breakpoints 1 and 2 to 255.
RMV RRUCHAIN

Use this command to remove an RRU chain/ring.
SET CPRILNKLOOP

Use this command to set a loopback on devices of a CPRI link. After a loopback is set on a CPRI link, a CPRI link performance test can be started to check the quality of the CPRI link.
STR CPRILBRNEG

Use this command to start negotiation on the common public radio interface (CPRI) line rate of a specified chain/ring. If the link cannot recover for 5 minutes or a longer time after the topology changes, try to recover the link by running this command.
STR CPRILNKTST

Use this command to start the performance test on a CPRI link. After the performance test is performed on a CPRI link, the performance test results will be reported, including the valid performance test period, actual loopback type, number of errored seconds, number of severely errored seconds, number of unavailable seconds, and number of bit errors. These results are used to check the quality of the CPRI link.
