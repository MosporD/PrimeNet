SRCIPROUTE6

TRANSPORT
  +-SRCIPROUTE6

Description

The SRCIPROUTE6 MO defines a source IPv6 route, which is used for data forwarding by configuring a source IPv6 routing table.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the SRCIPROUTE6 MO cannot be configured.
  • Relation with the VRF MO:
    • [Co-MPT, eNodeB, gNodeB]The VRF MO associated with an SRCIPROUTE6 MO must have been configured.
  • Relation with the OMCH MO:
    • [Co-MPT, eNodeB, gNodeB]If BEAR in an OMCH MO is set to IPV6, the value of NEXTHOP in an SRCIPROUTE6 MO in the same routing domain must be different from the value of IP6 in the OMCH MO.
  • Relation with the IPADDR6 and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, if SRCIP in an SRCIPROUTE6 MO is set to the same value as a configured IPADDR6 MO in the base station, and PT in the INTERFACE MO associated with the IPADDR6 MO is set to ETH or ETHTRK, RTTYPE in this SRCIPROUTE6 MO must be set to NEXTHOP.
    • [Co-MPT, eNodeB, gNodeB]If SRCIP in an SRCIPROUTE6 MO is set to the same value as a configured IPADDR6 MO in the base station, and PT in the INTERFACE MO associated with the IPADDR6 MO is set to ETH or ETHTRK, then SRCIP in any other SRCIPROUTE6 MO in the same routing domain must be different from SRCIP of this SRCIPROUTE6 MO.
  • Relation with the INTERFACE, IPADDR6, and LOOPBACK MOs:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, if SRCIP in an SRCIPROUTE6 MO is set to an existing IPADDR6 MO on a board, IPADDR6 in the same network segment as NEXTHOP in the SRCIPROUTE6 MO and IPADDR6 on which the SRCIP depends must be on the same board.
    • [Co-MPT, eNodeB, gNodeB]If SRCIP in an SRCIPROUTE6 MO is set to an existing IPADDR6 MO in the same routing domain, the IPADDR6 MO referenced by SRCIP in an SRCIPROUTE6 MO and the INTERFACE MO referenced by ITFID in the SRCIPROUTE6 MO must be configured on the same board.
  • Relation with the SRCIPROUTE6 MO:
    • [Co-MPT, eNodeB, gNodeB]If two SRCIPROUTE6 MOs have the same SRCIP value and the same VRFIDX value, RTTYPE in the two SRCIPROUTE6 MOs must be set to the same value.
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE is set to NEXTHOP in two SRCIPROUTE6 MOs and the two SRCIPROUTE6 MOs have the same SRCIP value and the same VRFIDX value, their PREF and NEXTHOP must be set to different values.
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE is set to IF in two SRCIPROUTE6 MOs and the two SRCIPROUTE6 MOs have the same SRCIP value and the same VRFIDX value, their PREF and ITFID must be set to different values.
  • Relation with the IPADDR6 MO:
    • [Co-MPT, eNodeB, gNodeB]If an IPADDR6 MO and an SRCIPROUTE6 MO are in the same routing domain, IPV6 in the IPADDR6 MO must be different from NEXTHOP in the SRCIPROUTE6 MO.
    • [Co-MPT, eNodeB, gNodeB]If the next hop address of an SRCIPROUTE6 MO is a global unicast address, an IPADDR6 MO must be in the same routing domain and on the same network segment as the global unicast address but different from the global unicast address.
  • Relation with the TUNNELITF MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, if SRCIP of an SRCIPROUTE6 MO is the same as LOCALIP6 of a TUNNELITF MO, RTTYPE of the SRCIPROUTE6 MO is set to NEXTHOP.
  • Relation with the INTERFACE MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, the INTERFACE MO corresponding to ITFID in an SRCIPROUTE6 MO must have been configured.
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an SRCIPROUTE6 MO is set to IF, PT in the INTFERFACE MO corresponding to ITFID in the SRCIPROUTE6 MO must be set to ETH, ETHTRK, or TUNNELITF.
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE is set to IF in multiple SRCIPROUTE6 MOs and the SRCIPROUTE6 MOs have the same SRCIP value and the same VRFIDX value, PT must be TUNNELITF for all the INTERFACE MOs corresponding to ITFID of the SRCIPROUTE6 MOs, or must not be TUNNELITF for any of the INTERFACE MOs corresponding to ITFID of the SRCIPROUTE6 MOs.
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an SRCIPROUTE6 MO is set to IF and PT in the INTERFACE MO corresponding to ITFID in the SRCIPROUTE6 MO is set to ETH, IPV6SW in the INTERFACE MO corresponding to ITFID in the SRCIPROUTE6 MO must be set to DISABLE.
  • Relation with the INTERFACE and PMTUCFG MOs:
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an SRCIPROUTE6 MO is set to IF, PT in the INTERFACE MO corresponding to ITFID in the SRCIPROUTE6 MO is set to ETH or ETHTRK, and IPV6SW in the INTERFACE MO is set to ENABLE, then MODE in the PMTUCFG MO must not be set to ACTIVE.
  • Relation with the IPSECBINDITF MO:
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an SRCIPROUTE6 MO is set to IF, the INTERFACE MO corresponding to ITFID in the SRCIPROUTE6 MO must be configured with an IPSECBINDITF MO.
  • Relation with the SCTPHOST MO:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in an SCTPHOST MO is set to IPv6 and SIGIP1SECSWITCH in the SCTPHOST MO is set to ENABLE, an SRCIPROUTE6 MO cannot be configured for the IPADDR6 MO corresponding to SIGIP1V6 in the same routing domain.
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in an SCTPHOST MO is set to IPv6 and SIGIP2SECSWITCH in the SCTPHOST MO is set to ENABLE, an SRCIPROUTE6 MO cannot be configured for the IPADDR6 MO corresponding to SIGIP2V6 (if valid) in the same routing domain.
  • Relation with the USERPLANEHOST MO:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION and IPSECSWITCH in a USERPLANEHOST MO are set to IPv6 and ENABLE, respectively, an SRCIPROUTE6 MO cannot be configured for the IPADDR6 MO corresponding to LOCIPV6 in the same routing domain.
  • Relation with the IPSECBINDITF, IPSECPOLICY, and IKEPEER MOs:
    • [Co-MPT, eNodeB, gNodeB]When RTTYPE is set to IF in an SRCIPROUTE6 MO, the INTERFACE MO specified by ITFID cannot be bound to the IPSECPOLICY MO that references an IKEPEER MO with REDUNDANCYFLAG set to SLAVE and IPVERSION set to IPV6.
    • [Co-MPT, eNodeB, gNodeB]In an IKEPEER MO referenced by an IPSECBINDITF MO, if REDUNDANCYFLAG is set to SLAVE and IPVERSION is set to IPV6, and if an SRCIPROUTE6 MO with RTTYPE set to IF has been configured on the master IPSECBINDITF MO, the total number of configured SRCIPROUTE6 MOs and all slave IPSECBINDITF MOs (with active IPSECBINDITF MOs configured with SRCIPROUTE6 MOs in the same IPSec redundancy group) cannot exceed 32.
  • Relation with the IPSECBINDITF and IPSECPOLICY MOs:
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an SRCIPROUTE6 MO is set to IF, ACLTYPE in the IPSECPOLICY MO that is bound to the same IPSECBINDITF MO as the INTERFACE MO corresponding to ITFID in the SRCIPROUTE6 MO must be set to IPV6 or IPV4+IPV6.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SRCIPROUTE6

Use this command to add a source IPv6 route.
DSP SRCIPROUTE6

Use this command to query the information about effective source IPv6 routes.
LST SRCIPROUTE6

Use this command to list the configuration of source IPv6 routes.
MOD SRCIPROUTE6

Use this command to modify a source IPv6 route.
RMV SRCIPROUTE6

Use this command to remove a source IPv6 route.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IPv6 Source Route Index

Indicates the index of a source IPv6 route.
VRF Index

Indicates the index of a VRF instance.
Source IPv6 Address

Indicates the source IPv6 address of a source IPv6 route.
Route Type

Indicates the type of a source-based IPv6 route. The value NEXTHOP indicates that IP packets transmitted through the route are forwarded to a specified next-hop IP address. The value IF indicates that IP packets transmitted through the route are forwarded through a specified outbound interface to a specified next-hop IP address.
Next-Hop IPv6 Address

Indicates the next-hop IPv6 address of a source IPv6 route.
Interface ID

Indicates the ID of the specified outbound interface.
Preference

Indicates the priority of the source IPv6 routing entry. A smaller parameter value indicates a higher priority.
User Label

Indicates the user-defined information.
Table 3 Dynamic parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the board to which a source IPv6 route belongs.
Subrack No.

Indicates the subrack number of the board to which a source IPv6 route belongs.
Slot No.

Indicates the slot number of the board to which a source IPv6 route belongs.
Actual Port Type

Indicates the type of the actual port.
Actual Port No.

Indicates the number of the actual port.
Valid State

Indicates the validity state of a source IPv6 route.
Number of Transmit Packets

Indicates the number of transmitted packets. When enhanced ping6 connectivity check is enabled, ping6 packets are directly forwarded without matching routes and the number of transmitted packets cannot be measured.
