MPLNK

TRANSPORT
  +-MPLNK

Description

The MPLNK MO consists of the parameters related to a PPP link in an MLPPP group. This MO is used to set the parameters of an MLPPP link.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, the MPLNK MO cannot be configured.
  • Relation with the PORTSECURITY MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The E1T1 MO that is associated with an MPLNK MO must meet either of the following conditions: (1) No PORTSECURITY MO is associated with the E1T1 MO; (2) A PORTSECURITY MO is associated with the E1T1 MO, but SWITCH in the PORTSECURITY MO is set to ENABLE.
  • Relation with the PPPLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]On a board, PPPLNKN in a PPPLNK MO must be different from PPPLNKN in an MPLNK MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB]The E1/T1 timeslots occupied by an PPPLNK MO and those occupied by an MPLNK MO cannot have an intersection.
  • Relation with the MPGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]Before adding an MPLNK MO, the associated MPGRP MO must have been configured. If CN, SRN, SN, SBT, and MPGRPN in an MPGRP MO are the same as CN, SRN, SN, SBT, and MPGRPN in an MPLNK MO, respectively, the two MOs are associated with each other.
    • [Co-MPT, NodeB, eGBTS, eNodeB]When removing an MPGRP MO, the system automatically removes the MPLNK MO that depends on the MPGRP MO.
  • Relation with the MPLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]Each MPLNK MO configured in the same slot must have a unique MLPPP link number. That is, PPPLNKN must be unique in the MPLNK MOs with an identical combination of CN, SRN, and SN.
    • [Co-MPT, NodeB, eGBTS, eNodeB]The E1/T1 timeslots used by any two MPLNK MOs cannot have an intersection.
    • [Co-MPT, NodeB, eGBTS, eNodeB]E1T1SN in the cross-board MPLNK MOs under the same MPGRP MO must be the same.
    • [Co-MPT, NodeB, eGBTS]The total number of cross-board TSCROSS MOs, backplane E1T1 MOs, and cross-board MPLNK MOs configured on the same board cannot exceed eight.
  • Relation with the E1T1 MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If SBT in an MPLNK MO is set to BACK_BOARD, the associated E1T1 MO must have been configured.
  • Relation with the MPT MO:
    • [Co-MPT, NodeB, eNodeB]In the MPT MO, if the TYPE parameter is set to UMPT and the BRDSPEC parameter is set to "UMPTe" or "UMPTg" or "UMPTga" (case insensitive), the number of MPLNK MOs configured on this board must be 0.
  • Relation with the TSCROSS MO:
    • [Co-MPT, NodeB, eGBTS]MPLNK and TSCROSS MOs cannot use the same backplane E1/T1 port.
    • [Co-MPT, NodeB, eGBTS]The E1/T1 timeslots occupied by an MPLNK MO and those occupied by a TSCROSS MO cannot have an intersection.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of MPLNK MOs must be less than or equal to 4 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD MPLNK

Use this command to add an MLPPP link to an MLPPP group.
DSP MPLNK

Use this command to query the status of one or all MLPPP links on a board.
LST MPLNK

Use this command to list the configurations of the MLPPP links in an MLPPP group.
RMV MPLNK

Use this command to remove an MLPPP link from an MLPPP group.
RST MPLNK

Use this command to reset an MLPPP link from an MLPPP group and restart the negotiation.
