EDC

EQUIPMENT
  +-CABINET
    +-SUBRACK
      +-EDC
        +-CPRIPORT[0~6]
        +-SFP[0~7]

Description

The EDC MO defines a multifunction extended digital card, which is used to connect to an RHUB or an external NE. Among ports on an EDC, ports CPRI 0 to CPRI 5 are used to connect to an RHUB, and the QSFP port that uses a one-to-four connector is used to connect to an external NE.</font>

Effective Scenario

Immediately

Relations Between MOs

  • Base class:

    RU

  • Possible parents:

    SUBRACK

  • Possible children:

    CPRIPORT[0~6];SFP[0~7]
  • Relation with the EXTCONNPORT, BBP, and RCSSERVER MOs:
    • [Co-MPT, eGBTS]The ExtConnPort MO referenced by the RCSSERVER MO must be configured on the BBP MO with TYPE set to UBBP or on the EDC MO with PT set to CPRI.
  • Relation with the EXTCONNPORT and RCSCLIENT MOs:
    • [Co-MPT, eGBTS]The ExtConnPort MO referenced by the RCSCLIENT MO must be configured on the EDC MO with TYPE set to MEDC.
  • Relation with the NODE MO:
    • [Co-MPT, eGBTS]The EDC MO can be configured only on the NODE MO with PRODUCTTYPE set to DBS3900 DCU or DBS5900 DCU.
  • Relation with the BBP, BRI, GTMU, RHUB, CXU, and RRUCHAIN MOs:
    • [Co-MPT]For an RRUCHAIN MO with TT set to CHAIN and AT set to a value other than PEERPORT, or an RRUCHAIN MO with TT set to RING or an RRUCHAIN MO with TT set to LOADBALANCE and AT set to a value other than PEERPORT, the following MO must have been configured:
    • 1. A BBP, BRI, GTMU, RHUB, MDU, EDC, or CXU with CXUTYPE set to RMU must have been configured. The board location is specified by HCN, HSRN, and HSN in the RRUCHAIN MO.
    • 2. For an RRUCHAIN MO with TT set to a value other than CHAIN, a BBP MO, BRI MO, GTMU MO, RHUB MO, MDU MO, or CXU MO with CXUTYPE set to RMU must have been configured. The board location is specified by TCN, TSRN, and TSN in the RRUCHAIN MO.
  • Relation with the CPRIPORT, BBP, BRI, GTMU, RHUB, and CXU MOs:
    • [Co-MPT]If ADMINISTRATIVESTATE in the CPRIPORT MO is set to BLOCKED, a BBP, BRI, GTMU, MDU, EDC, RHUB, or CXU with CXUTYPE set to RMU must be configured in the slot specified by CN, SRN, and SN in the CPRIPORT MO.

Parameter

Description

Indicates the type of the board.
Administrative State

Indicates the administrative state of the board, which can be blocked or unblocked. This parameter applies only to baseband processing boards, RF access boards, and RF boards. For other boards, the value of this parameter is NULL.
Duration of the shutting down state

Indicates the scheduled duration before a board is blocked.
Block Type

Indicates the block type of the board. IMMEDIATE (Immediate) means that the board is blocked and services carried on the board are interrupted immediately after the command is executed. SHUTDOWN (Shutdown) means that the board is blocked when no service is carried on the board. DELAY (Delay) means that the board is blocked and services carried by the board are interrupted after a scheduled duration.
Table 2 Dynamic parameters

Parameter

Description
Alarm Status(from RU)

Indicates the alarm status of the board hardware, which can be set to Normal, Warning, Minor, Major, or Critical. The alarm status of the PSU, PDB, and BDU is in the alarm status of the PMU.
Operational State(from RU)

Indicates the operational state of the board, which can be set to Enabled or Disabled. Enabled indicates that services can be carried on the board. Disabled indicates that no service can be carried on the board.
Availability Status(from RU)

Indicates the physical status of a board, which can be Uninstalled, Starting up, Normal, Inconsistent, Unconfigured, Power off, Fault, Communication lost, In test, or the combination of multiple states. For example, if a board is not configured and fails to communicate with the main control and transmission board, the availability status of the board is "Unconfigured, Communication lost." If a board is under management of the peer end, the availability status of the board may be Starting up, Communication lost, or Fault.

Indicates the electronic label, which is a text file with a maximum of 2 KB used to record the manufacturing information about equipment such as the board, sub-board, and optical module. "Description" indicates the board description in English. "Manufactured" indicates the manufacturing date of the board. "VendorName" indicates the name of the vendor providing the board.
