GDU

EQUIPMENT
  +-CABINET
    +-SUBRACK
      +-GDU

Description

The GNSS satellite signal Distribution Unit (GDU) MO is used for the centralized stacking scenario of the BBU, supporting high reliability and multi-channel distribution of GNSS clock sources.

Effective Scenario

Immediately

Relations Between MOs

  • Base class:

    RU

  • Possible parents:

    SUBRACK
  • Relation with the subrack that houses the GDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A subrack must be configured together with an GDU MO to house the GDU MO.
  • Relation with the TCU, PMU, EMU and FMU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The following cases are not allowed: 1. The combination of MCN, MSRN, MPN, and ADDR in the GDU MO is same as the combination of those in the TCU MOs; 2. The combination of MCN, MSRN, MPN, and ADDR in the GDU MO is same as the combination of those in the PMU MOs; 3. The combination of MCN, MSRN, MPN, and ADDR in the GDU MO is same as the combination of those in the EMU MOs; 4. The combination of MCN, MSRN, MPN, and ADDR in the GDU MO is same as the combination of those in the FMU MOs.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the number of the cabinet where the GDU is located.
Subrack No.

Indicates the number of the subrack where the GDU is located.
Slot No.

Indicates the number of the slot where the GDU is located.
Manager Cabinet No.

Indicates the cabinet number of the manager that manages the GDU. The manager of the GDU is usually a BBU.
Manager Subrack No.

Indicates the subrack number of the manager that manages the GDU. The manager of the GDU is usually a BBU.
Manager Port No.

Indicates the number of the GDU serial port connecting to the manager.
Address

Indicates the communication address of the GDU, which is determined by the settings of the 4-bit dual in-line package (DIP) switch on the GDU. The communication address is used by the GDU to communicate with the main control and transmission board. The value of this parameter must be consistent with the actual settings of the DIP switch. The 4-bit DIP switch can be treated as a 4-bit binary number. The settings of ON and OFF are represented by 1 and 0 respectively. Convert the 4-bit number from binary to decimal, and then the decimal number is used as the value of this parameter.
Port No.

Indicates the input port of the GDU. If it is set to AUTO, the GDU automatically selects a port number. If it is set to 0 or 1, the GDU forcibly switches the port number. In automatic switching mode, the GDU selects a normal port according to the port status. In this way, the faults caused by the failure of a single port can be avoided automatically. If port 0 or port 1 is forcibly specified, all output GNSS clock signals are abnormal if this port is interfered or faulty, and as a result, the GNSS clock reference source may be lost and services may be affected. The default value is AUTO.

Alarm Status(from RU)

Indicates the alarm status of the board hardware, which can be set to Normal, Warning, Minor, Major, or Critical. The alarm status of the PSU, PDB, and BDU is in the alarm status of the PMU.

Indicates the physical status of a board, which can be Uninstalled, Starting up, Normal, Inconsistent, Unconfigured, Power off, Fault, Communication lost, In test, or the combination of multiple states. For example, if a board is not configured and fails to communicate with the main control and transmission board, the availability status of the board is "Unconfigured, Communication lost." If a board is under management of the peer end, the availability status of the board may be Starting up, Communication lost, or Fault.
