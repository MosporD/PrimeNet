EMU

EQUIPMENT
  +-CABINET
    +-SUBRACK
      +-EMU
        +-ALMPORT[36~36]
        +-OUTPORT[6~6]

Description

The environment monitoring unit (EMU) MO is used for an indoor BS. It monitors the status of the environment (humidity, temperature, water, and smoke), burglar proofing (infrared and door status), and power distribution.

Effective Scenario

Immediately

Relations Between MOs

  • Base class:

    RU

  • Possible parents:

    SUBRACK

  • Possible children:

    ALMPORT[36~36];OUTPORT[6~6]
  • Relation with the subrack that houses the EMU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A subrack must be configured together with an EMU MO to house the EMU MO.
  • Relation with the SUBRACK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of EMU MOs configured on one SUBRACK MO must be greater than or equal to 0 and smaller than or equal to 1.
  • Relation with the OUTPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of OUTPORT MOs configured on one EMU MO must be 6.
  • Relation with the ALMPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ALMPORT MOs configured on one EMU MO must be 36.
  • Relation with the CABINET MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]TYPE in the CABINET MO where the EMU MO is configured cannot be set to any of the following values: BBC, RFC, and TP48300A.
  • Relation with the SUBRACK, RRU, and CCU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The MO corresponding to MCN and MSRN in the EMU MO must have been configured and be one of the following types: 1. SUBRACK MO with SRN set to 0 or 1; 2. RRU MO with SN set to 0; 3. CCU MO.
  • Relation with the TCU, PMU, EMU, FMU, CCU, MEB and GDU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The following cases are not allowed: 1. The combination of MCN, MSRN, MPN, and ADDR in the EMU MO is same as the combination of those in other EMU MOs; 2. The combination of MCN, MSRN, MPN, and ADDR in the EMU MO is same as the combination of those in the PMU MOs; 3. The combination of MCN, MSRN, MPN, and ADDR in the EMU MO is same as the combination of those in the TCU MOs; 4. The combination of MCN, MSRN, MPN, and ADDR in the EMU MO is same as the combination of those in the FMU MOs; 5. The combination of MCN, MSRN, and MPN in the EMU MO is same as the combination of those in the CCU MOs, and ADDR in the EMU MO is equal to 21; 6. The combination of MCN, MSRN, and MPN in the EMU MO is same as the combination of those in the MEB MOs, and ADDR in the EMU MO is equal to 10; 7. The combination of MCN, MSRN, MPN, and ADDR in the EMU MO is same as the combination of those in the GDU MOs.
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The RRU MO specified by MCN and MSRN in the EMU MO cannot be configured as an MRIU.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD EMU

Use this command to add an environment monitoring unit (EMU). When the EMU is added, an EMU subrack and an EMU board are added at the same time.
CLR EMUALM

Use this command to clear an environment monitoring unit (EMU) smoke or burglary alarm. When an EMU smoke alarm is reported, you must clear the fault that triggers the alarm, and then run this command to clear the alarm.
DSP EMU

Use this command to query the dynamic information about an environment monitoring unit (EMU).
LST EMU

Use this command to list the configuration of an environment monitoring unit (EMU).
MOD EMU

Use this command to modify the configuration of an environment monitoring unit (EMU).
RMV EMU

Use this command to remove an environment monitoring unit (EMU). When the EMU is removed, an EMU subrack and an EMU board are removed at the same time.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Burglar Alarm Auto Clear Permit

Indicates whether to enable the base station to automatically clear burglary alarms.
Clear Command Delay Time

Indicates the interval after the base station reports the burglary alarm until the command to clear this alarm is delivered. This parameter is applicable only when Burglar Alarm Auto Clear Permit is set to YES.
Clear Command Time Interval

Indicates the interval at which the base station automatically delivers the command to clear a burglary alarm. The base station stops periodic command deliveries when the alarm is cleared. This parameter is applicable only when Burglar Alarm Auto Clear Permit is set to YES.
Cabinet No.

Indicates the number of the cabinet where the EMU is located.
Subrack No.

Indicates the number of the subrack where the EMU is located.
Slot No.

Indicates the number of the slot where the EMU is located.
Manager Cabinet No.

Indicates the cabinet number of the manager that manages the EMU. The manager of the EMU is usually a BBU, RRU, or CCU.
Manager Subrack No.

Indicates the subrack number of the manager. The manager of the EMU is usually a BBU, RRU, or CCU.
Manager Port No.

Indicates the number of the serial port to which the EMU is connected. The serial port is the port through which the EMU is connected to the manager.
Address

Indicates the communication address of the EMU, which is determined by the settings of the 4-bit dual in-line package (DIP) switch on the EMU. The communication address is used by the EMU to communicate with the main control and transmission board. The value of this parameter must be consistent with the actual settings of the DIP switch. The 4-bit DIP switch can be treated as a 4-bit binary number. The settings of ON and OFF are represented by 1 and 0 respectively. Convert the 4-bit number from binary to decimal, and then the decimal number is used as the value of this parameter.
Temperature Alarm Lower Threshold

Indicates the lower limit of temperature. When the temperature is below the lower limit, an ALM-25650 Ambient Temperature Unacceptable is reported.
Temperature Alarm Upper Threshold

Indicates the upper limit of temperature. When the temperature exceeds the upper limit, an ALM-25650 Ambient Temperature Unacceptable is reported.
Humidity Alarm Lower Threshold

Indicates the lower limit of humidity. When the humidity is below the lower limit, an ALM-25651 Ambient Humidity Unacceptable alarm is reported.
Humidity Alarm Upper Threshold

Indicates the upper limit of humidity. When the humidity exceeds the upper limit, an ALM-25651 Ambient Humidity Unacceptable alarm is reported.
Special Analog Alarm Flag

Indicates whether to allow the reporting of a dedicated analog alarm. If the shield flag for an analog alarm is enabled, the analog alarm cannot be reported. The 48V_DISABLE check box under this parameter must deselected. Otherwise, ALM-26271 Inter-System Monitoring Device Parameter Settings Conflict will be reported mistakenly in a separate-MPT multimode base station that involves the GBTS.
Special Boolean Alarm Flag

Indicates whether to allow the reporting of a dedicated Boolean alarm. If the shield flag for a Boolean alarm is enabled, the Boolean alarm cannot be reported.

Indicates the physical status of a board, which can be Uninstalled, Starting up, Normal, Inconsistent, Unconfigured, Power off, Fault, Communication lost, In test, or the combination of multiple states. For example, if a board is not configured and fails to communicate with the main control and transmission board, the availability status of the board is "Unconfigured, Communication lost."
