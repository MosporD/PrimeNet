DSCP2QUEMAP

TRANSPORT
  +-DSCP2QUEMAP

Description

This MO is used to set the mapping between transport bearer priorities (only DSCPs are currently supported) and inner queues. The inner service scheduling function enables the data packets with different priorities to be scheduled to the corresponding queues based on this mapping.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the DSCP2QUEMAP MO cannot be configured.
  • Relation with the DSCP2QUEMAP MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]DSCP referenced by DSCP2QUEREFS in an DSCP2QUEMAP MO must be different from each other.
  • Relation with the INTERFACE MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]In the INTERFACE MO, if ITFTYPE is set to VLAN, the DSCP2QUEMAP MO must have been configured.

Function
