ALMFILTER

+-NE
  +-NODE
    +-SYSTEMOM
      +-ALMFILTER

Description

The alarm filter MO provides the functions of adding and querying the rules for alarm filtering by ratio.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    SYSTEMOM

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST ALMFILTER

Use this command to list the duration-based alarm filtering settings and times-based alarm filtering settings by alarm ID.
SET ALMFILTER

Use this command to set parameters related to the duration-based alarm filtering rule and times-based alarm filtering rule. The times-based alarm filtering rule is complementary to the duration-based alarm filtering rule to ensure that all useful alarms are reported.

An alarm is reported when the accumulated fault duration reaches the threshold or when the accumulated number of fault occurrences reaches the threshold. A cleared alarm is reported when the accumulated alarm cease duration and the number of fault recoveries reach the thresholds.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Alarm ID

Indicates the alarm ID.The alarm ID is the only index for alarms.
Filter Rule Type

Indicates the alarm filtering type.
Window for Raising Alarm

Indicates the time window of alarm generating.
Threshold for Raising Alarm

Indicates the accumulated fault persistence duration in the alarm generating time window.
Window for Ceasing Alarm

Indicates the time window of alarm clearing.
Threshold for Ceasing Alarm

Indicates the accumulated fault persistence duration in the alarm clearing time window.
Alarm Stat Time Window

Indicates the time window in which alarms are measured.
Alarm Raise Frequency Threshold

Indicates the accumulated number of fault occurrences in the alarm stat time window (STATTW).
Alarm Cease Frequency Threshold

Indicates the accumulated number of fault recoveries in the alarm stat time window (STATTW).
