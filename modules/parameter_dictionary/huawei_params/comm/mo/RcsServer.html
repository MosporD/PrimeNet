RCSSERVER

EQUIPMENT
  +-RCSSERVER

Description

The RCSSERVER MO defines an external NE that provides shared RF resources. The radio coverage service (RCS) server manages the operation of RF modules and allows other NEs to transmit and receive RF signals through these RF modules. The NEs that use the RF modules are called RCS clients.

Effective Scenario

Immediately

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD RCSSERVER

Use this command to add an RCS server and to add local NE ports that are connected to the RCS server. The RCS server provides shared external RRU resources for the local NE.
LST RCSSERVER

Use this command to list the configuration of an RCS server, which provides shared external RRU resources.
MOD RCSSERVER

Use this command to modify the configuration of an RCS server and to modify the configuration of local NE ports that are connected to the RCS server. The RCS server provides shared external RRU resources for the local NE.
RMV RCSSERVER

Use this command to remove an RCS server, which provides shared external RRU resources.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
RCS Server No.

Indicates the number of an RCS server.
RCS Server Name

Indicates the name of an RCS server. An RCS client searches for the RCS server on the network based on this RCS server name. Upon finding the RCS server, the RCS client establishes a connection with the RCS server. If the RCS server is a DCU, this parameter must be set to the NE name of the DCU.
RCS Connection Port List

Indicates the list of ports that are connected to external NEs.
