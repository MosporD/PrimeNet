RFRESQUOTA

EQUIPMENT
  +-CARRIERRESOURCE
    +-RFRESQUOTA

Description

Indicates the quota of RF resources allocated by the NE to a client NE.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CARRIERRESOURCE
  • Relation with the RCSCLIENT MO:
    • [Co-MPT]The RCSCLIENT MO corresponding to the RCSCLIENTNO parameter in the RFRESQUOTA MO must have been configured.
  • Relation with the RRU MO:
    • [Co-MPT]The RRU MO in the RRU list under the RFRESQUOTA MO must have been configured.
  • Relation with the RFRESQUOTA MO:
    • [Co-MPT]If an RRU is configured to multiple RFRESQUOTA MOs of one RCS client, the allocated frequency bands cannot overlap.
    • [Co-MPT]If the SCOPE parameter in the RFRESQUOTA MO is set to ALL, this RFRESQUOTA MO and other RFRESQUOTA MOs whose RCSCLIENTNO parameters are set to the same value cannot use overlapping frequency bands.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD RFRESQUOTA

Use this command to add an RF resource quota. Each client NE can correspond to multiple quotas.
LST RFRESQUOTA

Use this command to list configuration of RF resource quotas.
MOD RFRESQUOTA

Use this command to modify an RF resource quota. Each client NE can correspond to multiple quotas.
RMV RFRESQUOTA

Use this command to remove an RF resource quota.
