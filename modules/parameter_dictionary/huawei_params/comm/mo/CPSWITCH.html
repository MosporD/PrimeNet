CPSWITCH

TRANSPORT
  +-CPSWITCH

Description

This MO indicates a control port switch used to manage the switchover between active and standby channels over a control port.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS]When TYPE in the MDU MO is set to MDUC, ES in the CPSWITCH MO must be set to DISABLE.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST CPSWITCH

Use this command to list the setting of the control port (CP) switch.
SET CPSWITCH

Use this command to set the switch for the active/standby control port (CP) switchover.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CP Switch Flag

Indicates whether to enable active/standby switchover between CPs.
