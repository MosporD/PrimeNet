TACALG

TRANSPORT
  +-TACALG

Description

The TACALG MO consists of the parameters related to the admission control algorithm. When a service requests for admission, the BS allocates a certain amount of resources to the service based on the load on the resource group and the admission threshold for this type of service. By implementing admission control, the bandwidth for admitted services is provisioned, and the service quality of each admitted service and the admission success rate of high-priority users are both guaranteed. The TACALG MO takes effect only in LTE.

Indicates the UL admission threshold for handover services. A large value of this parameter will result in a high UL admission success rate of handed-over services.
Downlink Handover Service Admission Threshold

Indicates the DL admission threshold for the guaranteed bit rate (GBR) service. A large value of this parameter will result in a high DL admission success rate of GBR services.

Indicates the UL admission threshold for new iron-level services. A large value of this parameter will result in a high UL admission success rate of new iron-level services.
Downlink Iron New Service Admission Threshold

Indicates the DL admission threshold for new iron-level services. A large value of this parameter will result in a high DL admission success rate of new iron-level services.
Uplink Pre-emption Algorithm Switch

Indicates whether to enable the UL pre-emption algorithm. If this parameter is set to ON, the UL pre-emption algorithm is enabled. In this case, the service with a higher priority that requests for admission may pre-empt the resources of admitted services with lower priorities when UL transmission bandwidth is insufficient. If this parameter is set to OFF, the UL pre-emption algorithm is disabled. In this case, the service with a higher priority that requests for admission cannot pre-empt the resources of admitted services with lower priorities when UL transmission bandwidth is insufficient.
Downlink Pre-emption Algorithm Switch

Indicates whether to enable the UL pre-emption algorithm. If this parameter is set to ON, the UL pre-emption algorithm is enabled. In this case, the service with a higher priority that requests for admission may pre-empt the resources of admitted services with lower priorities when UL transmission bandwidth is insufficient. If this parameter is set to OFF, the UL pre-emption algorithm is disabled. In this case, the service with a higher priority that requests for admission cannot pre-empt the resources of admitted services with lower priorities when UL transmission bandwidth is insufficient.
Physical Port Up Link OverBooking Switch

Indicates whether to enable UL overbooking admission control. It is used to determine the admission bandwidth of the resource group and facilitate admission control.
Physical Port Down Link OverBooking Switch

Indicates whether to enable DL overbooking admission control. It is used to determine the admission bandwidth of the resource group and facilitate admission control.
Physical Port Up Link Admission Switch

Indicates whether to apply UL admission control over a physical port. If this parameter is set to ON, UL admission control is applied to the physical port. If this parameter is set to OFF, UL admission control is not applied to the physical port.
Physical Port Down Link Admission Switch

Indicates whether to apply DL admission control over a physical port. If this parameter is set to ON, DL admission control is applied to the physical port. If this parameter is set to OFF, DL admission control is not applied to the physical port.
Emergency Call Preferential Admission Switch

Indicates whether to preferentially admit emergency calls. When this parameter is set to ON, transmission admission control is not performed for emergency calls and emergency calls will be successfully admitted. When this parameter is set to OFF and the transmission admission algorithm switch is turned on, transmission admission control is performed for emergency calls. When this switch is set to OFF and the transmission admission algorithm switch is turned off, transmission admission control is not performed for emergency calls.
