ANTENNAPORT

EQUIPMENT
  +-CABINET
    +-SUBRACK
      +-RFU
        +-ANTENNAPORT
EQUIPMENT
  +-RRU
    +-ANTENNAPORT

Description

An AntennaPort MO is an antenna port that is located on an RRU or RFU and connected to a feeder. The antenna port labeled R0A also serves as an antenna control port.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RFU;RRU
  • Relation with the RRU and RFU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The RRU or RFU MO corresponding to CN, SRN, and SN in the ANTENNAPORT MO must have been configured.
  • Relation with the RETSUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]One of the following ANTENNAPORT MOs must have been configured: 1. An ANTENNAPORT MO corresponding to CONNCN1, CONNSRN1, CONNSN1, and CONNPN1 in the RETSUBUNIT MO. 2. An ANTENNAPORT MO corresponding to CONNCN2, CONNSRN2, CONNSN2, and CONNPN2 in the RETSUBUNIT MO.
  • Relation with the TMASUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The ANTENNAPORT MO corresponding to CONNCN, CONNSRN, CONNSN, and CONNPN in the TMASUBUNIT MO must have been configured.
  • Relation with the RVDSUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]One of the following ANTENNAPORT MOs must have been configured: 1. An ANTENNAPORT MO corresponding to CONNCN1, CONNSRN1, CONNSN1, and CONNPN1 in the RVDSUBUNIT MO. 2. An ANTENNAPORT MO corresponding to CONNCN2, CONNSRN2, CONNSN2, and CONNPN2 in the RVDSUBUNIT MO.
  • Relation with the RFU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ANTENNAPORT MOs configured on one RFU MO must be greater than or equal to 1 and smaller than or equal to 8.
  • Relation with the RASSUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]One of the following ANTENNAPORT MOs must have been configured: 1. An ANTENNAPORT MO corresponding to CONNCN1, CONNSRN1, CONNSN1, and CONNPN1 in the RASSUBUNIT MO. 2. An ANTENNAPORT MO corresponding to CONNCN2, CONNSRN2, CONNSN2, and CONNPN2 in the RASSUBUNIT MO.
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]When RT in the RRU MO is set to MPMU, the number of ANTENNAPORT MOs must be less than or equal to 6.
    • [Co-MPT, NodeB, eNodeB, gNodeB]When RT in the RRU MO is set to MPRF, the number of ANTENNAPORT MOs must be 2.
    • [Co-MPT, NodeB, eNodeB, gNodeB]When RT in the RRU MO is not set to MPMU, the number of ANTENNAPORT MOs must range from 1 to 16.
    • [eGBTS]The number of ANTENNAPORT MOs configured on one RRU MO must be greater than or equal to 1 and smaller than or equal to 8.
  • Relation with the SASUSUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS]The ANTENNAPORT MO corresponding to CONNCN, CONNSRN, CONNSN, and CONNPN in the SASUSUBUNIT MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
CFM TMACONNECTION

Use this command to query whether an RRU/RFU is connected to a common tower mounted amplifier (TMA). You can run this command to check whether an RRU/RFU is connected to a common TMA that does not support the AISG protocol and run the SCN ALD command to check whether an RRU/RFU is connected to an intelligent TMA that supports the AISG protocol.

Before performing this operation, ensure that the base station has been commissioned and its cell data has been configured and activated.
DSP ANTENNAPORT

Use this command to query the dynamic information about an antenna port.
LST ANTENNAPORT

Use this command to list the configuration of the antenna port.
MOD ANTENNAPORT

Use this command to modify the configuration of an antenna port.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the RRU or RFU where the antenna port is located.
Subrack No.

Indicates the subrack number of the RRU or RFU where the antenna port is located.
Slot No.

Indicates the slot number of the RRU or RFU where the antenna port is located.
Antenna Port No.

Indicates the number of the antenna port on the RRU or RFU. For the RRU that works in TDD or FDD mode and has eight channels to be connected to the antenna, the service channels are ANT1 to ANT8 and the corresponding ports on the antenna are R0A to R0H. For other RRUs/RFUs, the service channels are numbered from ANT0 and the corresponding port on the antenna is R0A.
Feeder Length

Indicates the length of the feeder at the antenna port.
DL Time Delay

Indicates the downlink delay of the antenna, that is, the propagation delay from the output port of an RF unit to the antenna port. If no TMA is configured, this parameter is set to the propagation delay of the feeder. In typical scenarios, the transmission speed of signals in feeders is 0.88 times the speed of light, and therefore the propagation delay of feeders can be calculated using the following formula: (feeder length x 10 x 100)/(3 x 88). In this formula, the propagation delay of feeders is in units of ns and the feeder length is in units of m. If the TMA is configured, the value of this parameter also includes the delay of the TMA. For details about the delay of the TMA, see the document provided by the TMA manufacturer.
UL Time Delay

Indicates the uplink delay of the antenna, that is, the propagation delay from the antenna port to the input port of an RF unit. If no TMA is configured, this parameter is set to the propagation delay of the feeder. In typical scenarios, the transmission speed of signals in feeders is 0.88 times the speed of light, and therefore the propagation delay of feeders can be calculated using the following formula: (feeder length x 10 x 100)/(3 x 88). In this formula, the propagation delay of feeders is in units of ns and the feeder length is in units of m. If the TMA is configured, the value of this parameter also includes the delay of the TMA. For details about the delay of the TMA, see the document provided by the TMA manufacturer.
ALD Power Switch

Indicates the state of the ALD power supply switch. The ALD power supply switches for the SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), STMA (Smart Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit) must be set to ON. In actual cases, the RRU/RFU automatically sets this switch to OFF for an Antenna port when the ALM-26530 RF Module ALD Current Abnormal alarm is reported due to overcurrent, overcurrent protection, or undercurrent protection (the RRU/RFU supports undercurrent protection and Low Current Protect Switch is set to ON for the RRU/RFU) on the Antenna port. For details, see ALM-26530 RF Module ALD Current Abnormal.
Current Alarm Threshold Type

Indicates the type of the ALD current alarm threshold. This parameter is valid only if the ALD power supply switch is turned on. If this parameter is not set to UER_SELF_DEFINE, the value of this parameter must be set according to the ALD type and connection mode, and this parameter value determines the current alarm thresholds.

1. For 12 dB non-AISG TMAs only: Undercurrent Alarm Occur Threshold must be set to 30 mA. Undercurrent Alarm Clear Threshold must be set to 40 mA. Overcurrent Occur Alarm Threshold must be set to 170 mA. Overcurrent Alarm Clear Threshold must be set to 150 mA.

2. For 24 dB non-AISG TMAs only: Undercurrent Alarm Occur Threshold must be set to 40 mA. Undercurrent Alarm Clear Threshold must be set to 60 mA. Overcurrent Occur Alarm Threshold must be set to 310 mA. Overcurrent Alarm Clear Threshold must be set to 280 mA.

3. For RET antennas (coaxial) only: Undercurrent Alarm Occur Threshold must be set to 25 mA. Undercurrent Alarm Clear Threshold must be set to 33 mA. Overcurrent Occur Alarm Threshold must be set to 150 mA. Overcurrent Alarm Clear Threshold must be set to 120 mA.

4. For 12 dB TMAs and RETs or 12 dB AISG TMAs only: Undercurrent Alarm Occur Threshold must be set to 30 mA. Undercurrent Alarm Clear Threshold must be set to 40 mA. Overcurrent Occur Alarm Threshold must be set to 450 mA. Overcurrent Alarm Clear Threshold must be set to 400 mA.

5. For 24 dB TMAs and RETs or 24 dB AISG TMAs only: Undercurrent Alarm Occur Threshold must be set to 40 mA. Undercurrent Alarm Clear Threshold must be set to 60 mA. Overcurrent Occur Alarm Threshold must be set to 850 mA. Overcurrent Alarm Clear Threshold must be set to 750 mA.

6. For 12 dB TMAs and AISUs: Undercurrent Alarm Occur Threshold must be set to 30 mA. Undercurrent Alarm Clear Threshold must be set to 40 mA. Overcurrent Occur Alarm Threshold must be set to 500 mA. Overcurrent Alarm Clear Threshold must be set to 450 mA.

7. For 24 dB TMAs and AISUs: Undercurrent Alarm Occur Threshold must be set to 40 mA. Undercurrent Alarm Clear Threshold must be set to 60 mA. Overcurrent Occur Alarm Threshold must be set to 650 mA. Overcurrent Alarm Clear Threshold must be set to 580 mA.

8. For AISUs only: Undercurrent Alarm Occur Threshold must be set to 10 mA. Undercurrent Alarm Clear Threshold must be set to 15 mA. Overcurrent Occur Alarm Threshold must be set to 350 mA. Overcurrent Alarm Clear Threshold must be set to 300 mA.
Undercurrent Alarm Occur Threshold

Indicates the undercurrent alarm occur threshold. When the ALD current value is smaller than this threshold, an ALM-26530 RF Unit ALD Current Out of Range alarm is reported. The specific problem is undercurrent.
Undercurrent Alarm Clear Threshold

Indicates the undercurrent alarm clear threshold. When the ALD current value is greater than this threshold, the ALM-26530 RF Unit ALD Current Out of Range alarm is cleared.
Overcurrent Alarm Occur Threshold

Indicates the overcurrent alarm occur threshold. When the ALD current value is greater than this threshold, an ALM-26530 RF Unit ALD Current Out of Range alarm is reported. The specific problem is overcurrent. When this threshold is lower than the maximum current supported by the hardware, the overcurrent alarm occur threshold prevails. When this threshold is higher than the maximum current supported by the hardware, the maximum current supported by the hardware serves as the overcurrent alarm occur threshold.
Overcurrent Alarm Clear Threshold

Indicates the overcurrent alarm clear threshold. When the overcurrent alarm clear threshold is lower than the maximum current supported by the hardware, the overcurrent alarm clear threshold prevails. In this case,when the ALD current value is lower than this threshold, ALM-26530 RF Unit ALD Current Out of Range is cleared. When the overcurrent alarm clear threshold is higher than the maximum current supported by the hardware, the maximum current supported by the hardware serves as the overcurrent alarm clear threshold. In this case, when the ALD current value is lower than the maximum current supported by the hardware, ALM-26530 RF Unit ALD Current Out of Range is cleared.
Switch of Configuring Ultra Delay

Indicates the ultra-large antenna delay switch. This switch determines the configurable range of uplink delay and downlink delay. When this parameter is set to OFF, the configurable range of both uplink delay and downlink delay is 0 to 4000 ns. When this parameter is set to ON, the configurable range of both uplink delay and downlink delay is 0 to 100, 000 ns. In normal sites, it is recommended that this parameter be set to OFF because the feeder delay is less than 4000 ns. In special sites such as optical fiber repeaters, it is recommended that this parameter be set to ON because the ultra-large delay is required.
Table 3 Dynamic parameters

Parameter

Description
ALD Current Value

Indicates the ALD current value. Value NULL indicates that this parameter fails to be queried or the ALD Actual Power Switch is OFF.
ALD Actual Power Switch

Indicates the actual status of the ALD power supply switch, which can be set to ON or OFF. ON indicates that this switch is set to on and OFF indicates that this switch is set to off.
ALD Current Out of Range Status

Indicates the status of the ALD current of an antenna port when the ALD power switch of the antenna port is set to on. If the status is No Alarm, the ALD power switch is set to on normally and the value of the CFMTMARESULT parameter is reliable. If the status is a value other than No Alarm, the ALD power switch is not set to on, the value of the CFMTMARESULT parameter is unreliable, and you need to determine whether the antenna port is connected to a common TMA based on the onsite conditions of the base station.
Delta of RTWP/RSSI

Indicates the difference in the RTWP/RSSI before and after the ALD power switch is set to on.
Confirm TMA Connection Result

Indicates the confirmation result of whether an antenna port is connected to a common TMA. If the confirmation fails for an RF module, you need to run the CFM TMACONNECTION command with the ALD Actual Power Switch, ALD Current Value(mA), ALD Current Out of Range, and Delta of RTWP parameters set to NULL on this RF module to obtain the reason for the confirmation failure.
