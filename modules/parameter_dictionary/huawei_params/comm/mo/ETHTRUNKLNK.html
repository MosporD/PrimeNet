ETHTRUNKLNK

TRANSPORT
  +-ETHTRUNK
    +-ETHTRUNKLNK

Description

An ETHTRKLNK MO consists of multiple parameters related to a member port of an Ethernet trunk, which contains multiple Ethernet ports. This enables load sharing among the Ethernet ports and provides higher reliability. The Ethernet port in an Ethernet trunk is called a member port. Member ports are aggregated into an Ethernet trunk in either manual or static mode. After being added to an Ethernet trunk in manual mode, a member port takes effect immediately without negotiating with the Ethernet trunk at the peer end. After being added to an Ethernet trunk in static mode, a member port does not take effect immediately but requires negotiation with the Ethernet trunk at the peer end based on the Link Aggregation Control Protocol (LACP). For details, see IEEE 802.3ad.

Effective Scenario

Immediately

    • 2. The value of ITFID in the IPADDR4 MO that meets condition 1 is the same as that of ITFID in an INTERFACE MO. In this INTERFACE MO, PT is set to LOOPINT, ETH, or ETHTRK.
    • 3. If PT in the INTERFACE MO that meets condition 2 is set to LOOPINT, the value of PORTID in this INTERFACE MO is the same as that of PORTID in an LOOPBACK MO. In addition, the values of CN, SRN, and SN in this LOOPBACK MO are the same as those of CN, SRN, and SN in the IPCLKLNK MO.

    • 6. The value of PORTID in the ETHTRUNK MO that meets condition 5 is the same as that of ETHTRKPORTID in an ETHTRUNKLNK MO.
    • 7. The value of ETHPORTID in the ETHTRUNKLNK MO that meets condition 6 is the same as that of PORTID in an ETHPORT MO. In addition, the values of CN, SRN, and SN in this ETHPORT MO are the same as those of CN, SRN, and SN in the IPCLKLNK MO.

MML Command

Function

Description

Indicates whether the member port is the primary port of an Ethernet trunk. Each Ethernet trunk has only one primary port. The primary port must be the first port added to an Ethernet trunk and the last port removed from the Ethernet trunk.
