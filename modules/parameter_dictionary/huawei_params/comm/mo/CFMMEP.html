CFMMEP

TRANSPORT
  +-CFMMD
    +-CFMMA
      +-CFMMEP

Description

The CFMMEP MO consists of the parameters related to the local maintenance association end point (MEP). Local MEPs and remote MEPs (RMEPs) determine the scope and boundaries of a maintenance domain (MD). The MD and MA to which MEPs belong determine the VLAN attributes and level for messages sent from the MEPs.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CFMMA
  • Relation with the CFMMEP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Only one CFMMEP MO can be configured in a CFMMA MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The cabinet number, subrack number, and slot number in a CFMMEP MO must be the same as those in the associated CFMMA MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the parent CFMMA MO of a CFMMEP MO is bound to a VLAN, the LEVEL value in the CFMMD MO to which the CFMMEP MO belongs must be greater than that of the CFMMD MO containing any CFMMEP MO not bound to a VLAN.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before adding a CFMMEP MO to an ETHPORT MO in an ETHTRK MO, ensure that LEVEL in the CFMMD MO to which the CFMMEP MO belongs is less than or equal to that in the CFMMD MO to which the CFMMEP MO configured for the ETHTRK MO belongs.
  • Relation with the CFMRMEP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Under a CFMMA MO, MEPID in the CFMMEP MO and RMEPID in the CFMRMEP MO cannot be set to the same value.
  • Relation with the CFMRMEP and CFMLOCALMEP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the TRANSCFGMODE in the GTRANSPARA MO is set to OLD, CFMMEP MO must be configured when a CFMRMEP MO has been configured in a CFMMA MO.
    • When the TRANSCFGMODE in the GTRANSPARA MO is set to NEW, CFMLOCALMEP MO must be configured when a CFMRMEP MO has been configured in a CFMMA MO.
  • Relation with the ETHTRKLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before a CFMMEP MO is configured on an ETHTRK MO or on an ETHPORT MO that is not added to an ETHTRK MO, BNDVLAN in the parent CFMMA MO of the CFMMEP MO must be set to YES.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If an ETHPORT MO configured with a CFMMEP MO has joined an ETHTRK MO, the CFMMA MO to which the CFMMEP MO belongs cannot be associated with any VLAN.
  • Relation with the CFMMA MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When adding a CFMMEP MO to an ETHPORT MO that belongs to an ETHTRK MO, CCMINTL in the CFMMD MO containing the CFMMEP MO in the ETHTRK MO must be greater than CCMINTL in the CFMMD MO containing the CFMMEP MO in the ETHTRKLNK MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When adding a CFMMEP MO to an ETHTRK MO that an ETHPORT MO belongs to it, CCMINTL in the CFMMD MO containing the CFMMEP MO in the ETHTRK MO must be greater than CCMINTL in the CFMMD MO containing the CFMMEP MO in the ETHTRKLNK MO.
  • Relation with the ETHTRK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before configuring a CFMMEP MO on an ETHTRK MO, ensure that the ETHTRK MO has been configured.
  • Relation with the PORTSECURITY MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The ETHPORT MO that is associated with a CFMMEP MO must meet either of the following conditions: (1) No PORTSECURITY MO is associated with the ETHPORT MO; (2) A PORTSECURITY MO is associated with the ETHPORT MO, but SWITCH in the PORTSECURITY MO is set to ENABLE.
  • Relation with the ETHDM and CFMLOCALMEP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the CFMMEP MO referenced by the ETHDM MO must have been configured.
    • If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the CFMLOCALMEP MO referenced by the ETHDM MO must have been configured.
  • Relation with the ETHLM and CFMLOCALMEP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the CFMMEP MO referenced by the ETHLM MO must have been configured.
    • If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the CFMLOCALMEP MO referenced by the ETHLM MO must have been configured.
  • Relation with the ETHLM and ETHTRKLNK MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the ETHLM MO is associated with the CFMMEP MO whose PT parameter is set to ETHTRK, the ETHLM MO cannot be activated. When the ETHLM MO is associated with the CFMMEP MO whose PT parameter is set to ETH and this port has been added to the ETHTRK MO, the ETHLM MO cannot be activated.
  • Relation with the BBP and CASCADEPORT MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to SCPRI/SRIO, this board cannot be configured with the CFMMEP MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]On a UBBP or LCOP board, if the CASCADEPORT MO in which the PN parameter is set to 6 does not exist, this board cannot be configured with the CFMMEP MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to 1*40GE or AUTO, and PT in the CFMMEP MO for this board is set to ETH, PN can only be set to 0 in the CFMMEP MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to 4*10GE, and PT in the CFMMEP MO for this board is set to ETH, PN parameter can only be set to 0, 1, 2, or 3 in the CFMMEP MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]On a UBBP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to 1*100GE, and PT in the CFMMEP MO for this board is set to ETH, PN can only be set to 0 in the CFMMEP MO.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the CFMMEP MO cannot be configured.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TYPE in an MDU MO is set to MDUC, the CFMMEP MO must meet the following conditions: SBT is set to BASE_BOARD; PN is set to a value within the range 0 to 2.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of CFMMEP MOs must be less than or equal to 8 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ACT CFMCC

Use this command to activate continuity check (CC) for the connectivity fault management (CFM) maintenance association end point (MEP).
ADD CFMMEP

Use this command to add a local maintenance association end point (MEP).
CFMPING

Use this command to start the CFM link loopback.
CFMTRACE

Use this command to start the CFM link trace.
DEA CFMCC

Use this command to deactivate continuity check (CC) for the local connectivity fault management (CFM) maintenance association end point (MEP).
DSP CFMMEP

Use this command to query the status of the local maintenance association end point (MEP).
LST CFMMEP

Use this command to list the configuration of the local maintenance association end point (MEP).
RMV CFMMEP

Use this command to remove a local connectivity fault management (CFM) maintenance association end point (MEP).
