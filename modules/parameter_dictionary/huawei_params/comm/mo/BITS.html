BITS

EQUIPMENT
  +-BITS

Description

A building integrated timing supply system (BITS) MO is a type of reference clock source. The BITS clock can be configured only on the USCU.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT
  • Relation with the GPS MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A unique combination is necessary for the following parameters: 1. CN, SRN, and SN in the BITS MO. 2. CN, SRN, and SN in the GPS MO.
  • Relation with the TOD MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A unique combination is necessary for the following parameters: 1. CN, SRN, and SN in the BITS MO. 2. CN, SRN, and SN in the TOD MO.
  • Relation with the TASM MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If MODE and CLKSRC in the TASM MO are set to MANUAL and BITS, respectively, the corresponding BITS MO must have been configured.
  • Relation with the EQUIPMENT, TASM, TOD, LINECLK, IPCLKLNK, INTERCLK, SYNCETH, and PEERCLK MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If SDRCONNSW and INTERSUBRACKCLKALIGNMODE in an EQUIPMENT MO are set to OFF and INDEPENDENT_GNSS_CLK, respectively, and if MODE in the TASM MO is set to AUTO, then only the GPS MO can be configured and other clock link MOs cannot be configured.
  • Relation with the TASM, SYNCETH, INTERCLK, LINECLK, TOD, and PEERCLK MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CLKSYNCMODE in a TASM MO is set to HYBRID, the SYNCETH, INTERCLK, LINECLK, PEERCLK, TOD, or BITS MO cannot be configured.
  • Relation with the EQUIPMENT, APPLICATION, PEERCLK, TOD, LINECLK, IPCLKLNK, INTERCLK, SYNCETH, and GPS MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If SDRCONNSW is set to OFF and INTERSUBRACKCLKALIGNMODE is set to PEER_RF_CLK in an EQUIPMENT MO and if AT in the APPLICATION MO is set to NodeB, it is allowed and only a PEERCLK MO in which PNT is set to RF can be configured, other clock link management objects cannot be configured.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The BITS MO cannot be configured under a MDU with TYPE is MDUC.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD BITS

Use this command to add a BITS clock link. If the NE can properly obtain synchronization signals from the BITS clock, this link becomes available.
DSP BITS

Use this command to query the running status of a specified BITS clock link.
LST BITS

Use this command to list the configuration of all BITS clock links.
MOD BITS

Use this command to modify the priority of the specific BITS clock link.
RMV BITS

Use this command to remove a specified BITS clock link.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
BITS Clock No.

Indicates the number of the BITS clock link.
Cabinet No.

Indicates the number of the cabinet where the BITS clock link is configured.
Subrack No.

Indicates the number of the subrack where the BITS clock link is configured.
Slot No.

Indicates the number of the slot where the BITS clock link is configured.
Priority

Indicates the priority of the clock source. The value 1 indicates that the current clock source has the highest priority, and the value 4 indicates that the current clock source has the lowest priority.
Table 3 Dynamic parameters

Parameter

Description
Link Active State

Indicates the activation status of the BITS clock link. If the link is active, the BITS clock link is the current clock source of the system.
Link Available State

Indicates the availability of a BITS clock link. Only an available clock link can serve as the current clock source. Otherwise, the clock link cannot be locked even if it is activated.
