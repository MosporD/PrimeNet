Description

Physical port on a board. It manages physical information of a port on a board.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    MDU;MPT
  • Relation with the CTRLLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When the combination of CN, SRN, and SN in the PHYPORT MO is the same as that of CN, SRN, and SN in the CTRLLNK MO, and PT is HEI, PN is 1, the ADMINISTRATIVESTATE cannot be BLOCKED.
    • [Co-MPT, NodeB, eGBTS, eNodeB]When the combination of CN, SRN, and SN in the PHYPORT MO is the same as that of UPCN, UPSRN, and UPSN in the CTRLLNK MO, and PT is HEI, PN is 0, the ADMINISTRATIVESTATE cannot be BLOCKED.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
BLK PHYPORT

Use this command to block a specified physical port.
DSP PHYPORT

Use this command to query the dynamic information of a physical port.
LST PHYPORT

Use this command to query the management status configured for a physical port.
UBL PHYPORT

Use this command to unblock a specified physical port.
