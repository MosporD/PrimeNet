ETHTRKLNK

TRANSPORT
  +-ETHTRK
    +-ETHTRKLNK

Description

An ETHTRKLNK MO consists of multiple parameters related to a member port of an Ethernet trunk, which contains multiple Ethernet ports. This enables load sharing among the Ethernet ports and provides higher reliability. The Ethernet port in an Ethernet trunk is called a member port. Member ports are aggregated into an Ethernet trunk in either manual or static mode. After being added to an Ethernet trunk in manual mode, a member port takes effect immediately without negotiating with the Ethernet trunk at the peer end. After being added to an Ethernet trunk in static mode, a member port does not take effect immediately but requires negotiation with the Ethernet trunk at the peer end based on the Link Aggregation Control Protocol (LACP). For details, see IEEE 802.3ad.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    ETHTRK
  • Relation with the CFMMEP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before a CFMMEP MO is configured on an ETHTRK MO or on an ETHPORT MO that is not added to an ETHTRK MO, BNDVLAN in the parent CFMMA MO of the CFMMEP MO must be set to YES.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If an ETHPORT MO configured with a CFMMEP MO has joined an ETHTRK MO, the CFMMA MO to which the CFMMEP MO belongs cannot be associated with any VLAN.
  • Relation with the IPSECBIND MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before configuring an IPSECBIND MO on an ETHPORT MO, ensure that the ETHPORT MO has not been added to an ETHTRK MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before binding an IPSECPOLICY MO to an ETHTRK MO, ensure that an ETHTRKLNK MO is configured in the ETHTRK MO.
  • Relation with the PACKETFILTER MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PT in a PACKETFILTER MO is set to ETH, and the ETHPORT MO is added to an ETHTRK MO, the PACKETFILTER MO cannot be added.
  • Relation with the RSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If an ETHPORT MO has been added to an ETHTRK MO, an RSCGRP MO that meets all the following conditions cannot be configured: (1) PT in the RSCGRP MO is set to ETH. (2) RSCGRPID in the RSCGRP MO is not set to AUTOPORT. (3) CN, SRN, SN, SBT, and PN in the RSCGRP MO are the same as those in the associated ETHTRKLNK MO, respectively.
  • Relation with the PORTSECURITY MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]An ETHPORT MO on which an ETHTRKLNK MO depends must meet either of the following conditions: (1) The corresponding PORTSECURITY MO is not configured. (2) If the corresponding PORTSECURITY MO has been configured, SWITCH in the PORTSECURITY MO is set to ENABLE.
  • Relation with the DEVIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A DEVIP MO with PT set to ETH and PN set to the same value as that in an ETHTRKLNK MO cannot be configured.
  • Relation with the ETHTRKLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before adding an ETHTRKLNK MO with FLAG set to NO, ensure that the associated ETHTRKLNK MO with FLAG set to YES has been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A maximum of four ETHTRKLNK MOs can be configured in one ETHTRK MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A maximum of one ETHTRKLNK MO with FLAG set to YES can be configured in one ETHTRK MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The data rates of all ETHTRKLNK MOs in an ETHTRK MO must be the same.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For ETHTRKLNK MOs with the same combination of CN, SRN, and SN but with different TN, their PN must be different.
  • Relation with the ETHTRK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When removing an ETHTRK MO, the system automatically removes the ETHTRKLNK MO that depends on the ETHTRK MO.
  • Relation with the IFIP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]An IFIP MO with PT set to ETH and PN set to the same value as that in an ETHTRKLNK MO cannot be configured.
  • Relation with the LR MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before adding an ETHTRKLNK MO, ensure that an LR MO is not enabled for the associated ETHPORT MO or LRSW in the LR MO is set to DISABLE.
  • Relation with the SUBIF MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PT in a SUBIF MO is set to ETH, and the corresponding ETHPORT MO has joined an ETHTRK MO, the SUBIF MO cannot be added.
  • Relation with the ETHLM and CFMMEP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the ETHLM MO is associated with the CFMMEP MO whose PT parameter is set to ETHTRK, the ETHLM MO cannot be activated. When the ETHLM MO is associated with the CFMMEP MO whose PT parameter is set to ETH and this port has been added to the ETHTRK MO, the ETHLM MO cannot be activated.
  • Relation with the BBP and CASCADEPORT MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to 4*10GE, the PN parameter in the ETHTRKLNK MO configured for this board can only set to 0, 1, 2, or 3.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the ETHTRKLNK MO cannot be configured.
  • Relation with the IPPATH MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT in an IPPATH MO is set to ETH, ensure that the Ethernet port is not associated with an ETHTRKLNK MO.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, the ETHTRKLNK MO cannot be configured.
  • Relation with the GPM MO:
    • [Co-MPT, NodeB]If PT and RSCGRPID in a GPM MO are set to ETH and DEFAULTPORT, respectively, ensure that the Ethernet port is not associated with an ETHTRKLNK MO.
  • Relation with the LANSWITCHPORT MO:
    • [Co-MPT, eNodeB]The settings of the following parameters in the LANSWITCHPORT MO's CN, SRN, SN, PN cannot be the same as those in the ETHTRKLNK MO. That is, the ETHPORT MO associated with the LANSWITCHPORT MO of the Ethernet type cannot be referenced by the ETHTRKLNK MO.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of ETHTRKLNK MOs must be less than or equal to 32 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

MML Command

Function

Use this command to list the configuration of member ports of Ethernet trunks.

Use this command to remove a member port from an Ethernet trunk.

Related Parameters

Table 2 Configuration parameters

Parameter

Description

Indicates the number of the cabinet housing the board where the member port of an Ethernet trunk is located.

Indicates the number of the subrack housing the board where the member port of an Ethernet trunk is located.

Indicates the number of the parent Ethernet trunk of the member port.
Port No.

Indicates the number of the member port in an Ethernet trunk.
Port Priority

Indicates the priority of the member port in an Ethernet trunk. A smaller parameter value indicates a higher priority.
Master Flag

Indicates whether the member port is the primary port of an Ethernet trunk. Each Ethernet trunk has only one primary port. The primary port must be the first port added to an Ethernet trunk and the last port removed from the Ethernet trunk.
Subboard Type

Indicates the type of sub-board on the board where the member port of an Ethernet trunk is located.
Table 3 Dynamic parameters

Parameter

Description
Port Status

Indicates the status of the member port in an Ethernet trunk.
MAC Address

Indicates the MAC address of the member port when being added to an Ethernet trunk. The format of the MAC address is XXXX-XXXX-XXXX.
Local Timeout Mode

Indicates which period is used for transmitting the LACP Protocol Data Units (PDUs) at the local end. When the long period is used, the LACP PDUs are transmitted at a long interval.
Peer Timeout Mode

Indicates which period is used for transmitting the LACP PDUs at the peer end.
Number of RX LACP Packets

Indicates the number of LACP PDUs received on the member port of an Ethernet trunk.
Number of TX LACP Packets

Indicates the number of LACP PDUs transmitted on the member port of an Ethernet trunk.
