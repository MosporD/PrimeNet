EPGROUP

TRANSPORT
  +-EPGROUP

Description

The EPGROUP MO consists of transmission end points, which can be control plane end points, user-plane end points, or both types of end points.

Effective Scenario

Immediately

    • [Co-MPT, eNodeB, gNodeB]The SCTP configurations of EndPoint conflict with the configurations of a manually configured SCTPLNK MO. The following two groups of four-tuple parameters must be different: One group of four-tuple parameters consists of the following parameters: SIGIP1V6 or SIGIP2V6 (when the value of SIGIP2V6 is not 0::0) in the SCTPHOST MO with IPVERSION set to IPv6 in the EPGROUP MO, PN, SIGIP1V6 or SIGIP2V6 (when the value of SIGIP2V6 is not 0::0) in the SCTPPEER MO with IPVERSION set to IPv6 in the EPGROUP MO, PN. The other group of four-tuple parameters consists of the following parameters: LOCIP6 or SECLOCIP6 (when the value of SECLOCIP6 is not 0::0) in the SCTPLNK MO whose CTRLMODE is set to MANUAL_MODE, PEERIP6 or SECPEERIP6 (when the value of SECPEERIP6 is not 0::0), LOCPORT, PEERPORT.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, TYPEFLAG in the EPGROUP MO must be set to COMMON.
  • Relation with the DFU MO:
    • [Co-MPT, eNodeB, gNodeB]When APPTYPE in the EPGROUP MO is set to eNodeB or gNodeB, APPTYPE in the DFU MO must have been set to the corresponding value.
  • Relation with the USERPLANEHOST, GTPU, and GEPMODELPARA MOs:
    • [Co-MPT, eNodeB, gNodeB]If a USERPLANEHOST MO with FLAG set to SLAVE is configured in an EPGROUP MO, then STATICCHK in the GTPU MO must be set to ENABLE. In addition, STATICCHKMODE in the GEPMODELPARA MO must be set to EPSTATICCHK, and STATICCHK in the EPGROUP MO must be set to ENABLE.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of EPGROUP MOs must be less than or equal to 8 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
  • Relation with the NODE MO:
    • [Co-MPT]An EPGROUP MO cannot be configured on a PRODUCTTYPE MO with PRODUCTTYPE set to DBS3900 DCU or DBS5900 DCU.

When this parameter is set to ENABLE(Enable), the GTP-U static detection function is enabled on all user-plane links in an endpoint group. Indicates whether to enable the IP PM session self-configuration function. If this parameter is set to ENABLE(Enable), the system will automatically generate IP PM sessions for links related to the local and peer end points. If this parameter is set to DISABLE(Disable), the system will not automatically generate IP PM sessions. If the value of this parameter is changed from ENABLE(Enable) to DISABLE(Disable) using the MOD EPGROUP command, the system will delete the automatically generated IP PM sessions for links related to the local and peer end points. This parameter is valid only for the user-plane links over the LTE S1 interface. IP PM is a Huawei proprietary protocol. Indicates the differentiated services code point (DSCP) of an IP PM session that is automatically generated by a base station. The parameter takes effect only in LTE.

Indicates the type of the application referenced by a DFU. The application provides the running environment for the DFU.

IP Protocol Version Preference

Indicates the IP protocol version that is preferentially used to automatically establish a control-plane link or user-plane path when the SCTP local IP address or user-plane local IP address in an EPGROUP MO is dual-stack and the IP address of the peer device is also dual-stack. If this parameter is set to IPv4, the IPv4 protocol is used to set up a control-plane link or user-plane path in the EPGROUP MO with the dual-stack peer device. If this parameter is set to IPv6, the IPv6 protocol is used to set up a control-plane link or user-plane path in the EPGROUP MO with the dual-stack peer device. Only one IP protocol can be selected to set up a control-plane link or user-plane path. IPv4 and IPv6 cannot be backed up for each other. This parameter is invalid when the local address or the IP address of the peer device is single-stack. This parameter takes effect only for LTE and NR.
