AAL2ADJNODE

TRANSPORT
  +-AAL2ADJNODE

Description

An AAL2ADJNODE MO is used to control the Access Link Control Application Part (ALCAP) protocol processing of a lower-level BS. The lower-level base station is cascaded under a hub base station based on the ATM Adaptation Layer Type 2 (AAL2).

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS]When TYPE in the MDU MO is set to MDUC, the AAL2ADJNODE MO cannot be configured.
  • Relation with the AAL2NODE MO:
    • [Co-MPT, NodeB]ADDR in an AAL2NODE MO must be different from that in an AAL2ADJNODE MO.
    • [Co-MPT, NodeB]An AAL2NODE MO and an AAL2ADJNODE MO cannot use the same SAALLNK MO.
    • [Co-MPT, NodeB]Before adding an AAL2ADJNODE MO, ensure that an AAL2NODE MO whose NT is set to HUB has been configured.
  • Relation with the SAALLNK MO:
    • [Co-MPT, NodeB]Before adding an AAL2ADJNODE MO, ensure that SAALNO in an SAALLNK MO is the same as LN in the AAL2ADJNODE MO under the same BS.
  • Relation with the AAL2ADJNODE MO:
    • [Co-MPT, NodeB]AAL2ADJNODE MOs cannot use the same SAALLNK MO.
    • [Co-MPT, NodeB]Each AAL2ADJNODE MO must have a unique value of ADDR.
  • Relation with the AAL2PATH MO:
    • [Co-MPT, NodeB]If NT in an AAL2PATH MO is set to ADJNODE, the AAL2ADJNODE MO whose ANI is the same as ANI in the AAL2PATH MO must have been configured.
  • Relation with the CPBEARER MO:
    • [Co-MPT, NodeB]When BEARTYPE in a CPBEARER MO is set to SAAL, the associated SAALLNK MO cannot be used by an AAL2ADJNODE MO. That is, LINKNO in the CPBEARER MO must be different from LN in the AAL2ADJNODE MO.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of AAL2ADJNODE MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD AAL2ADJNODE

Use this command to add an AAL2 adjacent node to a hub BS.

Multiple AAL2 adjacent nodes can be connected to a hub BS at the ATM adaptation layer type 2 (AAL2). It allows the hub BS to control access link control application part (ALCAP) processes of these AAL2 adjacent nodes.
DSP AAL2ADJNODE

Use this command to query the status of an adjacent AAL2 node of a hub BS.
LST AAL2ADJNODE

Use this command to list the adjacent AAL2 node configuration of the hub BS.
RMV AAL2ADJNODE

Use this command to dynamically remove an AAL2 adjacent node from a hub BS.
