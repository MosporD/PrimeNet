ND

  +-ND

Description

This object represents the IPv6 Neighbor Discovery Protocol.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    TRANSPORT

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP ND

Use this command to display the status of the IPv6 ND parameter entry.
LST ND

Use this command to list the configuration of an IPv6 ND parameter.
SET ND

Use this command to set IPv6 ND parameters.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Neighbor Discovery Reachable Time

Indicates the length of the timer for the reachable status of the neighbor discovery protocol entry in IPv6 transmission.
Table 3 Dynamic parameters

Parameter

Description
Interface ID

Indicates the index of the IPv6 interface.
VRF Index

Indicates the index of a VRF instance.
Destination IPv6 Address

Indicates the destination IPv6 address of the ND table entry.
VLANID

Indicates the VLAN ID of the ND table entry.
Neighbour State

Indicates the neighbor status of the ND table entry.
MAC Address

Indicates the MAC address of the ND table entry.
Neighbor Discovery Status Remaining Time

Indicates the remaining time of the ND entry reachable state when the neighbor state is reachable, and indicates the remaining time of the ND entry stale state when the neighbor state is stale.
