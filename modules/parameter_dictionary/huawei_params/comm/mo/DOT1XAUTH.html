DOT1XAUTH

TRANSPORT
  +-DOT1XAUTH

Description

This MO describes the parameters required during the 802.1x authentication of the BS. When the BS accesses the network, the 802.1x authentication is initiated according to the configuration of 802.1x if the network supports the 802.1X protocol.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the DOT1XAUTH MO cannot be configured.
  • Relation with the ETHPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The DOT1XAUTH MO associated with an ETHPORT MO must have been configured.
  • Relation with the DOT1XAUTH MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Any two DOT1XAUTH MOs must have different PORTID values.
  • Relation with the BBP and CASCADEPORT MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to AUTO, the PN parameter in the DOT1XAUTH MO configured for this board can only be set to 0.
  • Relation with the INTERFACE MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]TAGGED must be set to ENABLE if either of the following conditions is met: PORTID in the DOT1XAUTH MO is equal to PORTID in the INTERFACE MO, ITFTYPE is set to NORMAL, and PT is set to ETH; PORTID in the DOT1XAUTH MO is equal to ETHPORTID in the ETHTRUNKLNK MO, PORTID is equal to ETHTRKPORTID, ITFTYPE is set to NORMAL, and PT is set to ETHTRK.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of DOT1XAUTH MOs is 0 when the following conditions are met:
    • The Application MO is configured with AT set to GBTS.
    • The GTMU MO is configured with TYPE set to GTMU and BRDSPEC not set to "GTMUc" (case insensitive) or null.
    • The DOT1XAUTH MO is not configured with TYPE set to UMPT.
    • [Co-MPT, eGBTS]The number of DOT1XAUTH MOs does not exceed 48 when the following conditions are met:
    • The Application MO is configured with AT set to GBTS.
    • The GTMU MO is configured with TYPE set to GTMU and BRDSPEC set to "GTMUc" (case insensitive) or null.
    • The DOT1XAUTH MO is not configured with TYPE set to UMPT.

Function

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
802.1x Authentication ID

Indicates the ID of IEEE 802.1X authentication that is configured.
Port Type

Indicates the type of the port.
Port ID

Indicates the ID of the port on which IEEE 802.1X authentication is configured.
Authentic Method

Indicates the IEEE 802.1X authentication method. Currently, only Extensible Authentication Protocol Transport Layer Security (EAP-TLS), a unidirectional authentication method, is supported.
Table 3 Dynamic parameters

Parameter

Description
Cabinet No.

Indicates the number of the cabinet that provides the port on which IEEE 802.1X authentication is configured.
Subrack No.

Indicates the number of the subrack that provides the port on which IEEE 802.1X authentication is configured.
Slot No.

Indicates the number of the slot that provides the port on which IEEE 802.1X authentication is configured.
Authentic State

Indicates the status of IEEE 802.1X authentication. Possible states are as follows: UNAUTHENTICATED(Unauthenticated), AUTHENTICATING(Authenticating), AUTHENTIC_SUCCEED(Authenticate Succeed), AUTHENTIC_FAIL(Authenticate Fail), and DHCP_AUTHENTICATING(DHCP Activation Authenticating).
Authentic Succeed Number

Indicates the number of successful IEEE 802.1X authentications. The value of this parameter includes the successful IEEE 802.1X authentications during the DHCP process.
Fail Number

Indicates the number of IEEE 802.1X authentication failures. The value of this parameter includes the IEEE 802.1X authentication failures during the DHCP process.
Fail Reason

Indicates the cause of the latest IEEE 802.1X authentication failure or the latest unauthentication where the BS does not initiate the authentication. The value of this parameter is deleted after a successful IEEE 802.1X authentication.
Send EAP Packet Number

Indicates the number of transmitted Extensible Authentication Protocol (EAP) packets during the most recent IEEE 802.1X authentication.
Receive EAP Packet Number

Indicates the number of received Extensible Authentication Protocol (EAP) packets during the most recent IEEE 802.1X authentication.
Abnormal Packet Number

Indicates the number of abnormal packets received during the most recent IEEE 802.1X authentication.
