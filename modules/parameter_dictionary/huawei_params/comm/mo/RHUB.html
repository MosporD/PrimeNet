RHUB

EQUIPMENT
  +-RHUB
    +-ALMPORT[4~4]
    +-CPRIPORT[0~20]
    +-SFP[0~20]

Description

An RHUB MO consists of the configuration of an RRU HUB. The configuration contains the cabinet number, subrack number, slot number, chain/ring number, working mode, name, and other information about an RHUB.

Effective Scenario

Immediately

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the number of the cabinet where the RHUB is located.
Subrack No.

Indicates the number of the subrack where the RHUB is located.
Slot No.

Indicates the number of the slot where the RHUB is located.
RRU Chain No.

Indicates the ID of the RHUB chain. It uniquely identifies a chain within a base station.
RHUB Position

Indicates the position of the RHUB on the RRU chain/ring. It is calculated from the start port one by one.
RHUB Name

Indicates the name of the RHUB.
Location Name

Indicates the location information of an RHUB. Set this parameter to the location name of the site. The location name of the site is configured in a Location MO. Location names must be set to the same value for RF modules serving the same sector.
Ethernet Port 0 Rate

Indicates whether to configure the data rate of Ethernet port 0 on the RHUB. DISABLE indicates that the port is not used. You can set this parameter to other values to specify the data rate of this port.
Ethernet Port 1 Rate

Indicates whether to configure the data rate of Ethernet port 1 on the RHUB. DISABLE indicates that the port is not used. You can set this parameter to other values to specify the data rate of this port.
Ethernet Port 2 Rate

Indicates whether to configure the data rate of Ethernet port 2 on the RHUB. DISABLE indicates that the port is not used. You can set this parameter to other values to specify the data rate of this port.
Ethernet Port 3 Rate

Indicates whether to configure the data rate of Ethernet port 3 on the RHUB. DISABLE indicates that the port is not used. You can set this parameter to other values to specify the data rate of this port.
Maintenance Mode

Indicates the maintenance mode of an RHUB. The value INSTALL indicates device creation caused by network capability expansion, device reparenting, or access of a new device to the network. The value EXPAND indicates the subrack or carrier capacity expansion of a device. The value UPGRADE indicates a device upgrade. The value TESTING indicates that an installed device is being commissioned. ExpandStatus1 to ExpandStatus10 can be used by users to define maintenance modes. The default value of this parameter is NORMAL.
Start Time of Status Setting

Indicates the start time of maintenance status of the RHUB. This time refers to the local time (including the DST offset) on the NE. If this parameter is not specified, the start time of the maintenance status is 2000-01-01 00:00:00.
End Time of Status Setting

Indicates the end time of maintenance status of the RHUB. This time refers to the local time (including the DST offset) on the NE. If this parameter is not specified, the maintenance status ends at 2037-12-31 23:59:59.
Maintenance Mode Setting Remark

Indicates the remarks of maintenance status of the RHUB.
RHUB Specification

Indicates the type of an RHUB. This parameter needs to be set only when the MAE-Deployment is used for offline configuration. If this parameter is not set, the operation of the entire base station is not affected. Set this parameter based on the actual RHUB hardware type. The MAE-Deployment verifies the configuration based on the actual RHUB type. The MAE-Deployment can identify configuration errors before delivering the configuration to the base station, and display the main chain and branch chain ports of the RHUB based on the configuration type on the device panel. The value of this parameter must be the same as the hardware type of the RHUB. For example, for the RHUB5921 module, the value of this parameter is RHUB5921; for the RHUB5961 module, the value of this parameter is RHUB5961.

NORMAL indicates that the main control and transmission board works in normal mode. TDS-EVOLUTION indicates that the main control and transmission board works in TDS evolution mode. NULL is displayed for boards other than GTMU or when the working mode cannot be queried.
