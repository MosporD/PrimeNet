RAESUBUNIT

EQUIPMENT
  +-RAE
    +-RAESUBUNIT
      +-RAEDEVICEDATA[1~1]

Description

The RAE Subunit MO is the smallest unit that stores information about the antenna.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RAE

  • Possible children:

    RAEDEVICEDATA[1~1]
  • Relation with the RAE MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of RAESUBUNIT MOs configured on one RAE MO must be greater than or equal to 1 and smaller than or equal to 6.
  • Relation with the RAEDEVICEDATA MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of RAEDEVICEDATA MOs configured on one RAESUBUNIT MO must be 1.
  • Relation with the RRU, RFU, and AAMU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The RRU, RFU, or AAMU MO corresponding to CONNCN, CONNSRN, and CONNSN in the RAESUBUNIT MO must have been configured.
  • Relation with the RRU and RFU MOs:
    • [gNodeB]The RRU or RFU MO corresponding to CONNCN, CONNSRN, and CONNSN in the RAESUBUNIT MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DLD RAEFILE

Use this command to download the weighting factor file to the Remote eAntenna Extension (RAE).
DSP RAEFILE

Use this command to query the information about the Remote eAntenna Extension (RAE) files.
DSP RAEFUNCTION

Use this command to query the functions supported by the Remote eAntenna Extension (RAE).
DSP RAESUBUNIT

Use this command to query the dynamic information about a Remote eAntenna Extension (RAE) subunit.
DSP RAEWEIGHT

Use this command to query the weighting factor information of the Remote eAntenna Extension (RAE).
LST RAESUBUNIT

Use this command to list the configuration of a Remote eAntenna Extension (RAE) subunit.
MOD RAESUBUNIT

Use this command to modify a Remote eAntenna Extension (RAE) subunit.
RST RAEFILE

Use this command to restore Remote eAntenna Extension (RAE) files to default configuration.
ULD RAEFILE

Use this command to upload the weighting factor file and antenna pattern file to the Remote eAntenna Extension (RAE).

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Device No.

Indicates the device number of the RAE.
Subunit No.

Indicates the number of the RAE subunit, which starts from 1.
Subunit Name

Indicates the name of the RAE subunit. The name of the RAE subunit is optional, but the name configured for each RAE subunit must be unique.
Connect Port Cabinet No.

Indicates the cabinet number of the RRU or RFU that provides the antenna port to which the RAE subunit is connected.
Connect Port Subrack No.

Indicates the subrack number of the RRU or RFU that provides the antenna port to which the RAE subunit is connected.
Connect Port Slot No.

Indicates the slot number of the RRU or RFU that provides the antenna port to which the RAE subunit is connected.
