DIESELGEN

EQUIPMENT
  +-CABINET
    +-SUBRACK
      +-PMU
        +-DIESELGEN

Description

The DIESELGEN MO is a diesel generator. In the combined solar power supply mode of light and oil, the diesel generator provides power supply to the base station when the solar power system fails.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    PMU
  • Relation with the PMU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The PMU MO corresponding to CN, SRN, and SN in the DIESELGEN MO must have been configured and PTYPE in the PMU MO must be SC48200.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Only a PMU MO with PTYPE set to SC48200 can be configured with a lower-level DIESELGEN MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of DIESELGEN MOs configured on one PMU MO must be greater than or equal to 0 and smaller than or equal to 1.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD DIESELGEN

Use this command to add a diesel generator. The diesel generator is compatible only with the SC48200 power monitoring unit (PMU).
DSP DIESELGEN

Use this command to query the dynamic information about a diesel generator.
LST DIESELGEN

Use this command to list the configuration of a diesel generator.
MOD DIESELGEN

Use this command to modify the configuration of a diesel generator.
RMV DIESELGEN

Use this command to remove a diesel generator.
STP DIESELGENTST

Use this command to stop the ongoing diesel generator test. This command is applicable only to a diesel generator test that is performed on the SC48200 power monitoring unit (PMU).
STR DIESELGENTST

Use this command to start the diesel generator test immediately. If this command fails, an alarm indicating the diesel generator startup failure is reported. This command is applicable only to a diesel generator test that is performed on the SC48200 power monitoring unit (PMU).

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the number of the cabinet where the PMU managing the diesel generator is located.
Subrack No.

Indicates the number of the subrack where the PMU managing the diesel generator is located.
Slot No.

Indicates the number of the slot where the PMU managing the diesel generator is located.
Intelligent Control Flag

Indicates whether intelligent control of the diesel generator is enabled. When intelligent control is enabled, the PMU automatically controls the diesel generator according to the preset parameters, thus reducing the operation cost of the diesel generator.
Rated Power

Indicates the maximum rated output power of the diesel generator. It should be configured according to the rated output power printed on the nameplate of the diesel generator.
Table 3 Dynamic parameters

Parameter

Description
Oil Level

Indicates the oil level of the diesel generator.
Diesel Generator Current

Indicates the current of the diesel generator.
Total Running Time

Indicates the total running time of the diesel generator.
