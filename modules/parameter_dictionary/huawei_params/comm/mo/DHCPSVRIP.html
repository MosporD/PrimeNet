DHCPSVRIP

TRANSPORT
  +-DHCPSVRIP

Description

The DHCPSVRIP MO provides the IP address of the DHCP server. The DHCPSVRIP MO is used to specify the DHCP server for the DHCP relay function. Therefore, the lower level BS is able to communicate with the DHCP server through this BS.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the OMCH, DEVIP, PPPLNK, MPGRP, IFIP, and GTRANSPARA MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, and MODELSELECT of GTRANSPARA MO is set to TRADITION, the DHCPRELAYIP parameter in the DHCPSVRIP MO must be set to a valid IP address, and this IP address must be equal to any one value of the following parameters: IP in OMCH MO, IP in DEVIP MO, LOCALIP in PPPLNK MO, or LOCALIP in MPGRP MO. If MODELSELECT of GTRANSPARA MO is set to HOSTGW, the DHCPRELAYIP parameter in the DHCPSVRIP MO must be set to a valid IP address, and this IP address must be equal to any one value of the following parameters: IP in OMCH MO, IP in IFIP MO, LOCALIP in PPPLNK MO, or LOCALIP in MPGRP MO.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, DHCPRELAYIPSW in the DHCPSVRIP MO must be set to DISABLE.
  • Relation with the OMCH, IPADDR4, PPPLNK, MPGRP, and GTRANSPARA MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, and DHCPRELAYIPSW of DHCPSVRIP is set to ENABLE, DHCPRELAYIP parameter in the DHCPSVRIP MO must be set to a valid IP address, and this IP address must be equal to any one value of the following parameters: IP in OMCH MO in the same routing domain, IP in IPADDR4 MO in the same routing domain, LOCALIP in PPPLNK MO in the same routing domain, or LOCALIP in MPGRP MO in the same routing domain.
  • Relation with the OMCH, DEVIP, IFIP, and GTRANSPARA MOs:
    • [gNodeB]If MODELSELECT of GTRANSPARA is set to TRADITION, the DHCPRELAYIP parameter in the DHCPSVRIP MO must be set to a valid IP address, and this IP address must be equal to any one value of the following parameters: IP in OMCH MO, IP in DEVIP MO. If MODELSELECT of GTRANSPARA is set to HOSTGW, the DHCPRELAYIP parameter in the DHCPSVRIP MO must be set to a valid IP address, and this IP address must be equal to any one value of the following parameters: IP in OMCH MO, IP in IFIP MO.
  • Relation with the OMCH, IPADDR4, and GTRANSPARA MOs:
    • [gNodeB]When TRANSCFGMODE in a GTRANSPARA MO is set to NEW, DHCPRELAYIP parameter in the DHCPSVRIP MO must be set to a valid IP address, and this IP address must be equal to any one value of the following parameters: IP in OMCH MO in the same routing domain, IP in IPADDR4 MO in the same routing domain.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD DHCPSVRIP

Use this command to add the IP address of a DHCP server.
LST DHCPSVRIP

Use this command to list the configuration of the DHCP server IP address.
MOD DHCPSVRIP

Use this command to modify the settings of DHCP Relay IP Switch and DHCP Relay IP for the IP address of the DHCP server.
RMV DHCPSVRIP

Use this command to remove the IP address of a DHCP server.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
DHCP Server IP Address

Indicates the IP address of the DHCP server.
DHCP Relay IP Switch

Indicates whether to enable or disable the DHCP relay IP address. When this parameter is set to ENABLE, the DHCP relay IP address can be configured.
DHCP Relay IP

Indicates the DHCP relay IP address. When this parameter is configured, the base station uses it as the source IP address of the DHCP relay.
