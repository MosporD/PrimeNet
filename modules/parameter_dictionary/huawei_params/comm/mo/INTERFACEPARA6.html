INTERFACEPARA6

TRANSPORT
  +-INTERFACEPARA6

Description

A INTERFACEPARA6 MO is used to configure the parameters of interface.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the INTERFACEPARA6 MO cannot be configured.
  • Relation with the INTERFACE MO:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE in a GTRANSPARA MO is set to NEW, the IPV6SW in INTERFACE MO must be set ENABLE.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD INTERFACEPARA6

Use this command to add IPv6 parameters of interface.
LST INTERFACEPARA6

Use this command to list IPv6 parameters of interface.
MOD INTERFACEPARA6

Use this command to modify IPv6 parameters of interface.
RMV INTERFACEPARA6

Use this command to remove IPv6 parameters of interface.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Interface ID

Indicates the ID of an interface.
SEND Switch

Indicates whether the interface opens the Send protocol and currently only supports the Nonce and Timestamp mechanisms.
SEND Delta

Indicates the maximum difference between the moment when the ND message is received by the local side and the time at which the ND message is sent to the peer.
SEND Drift

Indicates the percentage of the maximum value of the receiver-to-sender system time difference value.
SEND Fuzz-Factor

Indicates the maximum time to live for a message.if the time at which the ND message is received by the local side is greater than delta-value, but within the Fuzz-value time range, it can still be received by the interface.
DHCPv6 Relay Switch

Indicates whether to enable the DHCPv6 relay function on an interface. If this parameter is set to ON, the interface can receive multicast packets of DHCPv6 requests sent by lower-level base stations.
