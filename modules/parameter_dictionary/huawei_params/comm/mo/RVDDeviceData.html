RVDDEVICEDATA

EQUIPMENT
  +-RVD
    +-RVDSUBUNIT
      +-RVDDEVICEDATA

Description

The RVDeviceData MO refers to the configuration saved in the antenna and the capability supported by the antenna. For details, see 3GPP TS25.466 and AISG2.0.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RVDSUBUNIT
  • Relation with the RVDSUBUNIT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of RVDDEVICEDATA MOs configured on one RVDSUBUNIT MO must be 1.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP RVDDEVICEDATA

Use this command to query the dynamic information in the remote vendor-defined antenna line device (RVD) data.
LST RVDDEVICEDATA

Use this command to list the configuration in the remote vendor-defined antenna line device (RVD) data.
MOD RVDDEVICEDATA

Use this command to modify the configuration in the remote vendor-defined antenna line device (RVD) data.
