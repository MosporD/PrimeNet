INTERFACE

TRANSPORT
  +-INTERFACE
    +-IPADDR4[0~128]

Description

An INTERFACE MO is used to configure IP-layer interfaces, classify these interfaces into normal interfaces and VLAN subinterfaces, and configure IP addresses and packet filtering.

Effective Scenario

Immediately

    TRANSPORT

  • Relation with the IPCLKLNK, IPADDR4, LOOPBACK, ETHPORT, ETHTRUNK, and ETHTRUNKLNK MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, an IPADDR4 MO corresponding to the IPCLKLNK MO with DEVTYPE set to OC_SLAVE must have been configured and the following conditions must be met:
    • 1. The value of CIP in the IPCLKLNK MO is the same as that of IP in the IPADDR4 MO, and The value of VRFIDX in the IPCLKLNK MO is the same as that of VRFIDX in the IPADDR4 MO.
    • 2. The value of ITFID in the IPADDR4 MO that meets condition 1 is the same as that of ITFID in an INTERFACE MO. In this INTERFACE MO, PT is set to LOOPINT, ETH, or ETHTRK.
    • 3. If PT in the INTERFACE MO that meets condition 2 is set to LOOPINT, the value of PORTID in this INTERFACE MO is the same as that of PORTID in an LOOPBACK MO. In addition, the values of CN, SRN, and SN in this LOOPBACK MO are the same as those of CN, SRN, and SN in the IPCLKLNK MO.
    • 4. If PT in the INTERFACE MO that meets condition 2 is set to ETH, the value of PORTID in this INTERFACE MO is the same as that of PORTID in an ETHPORT MO. In addition, the values of CN, SRN, and SN in this ETHPORT MO are the same as those of CN, SRN, and SN in the IPCLKLNK MO.
    • 5. If PT in the INTERFACE MO that meets condition 2 is set to ETHTRK, the value of PORTID in this INTERFACE MO is the same as that of PORTID in an ETHTRUNK MO.
    • 6. The value of PORTID in the ETHTRUNK MO that meets condition 5 is the same as that of ETHTRKPORTID in an ETHTRUNKLNK MO.
    • 7. The value of ETHPORTID in the ETHTRUNKLNK MO that meets condition 6 is the same as that of PORTID in an ETHPORT MO. In addition, the values of CN, SRN, and SN in this ETHPORT MO are the same as those of CN, SRN, and SN in the IPCLKLNK MO.

    • [gNodeB]In an SCTPHOST MO, if SIGIP1SECSWITCH is set to ENABLE, SIGIP1V4 must be configured on the same board as LOCIKEIPV4 in a referenced SCTPHOST MO.
    • [gNodeB]In an SCTPHOST MO, if SIGIP2SECSWITCH is set to ENABLE, SIGIP2V4 must be configured on the same board as LOCIKEIPV4 in a referenced SCTPHOST MO.
  • Relation with the USERPLANEHOST, IPADDR4, SECURITYHOST, ETHPORT, ETHTRUNKLNK, LOOPBACK, and GTRANSPARA MOs:
    • [gNodeB]If IPSECSWITCH is set to ENABLE for a USERPLANEHOST MO, LOCIPV4 for the USERPLANEHOST MO must be configured on the same board as LOCIKEIPV4 for the referenced SECURITYHOST MO.
