ACLRULE6

TRANSPORT
  +-ACL6
    +-ACLRULE6

Description

This MO is used to define the rules in an IPv6 access control list (ACL). The BS identifies and classifies data flows based on the rules.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    ACL6
  • Relation with the ACLRULE6 MO:
    • [Co-MPT, eNodeB, gNodeB]Each ACLRULE6 MO with CTRLMODE set to MANUAL_MODE in one ACL6 MO must have a unique configuration. Two ACLRULE6 MOs have the same configuration if all the following conditions are met: SIP and DIP in one ACLRULE6 MO are on the same network segments as those in the other MO, respectively; The prefix lengths of SIP and DIP in one ACLRULE6 MO are the same those in the other MO, respectively; The two ACLRULE6 MOs have the same combination of ACTION, PT, SMPT, SOP, SPT1, SPT2, DMPT, DOP, DPT1, DPT2, MDSCP, and DSCP.
    • [Co-MPT, eNodeB, gNodeB]A maximum of 256 ACLRULE6 MOs can be configured in an ACL6 MO.
    • [Co-MPT, eNodeB, gNodeB]The number of ACLRULE6 MOs with CTRLMODE set to MANUAL_MODE cannot exceed 320.
  • Relation with the IPSECPOLICY MO:
    • [Co-MPT, eNodeB, gNodeB]The ACL6 MO corresponding to an IPSECPOLICY MO must have at least one ACLRULE6 MO.
    • [Co-MPT, eNodeB, gNodeB]If an ACLRULE6 MO is referenced by an IPSECPOLICY MO, neither SOP nor DOP in the ACLRULE6 MO can be set to OP_NEQ.
    • [Co-MPT, eNodeB, gNodeB]If an ACLRULE6 MO is referenced by the IPSECPOLICY MO, MDSCP in the ACLRULE6 MO must be set to NO.
    • [Co-MPT, eNodeB, gNodeB]If ACLTYPE in an IPSECPOLICY MO is set to IPV6, ACTION in the ACLRULE6 MO used by the IPSECPOLICY MO must be set to PERMIT.
  • Relation with the ACLRULE MO:
    • [Co-MPT, eNodeB, gNodeB]On a BS, the total number of ACLRULE MOs and ACLRULE6 MOs must be less than or equal to 6092.
  • Relation with the IPSECBINDITF and IPSECPOLICY MOs:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in an IKEPEER MO in the IPSECPOLICY MO referenced by an IPSECBINDITF MO is set to IPV6, ACTION in the associated ACLRULE6 MO must be set to PERMIT.
  • Relation with the PACKETFILTERING and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]If ACLTYPE and MB in a PACKETFILTERING MO are set to IPV6 and DENY respectively, and if PT in the INTERFACE MO corresponding to PORTID is not set to TUNNELITF, then at least one ACLRULE6 MO with ACTION set to PERMIT and PT set to IP6 or ICMP6 exists in the ACL6 MO referenced by the PACKETFILTERING MO.
  • Relation with the PACKETFILTERING MO:
    • [Co-MPT, eNodeB, gNodeB]If ACLAUTOSWITCH is set to OFF, and FM in a PACKETFILTERING MO is set to ADV_ACL, and ACLTYPE in a PACKETFILTERING MO is set to IPV6, at least one ACLRULE6 MO which is created manually is included in the ACL6 MO corresponding to ACLID.
  • Relation with the IPSECPOLICY and ACL6 MOs:
    • [Co-MPT, eNodeB, gNodeB]If an ACL6 MO is referenced by an IPSECPOLICY MO with ACLTYPE set to IPV6, the ACL6 MO does not allow two ACLRULE6 MOs with the same SIP, SPFXLEN, DIP, and DPFXLEN values and with the protocol types being inclusive of each other. That is, if an ACLRULE6 MO with the protocol type being IPv6 has been configured, no ACLRULE6 MO with the protocol type being TCP, UDP, ICMP6, or SCTP can be configured.
    • [Co-MPT, eNodeB, gNodeB]If an ACL6 MO is referenced by an IPSECPOLICY MO with ACLTYPE set to IPV4+IPV6, the ACL6 MO does not allow two ACLRULE6 MOs with the same SIP, SPFXLEN, DIP, and DPFXLEN values and with the protocol types being inclusive of each other. That is, if an ACLRULE6 MO with the protocol type being IPv6 has been configured, no ACLRULE6 MO with the protocol type being TCP, UDP, ICMP6, or SCTP can be configured.
  • Relation with the MDU MO:
    • [Co-MPT, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, the ACLRULE6 MO cannot be configured.
  • Relation with the IPSECPOLICY and ACLRULE MOs:
    • [Co-MPT, eNodeB, gNodeB]If ACLTYPE in an IPSECPOLICY MO is set to IPV4+IPV6, the ACL6 MO associated with the IPSECPOLICY MO must contain an ACLRULE6 MO, and the ACL MO associated with the IPSECPOLICY MO must contain an ACLRULE MO.
    • [Co-MPT, eNodeB, gNodeB]If ACLTYPE in an IPSECPOLICY MO is set to IPV4+IPV6, ACTION in the ACLRULE MO and ACTION in the ACLRULE6 MO used by the IPSECPOLICY MO must be set to PERMIT.
  • Relation with the PACKETFILTERING, INTERFACE, IPADDR6, and LOOPBACK MOs:
    • [Co-MPT, eNodeB]A maximum of 64 ACLRULE6 MOs can be referenced by PACKETFILTERING on a board.
    • [gNodeB]A maximum of 64 ACLRULE6 MOs can be referenced by PACKETFILTERING on a board.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of ACLRULE6 MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function

Use this command to add a rule to an IPv6 access control list (ACL).
DSP ACLRULE6

Use this command to query the information about the effective IPv6 ACL rules.
LST ACLRULE6

Use this command to list the configuration of an IPv6 access control list (ACL) rule.
MOD ACLRULE6

Use this command to modify an IPv6 Access Control List (ACL) rule.
RMV ACLRULE6

Use this command to remove an ACL rule from an IPv6 ACL.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IPv6 ACL ID

Indicates the ID of an IPv6 access control list (ACL) to which the IPv6 access control rule belongs.
IPv6 Rule ID

Indicates the ID of an IPv6 ACL rule. The values 1 to 65535 indicate IPv6 ACL rules configured by users. The values 65431 to 65536 indicate the IPv6 ACL rules automatically generated during DHCP detection. The values 70000 to 79999 indicate packet filtering IPv6 ACL rules configured by the system (packet filtering ACL rules are not supported in IPv6 configuration currently). The values 80000 to 89999 indicate IPv6 IPsec ACL rules configured by the system.
IPv6 ACL Action

Indicates the action taken on the data that matches an IPv6 ACL rule. When the IPv6 ACL rule is referenced by an IPv6 IPSec policy, the BS encrypts or decrypts the data that matches the rule if this parameter is set to PERMIT, and does not encrypt or decrypt the data if this parameter is set to DENY.
Protocol Type

Indicates the protocol type of the data to which an IPv6 ACL rule is applied.
Source IPv6 Address

Indicates the source IPv6 address of data to which an IPv6 ACL rule is applied.
Source Address Prefix Length

Indicates the prefix length of a source IPv6 address. The prefix length is used to determine which bits must be compared for matching when IPv6 address matching is being performed.
Match Source Port

Indicates whether to check the source port number of each data stream before applying an ACL rule.
Source Port Operate

Indicates the filter criteria for a source port. If this parameter is set to OP_LT, the ACL rule is applied to the data stream whose source port number is smaller than or equal to the configured port number. If this parameter is set to OP_GT, the ACL rule is applied to the data stream whose source port number is larger than or equal to the configured port number. If this parameter is set to OP_EQ, the ACL rule is applied to the data stream whose source port number is equal to the configured port number. If this parameter is set to OP_NEQ, the ACL rule is applied to the data stream whose source port number is not equal to the configured port number. If this parameter is set to OP_RANGE, the ACL rule is applied to the data stream whose source port number is within the configured range.
Source Port 1

Indicates the source port number used when SMPT is set to YES. If SOP is set to OP_RANGE, this parameter indicates the smallest source port number. If SOP is not set to OP_RANGE, this parameter indicates a specific source port number.
Source Port 2

Indicates the source port number used when SMPT is set to YES. If SOP is set to OP_RANGE, this parameter indicates the largest source port number. This parameter is valid only when SOP is set to OP_RANGE.
Destination IPv6 Address

Indicates the destination IPv6 address of the data to which an IPv6 ACL rule is applied.
Destination Address Prefix Length

Indicates the prefix length of a destination IPv6 address. The prefix length is used to determine which bits must be compared for matching when IPv6 address matching is being performed.
Match Destination Port

Indicates whether to check the destination port number of each data stream before applying an ACL rule.
Destination Port Operate

Indicates the filter criteria for a destination port. This parameter is valid only when DMPT is set to YES. If this parameter is set to OP_LT, the ACL rule is applied to the data stream whose destination port number is smaller than or equal to the configured port number. If this parameter is set to OP_GT, the ACL rule is applied to the data stream whose destination port number is larger than or equal to the configured port number. If this parameter is set to OP_EQ, the ACL rule is applied to the data stream whose destination port number is equal to the configured port number. If this parameter is set to OP_NEQ, the ACL rule is applied to the data stream whose destination port number is not equal to the configured port number. If this parameter is set to OP_RANGE, the ACL rule is applied to the data stream whose destination port number is within the configured range.
Destination Port 1

Indicates the destination port number used when DMPT is set to YES. If DOP is set to OP_RANGE, this parameter indicates the smallest destination port number. If DOP is not set to OP_RANGE, this parameter indicates a specific destination port number.
Destination Port 2

Indicates the destination port number used when DMPT is set to YES. If DOP is set to OP_RANGE, this parameter indicates the largest destination port number. This parameter is valid only when DOP is set to OP_RANGE.
Match DSCP

Indicates whether to check the DSCP of each data stream before applying an IPv6 ACL rule.
DSCP

Indicates the DSCP that complies with an IPv6 ACL rule.
Control Mode

Indicates whether an object can be modified or deleted by the system. The value MANUAL_MODE means that only the user can modify or delete the object. The value AUTO_MODE means only the system can modify or delete the object.
Auto Config Flag

Indicates whether the object is created by the system. MANUAL_CREATED means that the object is configured by the user manually. AUTO_CREATED means that the object is created by the system.
Table 3 Dynamic parameters

Parameter

Description
Number of ACL6 Rules

Indicates the number of rules in the ACL6.
Minimum ACL6 Rule ID
