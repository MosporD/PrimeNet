USERPLANEHOST

TRANSPORT
  +-USERPLANEHOST

Description

This MO is used to configure information related to a user-plane host. When the user plane is set up automatically, the system automatically sets up a user-plane link between the configured user-plane host and a user-plane peer. The user-plane peer can be manually configured or automatically generated by the system.

Effective Scenario

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
User Plane Host ID

Indicates the ID of the user-plane host.
VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).
IP Version

Indicates the version of the user-plane host IP address.
Multicast Listener Switch

Indicates whether the user-plane host endpoint object is used for multicast listening. When this switch is turned on, the user-plane host endpoint object is used for multicast listening, and the corresponding interface ID needs to be specified. When this switch is turned off, the user-plane host endpoint object is not used for multicast listening and is used only for unicast services, requiring that the local IPv6 address be configured.
Interface ID

Indicates the ID of the interface enabled with multicast listening in an IPv6 network.
Local IP Address

Indicates the IPv4 Address of the user plane host.
Local IPv6 Address

Indicates the IPv6 Address of the user plane host. This parameter takes effect only in LTE and NR.
IPSec Auto Configure Switch

Indicates whether to enable automatic user-plane IPsec tunnel setup based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. If this parameter is set to ENABLE, an IPsec tunnel is automatically set up to encrypt transmitted data. If this parameter is set to DISABLE, no IPsec tunnel is automatically set up. If the value of this parameter is changed from ENABLE to DISABLE using the MOD USERPLANEHOST command, the system deletes the automatically set up IPsec tunnel.
Security Host ID

Indicates the security host ID used by the user-plane host.
User Label

Indicates the information about a user-plane local.
Master Flag

Indicates whether a user-plane host is active or standby. This parameter takes effect only for LTE and NR.

Currently, only the S1/GNBCUS1/NG interface supports the standby user-plane host.
