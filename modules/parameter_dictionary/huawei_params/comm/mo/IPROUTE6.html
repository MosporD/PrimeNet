IPROUTE6

TRANSPORT
  +-IPROUTE6

Description

The IPROUTE6 is a static IPv6 route, which is used for data forwarding through a routing table.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the MDU MO:
    • [Co-MPT, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, the IPROUTE6 MO cannot be configured.
  • Relation with the VRF MO:
    • [Co-MPT, eNodeB, gNodeB]If CTRLMODE in an IPROUTE6 MO is set to MANUAL_MODE, the VRF MO associated with an IPROUTE6 MO must have been configured.
  • Relation with the IPADDR6 MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, IPV6 in an IPADDR6 MO must be different from NEXTHOP in an IPROUTE6 MO.
    • [Co-MPT, eNodeB, gNodeB]If the next hop address of an IPROUTE6 MO is a global unicast address, an IPADDR6 MO must be in the same routing domain and on the same network segment as the global unicast address but different from the global unicast address.
  • Relation with the IPROUTE6 MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, IPROUTE6 MO with load sharing is not supported on a BS.
    • [Co-MPT, eNodeB, gNodeB]A route specified by the IPROUTE6 MO with the value of RTTYPE set to NEXTHOP cannot form a pair of active and standby routes with a route specified by the IPROUTE6 MO with the value of RTTYPE set to IF.
    • [Co-MPT, eNodeB, gNodeB]Each IPROUTE6 MO must have a unique combination of VRFIDX, DSTIP, PFXLEN, RTTYPE, ITFID, and NEXTHOP.
    • [Co-MPT, eNodeB, gNodeB]The number of IPROUTE6 MOs with CTRLMODE set to MANUAL_MODE cannot exceed 128.
  • Relation with the INTERFACE MO:
    • [Co-MPT, eNodeB, gNodeB]If the RTTYPE in the IPROUTE6 MO is set to IF, the INTERFACE MO corresponding to ITFID in the IPROUTE6 MO must have been configured.
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an IPROUTE6 MO is set to IF, PT in the INTERFACE MO corresponding to ITFID in the IPROUTE6 MO must be set to TUNNELITF or ETH or ETHTRK.
    • [Co-MPT, eNodeB, gNodeB]In an IPROUTE6 MO, if RTTYPE and CTRLMODE are set to IF and MANUAL_MODE, respectively, VRFIDX in the IPROUTE6 MO must be the same as VRFIDX in the associated INTFERFACE MO.
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE and CTRLMODE in an IPROUTE6 MO are set to IF and MANUAL_MODE, respectively, CTRLMODE in the INTERFACE MO cannot be set to AUTO_MODE.
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an IPROUTE6 MO is set to NEXTHOP, NEXTHOP in the IPROUTE6 MO is on the same network segment as IPADDR6 MO of an INTERFACE MO with PT set to ETH or ETHTRK, and CTRLMODE in the IPROUTE6 MO is set to MANUAL_MODE, CTRLMODE in the INTERFACE MO cannot be set to AUTO_MODE.
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, two IPROUTE6 MOs with RTTYPE set to IF cannot form active and stand routes if PT is set to ETH or ETHTRK in the INTERFACE MO corresponding to ITFID in one IPROUTE6 MO, and if PT is set to TUNNELITF in the INTERFACE MO corresponding to ITFID of the other IPROUTE6 MO.
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an IPROUTE6 MO is set to IF and PT in the INTERFACE MO corresponding to ITFID in the IPROUTE6 MO is set to ETH, IPV6SW in the INTERFACE MO corresponding to ITFID in the IPROUTE6 MO must be set to DISABLE.
  • Relation with the INTERFACE and PMTUCFG MOs:
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an IPROUTE6 MO is set to IF, PT in the INTERFACE MO corresponding to ITFID in the IPROUTE6 MO is set to ETH or ETHTRK, and IPV6SW in the INTERFACE MO is set to ENABLE, then MODE in the PMTUCFG MO must not be set to ACTIVE.
  • Relation with the OMCH MO:
    • [Co-MPT, eNodeB, gNodeB]If BEAR in an OMCH MO is set to IPv6 and BRT in the OMCH MO is set to YES, RTIDX in the OMCH MO must have been configured. That is, the value of RTIDX in an OMCH MO is the same as the value of RTIDX in an IPROUTE6 MO in the same routing domain.
    • [Co-MPT, eNodeB, gNodeB]If BEAR in an OMCH MO is set to IPv6 and BINDSECONDARYRT in the OMCH MO is set to YES, SECONDARYRTIDX in the OMCH MO must have been configured. That is, the value of SECONDARYRTIDX in an OMCH MO is the same as the value of RTIDX in an IPROUTE6 MO in the same routing domain.
    • [Co-MPT, eNodeB, gNodeB]If BEAR in an OMCH MO is set to IPv6, the value of NEXTHOP in an IPROUTE6 MO in the same routing domain must be different from the value of IP6 in the OMCH MO.
    • [Co-MPT, eNodeB, gNodeB]If BEAR in an OMCH MO is set to IPv6 and BRT in the OMCH MO is set to YES, the address specified by PEERIP6 in the OMCH MO must be on the same network segment as the address specified by DSTIP in the bound active IPROUTE6 MO.
  • Relation with the IPSECPOLICY and IPSECBINDITF MOs:
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an IPROUTE6 MO is set to IF, ACLTYPE in the IPSECPOLICY MO that is bound to the same IPSECBINDITF MO as the INTERFACE MO corresponding to ITFID in the IPROUTE6 MO must be set to IPV6 or IPV4+IPV6.
  • Relation with the IPADDR6 and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, the IPv6 address specified by NEXTHOP in the IPROUTE6 MO must be on the same network segment as the IPv6 address specified by IPV6 in the IPADDR6 MO that is configured on the INTERFACE MO with PT set to ETH or ETHTRK.
  • Relation with the INTERFACE and SECURITYTEMPLATE MOs:
    • [Co-MPT, eNodeB, gNodeB]If CTRLMODE in an IPROUTE6 MO is set to MANUAL_MODE, RTTYPE is set to IF, and PT in the INTERFACE MO corresponding to ITFID is set to TUNNELITF, PREF must be greater than PREF in the SECURITYTEMPLATE MO.
  • Relation with the OMCH and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]If BEAR in both the active and standby OMCH MOs is set to IPV6 and BRT in either OMCH MO references an IPROUTE6 MO in which RTTYPE is set to IF, PT in the INTERFACE MO corresponding to ITFID in the IPROUTE6 MO cannot be set to ETH or ETHTRK.
    • [Co-MPT, eNodeB, gNodeB]If BEAR in both the active and standby OMCH MOs is set to IPV6 and BINDSECONDARYRT in either OMCH MO references an IPROUTE6 MO in which RTTYPE is set to IF, PT in the INTERFACE MO corresponding to ITFID in the IPROUTE6 MO cannot be set to ETH or ETHTRK.
  • Relation with the IPSECBINDITF, IPSECPOLICY, and IKEPEER MOs:
    • [Co-MPT, eNodeB, gNodeB]When RTTYPE is set to IF in an IPROUTE6 MO, the INTERFACE MO specified by ITFID cannot be bound to the IPSECPOLICY MO that references an IKEPEER MO with REDUNDANCYFLAG set to SLAVE and IPVERSION set to IPV6.
    • [Co-MPT, eNodeB, gNodeB]In an IKEPEER MO referenced by an IPSECBINDITF MO, if REDUNDANCYFLAG is set to SLAVE and IPVERSION is set to IPV6, and if an IPROUTE6 MO with RTTYPE set to IF has been configured on the master IPSECBINDITF MO, the total number of configured IPROUTE6 MOs and all slave IPSECBINDITF MOs (with active IPSECBINDITF MOs configured with IPROUTE6 MOs in the same IPSec redundancy group) cannot exceed 128.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of IPROUTE6 MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Route Index

Indicates the index of a static IPv6 route. The value of RTIDX in the IPROUTE6 MOs configured by users ranges from 0 to 127. The value of RTIDX in the IPROUTE6 MOs configured by the system ranges from 10000 to 19999.
VRF Index

Indicates the index of a VRF instance.
Destination IPv6 Address

Indicates the destination IPv6 address of a static IPv6 route.
Prefix Length

Indicates the prefix length of the destination IPv6 address of a static IPv6 route.
Route Type

Indicates the type of IPv6 route. If this parameter is set to NEXTHOP, all the IP packets that meet the route direction are first forwarded to the specified next-hop IPv6 address. If this parameter is set to IF, all the IP packets that meet the route direction are first forwarded to the specified egress port.In IPv6 secure encryption and decryption scenarios, the outbound tunnel interface for incoming packets must be specified.
Next-Hop IPv6 Address

Indicates the next-hop IPv6 address of a static IPv6 route.
Interface ID

Indicates the ID of the IPv6 interface to which a static IPv6 route belongs. The value of ITFID in the IPROUTE6 MOs configured by users ranges from 0 to 1499. The value of ITFID in the IPROUTE6 MOs configured by the system ranges from 10000 to 19999.
Preference

Indicates the priority of a static IPv6 route. A smaller parameter value indicates a higher priority.
User Label

Indicates the user-defined information.
Control Mode

Indicates whether the object can be automatically modified or removed by the system. When this parameter is set to MANUAL_MODE, only users can perform operations on the object. When this parameter is set to AUTO_MODE, only the system can perform operations on the object.
Table 3 Dynamic parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the board to which an IPv6 route belongs.
Subrack No.

Indicates the subrack number of the board to which an IPv6 route belongs.
Slot No.

Indicates the slot number of the board to which an IPv6 route belongs.
Actual Port Type

Indicates the type of the actual port.
Actual Port No.

Indicates the number of the actual port.
Route Protocol

Indicates the type of the static IPv6 route. A static host route is a manually configured route with a 128-bit prefix. A static gateway route is a manually configured route with a non-128-bit prefix, with the next hop IP address on a different network segment from the egress port IP address. A dynamic host route is a dynamically learned (not manually configured) route with a 128-bit prefix. A dynamic gateway route is a dynamically learned (not manually configured) route with a non-128-bit prefix, with the next hop IP address on a different segment from the egress port IP address.
Route Status

Indicates the status of an IPv6 route.
