VRF

TRANSPORT
  +-VRF
    +-DSCPMAP[0~64]
    +-PRI2QUE[0~1]

Description

VRF is short for virtual routing and forwarding. The IP addresses and routes in the same routing domain must be unique, whereas those in different routing domains are independent of each other.

Effective Scenario

Immediately
