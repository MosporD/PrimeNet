CRLTSK

TRANSPORT
  +-CRLTSK

Description

A CRLTSK MO defines a CRL check task, in which a BS periodically obtains a CRL from the File Transfer Protocol (FTP) server or Lightweight Directory Access Protocol (LDAP) server.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the CRLTSK MO whose IPVERSION is set to IPV6 cannot be configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CRLTSK

Use this command to add a task of periodically updating a CRL.
LST CRLTSK

Use this command to list the configurations of tasks of periodically updating CRLs.
RMV CRLTSK

Use this command to remove a task of periodically updating a CRL.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IP Address

Indicates the IP address of the master FTP server or master LDAP server.
User Name

Indicates the user name used to log in to an FTP server or LDAP server.
Password

Indicates the password used to log in to an FTP server or LDAP server.
Port No.

Indicates the port number of an LDAP server.
File Name

Indicates the file name of a CRL. A file name specified with its path is supported when the access method is set to FTP.
Using CRL's Next Update

Indicates whether to update the CRL at the next update time specified in the CRL that is obtained during the latest update. If this parameter is set to ENABLE, the BS automatically updates the CRL when the next update time specified in the CRL arrives. If this parameter is set to DISABLE, the BS automatically updates the CRL based on the configured updating period.
CRL Updating Period

Indicates the interval at which the BS automatically obtains the CRL from the FTP server or LDAP server.
Task ID

Indicates the ID of the task for periodically obtaining the CRL.
Access Method

Indicates the method using which the BS periodically obtains a CRL.
Distinguish Name

Indicates the name of a node found in an LDAP server.
Source IP

Indicates the source IP address for downloading CRLs. When this parameter is set to 0.0.0.0, the effective local OM IP address serves as the source IP address to access the CRL server for updating CRL files.
Slave IP Address

Indicates the IP address of the slave FTP server or slave LDAP server. If the certificate fails to be obtained using the IP address of the master CRL server, the IP address of the slave CRL server is used only when this parameter is not set to 0.0.0.0. If the IP address of the slave CRL server is used, the slave port number, slave user name, and slave password need be configured.
Slave User Name

Indicates the user name for logging in to the slave FTP server or slave LDAP server.
Slave Password

Indicates the password for logging in to the slave FTP server or slave LDAP server.
Slave Port No.

Indicates the port number of a slave LDAP server.
Connection Mode

Indicates whether to use the SSL to protect the security of the connection.
Authenticate Peer

Indicates whether to authenticate the certificate of the peer end when SSL connection is used. This parameter does not take effect for TLS1.3.
Minimum DH Length

Indicates the minimum length of the Diffie-Hellman (DH) group allowed on the NE side when SSL connection is used and the peer certificate is authenticated. If the length of the DH key sent by the peer end is less than the value of this parameter when the DH is used as the key exchange algorithm in the algorithm set for authentication and negotiation, the SSL connection-based negotiation fails. The longer the DH key, the higher the security. When the value of this parameter is set to DH_0, peer SSL connection-based negotiation succeeds in spite of the DH key length.
IP Version

Indicates the IP protocol version.
IPv6 Address

Indicates the source IPv6 address of the master FTP server or master LDAP server.
IPv6 Source Address

Indicates the source IPv6 address for downloading CRLs. When this parameter is set to 0:0:0:0:0:0:0:0, the effective local OM IP address serves as the source IPv6 address to access the CRL server for updating CRL files.
Slave IPv6 Address

Indicates the IPv6 address of the slave FTP server or slave LDAP server. If the certificate fails to be obtained using the IP address of the master CRL server, the IP address of the slave CRL server is used only when this parameter is not set to 0:0:0:0:0:0:0:0. If the IP address of the slave CRL server is used, the slave port number, slave user name, and slave password need be configured.
Policy ID

Indicates the ID of TLS policy configured.
VRF Index

Indicates the index of a VRF instance.
TLS Secure Cipher Suite Switch

Indicates the TLS security algorithm switch. When the switch is off, it is compatible with non-AEAD (Authenticated Encryption with Associated Data) and non-PFS (Perfect Forward Secrecy) weak security algorithm sets, which poses a security risk. When the switch is turned on, TLS does not support weak security algorithm sets other than AEAD and non-PFS, and only negotiates the security algorithm set. This parameter is invalid when a WMPT serves as the main control board. If this parameter is set to ON, the switch actually takes effect from OFF.
