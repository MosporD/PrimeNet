SnmpAgent

TRANSPORT
  +-SnmpAgent

Description

This MO is used to set the SNMP agent, including the port number, version, function switch, and other data.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    TRANSPORT

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST SNMPAGENT

Use this command to query SNMP agent information.
SET SNMPAGENT

Use this command to set an SNMP agent.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Port

Indicates the port number of an SNMP agent. By default, port 161 is used. To use a non-default port, ensure that the port is not being used.
SNMP Agent Switch

Indicates whether to enable SNMP agent.
Version

Indicates the version of an SNMP agent.You are not advised to use V2C(V2C) because it has security risks.
IP Address

Indicates the IP address used by an SNMP agent.
Mask

Indicates the subnet mask used by an SNMP agent.
