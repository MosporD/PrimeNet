TOD

EQUIPMENT
  +-TOD

Description

Time of day (TOD) is a type of reference clock. The clock can be set to the input or output mode.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT
  • Relation with the BITS MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A unique combination is necessary for the following parameters: 1. CN, SRN, and SN in the BITS MO. 2. CN, SRN, and SN in the TOD MO.
  • Relation with the TASM MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If MODE and CLKSRC in the TASM MO are set to MANUAL and TOD, respectively, the corresponding TOD MO must have been configured.
  • Relation with the EQUIPMENT, TASM, BITS, LINECLK, IPCLKLNK, INTERCLK, SYNCETH, and PEERCLK MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If SDRCONNSW and INTERSUBRACKCLKALIGNMODE in an EQUIPMENT MO are set to OFF and INDEPENDENT_GNSS_CLK, respectively, and if MODE in the TASM MO is set to AUTO, then only the GPS MO can be configured and other clock link MOs cannot be configured.
  • Relation with the TASM, SYNCETH, INTERCLK, LINECLK, PEERCLK, and BITS MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CLKSYNCMODE in a TASM MO is set to HYBRID, the SYNCETH, INTERCLK, LINECLK, PEERCLK, TOD, or BITS MO cannot be configured.
  • Relation with the EQUIPMENT, APPLICATION, PEERCLK, BITS, LINECLK, IPCLKLNK, INTERCLK, SYNCETH, and GPS MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If SDRCONNSW is set to OFF and INTERSUBRACKCLKALIGNMODE is set to PEER_RF_CLK in an EQUIPMENT MO and if AT in the APPLICATION MO is set to NodeB, it is allowed and only a PEERCLK MO in which PNT is set to RF can be configured, other clock link management objects cannot be configured.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The TOD MO cannot be configured under a MDU with TYPE is MDUC.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD TOD

Use this command to add a Time of Day (TOD) clock link. If the NE can properly obtain the TOD synchronization signals, this link becomes available.
DSP TOD

Use this command to query the running status of a specified Time of Day (TOD) clock link.
LST TOD

Use this command to list the configuration of all Time of Day (TOD) clock links.
MOD TOD

Use this command to modify the feeder length and priority of a specified Time of Day (TOD) clock link.
RMV TOD

Use this command to remove a specified Time of Day (TOD) clock link.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
TOD Clock No.

Indicates the number of a TOD clock link. When TOD clock links are configured on a USCUb board, the numbers of the TOD clock links have a one-to-one relationship with the numbers of the TOD ports on the USCUb. For example, TOD clock link 0 corresponds to port 0, and TOD clock link 1 to port 1.
TOD Type

Indicates the type of a TOD clock link. It indicates whether the corresponding TOD port is an input or output port. An input port is used to input clock signals to the NE, and an output port is used to provide clock signals for other NEs. Only the TOD clock of input type can serve as a clock source.
Cabinet No.

Indicates the number of the cabinet where the TOD clock link is configured.
Subrack No.

Indicates the number of the subrack where the TOD clock link is configured.
Slot No.

Indicates the number of the slot where the TOD clock link is configured.
Cable Length

Indicates the length of the TOD feeder. The feeder delay is calculated on the basis of the TOD feeder length to ensure the clock accuracy. The clock accuracy is affected if there is an excessively large difference [more than 20 m (66 ft)] between the value of this parameter and the actual feeder length.
Priority

Indicates the priority of the clock source. The value 1 indicates that the current clock source has the highest priority, and the value 4 indicates that the current clock source has the lowest priority.
Table 3 Dynamic parameters

Parameter

Description
Link Active State

Indicates the activation status of a TOD clock link. If the link is active, the TOD clock link is the current clock source of the system.
Link Available State

Indicates the availability of a TOD clock link. Only an available clock link can serve as the current clock source. Otherwise, the clock link cannot be locked even if it is activated.
Delay

Indicates the feeder delay of the TOD clock link. The value is NULL when the clock source is not activated.
