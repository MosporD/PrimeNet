EXTCONNPORT

EQUIPMENT
  +-EXTCONNPORT

Description

An EXTCONNPORT MO defines a physical port that connects the local NE to an external NE. The configurations in this MO must match the working mode of the port on the external NE.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT
  • Relation with the BBP and RCSSERVER MOs:
    • [NodeB, eNodeB, gNodeB]The ExtConnPort MO referenced by the RCSSERVER MO must be configured on the BBP MO with TYPE set to UBBP.
  • Relation with the BBP, EDC, and RCSSERVER MOs:
    • [Co-MPT, eGBTS]The ExtConnPort MO referenced by the RCSSERVER MO must be configured on the BBP MO with TYPE set to UBBP or on the EDC MO with PT set to CPRI.
  • Relation with the EDC and RCSCLIENT MOs:
    • [Co-MPT, eGBTS]The ExtConnPort MO referenced by the RCSCLIENT MO must be configured on the EDC MO with TYPE set to MEDC.

Table 1 Related MML commands

Function
