PMTUCFG

TRANSPORT
  +-PMTUCFG

Description

A PMTUCFG MO is used to define the global configuration of the IPv6 path maximum transmission unit (PMTU) discovery.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the IPROUTE6 and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an IPROUTE6 MO is set to IF, PT in the INTERFACE MO corresponding to ITFID in the IPROUTE6 MO is set to ETH or ETHTRK, and IPV6SW in the INTERFACE MO is set to ENABLE, then MODE in the PMTUCFG MO must not be set to ACTIVE.
  • Relation with the DNSSRV MO:
    • [Co-MPT, eNodeB, gNodeB]If MODE in the PMTUCFG MO is set to ACTIVE, PORTNO cannot be the same as the PN in a DNSSRV MO of IPVER is set to IPv6.
  • Relation with the NTPCP MO:
    • [Co-MPT, eNodeB, gNodeB]If MODE in the PMTUCFG MO is set to ACTIVE, PORTNO cannot be the same as the PORT in a NTPCP MO of MODE is set to IPV6.
  • Relation with the SRCIPROUTE6 and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]If RTTYPE in an SRCIPROUTE6 MO is set to IF, PT in the INTERFACE MO corresponding to ITFID in the SRCIPROUTE6 MO is set to ETH or ETHTRK, and IPV6SW in the INTERFACE MO is set to ENABLE, then MODE in the PMTUCFG MO must not be set to ACTIVE.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mode

Indicates the PMTU discovery mode, which can be active or passive. In active mode, the base station sends discovery packets to perform PMTU discovery. In passive mode, the base station automatically adjusts the PMTU size based on the received ICMPv6 Packet Too Big message.
Protocol Type

Indicates the protocol type of PMTU discovery packets.
Port No.

Indicates the destination port number specified for PMTU discovery packets. The UDP port numbers of 60000-62559, 64679-64710, 65020, 65040, and 65043 are reserved for certain features of the base station such as NTP and cannot be used as this parameter value.
Timeout Duration

Indicates the timeout duration of waiting for a response to a single PMTU discovery.
AgingTime

Indicates the aging time of a PMTU entry. The recommended value range is 30 minutes to 60 minutes. In passive mode, this parameter is invalid for the user-plane path, SCTP link, and IKE link. PMTU entries of these links always become aged between 2:00 a.m. and 3:00 a.m.
DSCP

Indicates the DSCP value used by PMTU detection packets.
Table 3 Dynamic parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the board to which a PMTU entry belongs.
Subrack No.

Indicates the subrack number of the board to which a PMTU entry belongs.
Slot No.

Indicates the slot number of the board to which a PMTU entry belongs.
VRF Index

Indicates the index of a VRF instance.
Source IPv6 Address

Indicates the source IPv6 address of a PMTU entry.
Destination IPv6 Address

Indicates the destination IPv6 address of a PMTU entry.
Detection State

Indicates the discovery status of a PMTU entry with MODE set to ACTIVE. The value NULL indicates that the PMTU entry is not actively initiated by the base station.
Pmtu Value

Indicates the PMTU size of a PMTU entry.
IPv6 Address of Minimum MTU Hop

Indicates the IPv6 address of the node where the minimum MTU is detected by a PMTU entry. If the IPv6 address is the source address of a path, the PMTU entry does not receive a PTB packet and uses the MTU corresponding to the outbound interface of the base station route for detection.
Remaining Aging Time

Indicates the remaining aging time of the PMTU entry.
