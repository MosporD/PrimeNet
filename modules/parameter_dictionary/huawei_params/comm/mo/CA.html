CA

TRANSPORT
  +-CA

Description

A CA MO consists of the parameters related to a certification authority (CA).

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the CERTMK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If CASW in a CERTMK MO is set to ON, CANAME in a CA MO must have been configured.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the CA MO whose IPVERSION is set to IPV6 cannot be configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CA

Use this command to add a CA. The certificate request configuration information can be customized in the multi-PKI scenario.
LST CA

Use this command to list the configurations of CA.
MOD CA

Use this command to modify the configuration of a CA. The certificate request configuration information can be modified in the multi-PKI scenario.
RMV CA

Use this command to remove a CA.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Certificate Authority Name

Indicates the name of the CA. The CA name except item "ORGANIZATIONNAME" must not contain the following invalid characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), bar (|) and underscore (_). Otherwise, an error occurs when you run the REQ DEVCERT command to apply for a device certificate.
Certificate Authority URL

Indicates the URL of the CA. The URL can be either an http or https URL. The IP address in the URL must be a valid IP address. The default port number is 80 for http or 443 for https.
Certificate Registration Name

Indicates the name of a certificate registration authority (RA). The available character set of an RA name is the same as that of a CA name. This parameter is mandatory if the certificate registration server of the customer requires that the recipient in the received certificate request message be the name of the certificate registration server.
IP Version

Indicates the IP protocol version.
Signature Algorithm

Indicates the signature algorithm for message of CMP. The signature algorithm can be Secure Hash Algorithm 1 (SHA1), Secure Hash Algorithm 256 (SHA256) or Secure Hash Algorithm 384 (SHA384).
Certificate Fetch Mode

If this parameter is set to DEFAULT_MODE, the UPDSIP, INITREQURL, and INITREQSIP parameters do not need to be set. The base station uses the O&M IP address and URL as the source and destination IP addresses, respectively, for routine certificate management. Routine certificate management involves certificate application and certificate update, both of which can be done performed automatically or manually. When applying for a certificate for the first time during base station deployment by PnP, the base station uses the interface IP address as the source IP address, and the URL as the destination IP address.

If this parameter is set to CFG_UPD_SIP, INITREQURL and INITREQSIP do not need to be set. The base station uses UPDSIP and URL as the source and destination IP addresses, respectively, for routine certificate management. When applying for a certificate for the first time during base station deployment, the base station uses the interface IP address (during base station deployment by PnP) as the source IP address, and the URL as the destination IP address.

If this parameter is set to CFG_INIT_UPD_ADDR on the base station:

The base station uses UPDSIP and URL as the source and destination IP addresses, respectively, for routine certificate management.

During a request for a certificate for the first time during base station deployment, the base station uses the interface IP address (during base station deployment by PnP) as the source IP address, and the value of the INITREQURL parameter as the destination IP address.
Certificate Update Source IP

Indicates the source address for certificate management, such as automatic certificate update, manual certificate update, and manual certificate application. If the source address for certificate application in site deployment is not configured, the address will be used as the source address for acquiring the certificate for the first time.
CA URL During Site Deployment

Indicates the URL of the CA that is used during site deployment. The URL can be either an http or https URL. In the URL, the IP address must be a valid IP address, and the default port number is 80 for http or 443 for https. This parameter is mandatory when the CA uses different URLs during site deployment or certificate update.
Source IP for Applying for a Certificate During Site Deployment

Indicates the source IP address for the BS to access the CA and to initially obtain a certificate. This parameter is mandatory when the CA uses different URLs in the following scenarios:

-The BS initially obtains a certificate during site deployment.

-A certificate is updated.
Source IPv6 Address for Applying for a Certificate During Site Deployment

Indicates the source IPv6 address for the BS to access the CA and to initially obtain a certificate. This parameter is mandatory when the CA uses different URLs in the following scenarios:

-The BS initially obtains a certificate during site deployment.

-A certificate is updated.
Certificate Update Source IPv6 Address

Indicates the source IPv6 address for certificate management, such as automatic certificate update, manual certificate update, and manual certificate application. If the source address for certificate application in site deployment is not configured, the address will be used as the source address for acquiring the certificate for the first time.
Slave Certificate Authority URL

Indicates the slave URL of the CA. The URL can be either an HTTP or HTTPS URL. The IP address in the URL must be a valid IP address. The default port number is 80 for HTTP or 443 for HTTPS. If the certificate fails to be obtained using the CA URL, the slave CA URL can be used to obtain the certificate only when this parameter is set.
Slave CA URL During Site Deployment

Indicates the slave URL of the CA that is used during site deployment. The URL can be either an HTTP or HTTPS URL. In the URL, the IP address must be a valid IP address, and the default port number is 80 for HTTP or 443 for HTTPS. If the certificate fails to be obtained using the CA URL during site deployment, the slave CA URL during site deployment can be used to obtain the certificate only when this parameter is set.
Certificate Request Switch

Indicates the switch of certificate request configuration information. When this parameter is set to DEFAULT, the CA uses the request information configured in the CERTREQ MO. When this parameter is set to USERDEFINE, the CA requires the customized certificate request information.
Common Name

Indicates the common name of the certificate request file, which can be the electronic serial number (ESN), media access control (MAC) address, or IP address of a board.
Common Name Additional Info.

Indicates the additional information about a certificate common name. The information will be added behind the value of the COMMNAME parameter to compose a complete common name for a certificate request file. The default value is .huawei.com. A space is not supported before the value of this parameter, that is, a space is not supported before the character string. However, to meet requirements of consistency checks performed by some CA servers to the certificate common name in a certificate request packet and that in a Huawei device certificate, the certificate common name in a certificate request packet is displayed as "Board ESN"+space+"Common Name Additional Info" only when the certificate common name in a Huawei device certificate is "Board ESN"+space+"Common Name Additional Info". For example, when the value of this parameter is "eNodeB" and the certificate common name in a Huawei device certificate is "ESN eNodeB", a space is automatically added before "eNodeB", that is, the certificate common name in a certificate request packet is displayed as "ESN eNodeB".
Country

Indicates the country where a BS is located.
Organization

Indicates the organization that owns a BS.
Organizational Unit

Indicates the organization unit that owns a BS.
State or Province

Indicates the state or province where a BS is located.
Locality

Indicates the location of a BS.
Key Usage

Indicates the usage for a key, including KEY_AGREEMENT (key negotiation), DATA_ENCIPHERMENT (data encryption), KEY_ENCIPHERMENT (key encryption), and DIGITAL_SIGNATURE (digital signature). This parameter can be set to one or multiple values.
Certificate Request Signature Algorithm

Indicates the signature algorithm for a certificate request file.
Key Size

Indicates the length of a key, which can be 1024 bits, 2048 bits, 3072 bits or 4096 bits.
Local Name

Indicates the local name of a BS. This parameter is used to generate the DNS name of the subject alternative name of a certificate, so as to verify the peer's identification in IKE negotiation. If this parameter is not configured, the BS automatically uses the common name and its additional information to generate the DNS name.
Local IP

Indicates the IP address of the subject alternative name of a certificate.
Local IPv6 Address

Indicates the IPv6 address of the subject alternative name of a certificate. This parameter is invalid in the old transmission model.
Policy ID

Indicates the ID of TLS policy configured.
VRF Index for Applying for a Certificate During Site Deployment

Indicates the index of the VRF instance on which the IP address that is used to apply for a certificate during base station deployment depends.
VRF Index for Update a Certificate

Indicates the index of the VRF instance on which the source IP address used in routine certificate management (automatic certificate update, manual certificate update, and manual certificate application) depends.
Key Type

Indicates type of key of one certificate, which can be RSA or ECDSA.
ECC Curve

Indicates the name of the elliptic curve used by the key when the certificate key type is ECDSA. The elliptic curve allows P256 (secp256r1), P384 (secp384r1), and ED25519. ED25519 indicates the EdDSA signature scheme using SHA-512 and Curve25519.
TLS Secure Cipher Suite Switch

Indicates the TLS security algorithm switch. When the switch is off, it is compatible with non-AEAD (Authenticated Encryption with Associated Data) and non-PFS (Perfect Forward Secrecy) weak security algorithm sets, which poses a security risk. When the switch is turned on, TLS does not support weak security algorithm sets other than AEAD and non-PFS, and only negotiates the security algorithm set. This parameter is invalid when a WMPT serves as the main control board. If this parameter is set to ON, the switch actually takes effect from OFF.
