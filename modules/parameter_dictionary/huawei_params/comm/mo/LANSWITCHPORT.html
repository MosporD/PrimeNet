LANSWITCHPORT

TRANSPORT
  +-LANSW
    +-LANSWITCHPORT

Description

Switch ports controlled by a layer 2 LAN switch. A switch port supports two media types, Ethernet and air-interface link.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    LANSW
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, eNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the LANSWITCHPORT MO cannot be configured.
  • Relation with the ETHTRKLNK MO:
    • [Co-MPT, eNodeB]The settings of the following parameters in the LANSWITCHPORT MO's CN, SRN, SN, PN cannot be the same as those in the ETHTRKLNK MO. That is, the ETHPORT MO associated with the LANSWITCHPORT MO of the Ethernet type cannot be referenced by the ETHTRKLNK MO.
  • Relation with the HAGRP MO:
    • [Co-MPT, eNodeB]In one logical protection group, SN in an HAGRP MO must be the same as that in a LANSWITCHPORT MO.

Function

Table 3 Dynamic parameters

Parameter

Description

Indicates the state of a layer 2 LAN switch port.

Indicates the number of packets received by a layer 2 LAN switch port.
Number of Transmitted Packets

Indicates the number of packets transmitted by a layer 2 LAN switch port.
Number of Packets Discarded in RX Direction due to MAC MISS

Indicates the number of packets discarded by a layer 2 LAN switch port in the receive direction due to MAC MISS. MAC MISS means that searching for the forwarding table based on the destination MAC address of the packets fails. This parameter is valid only for layer 2 switch ports of the Ethernet type.
Dropped Packets In Reception direction Due to Broad Cast forwarding Rate Limit Overflow

Indicates the number of broadcast packets discarded by a layer 2 port in the receive direction when the number of broadcast packets exceeds a specified threshold. This parameter is valid only for layer 2 switch ports of the Ethernet type.
