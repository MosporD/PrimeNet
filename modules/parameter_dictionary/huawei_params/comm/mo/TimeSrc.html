TIMESRC

+-NE
  +-NODE
    +-SYSTEMOM
      +-TIMESRC

Description

The TIMESRC MO is used to manage the external clock sources for the time synchronization of the NE.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    SYSTEMOM
  • Relation with the TASM MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the TASM MO for a board, if FNSYNCSW is set to ON and CLKSYNCMODE is set to FREQ, in the TIMESRC MO for the board, TIMESRC must set to NTP and AUTOSWITCH must be set to OFF.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP TIMESRC

Use this command to query the type of available time source and autoswitch.
LST LATESTSUCCDATE

Use this command to query the last update time from an external reference time source.
LST TIMESRC

Use this command to list the type of the configured time sources and autoswitch.
SET TIMESRC

Use this command to set the time source and automatic switch.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Time Source

Indicates the external reference time source of the NE.
Automatic Switch

Indicates whether to enable automatic time source switchover. When the switch is turned on, the system switches over the time source when time synchronization fails. When the switch is turned off, the system does not switch over the time source.
Table 3 Dynamic parameters

Parameter

Description
Latest Successful Synchronization Time

Indicates the date and time of the last successfully-synchronized time of the NE. The format is as follows: YYYY-MM-DD HH:MM:SS.
