CERTMK

TRANSPORT
  +-CERTMK

Description

A CERTMK MO defines a verified device certificate. This device certificate identifies a BS during security negotiation.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the CA MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If CASW in a CERTMK MO is set to ON, CANAME in a CA MO must have been configured.
  • Relation with the IKEPEER MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If CERTSOURCE in an IKEPEER MO is set to CERTMK, APPCERT in a CERTMK MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CERTMK

Use this command to add a device certificate. The binding relationship between device certificates and a CA can be specified in the multi-PKI scenario.
DSP CERTMK

Use this command to query the status of device certificates.
LST CERTMK

Use this command to list the configurations of device certificates.
MOD CERTMK

Use this command to modify the binding relationship between device certificates and a CA.
RMV CERTMK

Use this command to remove a device certificate and the corresponding certificate file.
TST CERT

Use this command to test the validity of the certificates that are configured on the BS before delivery. These certificates are a device certificate named appcert.pem and a trusted certificate named caroot.pem.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Certificate File Name

Indicates the file name of a device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).
CA Switch

Indicates whether a CA server is specified for a device certificate. When this parameter is set to OFF, only one CA is configured or no CA is configured (the device certificate can be configured only in the offline mode). When this parameter is set to ON, a CA needs to be specified.
Certificate Authority Name

Indicates the name of the CA server specified by the certificate.
Table 3 Dynamic parameters

Parameter

Description
Status

Indicates the status of a device certificate.
Serial Number

Indicates the serial number of a device certificate.
Common Name

Indicates the common name of a device certificate.
Issuer

Indicates the issuer of a device certificate.
Expiration Date

Indicates the expiration date of a device certificate.
Effective Date

Indicates the date when a device certificate begins to take effect.
CA URL Last Used

Indicates the CA URL used to successfully obtain the certificate for the last time. After a system reset, version upgrade, or manual configuration of the device certificate, the value of this parameter is NULL.
Last Update Time of Certificate

Indicates the time when the certificate is successfully obtained for the last time. After a system reset, version upgrade, or manual configuration of the device certificate, the value of this parameter is NULL.
Key Type

Indicates type of key of one certificate, which can be RSA or ECDSA.
Key Size

Indicates the key length, which can be 1024 bits, 2048 bits, 3072 bits or 4096 bits. The key length of 1024 bits is not recommended. Otherwise, the security is undermined. If this parameter is set to KEYSIZE1024, the RRU still uses the value KEYSIZE2048 as the key length.
ECC Curve

Indicates the name of the elliptic curve used by the key when the certificate key type is ECDSA. The elliptic curve allows P256 (secp256r1), P384 (secp384r1), ED25519 and P521(secp521r1). ED25519 indicates the EdDSA signature scheme using SHA-512 and Curve25519.
