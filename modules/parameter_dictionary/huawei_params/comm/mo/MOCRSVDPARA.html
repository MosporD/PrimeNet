MOCRSVDPARA

+-NE
  +-NODE
    +-SYSTEMOM
      +-MOCRSVDPARA

Description

This MO is used to configure the MOI Reserved Parameter.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    SYSTEMOM
  • Relation with the MOCRSVDPARA MO:
    • [Co-MPT, eNodeB, gNodeB]MOCNAME in an MOCRSVDPARA MO can only be set to TRANSFUNCTIONSW, RRU, or GEPMODELPARA.
    • [Co-MPT, eNodeB, gNodeB]If MOCNAME in an MOCRSVDPARA MO is set to RRU, RSVDPARAID can only be set to HWPROTECTLVL, BRDENERGYMODEOP or BOARDPWRMODEOP.
    • [Co-MPT, eNodeB, gNodeB]If MOCNAME in an MOCRSVDPARA MO is set to RRU, and RSVDPARAID is set to BRDENERGYMODEOP, MOIKEY can only be set to the combination of decimal numbers and symbol &, and RSVDPARAVALUE can only be set to ON or OFF.
    • [Co-MPT, eNodeB, gNodeB]If MOCNAME in an MOCRSVDPARA MO is set to RRU and RSVDPARAID is set to BOARDPWRMODEOP, then MOIKEY can only be set to a combination of decimal numbers and ampersands (&), and RSVDPARAVALUE can only be set to a decimal number with a maximum of three digits.
    • [Co-MPT, eNodeB, gNodeB]If MOCNAME in an MOCRSVDPARA MO is set to TRANSFUNCTIONSW, MOIKEY can only be set to 0, RSVDPARAID can only be set to MODE, and RSVDPARAVALUE can only be set to SINGLECORE or MULTICORE.
    • [Co-MPT, eNodeB, gNodeB]If MOCNAME in an MOCRSVDPARA MO is set to GEPMODELPARA, MOIKEY can only be set to 0, RSVDPARAID can only be set to DIRECTIPSECMODE, and RSVDPARAVALUE can only be set to LOOSE_MODE.
  • Relation with the USERPLANEPEER MO:
    • [Co-MPT, eNodeB, gNodeB]If CTRLMODE is set to MANUAL_MODE and IPSECSWITCH is set to ENABLE in a USERPLANEPEER MO, MOCNAME in an MOCRSVDPARA MO cannot be set to GEPMODELPARA.
  • Relation with the SCTPPEER MO:
    • [Co-MPT, eNodeB, gNodeB]If CTRLMODE is set to MANUAL_MODE and SIGIP1SECSWITCH or SIGIP2SECSWITCH is set to ENABLE in an SCTPPEER MO, MOCNAME in an MOCRSVDPARA MO cannot be set to GEPMODELPARA.
