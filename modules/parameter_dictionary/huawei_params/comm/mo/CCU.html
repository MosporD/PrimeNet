CCU

EQUIPMENT
  +-CABINET
    +-SUBRACK
      +-CCU
        +-ALMPORT[32~32]

Description

A CCU MO defines a cabinet control unit (CCU). The CCU monitors the electromechanical devices such as the power monitoring unit (PMU), fan monitoring unit (FMU), temperature control unit (TCU), and environment monitoring unit (EMU) in a cabinet.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    SUBRACK

  • Possible children:

    ALMPORT[32~32]
  • Relation with the EMU, SUBRACK, and RRU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The MO corresponding to MCN and MSRN in the EMU MO must have been configured and be one of the following types: 1. SUBRACK MO with SRN set to 0 or 1; 2. RRU MO with SN set to 0; 3. CCU MO.
  • Relation with the SUBRACK and RRU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The MO corresponding to MCN and MSRN in the CCU MO must have been configured and be one of the following types: 1. SUBRACK MO with SRN set to 0 or 1; 2. RRU MO with SN set to 0.
  • Relation with the FMU, SUBRACK, and RRU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The MO corresponding to MCN and MSRN in the FMU MO must have been configured and be one of the following types: 1. SUBRACK MO with SRN set to 0 or 1; 2. RRU MO with SN set to 0; 3. CCU MO.
  • Relation with the CCU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the manager unit BBU has lower-level CCU MOs, DCF of at least one CCU MO must be set to YES.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If a manager unit RRU has lower-level CCU MOs, DCF in only one CCU can be set to YES.
  • Relation with the SUBRACK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of CCU MOs configured on one SUBRACK MO must be greater than or equal to 0 and smaller than or equal to 1.
  • Relation with the ALMPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of ALMPORT MOs configured on one CCU MO must be 32.
  • Relation with the TCU, PMU, EMU, andFMUMOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]It is not allowed in the following cases: 1. The combination of MCN, MSRN, and MPN in the PMU MO is same as the combination of those in the configured CCU MO, and ADDR in the PMU MO is equal to 21; 2. The combination of MCN, MSRN, and MPN in the FMU MO is same as the combination of those in the configured CCU MO, and ADDR in the FMU MO is equal to 21; 3. The combination of MCN, MSRN, and MPN in the TCU MO is same as the combination of those in the configured CCU MO, and ADDR in the TCU MO is equal to 21; 4. The combination of MCN, MSRN, and MPN in the EMU MO is same as the combination of those in the configured CCU MO, and ADDR in the EMU MO is equal to 21.
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The RRU MO specified by MCN and MSRN in the CCU MO cannot be configured as the MRIU.
  • Relation with the TCU, SUBRACK, RRU, and RHUB MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The MO corresponding to MCN and MSRN in the TCU MO must have been configured and be one of the following types: 1. SUBRACK MO with SRN set to 0 or 1; 2. RRU MO with SN set to 0; 3. CCU MO; 4. RHUB MO.
  • Relation with the PMU, SUBRACK, RRU, and RHUB MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The MO corresponding to MCN and MSRN in the PMU MO must have been configured and be one of the following types: 1. SUBRACK MO with SRN set to 0 or 1; 2. RRU MO with SN set to 0; 3. CCU MO; 4. RHUB MO.
  • Relation with the TCU, SUBRACK, and RRU MOs:
    • [gNodeB]The MO corresponding to MCN and MSRN in the TCU MO must have been configured and be one of the following types: 1. SUBRACK MO with SRN set to 0 or 1; 2. RRU MO with SN set to 0; 3. CCU MO.
  • Relation with the PMU, SUBRACK, and RRU MOs:
    • [gNodeB]The MO corresponding to MCN and MSRN in the PMU MO must have been configured and be one of the following types: 1. SUBRACK MO with SRN set to 0 or 1; 2. RRU MO with SN set to 0; 3. CCU MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CCU

Use this command to add a cabinet control unit (CCU). The CCU and its subrack are added at the same time.
CLR CCUALM

Use this command to clear a cabinet control unit (CCU) smoke alarm. When a CCU smoke alarm is reported, you must clear the fault that triggers the alarm, and then run this command to clear the alarm.
DSP CCU

Use this command to query the dynamic information about one or all cabinet control units (CCUs).
DSP CCUBATSENSORSTATE

Use this command to query the dynamic information about the battery sensor to which a CCU is connected.
LST CCU

Use this command to list the configuration of one or all cabinet control units (CCUs).
MOD CCU

Use this command to modify the configuration of a cabinet control unit (CCU).
RMV CCU

Use this command to remove a cabinet control unit (CCU). The CCU and its subrack are removed at the same time.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the CCU.
Subrack No.

Indicates the subrack number of the CCU.
Slot No.

Indicates the slot number of the CCU.
Manager Cabinet No.

Indicates the cabinet number of the manager unit of the CCU.
Manager Subrack No.

Indicates the subrack number of the manager unit of the CCU.
Manager Port No.

Indicates the number of the serial port where the CCU is connected. The serial port is the port through which the CCU is connected to the manager unit.
DirectConnectFlag

Indicates whether the CCU is directly connected to its manager unit.
Cascade No.

Indicates the position of the CCU on a CCU chain. On a CCU chain, the FE_R port on the upper-level CCU is connected to the FE_L port on the lower-level CCU. A CCU whose FE_L port is left unconnected is the first-level CCU and the CCU directly connected to the first-level CCU is the second-level CCU and so on.
Connected RAT

Indicates the working standard of the manager unit to which the CCU is connected.LTE TDD needs to be added to the working standard of the manager unit to which the CCU is connected only when the working mode of an NE to which the CCU is connected is LTE TDD. The working mode is LTE TDD only when Product Type is set to DBS3900, BTS3900, BTS3900A, BTS3900L, BTS3900AL, DBS3900_LampSite, DBS5900, BTS5900, BTS5900A, BTS5900L, BTS5900AL, or DBS5900_LampSite, Working Mode to NON-CONCURRENT, and LTE Mode to LTE_TDD, or when Product Type is set to DBS3900_LTE, BTS3900_LTE, BTS3900A_LTE, BTS3900L_LTE, BTS3900AL_LTE, DBS3900_LampSite_LTE, DBS5900_LTE, BTS5900_LTE, BTS5900A_LTE, BTS5900L_LTE, BTS5900AL_LTE, or DBS5900_LampSite_LTE and LTE Mode to LTE_TDD.
Special Boolean Alarm Flag

Indicates whether to allow the reporting of a dedicated Boolean alarm. If the shield flag for a Boolean alarm is enabled, the Boolean alarm cannot be reported.
Number of eBAT

Indicates the number of eBATs connected to a CCU. If this parameter is set to 0, no eBAT provides the monitoring function.
Battery Inner Resistance Alarm Threshold

Indicates the internal resistance alarm threshold of the battery monitored by the eBAT to which a CCU is connected.
