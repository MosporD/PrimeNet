IPGPM

TRANSPORT
  +-IPGPM

Description

This MO is used to set parameters related to the IPGPM detection.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the PPPLNK and IPRSCGRP MOs:
    • [Co-MPT, NodeB]If a IPGPM MO associated IPRSCGRP MO and a PPPLNK MO are configured on the same physical port, the MUXCP parameter must be set to DISABLE in the PPPLNK MO.
  • Relation with the MPGRP and IPRSCGRP MOs:
    • [Co-MPT, NodeB]If a IPGPM MO associated IPRSCGRP MO and a MPGRP MO are configured on the same physical port, the MUXCP parameter must be set to DISABLE in the MPGRP MO.
  • Relation with the IPGPM MO:
    • [Co-MPT, NodeB]The system supports a maximum of 20 IPGPM MOs.
    • [Co-MPT, NodeB]In an IPRSCGRP MO, only one IPGPM MO with DDM set to FPDT and DIR set to DOWN and only one IPGPM MO with DDM set to FPDT and DIR set to UP can be configured.
    • [Co-MPT, NodeB]On a loopback port, only one IPGPM MO with DDM set to FPDT and DIR set to DOWN and only one IPGPM MO with DDM set to FPDT and DIR set to UP can be configured.
  • Relation with the BBP, CASCADEPORT, IPRSCGRP, LOOPBACK, and BACKTUNNEL MOs:
    • [Co-MPT, NodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to SCPRI/SRIO or AUTO, this board cannot be configured with the IPGPM MO. That is, this board cannot be configured with the associated IPRSCGRP MO.
    • [Co-MPT, NodeB]On a UBBP or LCOP board, if the CASCADEPORT MO in which the PN parameter is set to 6 does not exist, the UBBP board cannot be configured with the IPGPM MO. That is, this board cannot be configured with the associated IPRSCGRP MO.
  • Relation with the BBP, CASCADEPORT, and IPRSCGRP MOs:
    • [Co-MPT, NodeB]On a UBBP or LCOP board, if PN is set to 6 and PM is set to 1*40GE in the CASCADEPORT MO and PT in the IPRSCGRP MO corresponding to the IPGPM MO of the board is set to ETH, then PN in the ETHPORT MO corresponding to the IPRSCGRP MO can only be set to 0.
    • [Co-MPT, NodeB]On a UBBP or LCOP board, if PN is set to 6 and PM is set to 4*10GE in the CASCADEPORT MO and PT in the IPRSCGRP MO corresponding to the IPGPM MO of the board is set to ETH, then PN in the ETHPORT MO corresponding to the IPRSCGRP MO can only be set to a value in the range of 0 to 3.
    • [Co-MPT, NodeB]On a UBBP board, if PN is set to 6 and PM is set to 1*100GE in the CASCADEPORT MO and PT in the IPRSCGRP MO corresponding to the IPGPM MO of the board is set to ETH, then PN in the ETHPORT MO corresponding to the IPRSCGRP MO can only be set to 0.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the IPGPM MO cannot be configured.
  • Relation with the IPRSCGRP MO:
    • [Co-MPT, NodeB]If PT in a IPGPM MO is not set to OTHER, the associated IPRSCGRP MO must have been configured and not be AUTOPORT.
  • Relation with the IPPATH MO:
    • [Co-MPT, NodeB]When PT in the IPGPM MO is not set to LOOPINT and RSCGRPNO in the associated IPRSCGRP MO is not set to DEFAULTPORT, if IPMUXSWITCH in the IPPATH MO corresponding to the IPGPM MO is set to ENABLE, TIMER in the IPPATH MO must be set to a value less than or equal to 1.
    • [Co-MPT, NodeB]When PT in the IPGPM MO is set to LOOPINT, if IPMUXSWITCH in the IPPATH MO corresponding to the IPGPM MO is set to ENABLE, TIMER in the IPPATH MO must be set to a value less than or equal to 1.
  • Relation with the IPPATH and IPRSCGRP MOs:
    • [Co-MPT, NodeB]When PT in the IPGPM MO is not set to LOOPINT and RSCGRPNO in the associated IPRSCGRP MO is set to DEFAULTPORT, if IPMUXSWITCH in the IPPATH MO corresponding to the IPGPM MO is set to ENABLE, TIMER in the IPPATH MO must be set to a value less than or equal to 1.
  • Relation with the LOOPBACK MO:
    • [Co-MPT, NodeB]If PT in a IPGPM MO is not set to LOOPINT, the associated LOOPBACK MO must have been configured.

MML Command

Function

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IP GPM Detection ID

Indicates the ID of an IP GPM detection.
Detection Direction

Indicates the direction of an IP GPM detection.
Delay Detection Method

Indicates the delay detection method at the bottom layer used by the IP GPM detection.
Detection Object

Indicates the object to be detected by the IP GPM on the base station side. If the detection object is IPRSCGRP, the IP GPM detects congestion on transmission links of users in the IP transmission resource group.
Port Type

Indicates the type of the port where an IP transmission resource group detected by the IP GPM is carried.
Port ID

Indicates the ID of the port where an IP transmission resource group detected by the IP GPM is carried.
IP Transmission Resource Group ID

Indicates the ID of the IP transmission resource group detected by the IP GPM.
Table 3 Dynamic parameters

Parameter

Description
Cabinet No.

Indicates the cabinet No. of the board where the IP transmission resource group detected by the IP GPM is located.
Subrack No.

Indicates the subrack No. of the board where the IP transmission resource group detected by the IP GPM is located.
Slot No.

Indicates the slot No. of the board where the IP transmission resource group detected by the IP GPM is located.
Working State

Indicates the working state of an IP GPM detection. If the number of samples within an IP GPM detection period is 0, the working state of the IP GPM detection is "NO_MEASUREMENT". If the number of samples within an IP GPM detection period is greater than 0, the working state of the IP GPM detection is "IN_MEASUREMENT".
