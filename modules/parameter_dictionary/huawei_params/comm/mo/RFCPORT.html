RFCPORT

EQUIPMENT
  +-CABINET
    +-SUBRACK
      +-RFC
        +-RFCPORT

Description

The RFCPORT MO is used to configure a port on the panel of an RF card, which is used to transmit RF signals to and receive RF signals from a third-party base station.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RFC

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP RFCPORT

Use this command to query the information about ports on RF cards.
LST RFCPORT

Use this command to list the configuration of ports on RF cards.
MOD RFCPORT

Use this command to modify the configuration of ports.
STR PORTPWRADJUST

Use this command to start power adjustment for a port. This ensures that the input RF signals meet power requirements.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the number of the cabinet housing the RF card which provides the port.
Subrack No.

Indicates the number of the subrack housing the RF card which provides the port.
Slot No.

Indicates the number of the slot housing the RF card which provides the port.
Port No.

Indicates the downlink switch of the port on the RF card.
DL Switch

Indicates the downlink switch of the port on the RF card.
UL Switch

Indicates the downlink switch of the port on the RF card.
Power Attenuation

Indicates the power attenuation value of the port on the RF card.
UL Gain Adjustment

Indicates the uplink gain adjustment value of the port on the RF card.
Table 3 Dynamic parameters

Parameter

Description
DL Input Power

Indicates the downlink input power of the port on the RF card. If all carriers on the port are deactivated, the value is invalid.
Attenuation of Power Adjustment

Indicates the power attenuation value of the port on the RF card.
Upper Threshold of Power

Indicates the over-power threshold of the port on the RF card.
Lower Threshold of Power

Indicates the under-power threshold of the port on the RF card.
Port Power After Adjustment

Indicates the power of the port on the RF card after power adjustment.
ID of the RFA Cell with Abnormal Power Adjustment

Indicates the ID of the RFA cell that encounters a power adjustment exception.
Start UL Frequency

Indicates the start uplink working frequency of the port on the RF card.
End UL Frequency

Indicates the end uplink working frequency of the port on the RF card.
Start DL Frequency

Indicates the start downlink working frequency of the port on the RF card.
End DL Frequency

Indicates the end downlink working frequency of the port on the RF card.
