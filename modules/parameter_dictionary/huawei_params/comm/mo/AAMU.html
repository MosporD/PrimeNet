AAMU

EQUIPMENT
  +-AAS
    +-AAMU
      +-CPRIPORT[2~2]
      +-SFP[2~2]

Description

An AAMU MO defines an AAMU, which manages communication links between the AAS and BBU and manages AARUs in the AAS.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    AAS

  • Possible children:

    CPRIPORT[2~2];SFP[2~2]
  • Relation with the GPS, CXU, RRU, and RHUB MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When a GPS MO is configured for a CXU MO in which CXUTYPE is set to CGPS, the GPS MO cannot be configured on a non-CGPS board.
    • [Co-MPT, NodeB, eGBTS, eNodeB]When GPS MO is configured on a non-CGPS board, GPS cannot be configured for a CXU MO in which CXUTYPE is set to CGPS.
  • Relation with the RRUCHAIN, RRU, RFU, and CXU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The total number of RRU, RFU, AAMU, and CXU MOs configured on the RRUCHAIN MO must be smaller than or equal to 21.
  • Relation with the SECTOREQM, RRU, RRUCHAIN, CXU, and RFU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If sector equipment antennas are distributed on multiple radio frequency units, these radio frequency units can neither be configured on different branches of trunk chains, nor be configured in hybrid networking modes including the branches of trunk chain.
  • Relation with the RAS, RRU, and RFU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The RRU, RFU, or AAMU MO corresponding to CTRLCN, CTRLSRN, and CTRLSN in the RAS MO must have been configured.
  • Relation with the AAMU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The RRUCHAIN MO where the AAMU MO is located must have been configured.
  • Relation with the RET, RRU, and RFU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The RRU, RFU, or AAMU MO corresponding to CTRLCN, CTRLSRN, and CTRLSN in the RET MO must have been configured.
  • Relation with the RVD, RRU, and RFU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The RRU, RFU, or AAMU MO corresponding to CTRLCN, CTRLSRN, and CTRLSN in the RVD MO must have been configured.
  • Relation with the RAE, RRU, and RFU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The RRU, RFU, or AAMU MO corresponding to CTRLCN, CTRLSRN, and CTRLSN in the RAE MO must have been configured.
  • Relation with the RRUCHAIN, CXU, RRU, RFU, and RHUB MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PROTOCOL is set to eCPRI and TT is set to CHAIN or LOADBALANCE in an RRUCHAIN MO, then only RRU MOs with RT set to AIRU can be configured on this RRUCHAIN MO.
  • Relation with the RAESUBUNIT, RRU, and RFU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The RRU, RFU, or AAMU MO corresponding to CONNCN, CONNSRN, and CONNSN in the RAESUBUNIT MO must have been configured.
  • Relation with the EXTRRURES, RRU, CXU, and RHUB MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]Each of the following MOs must have a unique combination of cabinet number, subrack number, and slot number: EXTRRURES, RRU, AAMU, RHUB and CXU.
  • Relation with the AARU, RHUB, RRU, and CXU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]Only the cabinet number and subrack number of the RRU MO with RT set to MPRF can be the same as those of the RRU MO with RT set to MPMU.
  • Relation with the RHUB, RRU, and CXU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]Only the cabinet number and subrack number of the AARU MO can be the same as those of the AAMU MO.
  • Relation with the AAMU, RRU, and RFU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If BM in the RRUCHAIN MO where the AAMU MO is located is set to HOT, the total number of AAMU, RRU, and RFU MOs configured on the RRUCHAIN MO must be 0 or 1.
  • Relation with the RRU, RFU, and RRUCHAIN MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If an RRUCHAIN MO corresponding to the RRU MO, RFU MO, or AAMU MO is configured on a CXU in which CXUTYPE is set to RMU, TP in the RRU MO, RFU MO, or AAMU MO must be set to BRANCH.
  • Relation with the CXU and RRUCHAIN MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TP in the AAMU MO is set to BRANCH, a CXU MO with CXUTYPE set to RMU must be configured in the cabinet specified by RCN in the AAMU MO.
  • Relation with the RRU, CXU, and RRUCHAIN MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If an RRUCHAIN MO corresponds to a CXU MO with CXUTYPE set to RMU, the total number of RRU, AAMU, and CXU MOs in the RRUCHAIN MO must be less than or equal to seven.
  • Relation with the RRU, RFU, RHUB, CXU, and RRUCHAIN MOs:
    • [Co-MPT, NodeB, eNodeB]If an RRUCHAIN MO corresponds to a CXU MO with CXUTYPE set to RMU, only the following MOs corresponding to the RRUCHAIN MO can be configured:
    • 1. RRU MOs with RT set to MRRU, LRRU, MRXU, PRRU, or AIRU and TP set to BRANCH.
    • 2. AAMU MOs with TP set to BRANCH.
    • 3. CXU MOs with CXUTYPE set to CGPS or RPCU.
    • 4. RFU MOs with RT set to MRFU and TP set to BRANCH.
  • Relation with the RRUCHAIN, CXU, RRU, and RFU MOs:
    • [Co-MPT, NodeB, eNodeB]If TT is set to TRUNK_CHAIN and PROTOCOL is set to CPRI in an RRUCHAIN MO, this RRUCHAIN MO can be composed only of CXU MOs with CXUTYPE set to RMU, RRU MOs with RT set to AIRU or RHUB.
    • [eGBTS]If TT is set to TRUNK_CHAIN and PROTOCOL is set to CPRI in an RRUCHAIN MO, this RRUCHAIN MO can be composed only of CXUs with CXUTYPE set to RMU.
  • Relation with the RRU, RFU, and RHUB MOs:
    • [Co-MPT, NodeB, eNodeB]Under a base station, the total number of RRU, RFU, AAMU, and RHUB MOs must be less than or equal to 420.
  • Relation with the AAMU, RRU, RFU, CXU, and RHUB Mos:
    • [Co-MPT, NodeB, eNodeB]The CXU MO with CXUTYPE set to RPCU must be at the lowest level of the RRUCHAIN MO, and only the RRU or RFU MO can be configured at the upper level.
  • Relation with the RHUB MO:
    • [Co-MPT, NodeB, eNodeB]The RRUCHAIN MO where the RHUB MO is located must not have RRU MO, RFU MO, AAMU MO, and CXU MO.
  • Relation with the AAMU, RRU, RFU, and RHUB MOs:
    • [Co-MPT, NodeB, eNodeB]When HCN, HSRN, and HSN in an RRUCHAIN MO are the same as CN, SRN, and SN in the RHUB MO, respectively, the RT in the RRU MO that is configured on this RRUCHAIN MO must be set to MPMU or MPRF.
  • Relation with the RRUCHAIN MO:
    • [Co-MPT, NodeB, eNodeB]CR in an RRUCHAIN MO where an AAMU MO is located cannot be set to MANUAL.
  • Relation with the RRU and RFU MOs:
    • [eGBTS]Under a base station, the total number of RRU, RFU and AAMU MOs must be less than or equal to 195.

Related Parameters

Table 1 describes the parameters related to this MO.

Table 1 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the number of the cabinet where the AAMU is located.
Subrack No.

Indicates the number of the subrack where the AAMU is located.
Slot No.

Indicates the slot number of the AAMU.
Topo Position

Indicates the position where the AAS is installed in the topology.
AAS Chain No.

Indicates the ID of an RRU chain/ring which the AAS is inserted in.
AAS Position

Indicates where the AAS is inserted in an RRU chain/ring. It is calculated from the start port one by one.
