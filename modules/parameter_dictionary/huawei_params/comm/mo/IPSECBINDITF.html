IPSECBINDITF

TRANSPORT
  +-IPSECBINDITF

Description

This MO indicates the binding relationship between the IP Security (IPSec) policy group and the interface. An IPSec tunnel is negotiated to protect the data streams on an interface only after an IPSec policy group is bound to the interface.

Effective Scenario

Immediately

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD IPSECBINDITF

Use this command to bind an IPSec policy group to an interface. IPSec tunnels are negotiated to protect the data streams flowed through an interface only after an IPSec policy group is bound to the interface.
LST IPSECBINDITF

Use this command to list the binding relation between the IPSECBINDITF MO and the interface.
MOD IPSECBINDITF

Use this command to modify the parameters in an IPSECBINDITF object.
RMV IPSECBINDITF

Use this command to remove the binding of an IPSec policy group to an interface. The execution of this command terminates the protection mechanism applied to the data streams flowed through the interface.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IPSec Bind Interface ID

Indicates the ID of an IPSECBINDITF object. The value of IPSECBINDITFID in the IPSECBINDITF MOs configured by users ranges from 0 to 235. The value of IPSECBINDITFID in the IPSECBINDITF MOs configured by the system ranges from 10000 to 19999.
Policy Group Name

Indicates the name of the IPSec policy group.
Interface ID

Indicates the ID of the interface to which the IPsec policy group is bound. When IPsec Policy Group Binding Mode in the IKECFG MO is set to ALL, an IPsec policy group can be bound only to a common interface and the IPsec policies take effect on the common interface and all VLAN subinterfaces in the default routing domain of the physical port on which the common interface is located. When IPsec Policy Group Binding Mode in the IKECFG MO is set to SINGLE, the IPsec policies take effect only on the interface bound to the IPsec policy group. The interface IDs in the range of 0 to 1499 are used for user-configured interfaces, and the interface IDs in the range of 10000 to 19999 are used for system-configured interfaces.
Control Mode

Indicates whether the object can be modified or deleted by the system. The value MANUAL_MODE means that only the user can modify or delete the object. The value AUTO_MODE means only the system can modify or delete the object.
