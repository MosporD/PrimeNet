GTPU

TRANSPORT
  +-GTPU

Description

A GTP-U MO defines GTP-U global parameters, which are used to set GTP-U service packets and the GTP-U detection global function.

Effective Scenario

Not involved

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the USERPLANEHOST, EPGROUP, and GEPMODELPARA MOs:
    • [Co-MPT, eNodeB, gNodeB]If a USERPLANEHOST MO with FLAG set to SLAVE is configured in an EPGROUP MO, then STATICCHK in the GTPU MO must be set to ENABLE. In addition, STATICCHKMODE in the GEPMODELPARA MO must be set to EPSTATICCHK, and STATICCHK in the EPGROUP MO must be set to ENABLE.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
ECHO Frame Timeout

Indicates the maximum wait time for an echo response. If no echo response is received during the period specified by this parameter, the timer has expired.
ECHO Frame Timeout Count

Indicates the maximum number of timeouts of the echo response waiting timer. If no echo response is received after the number specified by this parameter is reached, the GTP-U path in use fails.
DSCP

Indicates the differentiated services code point (DSCP) of a GTP-U control packet.
Static Check Switch

Indicates whether to enable static detection in compliance with GPRS Tunneling Protocol for User Plane (GTP-U). If this parameter is set to ENABLE, the GTP-U static check is enabled. If this parameter is set to DISABLE, the GTP-U static check is disabled.
Uplink GTP-U Sequence Number Padding Switch

Indicates the switch for padding the sequence numbers of uplink GTP-U service packets. If this parameter is set to ENABLE(Enable), consecutive sequence numbers in ascending order will be padded for uplink GTP-U service packets sent by the local end. If this parameter is set to DISABLE(Disable), the padding function will not take effect. This parameter is valid for the S1 interface only and its setting takes effect on the UMPT/UMDU board only.
Downlink GTP-U Sequence Number Check Switch

Indicates the switch for checking the sequence numbers of downlink GTP-U service packets. If this parameter is set to ENABLE(Enable), the local end performs statistics on the disorders and discontinuous sequence numbers on downlink GTP-U service packets. If this parameter is set to DISABLE(Disable), the check function will not take effect and the values of corresponding performance counters are invalid. This parameter is valid only for the UMPT/UMDU board. The values of corresponding performance counters reported for boards that do not support this parameter are invalid.
Table 3 Dynamic parameters

Parameter

Description
Number of transmitted packets in a GTP-U ECHO test

This parameter indicates the number of transmitted packets in a GTP-U ECHO test.
Number of received packets in a GTP-U ECHO test

This parameter indicates the number of received packets in a GTP-U ECHO test.
Static GTP-U ECHO test switch

Indicates whether to enable the GTP-U static detection function for a link. When this parameter is set to ENABLE(Enable), the GTP-U static detection function is enabled for a link. When this parameter is set to DISABLE(Disable), the GTP-U static detection function is disabled for a link. If the local and peer IP addresses specified using the DSP GTPUECHO command are the same as those of an IP path or user-plane link, the value of Static GTP-U ECHO test switch is the same as that of Static Check Switch for the IP path or user-plane link. If the local and peer IP addresses specified using the DSP GTPUECHO command do not match a corresponding IP path or user-plane link, the value of Static GTP-U ECHO test switch is the same as that of Static Check Switch in the GTPU MO.
