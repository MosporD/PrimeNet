TWAMPCLIENT

TRANSPORT
  +-TWAMPCLIENT
    +-TWAMPSENDER[0~16]

Description

A TWAMPCLIENT MO configures a Two-way Active Measurement Protocol (TWAMP) client. In the full architecture, it establishes a TCP connection with a TWAMP responder to negotiate control information about measurement sessions, such as DSCP and UDP port numbers. In the light architecture, it is used to configure an IP link to a TWAMP responder.

Effective Scenario

Immediately

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD TWAMPCLIENT

Use this command to add a TWAMP client.
DSP TWAMPCLIENT

Use this command to query the negotiation status of a TWAMP client. This command takes effect only when the TWAMP client works in the full architecture.
LST TWAMPCLIENT

Use this command to query the configuration of a TWAMP client.
MOD TWAMPCLIENT

Use this command to modify the configuration of a TWAMP client.
RMV TWAMPCLIENT

Use this command to remove a TWAMP client.

Parameter

Description
