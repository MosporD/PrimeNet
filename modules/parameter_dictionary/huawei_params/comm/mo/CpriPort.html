Description

CPRI ports comply with the CPRI or eCPRI protocol. The link between the CPRI ports of the BBU and the RRU allows transfer of control signals and user data between the BBU and the RRU.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    AAMU;BBP;BRI;CXU;GTMU;MDU;RFU;RHUB;RRU;UCIU;EDC
  • Relation with the CPRIPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, if TT is set to CHAIN and AT is not set to PEERPORT, or when TT is set to RING or when TT is set to LOADBALANCE and AT is not set to PEERPORT, the CPRIPORT MO meeting the following conditions must be already configured:
    • 1. The CPRIPORT MO is associated with HCN, HSRN, HSN, HPN, and HSPN in the RRUCHAIN MO.
    • 2. When TT in the RRUCHAIN MO is not set to CHAIN, the CPRIPORT MO is associated with TCN, TSRN, TSN, TPN, and TSPN in the RRUCHAIN MO.
  • Relation with the RRUCHAIN MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, if TT is set to TRUNK_CHAIN and AT is not set to PEERPORT, the CPRIPORT MO meeting the following conditions must be already configured:
    • 1. When the value of CONNPORTNUM in the RRUCHAIN MO is greater than or equal to 1, the CPRIPORT MO is associated with CONNCN1, CONNSRN1, CONNSN1, CONNPN1, and CONNSPN1 in the RRUCHAIN MO.
    • 2. When the value of CONNPORTNUM in the RRUCHAIN MO is greater than or equal to 2, the CPRIPORT MO is associated with CONNCN2, CONNSRN2, CONNSN2, CONNPN2, and CONNSPN2 in the RRUCHAIN MO.
    • 3. When the value of CONNPORTNUM in the RRUCHAIN MO is greater than or equal to 3, the CPRIPORT MO is associated with CONNCN3, CONNSRN3, CONNSN3, CONNPN3, and CONNSPN3 in the RRUCHAIN MO.
    • 4. When the value of CONNPORTNUM in the RRUCHAIN MO is 4, the CPRIPORT MO is associated with CONNCN4, CONNSRN4, CONNSN4, CONNPN4, and CONNSPN4 in the RRUCHAIN MO.
  • Relation with the BBP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE is set to LCOP in the BBP MO that corresponds to the board specified by CN, SRN, and SN in a CPRIPORT MO, ADMINISTRATIVESTATE in the CPRIPORT MO must be set to UNBLOCKED.
  • Relation with the BBP, BRI, GTMU, RHUB, and CXU MOs:
    • [NodeB, eGBTS, eNodeB]If ADMINISTRATIVESTATE in the CPRIPORT MO is set to BLOCKED, a BBP, BRI, GTMU, MDU, RHUB, or CXU with CXUTYPE set to RMU must be configured in the slot specified by CN, SRN, and SN in the CPRIPORT MO.
  • Relation with the BBP, BRI, GTMU, RHUB, CXU, and EDC MOs:
    • [Co-MPT]If ADMINISTRATIVESTATE in the CPRIPORT MO is set to BLOCKED, a BBP, BRI, GTMU, MDU, EDC, RHUB, or CXU with CXUTYPE set to RMU must be configured in the slot specified by CN, SRN, and SN in the CPRIPORT MO.
  • Relation with the BBP, RHUB, and CXU MOs:
    • [gNodeB]If ADMINISTRATIVESTATE in the CPRIPORT MO is set to BLOCKED, a BBP, MDU, RHUB, or CXU with CXUTYPE set to RMU must be configured in the slot specified by CN, SRN, and SN in the CPRIPORT MO.

Related MML Commands

Table 1 Related MML commands

MML Command

Function
BLK CPRIPORT

Use this command to block a CPRI port.
DSP BRDARPSPOOFING

Use this command to query the ARP anti-spoofing information of boards.
DSP BRDINVALIDPKTINFO

Use this command to query the information about invalid packets on a board to trace attack sources.
DSP CPRIPORT

Use this command to query the dynamic information about a CPRI port on a BBU or a board on an RRU chain/ring.
DSP RRUCHAINPHYTOPO

Use this command to query the topology and hardware information about the RRU chain/ring connected to a CPRI port.
DSP RRUIPPM

Use this command to query the IP PM information of RRUs.
DSP RRUTLSERRINFO

Use this command on BBUs to query the TLS information of RRUs. In the query result, a maximum of three latest records (including historical data) can be displayed for an RRU.
LST CPRIPORT

Use this command to query the state of the CPRI port.
UBL CPRIPORT

Use this command to unblock a CPRI port.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the board where the CPRI port is located. This parameter is configured automatically when the CPRI port is created. The CPRI port is used for the configuration check when an RRU chain/ring is added.
Subrack No.

Indicates the subrack number of the board where the CPRI port is located. This parameter is configured automatically when the CPRI port is created. The CPRI port is used for the configuration check when an RRU chain/ring is added.
Slot No.

Indicates the slot number of the board where the CPRI port is located. This parameter is configured automatically when the CPRI port is created. The CPRI port is used for the configuration check when an RRU chain/ring is added.
Port No.

Indicates the port number of the board where the CPRI port is located. This parameter is configured automatically when the CPRI port is created. A CPRI port is created automatically when a board with CPRI ports is added by running the ADD BRD command. The CPRI port is used for the configuration check when an RRU chain/ring is added.
Administrative Status

Indicates the administrative state of a CPRI port. The administrative state of a CPRI port can be BLOCKED or UNBLOCKED. The value BLOCKED indicates that the CPRI port is blocked or a breakpoint is configured near the CPRI port at the local or peer mode. The value UNBLOCKED indicates that the CPRI port is unblocked and no breakpoint is configured near the CPRI port at the local or peer mode. If CPRI MUX/eCPRI MUX is deployed in separate-MPT scenarios, the queried value of this parameter is NULL for the baseband processing board on the converged party.
Port Type

Indicates the type of the CPRI port.
Sub Port No.

Indicates the number of a sub-port on a CPRI port. This parameter is valid only when the port mode of XCI on the RMU is 2x10GE or the port is on the baseband processing board. The value NULL indicates that the connected port of the device has no subport.
SFP Switch

Indicates whether to enable the TX function of the optical module on the port. When this switch is turned on, the optical laser of the optical module works properly. When this switch is turned off, the optical laser of the optical module stops transmitting optical signals. This parameter is invalid when the board type is RHUB or RMU.
Table 3 Dynamic parameters

Parameter

Description
CPRI Bit Rate

Indicates the rate at the CPRI port. The optical or electrical module where the port located is securely installed and a CPRI link has not been established, the queried value of this parameter is UNKNOWN. If the optical or electrical module is incorrectly installed, the queried value of this parameter is NULL. For details about the CPRI, see the CPRI specifications.
Install Status

Indicates the in-position state of the CPRI port. If CPRI MUX/eCPRI MUX is deployed in separate-MPT scenarios, the queried value of this parameter is NULL on the converged party side.
CPRI Port Mode

Indicates the mode of the CPRI port. There are two modes: Maser and Slave.
SFP Module Type

Indicates the type of the optical or electrical module. If CPRI MUX/eCPRI MUX is deployed in separate-MPT scenarios, the queried value of this parameter is NULL on the converged party. If the optical or electrical module is incorrectly installed, the queried value of this parameter is NULL.
CPRI Port Mux Status

Indicates the multiplexing status of a CPRI port. When the channel between the converged party and the converged party fails, "UNKNOWN" is displayed if you query the status of a CPRI port of the aggregated party and "NULL" is displayed if you query the status of a CPRI port on an RRU. The value of the CpriMuxStatus parameter for an RMU port connecting to a lower-level node is NORMAL(Normal).
Availability Status

Indicates the availability state of a CPRI port. The availability state of a CPRI port can be NORMAL, INBREAKPOIT, or NULL. The value INBREAKPOIT indicates that a breakpoint is configured on the chain/ring. In this case, the CPRI link is disconnected although fiber optic cables are connected. The breakpoint is configured to prevent temporary alarms from being reported during network operations. The value NORMAL indicates that no breakpoint is configured on the chain/ring and the CPRI port is unblocked. The value NULL indicates that the CPRI port is blocked and no breakpoint is configured near the CPRI port. If CPRI MUX/eCPRI MUX is deployed in separate-MPT scenarios, the queried value of this parameter is NULL on the converged party.
Remaining Continuous Bandwidth

Indicates the bandwidth that has not been occupied. If the optical module is not in position or the type of the optical module is QSFP, this parameter value is NULL.
Remaining Discontinuous Bandwidth

Indicates the bandwidth that is fragmented after bandwidth usage changes due to cell deletion or configuration modification and cannot be used by other cells. If the optical module is not in position or the type of the optical module is QSFP, this parameter value is NULL.
Protocol Type

Indicates the effective protocol type of the port.
Cable Reservation Status

Indicates whether network cables are reserved for the RRU downstream port. Only certain pRRUs support this parameter. If this parameter is not supported or no network cable is reserved, the queried value of this parameter is NULL.
Network Cable Length Level

Indicates the length level of the Ethernet cable between the electrical RHUB branch chain port and the first-level RRU. Level 1 indicates that the tested Ethernet cable supports a maximum data rate of 10.1 Gbit/s within the specified length range. Level 2 indicates that the tested Ethernet cable supports a maximum data rate of 3.0 Gbit/s within the specified length range. NULL indicates that the test result of the Ethernet cable length level is not available. The network cable length level is not found. The possible cause is that no link is set up between the RHUB and the pRRU at the physical layer, or the measurement is not complete after the link is set up at the physical layer.
