HYBRIDCLK

EQUIPMENT
  +-HYBRIDCLK

Description

The HYBRIDCLK MO is the hybrid clock.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT
  • Relation with the IPCLKLNK and SYNCETH MOs:
    • [Co-MPT, NodeB, eNodeB, gNodeB]In a HYBRIDCLK MO, if TCLKSRC is set to IPCLK and FCLKSRC is set to SYNCETH, the SYNCETH MO and IPCLKLNK MO with DEVTYPE set to OC_SLAVE and ICPT set to PTP must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD HYBRIDCLK

Use this command to add a hybrid reference clock.
DSP HYBRIDCLK

Use this command to query the running status of a hybrid reference clock.
LST HYBRIDCLK

Use this command to query the configuration of a hybrid reference clock.
RMV HYBRIDCLK

Use this command to remove the hybrid reference clock.
