RETPORT

EQUIPMENT
  +-RRU
    +-RETPORT

Description

The RetPort MO is a port on the RRU to which the multi-wire cable can be connected. The MO is used by the BS to communicate with and control the ALD using RS485 signals.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RRU
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of RETPORT MOs configured on one RRU MO must be greater than or equal to 0 and smaller than or equal to 1.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function

Use this command to list the configuration of a remote electrical tilting (RET) port.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number of the RRU where the RET port is located.
Subrack No.

Indicates the subrack number of the RRU where the RET port is located.
Slot No.

Indicates the slot number of the RRU where the RET port is located.
Port No.

Indicates the number of the RET port on an RRU. This parameter is set to RET_PORT.
ALD Power Switch

Indicates the state of the ALD power supply switch. If SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), RAS (Remote Azimuth Steering Unit), or RGPS (Remote GPS) is used, the ALD power supply switch must be set to ON. In actual running, the RRU automatically sets this switch to OFF for an RET port when the ALM-26530 RF Module ALD Current Abnormal alarm is reported due to overcurrent, overcurrent protection, or undercurrent protection (the RRU supports undercurrent protection and Low Current Protect Switch is set to ON for the RRU) on the RET port. For details, see ALM-26530 RF Module ALD Current Abnormal.
Current Alarm Threshold Type

Indicates the type of the ALD current alarm threshold. This parameter is valid only if the ALD power supply switch is turned on. If this parameter is not set to UER_SELF_DEFINE, the current alarm thresholds must be set according to the ALD type and connection mode.

1. For RET antennas only (multi-wire cable), Undercurrent Alarm Occur Threshold must be set to 10 mA, Undercurrent Alarm Clear Threshold must be set to 15 mA, Overcurrent Alarm Occur Threshold must be set to 150 mA, and Overcurrent Alarm Clear Threshold must be set to 120 mA.

2. For RET antennas and AISUs, Undercurrent Alarm Occur Threshold must be set to 20 mA, Undercurrent Alarm Clear Threshold must be set to 25 mA, Overcurrent Alarm Occur Threshold must be set to 550 mA, and Overcurrent Alarm Clear Threshold must be set to 510 mA.

3. For AISUs only, Undercurrent Alarm Occur Threshold must be set to 10 mA, Undercurrent Alarm Clear Threshold must be set to 15 mA, Overcurrent Alarm Occur Threshold must be set to 350 mA, and Overcurrent Alarm Clear Threshold must be set to 300 mA.

4. For RGPS only, Undercurrent Alarm Occur Threshold must be set to 0 mA, Undercurrent Alarm Clear Threshold must be set to 10 mA, Overcurrent Alarm Occur Threshold must be set to 300 mA, and Overcurrent Alarm Clear Threshold must be set to 200 mA.

5. For RGPSs and AISUs, Undercurrent Alarm Occur Threshold must be set to 10 mA, Undercurrent Alarm Clear Threshold must be set to 15 mA, Overcurrent Alarm Occur Threshold must be set to 350 mA, and Overcurrent Alarm Clear Threshold must be set to 300 mA.
Undercurrent Alarm Occur Threshold

Indicates the undercurrent alarm occur threshold. When the ALD current value is smaller than this threshold, an ALM-26530 RF Unit ALD Current Out of Range alarm is reported. The specific problem is undercurrent.
Undercurrent Alarm Clear Threshold

Indicates the undercurrent alarm clear threshold. When the ALD current value is greater than this threshold, the ALM-26530 RF Unit ALD Current Out of Range alarm is cleared.
Overcurrent Alarm Occur Threshold

Indicates the overcurrent alarm occur threshold. When the overcurrent alarm occur threshold is lower than the maximum current supported by the hardware, the overcurrent alarm occur threshold prevails. In this case, when the ALD current value is greater than this threshold, ALM-26530 RF Unit ALD Current Out of Range is reported and the specific problem is overcurrent. When the overcurrent alarm occur threshold is higher than the maximum current supported by the hardware, the maximum current supported by the hardware serves as the overcurrent alarm threshold. In this case, when the ALD current value is the same as or greater than the maximum current supported by the hardware, ALM-26530 RF Unit ALD Current Out of Range is reported and the specific problem is overcurrent protection.
Overcurrent Alarm Clear Threshold

Indicates the overcurrent alarm clear threshold. When the overcurrent alarm clear threshold is lower than the maximum current supported by the hardware, the overcurrent alarm clear threshold prevails. When the ALD current value is lower than this threshold, ALM-26530 RF Unit ALD Current Out of Range is cleared.When the overcurrent alarm clear threshold is higher than the maximum current supported by the hardware, the maximum current supported by the hardware serves as the overcurrent alarm threshold. When the ALD current value is lower than the maximum current supported by the hardware, ALM-26530 RF Unit ALD Current Out of Range is cleared.
