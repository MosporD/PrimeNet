SECTOR

EQUIPMENT
  +-CARRIERRESOURCE
    +-SECTOR

Description

A SECTOR MO consists of parameters related to a radio area covered by a set of RF antennas with the same coverage.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CARRIERRESOURCE
  • Relation with the SECTOR MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]An antenna can be configured only in one SECTOR MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the slot number is 255 for antennas in a sector, a maximum of two antennas can be configured for the sector. If two antennas are configured, the following conditions must be met: 1. The channel number of each antenna can only be R0A or R0B. 2. The antennas have the same cabinet number and subrack number.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If two antennas in the same sector or different sectors have the same cabinet number and subrack number, the slot numbers of the two antennas cannot be 255 and a number other than 255.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The total number of sector antennas in all the sectors of a base station must be less than or equal to 1152.
  • Relation with the SECTOREQM MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The SECTOR MO corresponding to the SECTOREQM MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]An antenna in the sector equipment must exist in the sector that is quoted by the sector equipment.
  • Relation with the LOCATION MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in the SECTOR MO is not left blank, POSITIONINGMETHOD in the LOCATION MO corresponding to this character string cannot be set to POSITIONING_BY_UE.
  • Relation with the MPT and NODE MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The base station can support a maximum of 108 sectors when it is configured with the UMPTa/b board.
    • [Co-MPT, NodeB, eGBTS, eNodeB]The base station can support a maximum of 576 sector antennas when it is configured with the UMPTa/b board.
  • Relation with the MPT, GTMU, and NODE MOs:
    • [Co-MPT, eGBTS]A DBS3900, BTS3900, BTS3900A, BTS3900L, or BTS3900AL working in non-concurrent multiple modes supports a maximum of 12 sectors when it is configured with the GTMU board(the specification is configured as GTMUb) but not the UMPT board.
    • [Co-MPT, eGBTS]A DBS3900, BTS3900, BTS3900A, BTS3900L, or BTS3900AL working in non-concurrent multiple modes supports a maximum of 48 sector antennas when it is configured with the GTMU board(the specification is configured as GTMUb) but not the UMPT board.
    • [Co-MPT, eGBTS]A DBS3900, BTS3900, BTS3900A, BTS3900L, or BTS3900AL working in non-concurrent multiple modes supports a maximum of 108 sectors when it is configured with the GTMU board(the specification is not configured as GTMUb) but not the UMPT board.
    • [Co-MPT, eGBTS]A DBS3900, BTS3900, BTS3900A, BTS3900L, or BTS3900AL working in non-concurrent multiple modes supports a maximum of 288 sector antennas when it is configured with the GTMU board(the specification is not configured as GTMUb) but not the UMPT board.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Sector ID

Indicates the number of the sector.
Sector Name

Indicates the name of the sector.
Location Name

Indicates the location name of the base station. Generally, the LocationName parameter is set to the same value for all sectors in an RF site, and base station can acquire the location information of RF modules through this parameter. However, if the LocationName parameter of the RF module is set in the RRU or AAS MO, the base station will acquire the location information of RF modules through the RRU or AAS MO.
User Label

Indicates the user-defined information of a sector. The value of this parameter consists of xx::yy and common character strings, which are separated by percentage signs (%), for example, %tel::88888888%owner::huawei%20130101. xx::yy indicates that the value of xx is yy.
Antenna Azimuth

Indicates the azimuth of the sector antenna main lobe, which is an angle rotating clockwise from the due north to the direction of the sector antenna main lobe. For example, this parameter is set to 0 for the due north and to 900 for the due east (the unit is 0.1 degrees). This parameter is only for directional antennas. The value 65535 indicates that this parameter is invalid.
Sector Antenna

Indicates the information about the sector antenna.
Table 3 Dynamic parameters

Parameter

Description
Mode

Indicates the mode in which the RRU channel connected to a sector antenna is working.
RX Frequency Range

Indicates the range of RX frequencies supported by the RRU channel connected to a sector antenna.
TX Frequency Range

Indicates the range of TX frequencies supported by the RRU channel connected to a sector antenna.
Sector License

Indicates the license to be requested for a sector.
License State

Indicates the license status of a sector.
