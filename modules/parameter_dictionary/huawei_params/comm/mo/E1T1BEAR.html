E1T1BEAR

TRANSPORT
  +-E1T1BEAR

Description

An E1T1BEAR MO consists of the parameters for setting the bearing mode of the E1/T1 port on a board. The bearing mode is classified into IP and ATM.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS]When TYPE in the MDU MO is set to MDUC, the E1T1BEAR MO cannot be configured.
  • Relation with the PPPLNK MO:
    • [Co-MPT, NodeB]MODE in the E1T1BEAR MO associated with a PPPLNK MO must be set to IP.
  • Relation with the MPGRP MO:
    • [Co-MPT, NodeB]MODE in the E1T1BEAR MO associated with an MPGRP MO must be set to IP.
  • Relation with the UNILNK MO:
    • [Co-MPT, NodeB]The E1T1BEAR MO in a UNILNK MO must have been configured.
    • [Co-MPT, NodeB]MODE in the E1T1BEAR MO associated with a UNILNK MO must be set to ATM.
  • Relation with the IMAGRP MO:
    • [Co-MPT, NodeB]The E1T1BEAR MO associated with an IMAGRP MO must have been configured.
    • [Co-MPT, NodeB]MODE in the E1T1BEAR MO associated with an IMAGRP MO must be set to ATM.
  • Relation with the FRAATM MO:
    • [Co-MPT, NodeB]The E1T1BEAR MO in an FRAATM MO must have been configured.
    • [Co-MPT, NodeB]MODE in the E1T1BEAR MO associated with an FRAATM MO must be set to ATM.
  • Relation with the HAGRP MO:
    • [Co-MPT, NodeB]In one logical protection group, SN in an HAGRP MO must be the same as that in an E1T1BEAR MO.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of E1T1BEAR MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
    • [Co-MPT, eGBTS]The number of E1T1BEAR MOs with MODE set to ATM is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD E1T1BEAR

Use this command to add the bearing mode for E1/T1 ports on a specified board.
LST E1T1BEAR

Use this command to list the bearing mode settings of E1/T1 ports.
RMV E1T1BEAR

Use this command to remove an E1/T1 bearing mode of a specified board.
SET E1T1BEAR

Use this command to set the bearing mode of an E1/T1 port on a specified board.
