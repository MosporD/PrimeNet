IFIP

TRANSPORT
  +-IFIP

Description

This MO indicates the interface IP address for a PPP port, MP port, Ethernet port, Ethernet CI port, subinterface, or Ethernet trunk port. The interface IP address takes effect immediately after being configured.

Effective Scenario

Immediately
