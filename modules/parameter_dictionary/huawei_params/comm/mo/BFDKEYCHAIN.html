BFDKEYCHAIN

TRANSPORT
  +-BFDKEYCHAIN
    +-BFDKEY[0~3]

Description

The BFDKEYCHAIN MO is used to configure a BFD key chain. Multiple BFD key chains can be configured.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT

  • Possible children:

    BFDKEY[0~3]
  • Relation with the BFDKEY MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A maximum of 3 BFDKEY MOs can be configured in one BFDKEYCHAIN MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The BFDKEYCHAIN MO instance used by a BFDKEY MO must have been configured.
  • Relation with the BFD MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When BFDAUTHSW in the BFD MO is set to ON, the BFDKEYCHAIN MO instance used by a BFD MO must have been configured.
  • Relation with the BFDSESSION MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When BFDAUTHSW in the BFDSESSION MO is set to ON, the BFDKEYCHAIN MO instance used by a BFDSESSION MO must have been configured.
