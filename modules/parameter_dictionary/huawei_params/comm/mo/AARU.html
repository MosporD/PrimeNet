AARU

EQUIPMENT
  +-AAS
    +-AARU
      +-RXBRANCH[0~8]
      +-TXBRANCH[0~8]
      +-VANTENNAPORT[32~32]
      +-VRET[1~1]

Description

An AARU MO defines an AARU, which provides ports for sending and receiving baseband and RF signals and processes the uplink and downlink baseband signals.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    AAS

  • Possible children:

    RXBRANCH[0~8];TXBRANCH[0~8];VANTENNAPORT[32~32];VRET[1~1]
  • Relation with the AAS MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The AAS MO corresponding to CN and SRN in the AARU MO must have been configured.
  • Relation with the VRET MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The AARU MO corresponding to DEVICENO, CONNCN, CONNSRN, and CONNSN in the VRET MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB]The VRET MO corresponding to AARU MO must exist.
  • Relation with the TXBRANCH and RXBRANCH MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The number of TXBRANCH MOs related to the AARU MO must be equal to TXNUM in the AARU MO, and the number of RXBRANCH MOs related to the AARU MO must be equal to RXNUM in the AARU MO.
  • Relation with the AAMU, RHUB, RRU, and CXU MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]Only the cabinet number and subrack number of the RRU MO with RT set to MPRF can be the same as those of the RRU MO with RT set to MPMU.
  • Relation with the RRUCHAIN MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If an RRUCHAIN MO with TT set to LOADBALANCE is connected to a CXU MO with CXUTYPE set to RMU and an AARU MO, RS in the AARU MO cannot be set to UO and GO.
  • Relation with the CXU and RRUCHAIN MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If an RRUCHAIN is connected to a CXU MO with CXUTYPE set to RMU and an AARU MO, RS in the AARU MO must be included in the working mode of the RMU.
  • Relation with the VANTENNAPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]The number of VANTENNAPORT MOs configured on one AARU MO must be 32.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD AARU

Use this command to add an active antenna radio unit (AARU).
DSP AARU

Use this command to query the dynamic information about an active antenna radio unit (AARU). The information to be queried is as follows: the number of RX and TX channels, Maximum output power on the TX channel, the uplink channel gain, and other information about the AARU.
LST AARU

Use this command to list the active antenna radio unit (AARU) configuration.
MOD AARU

Use this command to modify the active antenna radio unit (AARU) configuration.
RMV AARU

Use this command to remove an active antenna radio unit (AARU).
STR ANTTEST

Use this command to start an antenna quality test for an active antenna-radio unit (AARU), a radio unit (RU) in the AAU that supports this test, or a radio phase calibration unit (RPCU).

Related Parameters

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the number of the cabinet where the AARU is located.

Indicates the intermediate frequency offset of the AARU. This parameter is set during the network planning to avoid the external signal interference around the current received frequency, and accordingly improve the receiver sensitivity of the system.

Indicates the number of logical TX channels of the AARU. For details, see AAS Feature Parameter Description.

Indicates whether to enable TX channels on the AARU, ON indicates that TX channels are enabled and OFF indicates that TX channels are disabled. On the AARU, all TX channels must be simultaneously enabled or disabled.
AARU Work Standard

Indicates the working standard of the AARU.
VRET No.

Indicates the number of a virtual antenna corresponding to the AARU.
Power Supply Group ID

Indicates the ID of a group which consists of one or multiple AARUs served by the same power supply system. This parameter must be set to the same value for AARUs served by the same power supply system. This parameter must be set to different values for AARUs served by different power supply systems.

Max Tilt Difference Between Carriers

Indicates the maximum tilt difference between carriers supported by the virtual antenna subunit corresponding to the AARU.
The length of the fiber optic cable between the BBU and RF module

Indicates the length of the fiber optic cable between the BBU and RF module. When the RF module works in cold backup mode, the parameter indicates the length of the fiber optic cable that carries RF data. When the RF module works in hot backup or load sharing mode, there are two fiber optic cables between the BBU and RF module, and the parameter indicates the length of the shorter one. The parameter is inaccurate due to factors such as the refractive index. The longer the fiber optic cable, the smaller the error. The relationship between the length of the fiber optic cable and the error is as follows: When the length of the fiber optic cable is smaller than 600 m, the error is large and the parameter is for your reference only. When the length of the fiber optic cable ranges from 600 m to 2000 m, the error is less than 10%. When the length of the fiber optic cable ranges from 2000 m to 12000 m, the error is less than 5%. When the length of the fiber optic cable is greater than 12000 m, the error is less than 2.5%.
