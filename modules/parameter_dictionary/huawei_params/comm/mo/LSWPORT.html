LSWPORT

TRANSPORT
  +-LANSW
    +-LSWPORT

Description

Switch ports controlled by a layer 2 LAN switch. A switch port supports two media types, Ethernet and air-interface link.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    LANSW
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, eNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the LSWPORT MO cannot be configured.
  • Relation with the ETHPORT MO:
    • [Co-MPT, eNodeB]The ETHPORT MO on which ETHPORTID in an LSWPORT MO depends must exist.
  • Relation with the ETHTRUNKLNK MO:
    • [Co-MPT, eNodeB]The settings of the following parameters in the LSWPORT MO's CN, SRN, SN, PN cannot be the same as those in the ETHTRUNKLNK MO. That is, the ETHPORT MO associated with the LSWPORT MO of the Ethernet type cannot be referenced by the ETHTRUNKLNK MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD LSWPORT

Use this command to add a layer 2 LAN switch port of Ethernet type.
DSP LSWPORT

Use this command to query the operating status of a layer 2 LAN switch port.
LST LSWPORT

Use this command to list all configured layer 2 LAN switch ports.
MOD LSWPORT

Use this command to modify the configuration of a layer 2 LAN switch port.
RMV LSWPORT

Use this command to remove a layer 2 LAN switch port of Ethernet type.

Indicates the number of packets discarded by a layer 2 LAN switch port in the receive direction due to MAC MISS. Dropped Packets In Reception direction Due to Broad Cast forwarding Rate Limit Overflow

Indicates the number of broadcast packets discarded by a layer 2 port in the receive direction when the number of broadcast packets exceeds a specified threshold. This parameter is valid only for layer 2 switch ports of the Ethernet type.
