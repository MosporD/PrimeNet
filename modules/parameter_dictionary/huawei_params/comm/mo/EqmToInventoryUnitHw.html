EQMTOINVENTORYUNITHW

EQUIPMENT
  +-EQMTOINVENTORYUNITHW

Description

The EQMTOINVENTORYUNITHW MO defines the mapping between the inventory hardware model and the configuration object model.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT

Related Parameters

Table 1 describes the parameters related to this MO.

Table 1 Configuration parameters

Parameter

Description
Inventory Unit Hardware ID

Indicates the ID of an inventory hardware unit.
MOC name

Indicates the type of the configuration object managing an inventory hardware unit.
Cabinet No.

Indicates the key fields of the cabinet housing the configuration object corresponding to an inventory hardware unit. This parameter is valid only when the key fields include the cabinet number. The default value 65535 indicates that this parameter is invalid.
Subrack No.

Indicates the key fields of the subrack housing the configuration object corresponding to an inventory hardware unit. This parameter is valid only when the key fields include the subrack number. The default value 65535 indicates that this parameter is invalid.
Slot No.

Indicates the key fields of the slot holding the configuration object corresponding to an inventory hardware unit. This parameter is valid only when the key fields include the slot number. The default value 65535 indicates that this parameter is invalid.
Module ID

Indicates the ID of an optical module. This parameter is valid only for optical modules. The default value 65535 indicates that this parameter is invalid.
Device No.

Indicates the ID of an antenna line device (ALD). This parameter is valid only for ALDs. The default value 65535 indicates that this parameter is invalid.
Subboard Type

Indicates the sub-board type. This parameter is valid only for optical modules.
