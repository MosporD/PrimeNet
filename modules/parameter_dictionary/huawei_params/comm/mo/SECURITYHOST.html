SECURITYHOST

TRANSPORT
  +-SECURITYHOST

Description

The SECURITYHOST MO is used to configure the parameters related to a security host. This MO can be referenced by multiple SCTP hosts or user-plane hosts for configuring their security attributes.

Effective Scenario

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Security Host ID

Indicates the ID of a security host.
SeGW Switch

Indicates whether to enable the peer end to perform IPSec negotiation with the local end through an SeGW. When this parameter is set to DISABLE, the peer end performs IPSec negotiation with the local end directly. When this parameter is set to ENABLE, the peer end establishes an IPSec tunnel to the local end through an SeGW.
SeGW Config Mode

Indicates the configuration mode of the SeGW.
IP Version

Indicates the IP protocol version of a security host.
Local IKE IP Address

Indicates the IP address of the physical port to which an IPsec policy group is to be bound as well as the local IP address of the corresponding IKE peer when SeGW Switch is set to DISABLE. This parameter specifies the IP address of the physical port to which an IPsec policy group is to be bound when SeGW Switch is set to ENABLE.
Local IKE IPv6 Address

Indicates the IPv6 address of the physical port to which an IPv6 IPsec policy group is to be bound as well as the local IPv6 address of the corresponding IPv6 IKE peer when SeGW Switch is set to DISABLE. This parameter specifies the IPv6 address of the physical port to which an IPv6 IPsec policy group is to be bound when SeGW Switch is set to ENABLE. This parameter takes effect only for LTE and NR.
IKE Peer Name

Indicates the name of the IKE peer.
IPSec Proposal Name

Indicates the name of the IPSec proposal used for IPSec negotiation between the local end and the security gateway (SeGW).
Security Parameters Template ID

Indicates the ID of the security parameter template referenced by a security host.
User Label

Indicates the description of a security host.
VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).
