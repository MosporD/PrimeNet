TSCROSS

TRANSPORT
  +-TSCROSS

Description

This MO indicates the timeslot cross-connection established between two E1/T1 ports. This enables one E1/T1 port to use the transport resources of the other E1/T1 port.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the E1T1 MO:
    • [Co-MPT, NodeB, eGBTS]The source and destination E1/T1 ports of a timeslot cross-connection must have the same working mode. The source E1/T1 port of a timeslot cross-connection corresponds to the E1T1 MO whose PS is set to ALLPORT and whose CN, SRN, SN, and SBT are the same as CN, SRN, SRCSN, and SRCSBT in the TSCROSS MO, respectively. The destination E1/T1 port of a timeslot cross-connection corresponds to the E1T1 MO whose PS is set to ALLPORT and whose CN, SRN, SN, and SBT are the same as CN, SRN, DSTSN, and DSTSBT in the TSCROSS MO, respectively. The two E1T1 MOs must have the same WORKMODE. If no E1T1 MO with PS set to ALLPORT has been configured, WORKMODE in the E1T1 MOs must be set to the default value, namely, E1_UNBA.
    • [Co-MPT, NodeB, eGBTS]Before adding a TSCROSS MO, ensure that the associated backplane E1T1 MO has been configured.
  • Relation with the TSCROSS MO:
    • [Co-MPT, NodeB, eGBTS]The total number of cross-board TSCROSS MOs, backplane E1T1 MOs, and cross-board MPLNK MOs configured on the same board cannot exceed eight.
    • [Co-MPT, NodeB, eGBTS]If either SRCPN or DSTPN in a TSCROSS MO is configured on a backplane E1T1 MO, the E1/T1 port corresponding to the backplane E1T1 MO has been occupied. In this case, the backplane E1T1 MO cannot be used by the ports corresponding to SRCPN and DSTPN in other TSCROSS MOs.
    • [Co-MPT, NodeB, eGBTS]A TSCROSS MO whose SRCTSN and DSTTSN have an intersection with those in an existing TSCROSS MO cannot be configured.
  • Relation with the HAGRP MO:
    • [Co-MPT, NodeB, eGBTS]In one logical protection group, SN in an HAGRP MO must be the same as SRCSN or DSTSN in a TSCROSS MO.
  • Relation with the PPPLNK MO:
    • [Co-MPT, NodeB, eGBTS]PPPLNK and TSCROSS MOs cannot use the same backplane E1/T1 port.
    • [Co-MPT, NodeB, eGBTS]The E1/T1 timeslots occupied by a PPPLNK MO and those occupied by a TSCROSS MO cannot have an intersection.
  • Relation with the MPLNK MO:
    • [Co-MPT, NodeB, eGBTS]MPLNK and TSCROSS MOs cannot use the same backplane E1/T1 port.
    • [Co-MPT, NodeB, eGBTS]The E1/T1 timeslots occupied by an MPLNK MO and those occupied by a TSCROSS MO cannot have an intersection.
  • Relation with the IMALNK MO:
    • [Co-MPT, NodeB, eGBTS]If SBT in an IMALNK MO is set to BACK_BOARD, the combination of CN, SRN, SN, SBT, and IMALNKN in the IMALNK MO must be different from the following combinations in the TSCROSS MO: (1) the combination of CN, SRN, SRCSN, SRCSBT, and SRCPN; (2) the combination of CN, SRN, DSTSN, DSTSBT, and DSTPN.
    • [Co-MPT, NodeB]A TSCROSS MO whose SRCTSN and DSTTSN have been used by an IMALNK MO on the same port cannot be configured.
  • Relation with the UNILNK MO:
    • [Co-MPT, NodeB, eGBTS]If SBT in a UNILNK MO is set to BACK_BOARD, the combination of CN, SRN, SN, SBT, and UNILNKN in the UNILNK MO must be different from the following combinations in the TSCROSS MO: (1) the combination of CN, SRN, SRCSN, SRCSBT, and SRCPN; (2) the combination of CN, SRN, DSTSN, DSTSBT, and DSTPN.
    • [Co-MPT, NodeB]A TSCROSS MO whose SRCTSN and DSTTSN have been used by a UNILNK MO on the same port cannot be configured.
  • Relation with the FRAATM MO:
    • [Co-MPT, NodeB, eGBTS]If SBT in an FRAATM MO is set to BACK_BOARD, the combination of CN, SRN, SN, SBT, and PN in the FRAATM MO must be different from the following combinations in the TSCROSS MO: (1) the combination of CN, SRN, SRCSN, SRCSBT, and SRCPN; (2) the combination of CN, SRN, DSTSN, DSTSBT, and DSTPN.
    • [Co-MPT, NodeB]A TSCROSS MO whose SRCTSN and DSTTSN have been used by an FRAATM MO on the same port cannot be configured.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS]When TYPE in the MDU MO is set to MDUC, the TSCROSS MO cannot be configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD TSCROSS

Use this command to add a timeslot cross connection between two E1/T1 ports.

In a dual-mode BS, after an E1/T1 port on the backplane is configured on a board, a timeslot cross connection from the panel of the board to the backplane must be created so that the source board can use the E1/T1 port shared by the destination board.

In a dual-mode co-site base station, a timeslot cross connection from the panel of the source board to that of the destination board must be created so that transparent transmission of E1/T1 signals is available or E1/T1 ports are shared.
LST TSCROSS

Use this command to list the configurations of all timeslot cross-connections.
RMV TSCROSS

Use this command to remove a configured timeslot cross-connection.
