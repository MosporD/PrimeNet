TUNNEL

TRANSPORT
  +-TUNNEL

Description

A TUNNEL MO is used to set the parameters related to backplane communication when co-transmission is implemented between radio access technologies.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the RSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PT in an RSCGRP MO is set to TUNNEL, the TUNNEL MO corresponding to PN in the RSCGRP MO must have been configured.
  • Relation with the TUNNEL MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]All the TUNNEL MOs configured for a BS can only cross two subracks.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Each TUNNEL MO must have a unique combination of SCN, DCN, SSRN, DSRN, SSN, and DSN.
  • Relation with the SUBIF MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A TUNNEL MO and a SUBIF MO cannot both be configured.
  • Relation with the VRF MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A TUNNEL MO and a VRF MO whose VRFIDX is set to 1 to 7 cannot both be configured.
  • Relation with the IPRT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If RTTYPE and IFT are set to IF and TUNNEL, respectively in an IPRT MO, IFNO in the IPRT MO must be the same as TUNNELID in the associated TUNNEL MO.
  • Relation with the LR MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PT in an LR MO is set to TUNNEL, the associated TUNNEL MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When removing a TUNNEL MO, the system automatically removes the LR MO that depends on the TUNNEL MO.
  • Relation with the PACKETFILTER MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PT in a PACKETFILTER MO is set to TUNNEL, the TUNNEL MO corresponding to PN in the PACKETFILTER MO must have been configured.
  • Relation with the HAGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the logical protection group where the SSN of the TUNNEL MO is located, the value of SN in the HAGRP MO must be the same as the value of SSN in the TUNNEL MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the logical protection group where the DSN of the TUNNEL MO is located, the value of SN in the HAGRP MO must be the same as the value of DSN in the TUNNEL MO.
  • Relation with the SRCIPRT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the RTTYPE and IFT parameters under the SRCIPRT MO are set to IF and TUNNEL, respectively, the IFNO parameter under the SRCIPRT MO must be set to the same value as that of the TUNNELID parameter under the TUNNEL MO.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, the TUNNEL MO cannot be configured.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, the TUNNEL MO cannot be configured.
  • Relation with the IPPATH MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT and JNRSCGRP in an IPPATH MO are set to TUNNEL and DISABLE, respectively, the associated TUNNEL MO must have been configured.
  • Relation with the DLFLOWCTRLPARA MO:
    • [Co-MPT, NodeB, eGBTS]If PT in a DLFLOWCTRLPARA MO is set to TUNNEL, the associated TUNNEL MO must have been configured.
  • Relation with the ULFLOWCTRLPARA MO:
    • [Co-MPT, NodeB, eGBTS]If PT in a ULFLOWCTRLPARA MO is set to TUNNEL, the associated TUNNEL MO must have been configured.
  • Relation with the DLFLOWCTRLPARA and ULFLOWCTRLPARA MOs:
    • [Co-MPT, NodeB, eGBTS]When removing a TUNNEL MO, the system automatically removes the DLFLOWCTRLPARA and ULFLOWCTRLPARA MOs that depend on the TUNNEL MO.
  • Relation with the GPM MO:
    • [Co-MPT, NodeB]If PT and RSCGRPID in a GPM MO are set to TUNNEL and DEFAULTPORT, respectively, the associated TUNNEL MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD TUNNEL

Use this command to add a tunnel that is for backplane communication when co-transmission is implemented between radio access technologies.
DSP TUNNEL

Use this command to query the status of a tunnel.
LST TUNNEL

Use this command to list the configurations of a tunnel.
MOD TUNNEL

Use this command to modify the configurations of a tunnel.
RMV TUNNEL

Use this command to remove a tunnel.
