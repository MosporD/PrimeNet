Related Parameters

Table 1 and Table 2 describes the parameters related to this MO.

Table 1 Configuration parameters

Parameter

Description
Inventory Unit Hardware ID

Indicates the ID of an inventory hardware unit.
Table 2 Dynamic parameters

Parameter

Description
Product Number

Indicates the code of a product. The value of this parameter corresponds to the PN number on the paper label and the Item field in the electronic label.
Description

Indicates the description on an electronic label. The value of this parameter corresponds to manufacturerData defined in the 3GPP specifications. This parameter is valid only when the inventory hardware unit is an optical module or RF module.
Vendor Name

Indicates the supplier of an inventory hardware unit.
Serial Number

Indicates the asset serial number of an inventory hardware unit. The value of this parameter corresponds to the BarCode field on an electronic label and the SN on a paper label.
Creditable

Indicates whether the asset information of an inventory hardware unit is trusted. If communications of an inventory hardware unit are abnormal, the asset information of the unit is untrusted.
Unit Position

Indicates the installation position of the inventory object.
Hardware Version

Indicates the hardware version of the inventory object.
Slot Position

Indicates the slot position of the inventory object.
Archives Information Version

Indicates the electronic label version of the inventory object.
BOM Number

Indicates the BOM code of the inventory object. The value of this parameter corresponds to the Item field on an electronic label.
Model

Indicates the model of an inventory hardware unit. The value of this parameter corresponds to the Model field on an electronic label.
Unit Name

Indicates the unit name of the inventory device. The unit name of a board equals the value of boardName in the device archive, and that of an antenna is always "Antenna".
Extra Information

Indicates the additional information of the inventory device, which refers to the additional information in the electronic label.
