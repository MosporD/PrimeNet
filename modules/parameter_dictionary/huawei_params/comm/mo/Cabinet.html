CABINET

EQUIPMENT
  +-CABINET
    +-SUBRACK[1~60]

Description

A Cabinet MO is an actual or virtual cabinet. An actual cabinet provides various functions according to its type, for example, power distribution, environment monitoring, and surge protection. A virtual cabinet is only a container of Subrack MOs.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT

  • Possible children:

    SUBRACK[1~60]
  • Relation with the CABINET MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The number of SUBRACK MOs with TYPE set to RFU under a CABINET MO must be 0 or 1 when TYPE in this CABINET MO is set to one of the following values: RFC, BTS3900, BTS3012_SRAN, BTS3012AE_SRAN, BTS3900AL, and BTS5900.
    • [Co-MPT, NodeB, eGBTS, eNodeB]TYPE in the SUBRACK MO can be set to BLADEBBU only when TYPE in the CABINET MO is set to VIRTUAL.
  • Relation with the FMU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The FMU MO with SRN set to 12 cannot be configured in/for a CABINET MO when TYPE in the CABINET MO is set to one of the following values: RFC, BTS3900, BTS3900AL, BTS5900, RFC5906, IFS5906.
  • Relation with the BDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The TYPE in the CABINET MO which is corresponding to BDU must be set to APM30, TMC, BTS3900, BTS3900L, BTS5900, BTS5900L, BTS3900AL, OMB, MRE1000, APM5930, OPM or VIRTUAL.
  • Relation with the LOCATION MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in a CABINET MO is not set to NULL, the corresponding LOCATION must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME in the CABINET MO is not left blank, POSITIONINGMETHOD in the LOCATION MO corresponding to this character string cannot be set to POSITIONING_BY_UE.
  • Relation with the RFU and LOCATION MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If LOCATIONNAME of a CABINET housing the RFU is not set to NULL, the corresponding LOCATION with LOCATIONTYPE set to BTSSITE or RFSITE must have been configured.
  • Relation with the SUBRACK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the CABINET MO is set to IFS5906, only the FMU, EMU, or MEB MO can be configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the CABINET MO is set to RFC5906, only the FMU, EMU, or MEB MO can be configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the CABINET MO is set to OPM, only the PMU MO can be configured.
  • Relation with the PMU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the CABINET MO housing the PMU MO is set to OPM, SRN in the PMU MO must be set to 7.
  • Relation with the RRU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When SN in the RRU MO is set to a value greater than 0 and RT in the RRU MO is not set to MPRF, SRN in the RRU MO must be set to 60, and TYPE in the CABINET MO where the RRU MO is located must be set to RFC5906 or IFS5906.
  • Relation with the CXU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When SN in the CXU MO is set to a value greater than 0, SRN in the CXU MO must be set to 60, and TYPE in the CABINET MO where the CXU MO is located must be set to RFC5906 or IFS5906.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CABINET

Use this command to add a cabinet.
DSP CABMFRINFO

Use this command to query the manufacturing information about a cabinet.
LST CABINET

Use this command to list the configuration of a cabinet. If the cabinet number is not specified, the system would list the configuration of all cabinets.
MOD CABINET

Use this command to modify attributes, including the cabinet description of a cabinet.
RMV CABINET

Use this command to remove a cabinet.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cabinet No.

Indicates the cabinet number.
Cabinet Type

Type of a cabinet. This parameter is set to VIRTUAL when the type of a cabinet is not within the value range of this parameter.
Cabinet Description

Indicates a brief description of the cabinet, which can be the function, location, and some other information of the cabinet. If the value of this parameter for the cabinet housing the root BBU includes tlmmpsw, both the MLPPP group fault detection period and PPP link fault detection period are automatically set to 1s.
Location Name

Indicates the location information of a cabinet. Set this parameter to the location name of the site. The location name of the site is configured in the Location object. LocationName must be set to the same value for RF modules serving the same sector.

Parameter

Description
Model

Indicates the physical type of cabinet.
