ACL

TRANSPORT
  +-ACL
    +-ACLRULE[0~6092]

Description

An access control list (ACL) is an instruction list for ports on routers and switches, which is used to control packets received on or transmitted from the port. Applied to all router protocols, an ACL contains matching relations, conditions, and query commands. The ACL framework is aimed at access control.

Effective Scenario

Immediately

  • Relation with the PACKETFILTERING MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If FM in a PACKETFILTERING MO is set to ADV_ACL, and ACLTYPE in a PACKETFILTERING MO is set to IPV4, the ACL MO corresponding to ACLID must have been configured. If FM in a PACKETFILTERING MO is set to L2_ACL, the ACL MO corresponding to ACLID must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The ACL MOs corresponding to ACLID in the PACKETFILTERING MO must be configured manually.
  • Relation with the PACKETFILTER MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]PT in a PACKETFILTER MO is set to ETH, ETHTRK, TUNNEL, or ETHCI. If FM is set to ADV_ACL, the ACL MO corresponding to ACLID must use the default VRF instance. If FM is set to L2_ACL, the ACL MO corresponding to ACLID2 must use the default VRF instance. If FM is set to ADV_AND_L2, the ACL MOs corresponding to ACLID and ACLID2 must use the default VRF instance.

  • Relation with the VRF MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The VRF MO used by an ACL MO must have been configured.
  • Relation with the ACLRULE MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If an ACLRULE MO is manually configured, the corresponding ACL MO must also be manually configured.
  • Relation with the IPSECPOLICY MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]CTRLMODE in the IPSECPOLICY MO must be set to the same value as CTRLMODE in the corresponding ACL MO.
  • Relation with the IPSECPOLICY and IKEPEER MOs:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If ACLTYPE in the IPSECPOLICY MO is set to IPV4 or IPV4+IPV6, and the IPVERSION in the IKEPEER MO referenced by this IPSECPOLICY MO is set to IPV4, VRFIDX in the ACL MO corresponding to an IPSECPOLICY MO must be set to 0.
    • [eGBTS]If ACLTYPE in the IPSECPOLICY MO is set to IPV4, and the IPVERSION in the IKEPEER MO referenced by this IPSECPOLICY MO is set to IPV4, VRFIDX in the ACL MO corresponding to an IPSECPOLICY MO must be set to 0.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, a maximum of 128 ACL MOs can be manually created in a base station.
  • Relation with the ACL MO:
    • [Co-MPT, eNodeB, gNodeB]On a BS, the total number of ACL MOs and ACL6 MOs must be less than or equal to 584.
    • [Co-MPT, eNodeB, gNodeB]A maximum of 256 ACL MOs can be manually created in a base station.
  • Relation with the IPSECPOLICY and ACL6 MOs:
    • [Co-MPT, eNodeB, gNodeB]If ACLTYPE in an IPSECPOLICY MO is set to IPV4+IPV6, the ACL and ACL6 MOs referenced by the IPSECPOLICY MO must have been configured.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of ACL MOs must be less than or equal to 16 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
ACL ID

Indicates the ID of the access control list (ACL) to which an access control rule belongs. An ACL rule with an ACL ID ranging from 3000 to 3999 indicates a high-level rule based on the layer 3 and layer 4 information configured by users. An ACL rule with an ACL ID ranging from 4000 to 4999 indicates a layer 2 rule based on the MAC layer information configured by users. An ACL rule with an ACL ID ranging from 7000 to 7999 indicates a high-level rule based on the layer 3 and layer 4 information configured by the system.
VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).
Description

Indicates the brief description of an ACL.
Control Mode

Indicates whether an object can be modified or deleted by the system. The value MANUAL_MODE means that only users can modify or delete the object. The value AUTO_MODE means only the system can modify or delete the object.
Auto Config Flag

Indicates whether an object is created by the system. The value MANUAL_CREATED means that the object is manually configured by users. The value AUTO_CREATED means that the object is created by the system.
Table 3 Dynamic parameters

Parameter

Description
Number of ACL Rules

Indicates the number of rules in the ACL.
Maximum ACL Rule ID

Indicates the largest rule ID in the ACL. This parameter takes effect only when the number of rules in an ACL is greater than 0.
Minimum ACL Rule ID

Indicates the smallest rule ID in the ACL. This parameter takes effect only when the number of rules in an ACL is greater than 0.
