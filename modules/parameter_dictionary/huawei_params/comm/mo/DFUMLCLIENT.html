DFUMLCLIENT

TRANSPORT
  +-DFUMLCLIENT

Description

A DFUMLCLIENT MO defines the information about a distributed function unit (DFU) management link client.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the IPADDR4 and OMCH MOs:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE is set to NEW, and IPVERSION in a DFUMLCLIENT MO is set to IPV4, IPVERSION in the DFUMLCLIENT MO must be set to the same value as IP in the OMCH MO or as IP in an IPADDR4 MO in the same routing domain.
  • Relation with the DEVIP and OMCH MOs:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE is set to OLD, and IPVERSION in a DFUMLCLIENT MO is set to IPV4, IPVERSION in the DFUMLCLIENT MO must be set to the same value as IP in the OMCH MO or as IP in an DEVIP MO in the same routing domain.
  • Relation with the VRF MO:
    • [Co-MPT, eNodeB, gNodeB]The VRF MO corresponding to VRFIDX in DFUMLCLIENT MO must have been configured.
  • Relation with the DFUMLCLIENT MO:
    • [Co-MPT, eNodeB, gNodeB]A maximum of two DFUMLCLIENT MO can be configured.
    • [Co-MPT, eNodeB, gNodeB]The UID parameters in different DFUMLCLIENT MOs must vary.
  • Relation with the DFU MO:
    • [Co-MPT, eNodeB, gNodeB]The DFU MO specified by UID in the DFUMLCLIENT MO must exist.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD DFUMLCLIENT

Use this command to add a DFU management link client.
DSP DFUMLCLIENT

Use this command to query the status of a DFU management link client.
LST DFUMLCLIENT

Use this command to list the configuration of DFU management link clients.
MOD DFUMLCLIENT

Use this command to modify a DFU management link client.
RMV DFUMLCLIENT

Use this command to remove a DFU management link client.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Client ID

Indicates the ID of a DFU management link client.
VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).
IP Version

Indicates the IP protocol version of a DFU management link client.
Client IPv4 Address

Indicates the IPv4 address of a DFU management link client.
Unit ID

Indicates the ID of a DFU.
User Label

Indicates the user-defined information about a DFU management link client.
Table 3 Dynamic parameters

Parameter

Description
Server IPv4 Address

Indicates the IPv4 address of a DFU management link server.
