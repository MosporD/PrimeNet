BACKTUNNEL

TRANSPORT
  +-BACKTUNNEL

Description

A BACKTUNNEL MO is used to configure a backplane communication tunnel when multimode co-transmission is used.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the PACKETFILTERING MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PT in a PACKETFILTERING MO is set to TUNNEL, the BACKTUNNEL MO corresponding to PORTID in the PACKETFILTERING MO must have been configured.
  • Relation with the PORTLR MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PT in an PORTLR MO is set to TUNNEL, the associated BACKTUNNEL MO must have been configured.
  • Relation with the IPROUTE4 MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If RTTYPE and PT are set to IF and TUNNEL, respectively in an IPROUTE4 MO, PORTID in the IPROUTE4 MO must be the same as PORTID in the associated BACKTUNNEL MO.
  • Relation with the SRCIPROUTE4 MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the RTTYPE and PT parameters under the SRCIPROUTE4 MO are set to IF and TUNNEL, respectively, the PORTID parameter under the SRCIPROUTE4 MO must be set to the same value as that of the PORTID parameter under the BACKTUNNEL MO.
  • Relation with the BACKTUNNEL MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]Each BACKTUNNEL MO must have a unique combination of SCN, DCN, SSRN, DSRN, SSN, and DSN.
    • [Co-MPT, NodeB, eNodeB, gNodeB]All the BACKTUNNEL MOs configured for a BS can only cross two subracks.
  • Relation with the HAGRP MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]In the logical protection group where the SSN of the BACKTUNNEL MO is located, the value of SN in the HAGRP MO must be the same as the value of SSN in the BACKTUNNEL MO.
    • [Co-MPT, NodeB, eNodeB, gNodeB]In the logical protection group where the DSN of the BACKTUNNEL MO is located, the value of SN in the HAGRP MO must be the same as the value of DSN in the BACKTUNNEL MO.
  • Relation with the IPRSCGRP MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If PT in an IPRSCGRP MO is set to TUNNEL, the associated BACKTUNNEL MO must have been configured.
    • [Co-MPT, eNodeB]The sum of non-default IPRSCGRP and RSCGRP MOs must be less than or equal to 16 on a board.
    • [NodeB]A maximum of eight IPRSCGRP MOs whose RSCGRPNO is not set to DEFAULTPORT or AUTOPORT can be configured on a board.
  • Relation with the IPPATH MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW and JNIPRSCGRP is set to DISABLE, and BPT in an IPPATH MO is set to TUNNEL respectively, the associated BACKTUNNEL MO must have been configured.
  • Relation with the IPPATH, IPADDR4, LOOPBACK, and INTERFACE MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW, and JNIPRSCGRP is set to DISABLE, and BPT in an IPPATH MO is set to TUNNEL, the IPADDR4 MO that is in the same routing domain as the IPPATH MO must have been configured, and also INTERFACE MO must have been configured on the LOOPBACK MO, which is on the same board with the corresponding BACKTUNNEL MO the IPPATH MO bears on.
  • Relation with the IPPATH, IPADDR4, LOOPBACK, IPRSCGRP, and INTERFACE MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If TRANSCFGMODE is set to NEW, and JNIPRSCGRP is set to ENABLE, and the PT in corresponding IPRSCGRP MO is set to TUNNEL, the IPADDR4 MO that is in the same routing domain as the IPPATH MO must have been configured, and also INTERFACE MO must have been configured on the LOOPBACK MO, which is on the same board with the corresponding BACKTUNNEL MO the IPPATH MO bears on.
  • Relation with the IP2IPRSCGRP and IPRSCGRP MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB]A maximum of two IP2IPRSCGRP MOs with IPVERSION set to IPV4 and DSTIPV4 located on the same network segment can be bound to the same destination network segment in the same routing domain of the same board.
    • [Co-MPT, NodeB, eGBTS, eNodeB]A board can be configured with a maximum of 32 IP2IPRSCGRP MOs with IPVERSION set to IPV4 on condition that the corresponding IPRSCGRP MOs are on the same board.
    • [Co-MPT, eNodeB]A maximum of two IP2IPRSCGRP MOs with IPVERSION set to IPV6 and DSTIPV6 located on the same network segment can be bound to the same destination network segment in the same routing domain of the same board.
    • [Co-MPT, eNodeB]A board can be configured with a maximum of 32 IP2IPRSCGRP MOs with IPVERSION set to IPV6 on condition that the corresponding IPRSCGRP MOs are on the same board.
    • [gNodeB]A maximum of two IP2IPRSCGRP MOs with IPVERSION set to IPV4 and DSTIPV4 located on the same network segment can be bound to the same destination network segment in the same routing domain of the same board.
    • [gNodeB]A maximum of two IP2IPRSCGRP MOs with IPVERSION set to IPV6 and DSTIPV6 located on the same network segment can be bound to the same destination network segment in the same routing domain of the same board.
    • [gNodeB]A maximum of 32 IP2IPRSCGRP MOs this IPVERSION are set to IPV4.
    • [gNodeB]A maximum of 32 IP2IPRSCGRP MOs this IPVERSION are set to IPV6.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the BACKTUNNEL MO cannot be configured.
  • Relation with the IPULFLOWCTRLPARA MO:
    • [Co-MPT, NodeB, eGBTS]If PT in a IPULFLOWCTRLPARA MO is set to TUNNEL, the associated BACKTUNNEL MO must have been configured.
  • Relation with the IPDLFLOWCTRLPARA MO:
    • [Co-MPT, NodeB, eGBTS]If PT in a IPDLFLOWCTRLPARA MO is set to TUNNEL, the associated BACKTUNNEL MO must have been configured.
  • Relation with the BBP, CASCADEPORT, IPGPM, IPRSCGRP, and LOOPBACK MOs:
    • [Co-MPT, NodeB]On a UBBP or LCOP board, if in the CASCADEPORT MO, the PN parameter is set to 6 and the PM parameter is set to SCPRI/SRIO or AUTO, this board cannot be configured with the IPGPM MO. That is, this board cannot be configured with the associated IPRSCGRP MO.
    • [Co-MPT, NodeB]On a UBBP or LCOP board, if the CASCADEPORT MO in which the PN parameter is set to 6 does not exist, the UBBP board cannot be configured with the IPGPM MO. That is, this board cannot be configured with the associated IPRSCGRP MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD BACKTUNNEL

Use this command to add a backplane tunnel, which is used for backplane-based communication in multimode co-transmission scenarios.
DSP BACKTUNNEL

Use this command to query the status of a backplane tunnel.
LST BACKTUNNEL

Use this command to list the configuration of backplane tunnels.
MOD BACKTUNNEL

Use this command to modify a backplane tunnel.
RMV BACKTUNNEL

Use this command to remove a backplane tunnel.
