ETH3AH

TRANSPORT
  +-ETH3AH

Description

This MO helps to implement the functions such as link monitoring, fault detection, and remote loopback described in the IEEE 802.3ah. This MO is used for Operation, Administration and Maintenance (OAM) of the last kilometer on the Ethernet.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the PORTSECURITY MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]An ETHPORT MO on which an ETH3AH MO depends must meet either of the following conditions: (1) The corresponding PORTSECURITY MO is not configured. (2) If the corresponding PORTSECURITY MO has been configured, SWITCH in the PORTSECURITY MO is set to ENABLE.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the ETH3AH MO cannot be configured.
  • Relation with the ETHPORT MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]The ETHPORT MO corresponding to ETH3AH MO must have been configured.
  • Relation with the ETH3AH MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]Any two ETH3AH MOs must have different ETHPORTID values.
  • Relation with the INTERFACE MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]TAGGED must be set to ENABLE if either of the following conditions is met: ETHPORTID in the ETH3AH MO is equal to PORTID in the INTERFACE MO, ITFTYPE is set to NORMAL, and PT is set to ETH; ETHPORTID in the ETH3AH MO is equal to ETHPORTID in the ETHTRUNKLNK MO, PORTID is equal to ETHTRKPORTID, ITFTYPE is set to NORMAL, and PT is set to ETHTRK.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of ETH3AH MOs must be less than or equal to 32 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Ethernet OAM 3AH Object ID

Indicates the ID of the ETHOAM3AH MO.
Ethernet Port ID

Indicates the ID of an Ethernet port.
Work Mode

Indicates the work mode of the IEEE802.3ah Ethernet OAM.

If this parameter is set to ACTIVE, the local end initiates the IEEE802.3ah Ethernet OAM negotiation.

If this parameter is set to PASSIVE, the local end does not initiate the negotiation; instead, the local end waits for receiving negotiation packets from the peer end.
Detection Period

Indicates the internal at which a Protocol Data Unit (PDU) is transmitted for fault detection. A shorter interval indicates that Ethernet link faults can be detected more quickly.
Maximum PDU Size

Indicates the maximum size of a protocol data unit (PDU).
Loopback Flag

Indicates whether remote loopback can be enabled at the port where 3AH detection is activated. This parameter is valid only when Work Mode is set to ACTIVE. If this parameter is set to ENABLE, OAM 3AH loopback is allowed. For details, see the descriptions of the STR ETHOAMLOOPTST command. During the loopback, the local end can send only 3AH packets rather than other types of packets. If this parameter is set to DISABLE, the local end cannot initiate loopback.
Fault Report Flag

Indicates whether to enable indication of link faults.
Error Frame Event Duration

Indicates the duration of the erroneous frame event.
Error Frame Event Threshold

Indicates the threshold for the erroneous frame event. If the number of erroneous frames within a second exceeds the threshold, an erroneous frame event occurs. This event is checked every other second.
Error Frame Seconds Summary Event Duration

Indicates the duration of the Error Frame Seconds Summary Event. An error frame second refers to a second within which one or more error frames are detected.
Error Frame Seconds Summary Event Threshold

Indicates the threshold for the accumulated erroneous frame event. If the length of time that erroneous frames occupy within a sampling period specified through the ERRFRMSCDEVTPRD parameter exceeds the threshold, an accumulated erroneous frame event occurs.
