VLANCLASS

TRANSPORT
  +-VLANCLASS

Description

The VLANCLASS MO is used to map services with different VLAN tags according to the service type. There are two mapping modes. If the service type is user data, VLAN tags are mapped on the basis of the user data packet priorities (DSCPs). If the service type is not user data, VLAN tags are mapped to user data/non user data on the basis of the service type.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the VLANCLASS MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The total number of different VLAN IDs between VLANID in the VLANCLASS MO and VLANID in the VLANMAP MO whose VLANMODE is set to SINGLEVLAN cannot exceed 48.
  • Relation with the SUBIF MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A VLANCLASS MO and a SUBIF MO cannot both be configured.
  • Relation with the VRF MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A VLANCLASS MO and a VRF MO whose VRFIDX is set to 1 to 7 cannot both be configured.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, the VLANCLASS MO cannot be configured.
  • Relation with the INTERFACE MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in a GTRANSPARA MO is set to NEW, a VLANCLASS MO and an INTERFACE MO with ITFTYPE set to VLAN cannot be configured at the same time.
  • Relation with the INTERFACE, VLANMAP, and SUBNETVLAN MOs:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW and a VLANMAP or a VLANCLASS or a SUBNETVLAN MO is configured, the TAGGED in the INTERFACE MO with ITFTYPE set to NORMAL must be set to ENABLE.

Related MML Commands

Table 1 Related MML commands

MML Command

Function

Use this command to modify a mapping from traffic types to VLANs.
RMV VLANCLASS

Use this command to remove a VLAN priority mapping from the VLAN group.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
VLAN Group No.

Indicates the VLAN group that the added VLAN mapping belongs to. Multiple VLAN groups are used in the scenario in which telecom operators share transport resources and use different VLAN policies.
Traffic Type

Indicates the traffic type. Traffic of different types is transmitted through different VLANs. OTHER data is the data except the user data, signaling, high-priority OM data, and low-priority OM data. OTHER data includes the data of the IEEE 1588 V2 clock, clock over IP, and Address Resolution Protocol (ARP) services. OM_HIGH data includes the data of the NTP, switchover between remote maintenance channels, and TCP services.
User Data Service Priority

Indicates the DSCP priority of user data.
VLAN ID

Indicates the VLAN ID that the service data belongs to.
VLAN Priority

Indicates the VLAN priority. A greater parameter value indicates a higher priority.
