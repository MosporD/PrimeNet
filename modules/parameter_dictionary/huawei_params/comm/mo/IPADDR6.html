IPADDR6

TRANSPORT
  +-IPADDR6

Description

This MO indicates an IPv6 address of an interface.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the DNSSRV MO:
    • [Co-MPT, eNodeB, gNodeB]When the IPVER parameter in the DNSSRV MO is set to IPv6, the DNSCIP6 parameter in the DNSSRV MO must be the IPADDR6 MO configured in the same routing domain of the base station.
    • [Co-MPT, eNodeB, gNodeB]The DNSSIP6 parameter in the DNSSRV MO must be different from the IPV6 parameter in the IPADDR6 MO in the same routing domain.
  • Relation with the DNSSRV, IPADDR4, LOOPBACK, and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]The DNSCIP4 and DNSCIP6 parameters in all DNSSRV MOs must be configured on the same board.
  • Relation with the IPCLKLNK MO:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD and DEVTYPE and IPMODE in an IPCLKLNK MO are set to OC_SLAVE and IPV6 respectively, a configured IPADDR6 MO must exist.
  • Relation with the IPCLKLNK, INTERFACE, LOOPBACK, ETHPORT, ETHTRUNK, and ETHTRUNKLNK MOs:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to NEW, an IPADDR6 MO corresponding to the IPCLKLNK MO with DEVTYPE set to OC_SLAVE and IPMODE set to IPV6 must have been configured and the following conditions must be met:
    • 1. The value of CIPV6 in the IPCLKLNK MO is the same as that of IPV6 in the IPADDR6 MO, and The value of VRFIDX in the IPCLKLNK MO is the same as that of VRFIDX in the IPADDR6 MO.
    • 2. The value of ITFID in the IPADDR6 MO that meets condition 1 is the same as that of ITFID in an INTERFACE MO. In this INTERFACE MO, PT is set to LOOPINT, ETH, or ETHTRK.
    • 3. If PT in the INTERFACE MO that meets condition 2 is set to LOOPINT, the value of PORTID in this INTERFACE MO is the same as that of PORTID in an LOOPBACK MO. In addition, the values of CN, SRN, and SN in this LOOPBACK MO are the same as those of CN, SRN, and SN in the IPCLKLNK MO.
    • 4. If PT in the INTERFACE MO that meets condition 2 is set to ETH, the value of PORTID in this INTERFACE MO is the same as that of PORTID in an ETHPORT MO. In addition, the values of CN, SRN, and SN in this ETHPORT MO are the same as those of CN, SRN, and SN in the IPCLKLNK MO.
    • 5. If PT in the INTERFACE MO that meets condition 2 is set to ETHTRK, the value of PORTID in this INTERFACE MO is the same as that of PORTID in an ETHTRUNK MO.
    • 6. The value of PORTID in the ETHTRUNK MO that meets condition 5 is the same as that of ETHTRKPORTID in an ETHTRUNKLNK MO.
    • 7. The value of ETHPORTID in the ETHTRUNKLNK MO that meets condition 6 is the same as that of PORTID in an ETHPORT MO. In addition, the values of CN, SRN, and SN in this ETHPORT MO are the same as those of CN, SRN, and SN in the IPCLKLNK MO.
  • Relation with the TWAMPRESPONDER MO:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a TWAMPRESPONDER MO is set to IPv6, LOCALIPV6 in the TWAMPRESPONDER MO must have been configured. That is, LOCALIPV6 is IPV6 of an IPADDR6 MO in the same routing domain.
  • Relation with the MDU MO:
    • [Co-MPT, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, the IPADDR6 MO cannot be configured.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the IPADDR6 MO cannot be configured.
  • Relation with the INTERFACE MO:
    • [Co-MPT, eNodeB, gNodeB]If PT in an INTERFACE MO is set to TUNNELITF, the IPADDR6 MO cannot be configured.
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, the INTERFACE MO associated with an IPADDR6 MO must have been configured.
    • [Co-MPT, eNodeB, gNodeB]The INTERFACE MO depended by IPADDR6 MO whose PT must be ETH, LOOPINT, ETHTRK.
    • [Co-MPT, eNodeB, gNodeB]If an IPADDR6 MO is configured on an INTERFACE MO, the IPV6SW must be set ENABLE.
    • [Co-MPT, eNodeB, gNodeB]When PFXLEN in an IPADDR6 MO is set to 128, PT in the INTERFACE MO that corresponds to ITFID in the IPADDR6 MO must be set to LOOPINT.
  • Relation with the IPADDR6 MO:
    • [Co-MPT, eNodeB, gNodeB]No identical globally scoped unicast address can be added in the same routing domain, for example, 2001:DB8::1/64 and 2001:DB8::1/65 are identical globally scoped unicast addresses.
    • [Co-MPT, eNodeB, gNodeB]When the IPADDR6 MO is configured as a globally scoped unicast address, the globally scoped unicast addresses of any two INTERFACE MOs in the same routing domain cannot have overlapped network segments.
    • [Co-MPT, eNodeB, gNodeB]A maximum of eight IPADDR6 MOs can be configured for an INTERFACE MO.
  • Relation with the INTERFACE and LOOPBACK MOs:
    • [Co-MPT, eNodeB, gNodeB]If IPADDR6 MO is configured on a different board, VRFIDX must be set to 0.
  • Relation with the IPROUTE6 MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, IPV6 in an IPADDR6 MO must be different from NEXTHOP in an IPROUTE6 MO.
    • [Co-MPT, eNodeB, gNodeB]If the next hop address of an IPROUTE6 MO is a global unicast address, an IPADDR6 MO must be in the same routing domain and on the same network segment as the global unicast address but different from the global unicast address.
  • Relation with the OMCH MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, if an IPV6 in the IPADDR6 MOs is on the same network segment as the IP6 in the OMCH MO, one of the IPV6 in the IPADDR6 MOs must be the same as the IP6 in the OMCH MO.
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, if the IPV6 in the IPADDR6 MO is the same with the IP6 in the OMCH MO, the IP6 of the active and standby OMCH MOs cannot be on the same network segment.
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, PEERIP6 in an OMCH MO must be different from IPV6 in an IPADDR6 MO.
  • Relation with the SCTPLNK MO:
    • [Co-MPT, eNodeB, gNodeB]LOCIP6 in an SCTPLNK MO with CTRLMODE set to MANUAL_MODE must be the same as IPV6 in an existing IPADDR6 MO in the same routing domain.
    • [Co-MPT, eNodeB, gNodeB]SECLOCIP6 in an SCTPLNK MO with CTRLMODE set to MANUAL_MODE must be 0:0:0:0:0:0:0:0 or IPV6 in an IPADDR6 MO in the same routing domain.
  • Relation with the SCTPHOST MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, SIGIP1V6 in an SCTPHOST MO must be the same as IPV6 in a configured IPADDR6 MO.
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, SIGIP2V6 (SIGIP2V6 is not set to 0::0) in an SCTPHOST MO must be the same as IPV6 in a configured IPADDR6 MO.
  • Relation with the USERPLANEHOST MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, LOCIPV6 in a USERPLANEHOST MO must be the same as IPV6 in a configured IPADDR6 MO.
  • Relation with the USERPLANEPEER MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, PEERIPV6 in a USERPLANEPEER MO must be different from IPV6 in a configured IPADDR6 MO.
  • Relation with the SECURITYHOST MO:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a SECURITYHOST MO is set to IPv6, LOCIKEIPV6 in the SECURITYHOST MO must be set to the same value as IPV6 in a configured IPADDR6 MO of the ETH or ETHTRK type, and the SECURITYHOST and IPADDR6 MOs must have the same VRF index.
  • Relation with the SECURITYPEER MO:
    • [Co-MPT, eNodeB, gNodeB]PEERIKEIPV6 in a SECURITYPEER MO must be different from IPV6 in a configured IPADDR6 MO.
  • Relation with the PORTSECURITY and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]If the following conditions are met, the IPADDR6 MO that corresponds to an INTERFACE MO cannot be configured: - The values of CN, SRN, SN, SBT, and PN in the ETHPORT MO that is referenced by the INTERFACE MO are the same as those of CN, SRN, SN, SBT, and PN in the PORTSECURITY MO, respectively. - PT in the PORTSECURITY MO is set to ETH. - SWITCH in the PORTSECURITY MO is set to DISABLE.
  • Relation with the SCTPHOST and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in an SCTPHOST MO is set to IPv6 and SIGIP1SECSWITCH in the SCTPHOST MO is set to ENABLE, PT in the INTERFACE MO where the IPADDR6 MO corresponding to SIGIP1V6 in the SCTPHOST MO is located must be set to LOOPBACK.
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in an SCTPHOST MO is set to IPv6 and SIGIP2SECSWITCH in the SCTPHOST MO is set to ENABLE, PT in the INTERFACE MO where the IPADDR6 MO corresponding to SIGIP2V6 in the SCTPHOST MO is located must be set to LOOPBACK.
    • [Co-MPT, eNodeB, gNodeB]In an SCTPHOST MO, if IPVERSION is set to IPv6 and SIGIP1SECSWITCH or SIGIP2SECSWITCH is set to ENABLE, VRFIDX must be different from VRFIDX in an IPADDR6 MO associated with an INTERFACE MO whose PT is set to ETH or ETHTRK.
  • Relation with the USERPLANEHOST and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION and IPSECSWITCH in a USERPLANEHOST MO are set to IPv6 and ENABLE, respectively, PT in the INTERFACE MO where the IPADDR6 MO corresponding to LOCIPV6 in the USERPLANEHOST MO is located must be set to LOOPBACK.
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION and IPSECSWITCH in a USERPLANEHOST MO are set to IPv6 and ENABLE, respectively, VRFIDX in the USERPLANEHOST MO must be different from VRFIDX in an IPADDR6 MO associated with an INTERFACE MO whose PT is set to ETH or ETHTRK.
  • Relation with the TUNNELITF and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]The value of LOCALIP6 in a TUNNELITF MO with CTRLMODE set to MANUAL_MODE must be the same as that of IPV6 in an IPADDR6 MO that has been configured in the same routing domain on the base station, and the IPADDR6 MO must be configured on the INTERFACE MO with PT set to ETH or LOOPINT.
  • Relation with the TUNNELITF MO:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, REMOTEIP6 in a TUNNELITF MO with CTRLMODE set to MANUAL_MODE must be different from IPV6 in an IPADDR6 MO.
  • Relation with the SRCIPROUTE6 and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, if SRCIP in an SRCIPROUTE6 MO is set to the same value as a configured IPADDR6 MO in the base station, and PT in the INTERFACE MO associated with the IPADDR6 MO is set to ETH or ETHTRK, RTTYPE in this SRCIPROUTE6 MO must be set to NEXTHOP.
    • [Co-MPT, eNodeB, gNodeB]If SRCIP in an SRCIPROUTE6 MO is set to the same value as a configured IPADDR6 MO in the base station, and PT in the INTERFACE MO associated with the IPADDR6 MO is set to ETH or ETHTRK, then SRCIP in any other SRCIPROUTE6 MO in the same routing domain must be different from SRCIP of this SRCIPROUTE6 MO.
  • Relation with the SRCIPROUTE6, INTERFACE, and LOOPBACK MOs:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, if SRCIP in an SRCIPROUTE6 MO is set to an existing IPADDR6 MO on a board, IPADDR6 in the same network segment as NEXTHOP in the SRCIPROUTE6 MO and IPADDR6 on which the SRCIP depends must be on the same board.
    • [Co-MPT, eNodeB, gNodeB]If SRCIP in an SRCIPROUTE6 MO is set to an existing IPADDR6 MO in the same routing domain, the IPADDR6 MO referenced by SRCIP in an SRCIPROUTE6 MO and the INTERFACE MO referenced by ITFID in the SRCIPROUTE6 MO must be configured on the same board.
  • Relation with the SRCIPROUTE6 MO:
    • [Co-MPT, eNodeB, gNodeB]If an IPADDR6 MO and an SRCIPROUTE6 MO are in the same routing domain, IPV6 in the IPADDR6 MO must be different from NEXTHOP in the SRCIPROUTE6 MO.
    • [Co-MPT, eNodeB, gNodeB]If the next hop address of an SRCIPROUTE6 MO is a global unicast address, an IPADDR6 MO must be in the same routing domain and on the same network segment as the global unicast address but different from the global unicast address.
  • Relation with the TWAMPCLIENT MO:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a TWAMPCLIENT MO is set to IPv6, PEERIPV6 in the TWAMPCLIENT MO must be different from IPV6 in the IPADDR6 MO in the same routing domain.
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a TWAMPCLIENT MO is set to IPv6, LOCALIPV6 of the TWAMPCLIENT MO must be set to IPV6 of a configured IPADDR6 MO in the same routing domain.
  • Relation with the IPROUTE6 and INTERFACE MOs:
    • [Co-MPT, eNodeB, gNodeB]In the same routing domain, the IPv6 address specified by NEXTHOP in the IPROUTE6 MO must be on the same network segment as the IPv6 address specified by IPV6 in the IPADDR6 MO that is configured on the INTERFACE MO with PT set to ETH or ETHTRK.
  • Relation with the SCTPHOST, SECURITYHOST, INTERFACE, and LOOPBACK MOs:
    • [Co-MPT, eNodeB, gNodeB]In an SCTPHOST MO, if SIGIP1SECSWITCH is set to ENABLE, SIGIP1V6 must be configured on the same board as LOCIKEIPV6 in a referenced SCTPHOST MO.
    • [Co-MPT, eNodeB, gNodeB]In an SCTPHOST MO, if SIGIP2SECSWITCH is set to ENABLE, SIGIP2V6 must be configured on the same board as LOCIKEIPV6 in a referenced SCTPHOST MO.
  • Relation with the USERPLANEHOST, SECURITYHOST, INTERFACE, and LOOPBACK MOs:
    • [Co-MPT, eNodeB, gNodeB]If IPSECSWITCH is set to ENABLE for a USERPLANEHOST MO, LOCIPV6 for the USERPLANEHOST MO must be configured on the same board as LOCIKEIPV6 for the referenced SECURITYHOST MO.
  • Relation with the SCTPLNK, INTERFACE, and LOOPBACK MOs:
    • [Co-MPT, eNodeB]When CTRLMODE is set to MANUAL_MODE and SECLOCIP6 is valid in an SCTPLNK MO, the IPADDR6 MOs for LOCIP6 and SECLOCIP6 of this MO must be configured on the same board.
  • Relation with the SCTPHOST, INTERFACE, ETHPORT, PPPLNK, MPGRP, ETHTRUNKLNK, ETHCIPORT, LOOPBACK, and GTRANSPARA MOs:
    • [Co-MPT, eNodeB]When SIGIP2V6 is valid in an SCTPHOST MO, the IPADDR6 MOs for SIGIP1V6 and SIGIP2V6 of this MO must be configured on the same board.
  • Relation with the PACKETFILTERING, ACLRULE6, INTERFACE, and LOOPBACK MOs:
    • [Co-MPT, eNodeB]A maximum of 64 ACLRULE6 MOs can be referenced by PACKETFILTERING on a board.
    • [gNodeB]A maximum of 64 ACLRULE6 MOs can be referenced by PACKETFILTERING on a board.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of IPADDR6 MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
  • Relation with the SCTPHOST, INTERFACE, ETHPORT, ETHTRUNKLNK, LOOPBACK, and GTRANSPARA MOs:
    • [gNodeB]When SIGIP2V6 is valid in an SCTPHOST MO, the IPADDR6 MOs for SIGIP1V6 and SIGIP2V6 of this MO must be configured on the same board.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD IPADDR6

Use this command to add an IPv6 address.
DSP IPADDR6

Use this command to query the IPv6 addresses configured on IPv6 interfaces.

Use this command to list the configured IPv6 addresses.
MOD IPADDR6

Use this command to modify the configuration of an IPv6 address.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IPv6 Address ID

Indicates the IPv6 Address ID of an interface.
Interface ID

Indicates the interface number. When Transmission Configuration Mode in the GTRANSPARA MO is set to NEW, this parameter indicates the interface number (0 to 1499) of the INTERFACE MO.
IPv6 Address

Indicates the IPv6 address.
Prefix Length

Indicates the length of the prefix of the IPv6 address, the prefix length of a loopback address is internally fixed to 128 bits.
VRF Index

Indicates the index of a VRF instance.
User Label

Indicates the user-defined information about an IPv6 address.
Table 3 Dynamic parameters

Parameter

Description
Address Status

Indicates the status of the IPv6 address. The value IP6_DAD_OK(Valid) indicates that the IPv6 address is in effect. The value IP6_DAD_TENTATIVE(Tentative) indicates that the DAD detection of the IPv6 address is not complete. The value IP6_DAD_DUPLICATED(Duplicate) indicates that the IPv6 address conflicts with the address of a neighbor.
Valid Lifetime

Indicates the time interval during which the IPv6 address is in the valid state.
Preferred Lifetime

Indicates the time interval during which the IPv6 address is in the preferred state. Valid states are categorized into the preferred state and the deprecated state. In the preferred state, an address can be freely used; in the deprecated state, the connections previously established on this address are still usable, whereas any connection newly established on this address is not usable.
Cabinet No.

Indicates the cabinet number of the board to which the IPv6 address belongs.
Subrack No.

Indicates the subrack number of the board to which the IPv6 address belongs.
Slot No.

Indicates the slot number of the board to which the IPv6 address belongs.
Port Type

Indicates the type of the port.
Port No.

Indicates the number of the port.
