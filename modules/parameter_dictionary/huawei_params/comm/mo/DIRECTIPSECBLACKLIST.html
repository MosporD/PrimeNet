DIRECTIPSECBLACKLIST

TRANSPORT
  +-DIRECTIPSECBLACKLIST

Description

The DIRECTIPSECBLACKLIST MO is used to shield direct IPsec tunnels automatically set up over the X2/Xn interface. When automatically set up direct IPsec tunnels cannot function normally, the eNodeBs can shield the IPsec tunnels by adding the IP address of the security peer to the blacklist to mask alarms and prevent direct IPsec tunnels from frequent automatic setup.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the SECURITYPEER MO:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a SECURITYPEER MO is set to IPv4, PEERIKEIPV4 in the SECURITYPEER MO must be different from SECURITYPEERIPV4 in the DIRECTIPSECBLACKLIST MO.
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a SECURITYPEER MO is set to IPv6, PEERIKEIPV6 in the SECURITYPEER MO must be different from SECURITYPEERIPV6 in a DIRECTIPSECWHITELIST MO.
  • Relation with the DIRECTIPSECWHITELIST MO:
    • [Co-MPT, eNodeB, gNodeB]A DIRECTIPSECBLACKLIST MO and a DIRECTIPSECWHITELIST MO cannot both be configured.
  • Relation with the DIRECTIPSECBLKLST MO:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a DIRECTIPSECBLACKLIST MO is set to IPv4, SECURITYPEERIPV4 in the DIRECTIPSECBLACKLIST MO must be different from SECURITYPEERIP in the DIRECTIPSECBLKLST MO.
  • Relation with the DIRECTIPSECBLACKLIST MO:
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a DIRECTIPSECBLACKLIST MO is set to IPv4, SECURITYPEERIPV4 in the DIRECTIPSECBLACKLIST MO must be different from SECURITYPEERIPV4 in any existing DIRECTIPSECBLACKLIST MO.
    • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a DIRECTIPSECBLACKLIST MO is set to IPv6, SECURITYPEERIPV6 in the DIRECTIPSECBLACKLIST MO must be different from SECURITYPEERIPV6 in any existing DIRECTIPSECBLACKLIST MO.
    • [Co-MPT, gNodeB]The number of blacklists configured in the DIRECTIPSECBLKLST and DIRECTIPSECBLACKLIST MOs on a base station cannot exceed 384.
    • [eNodeB]The number of blacklists configured in the DIRECTIPSECBLKLST and DIRECTIPSECBLACKLIST MOs on a base station cannot exceed 128.
  • Relation with the MDU MO:
    • [Co-MPT]When TYPE in the MDU MO is set to MDUC, a maximum of 256 DIRECTIPSECBLACKLIST MOs can be configured.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT]The number of DIRECTIPSECBLACKLIST MOs must be 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.

Indicates the security peer IPv6 address of a direct IPsec blacklist. This IPv6 address must be set to a globally scoped unicast address.
