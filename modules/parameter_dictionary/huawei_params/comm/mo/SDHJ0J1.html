SDHJ0J1

TRANSPORT
  +-SDHJ0J1

Description

The J0 byte indicates the regeneration section trace byte. It is used as the field access point identifier during retransmission. This byte helps verify that the RX end continuously connects to the specified TX end. The J1 byte indicates the higher-order path trace byte. It is used as the higher-order path access point identifier during retransmission. By using the J1 byte, the RX end of the path continuously connects to the specified TX end. The J0 and J1 bytes enable operators to detect and rectify faults in advance for a shorter restoration period of the network. On the network of one operator, the J0 and J1 bytes can be any characters. At the boundaries between the networks of two operators, however, the J0 and J1 bytes at the RX end must be the same as those at the TX end. This MO is used to manage configured parameters of the J0 and J1 bytes on an optical interface board.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS]When TYPE in the MDU MO is set to MDUC, the SDHJ0J1 MO cannot be configured.
  • Relation with the STM1 MO:
    • [Co-MPT, NodeB]When adding an STM1 MO, the system automatically adds the associated SDHJ0J1 MO. When removing an STM1 MO, the system automatically removes the SDHJ0J1 MO that depends on the STM1 MO.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of SDHJ0J1 MOs is 0 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
