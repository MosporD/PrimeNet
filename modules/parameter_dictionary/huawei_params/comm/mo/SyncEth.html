SYNCETH

EQUIPMENT
  +-SYNCETH

Description

The SyncEth MO is the synchronous Ethernet, which is a type of reference clock source. The Synchronous-Ethernet clock inherits the basic principles of clock synchronization in Synchronous Digital Hierarchy (SDH) and Plesiochronous Digital Hierarchy (PDH) networks. That is, downstream nodes extract and trace upstream clocks by recovering the clocks from the parallel bit streams at the physical layer. Therefore, the clocks are irrelevant to upper-layer services.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EQUIPMENT
  • Relation with the PORTSECURITY MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TYPE in the SYNCETH MO is set to IN, SWITCH in the PORTSECURITY MO corresponding to CN, SRN, SN and PN in the SYNCETH MO must be set to ENABLE.
  • Relation with the GPS and TASM MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If MODE and CLKSRC in the TASM MO are set to MANUAL and GPS+SYNCETH, respectively, the corresponding GPS and SYNCETH MOs must have been configured.
  • Relation with the TASM MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If MODE and CLKSRC in the TASM MO are set to MANUAL and SYNCETH, respectively, the corresponding SYNCETH MO must have been configured.
  • Relation with the IPCLKLNK and TASM MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If MODE is set to MANUAL and CLKSRC is set to SYNCETH+IPCLK in the TASM MO, the corresponding SYNCETH MO and IPCLKLNK MO in which DEVTYPE is set to OC_SLAVE or ICPT is set to HW_DEFINED must have been configured.
  • Relation with the EQUIPMENT, TASM, BITS, TOD, LINECLK, IPCLKLNK, INTERCLK, and PEERCLK MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If SDRCONNSW and INTERSUBRACKCLKALIGNMODE in an EQUIPMENT MO are set to OFF and INDEPENDENT_GNSS_CLK, respectively, and if MODE in the TASM MO is set to AUTO, then only the GPS MO can be configured and other clock link MOs cannot be configured.
  • Relation with the TASM, INTERCLK, LINECLK, TOD, PEERCLK, and BITS MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CLKSYNCMODE in a TASM MO is set to HYBRID, the SYNCETH, INTERCLK, LINECLK, PEERCLK, TOD, or BITS MO cannot be configured.
  • Relation with the EQUIPMENT, APPLICATION, PEERCLK, BITS, TOD, LINECLK, IPCLKLNK, INTERCLK, and GPS MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If SDRCONNSW is set to OFF and INTERSUBRACKCLKALIGNMODE is set to PEER_RF_CLK in an EQUIPMENT MO and if AT in the APPLICATION MO is set to NodeB, it is allowed and only a PEERCLK MO in which PNT is set to RF can be configured, other clock link management objects cannot be configured.
  • Relation with the HYBRIDCLK and IPCLKLNK MOs:
    • [Co-MPT, NodeB, eNodeB, gNodeB]In a HYBRIDCLK MO, if TCLKSRC is set to IPCLK and FCLKSRC is set to SYNCETH, the SYNCETH MO and IPCLKLNK MO with DEVTYPE set to OC_SLAVE and ICPT set to PTP must have been configured.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
SyncEth Clock No.

Indicates the number of the synchronous-Ethernet clock link. A maximum of two links can be configured currently.
Cabinet No.

Indicates the number of the cabinet where the synchronous-Ethernet clock link is configured.
Subrack No.

Indicates the number of the subrack where the synchronous-Ethernet clock link is configured.
Slot No.

Indicates the number of the slot where the synchronous-Ethernet clock link is configured.
Port No.

Indicates the number of the port where the synchronous-Ethernet clock link is configured.
SSM Selection

Indicates whether handling of SSM frames is supported. The setting of this parameter is consistent with the setting on the Ethernet clock server.

The synchronization status message (SSM) carries clock quality information, which is specified in ITU-T.

This parameter is valid only when the synchronous-Ethernet clock link is of the input type.
Priority

Indicates the priority of the clock source. The value 1 indicates that the current clock source has the highest priority, and the value 4 indicates that the current clock source has the lowest priority.
SyncEth Type

Indicates the type of a synchronous-Ethernet clock link. It indicates whether the corresponding synchronous-Ethernet port is an input or output port. An input port is used to import clock signals to the NE, and an output port is used to export clock signals to other NEs. Only the synchronous-Ethernet clock of input type can serve as a clock source.
Table 3 Dynamic parameters

Parameter

Description
Link Active State

Indicates the activation status of a synchronous-Ethernet clock link. If the link is active, the synchronous-Ethernet clock link is the current clock source of the system. This parameter is valid only when the synchronous-Ethernet clock link is of the input type.
Link Available State

Indicates the availability of a synchronous-Ethernet clock link. Only an available clock link can serve as the current clock source. Otherwise, the clock link cannot be locked even if it is activated. This parameter is valid only when the synchronous-Ethernet clock link is of the input type.
Clock Source Quality Level

Indicates the quality level of the synchronous-Ethernet clock from network. The values for this parameter are listed in quality descending order. QL-PRC indicates the highest quality level. If SSM Selection is set to DISABLE(DISABLE) or the clock quality level is invalid, the value of Clock Source Quality Level is NULL.
