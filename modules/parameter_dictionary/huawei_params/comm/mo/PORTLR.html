PORTLR

TRANSPORT
  +-PORTLR

Description

This MO is used to set the rate of uplink and downlink data transmitted over a physical port. By setting the data rate, the transmission rate and reception rate on the Ethernet port, MLPPP group, Tunnel, and Ethernet trunk are limited, data is transmitted to the external network at a specified rate, and the QoS is guaranteed.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the BACKTUNNEL MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PT in an PORTLR MO is set to TUNNEL, the associated BACKTUNNEL MO must have been configured.
  • Relation with the PORTLR MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]An PORTLR MO can be configured on only one BACKTUNNEL MO.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Only one PORTLR MO can be configured on one port.
  • Relation with the ETHPORT MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PT in an PORTLR MO is set to ETH, the associated ETHPORT MO must have been configured.
  • Relation with the ETHTRUNKLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Before adding an ETHTRUNKLNK MO, ensure that an PORTLR MO is not configured for the associated ETHPORT MO.
  • Relation with the ETHTRUNK and ETHTRUNKLNK MOs:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PT in an PORTLR MO is set to ETHTRK, the associated ETHTRUNK MO must have been configured, and at least one ETHTRUNKLNK MO is included in the ETHTRUNK MO.
  • Relation with the IPRSCGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]An IPRSCGRP MO whose RSCGRPNO is not AUTOPORT and an PORTLR MO can be configured on only one BACKTUNNEL MO.
  • Relation with the GTRANSPARA MO:
    • [Co-MPT, NodeB, eNodeB, gNodeB]If TRANSCFGMODE in the GTRANSPARA MO is set to OLD, the PORTLR MO cannot be configured.
  • Relation with the MPGRP MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]If PT in an PORTLR MO is set to MPGRP, the associated MPGRP MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD PORTLR

Use this command to add the data rate of a physical port. Rate limitation is implemented between the data link layer and the physical layer. The length of a packets measures only the header of the data link layer, not the header of the physical layer. If the port type is set to MPGRP, rate limitation is performed only at the IP layer, but not at the MP header.
LST PORTLR

Use this command to list the configuration of all the port rates.
MOD PORTLR

Use this command to modify the configuration for the data rate of a physical port.
RMV PORTLR

Use this command to remove the data rate of a physical port.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Port Rate Limit ID

Indicates the port rate limit ID.
Port Type

Indicates the port type.
Port ID

Indicates the port ID.
UL Committed Information Rate

Indicates the UL committed information rate after rate limitation is configured at a port. The precision of the UL committed information rate supported by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga, UMDU or GTMUc is 64 kbit/s, the precision supported by the other board is 32 kbit/s. If the configured UL committed information rate is not a multiple of the precision, the UL committed information rate is rounded up. For the GTMUb, the value of CIR ranges from 64 to 100000. If this parameter is set to a value greater than the maximum allowed value or less than the minimum allowed value, the maximum or the minimum allowed value takes effect.
Committed Burst Size

Indicates the Committed Burst Size (CBS) after rate limitation is configured at a port. The minimum rate supported by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga, UMDU or GTMUc is 64 kbit/s. For the GTMUb, the value of CBS ranges from 63 kbit to 256 kbit. If this parameter is set to a value greater than the maximum allowed value or less than the minimum allowed value, the maximum or the minimum allowed value takes effect.
Excessive Burst Size

Indicates the Excess Burst Size (EBS) after rate limitation is configured at a port.
DL Committed Information Rate

Indicates the DL committed information rate after rate limitation is configured at a port. The parameter does not take effect in GSM and NR. For UMTS, if the downlink flow control switch is set to DYNAMIC_BW_SHAPING or STATIC_BW_SHAPING, this parameter is valid. If the downlink flow control switch is set to BW_SHAPING_ONOFF_TOGGLE, this parameter is valid when traffic congestion is detected. In other cases, this parameter is invalid. For LTE, this parameter computes the value of Physical Port Down Link Admission. The minimum rate supported by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga or UMDU is 64 kbit/s.
