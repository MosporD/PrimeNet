IPRSCGRP

TRANSPORT
  +-IPRSCGRP
    +-IPRSCGRPALG[0~1]

Description

The IPRSCGRP MO indicates a collection of data streams. NEs perform bandwidth management on IP transmission resource groups, including configuring the bandwidth of an IP transmission resource group, traffic shaping, admission control, and flow control. Multiple IP transmission resource groups can be configured on a physical bearer link, and each IP transmission resource group occupies part of the bandwidth of the physical bearer link exclusively. Each IP transmission resource group performs the functions such as admission control, congestion control, and HSPA flow control independently. Each IP transmission resource group has multiple transport bearers, which share the bandwidth configured for the IP transmission resource group.

The UBBPe, UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s RX peak information rate. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s RX peak information rate. The value of RX peak information rate is set to the maximum value of RX peak information rate supported by the board when it bigger than the maximum one. Only the LTE supports this function currently.

If the parameter is set to a value greater than the maximum TX peak burst size supported by a board, the maximum TX peak burst size supported by the board takes effect.
