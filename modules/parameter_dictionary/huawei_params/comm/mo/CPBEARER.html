CPBEARER

TRANSPORT
  +-CPBEARER

Description

A Control Port (CP) bearer MO consists of the parameters related to bearers for application-layer control interfaces such as the NodeB Control Port (NCP), Communication Control Port (CCP), S1, and X2 interfaces.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    TRANSPORT
  • Relation with the CPBEARER MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If BEARTYPE in a CPBEARER MO is set to SCTP, the SCTP link specified by SCTPNO in the associated SCTPLNK MO can carry only one CP bearer.
    • [Co-MPT, NodeB, eNodeB, gNodeB]If two CPBEARER MOs work in active/standby mode, ensure that BEARTYPE in at least one CPBEARER MO is not set to SCTP.
    • [eNodeB, gNodeB]If BEARTYPE in a CPBEARER MO is set to SAAL, an SAALLNK MO whose SAALNO is the same as LINKNO in the CPBEARER MO must have been configured.
    • [Co-MPT, NodeB]If BEARTYPE in a CPBEARER MO is set to SAAL, the SAAL link specified by SAALNO in the associated SAALLNK MO can carry only one CP bearer.
  • Relation with the SCTPLNK MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If BEARTYPE in a CPBEARER MO is set to SCTP, an SCTPLNK MO whose SCTPNO is the same as LINKNO in the CPBEARER MO must have been configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If BEARTYPE in the CPBEARER MO is set to SCTP, CTRLMODE must be set to the same value as CTRLMODE that is associated with the SCTPLNK MO.
  • Relation with the MDU MO:
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, a maximum of 384 CPBEARER MOs can be configured.
    • [Co-MPT, NodeB, eGBTS, eNodeB]When TYPE in the MDU MO is set to MDUC, FLAG in the CPBEARER MO must be set to MASTER.
  • Relation with the SAALLNK MO:
    • [Co-MPT, NodeB]If BEARTYPE in a CPBEARER MO is set to SAAL, an SAALLNK MO whose SAALNO is the same as LINKNO in the CPBEARER MO must have been configured.
  • Relation with the AAL2NODE MO:
    • [Co-MPT, NodeB]When BEARTYPE in a CPBEARER MO is set to SAAL, the associated SAALLNK MO cannot be used by an AAL2NODE MO. That is, LINKNO in the CPBEARER MO must be different from LN in the AAL2NODE MO.
  • Relation with the AAL2ADJNODE MO:
    • [Co-MPT, NodeB]When BEARTYPE in a CPBEARER MO is set to SAAL, the associated SAALLNK MO cannot be used by an AAL2ADJNODE MO. That is, LINKNO in the CPBEARER MO must be different from LN in the AAL2ADJNODE MO.
  • Relation with the GTMU, MPT, and APPLICATION MOs:
    • [Co-MPT, eGBTS]The number of CPBEARER MOs must be less than or equal to 4 when the Application MO with AT set to GBTS and the GTMU MO with TYPE set to GTMU are configured but the MPT MO with TYPE set to UMPT is not configured.
  • Relation with the NODE MO:
    • [Co-MPT]An CPBEARER MO cannot be configured on a PRODUCTTYPE MO with PRODUCTTYPE set to DBS3900 DCU or DBS5900 DCU.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CP Bear No.

Indicates the number of a Control Port (CP) bearer. The value of CPBEARID in the CPBEARER MOs configured by users ranges from 0 to 65535. The value of CPBEARID in the CPBEARER MOs configured by the system ranges from 70000 to 79999.
Flag

Indicates whether the transport channel carried on the CP bearer is a master or slave channel.
Bear Type

Indicates the type of CP bearer. The LTE and NR do not support SAAL.
Link No.

Indicates the number of a link carried on the CP bearer.
Control Mode

Indicates whether the object can be modified or deleted by the system. The value MANUAL_MODE means that only the user can modify or delete the object. The value AUTO_MODE means only the system can modify or delete the object. The NR does not support MANUAL_MODE.
Auto Config Flag

Indicates whether the object is created by the system. MANUAL_CREATED means that the object is configured by the user manually. AUTO_CREATED means that the object is created by the system. The NR does not support MANUAL_CREATED.
Table 3 Dynamic parameters

Parameter

Description
Port Status

Indicates the status of a CP bearer.
Used Status

Indicates whether the CP bearer is in use.
