SCTPPEER

TRANSPORT
  +-SCTPPEER

Description

The SCTPPEER MO is used to configure an SCTP peer. This MO can be automatically or manually created.

Effective Scenario

Immediately

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SCTPPEER

Use this command to add an SCTP peer.
BLK SCTPPEER

Use this command to block an SCTP peer. After an SCTP peer is blocked, all SCTP links related to this SCTP peer are also blocked.
LST SCTPPEER

Use this command to list the configurations of an SCTP peer and check whether the object is created by the system. If the value of Auto Config Flag is Manual Created, the object is configured by the user manually. If the value of Auto Config Flag is Auto Created, the object is created by the system.
MOD SCTPPEER

Use this command to modify an SCTP peer.
RMV SCTPPEER

Use this command to remove an SCTP peer.
UBL SCTPPEER

Use this command to unblock an SCTP peer. After an SCTP peer is unblocked, all SCTP links related to this SCTP peer are also unblocked.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
SCTP Peer ID

Indicates the ID of the SCTP peer. The value of SCTPPEERID in the SCTPPEER MOs configured by users ranges from 0 to 65535. The value of SCTPPEERID in the SCTPPEER MOs configured by the system ranges from 70000 to 79999.
VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).
IP Version

Indicates the IP protocol version of an SCTP peer.
First Peer IP Address

Indicates the first peer SCTP IPv4 address, which is used by the base station to establish a signaling channel. That is, this address is the first peer IPv4 address for automatically establishing an SCTP link.
First Peer IPv6 Address

Indicates the first peer SCTP IPv6 address, which is used by the base station to establish a signaling channel. That is, this address is the first peer IPv6 address for automatically establishing an SCTP link.
IPSec Auto Configure Switch for First Peer IP

Indicates whether to use the first peer IP address to automatically set up an IPsec tunnel between the local and peer ends based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. The IPsec tunnel is used to encrypt data to be transmitted on the SCTP link that is set up using the first peer IP address of the SCTP peer. When the value of this parameter is changed from ENABLE to DISABLE using the MOD SCTPPEER command, the system automatically deletes the IPsec tunnel that has been automatically set up.
Security Peer ID for First Peer IP

Indicates the ID of the security peer referenced by the first IP address of the SCTP peer.
Second Peer IP Address

Indicates the second peer SCTP IPv4 address, which is used by the base station to establish a signaling channel. That is, this address is the second peer IPv4 address for automatically establishing an SCTP link.
Second Peer IPv6 Address

Indicates the second peer SCTP IPv6 address, which is used by the base station to establish a signaling channel. That is, this address is the second peer IPv6 address for automatically establishing an SCTP link.
IPSec Auto Configure Switch for Second Peer IP

Indicates whether to use the second peer IP address to automatically set up an IPsec tunnel between the local and peer ends based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. The IPsec tunnel is used to encrypt data to be transmitted on the SCTP link that is set up using the second peer IP address of the SCTP peer. When the value of this parameter is changed from ENABLE to DISABLE using the MOD SCTPPEER command, the system automatically deletes the IPsec tunnel that has been automatically set up.
Security Peer ID for Second Peer IP

Indicates the ID of the security peer referenced by the second IP address of the SCTP peer.
Peer SCTP Port No.

Indicates the number of the peer SCTP port, which is used for automatically setting up an SCTP link.
Remote ID

Indicates the remote ID. This parameter is used by the system during the automatic configuration of this MO. If this parameter is manually configured, the system may fail to automatically modify or delete the MO.
Control Mode

Indicates whether the object can be automatically modified or removed by the system. If this parameter is set to MANUAL_MODE, only users can operate this object. If this parameter is set to AUTO_MODE, the system can modify or remove this object and users can only remove this object.
Auto Config Flag

Indicates whether the object is created by the system. MANUAL_CREATED means that the object is configured by the user manually. AUTO_CREATED means that the object is created by the system.
User Label

Indicates the description of the SCTP peer.
Block Flag

Indicates whether the SCTPPEER is blocked or not.
Simple Mode Switch

Indicates the simplified mode switch of an SCTP peer. The parameter takes effect only in LTE.
End Point Group ID

Indicates the end point group ID of an SCTP peer. The parameter takes effect only in LTE.
