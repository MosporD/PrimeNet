# Excess — non-essential project files

Moved here to keep the PrimeNet workspace lean. **The Flask app does not import anything from this folder.**

## Contents

| Path | What it was |
|------|-------------|
| Root `*.md`, `*.pdf`, `*.pptx` | Documentation and presentations |
| `docs/` | Executive brief, deployment guide, Mermaid workflow diagrams |
| `tools/` | Dev utilities (`inspect_headers.py`) |
| `license_service/` | Optional standalone license server (only if using `NCM_LICENSE_SERVER_URL`) |
| `scripts/nemo_cs_*` | Nemo reverse-engineering C# tools |
| `scripts/_*.py`, `debug_*`, `add_*_tables.py`, etc. | One-off diagnostics and migrations |
| `scripts/render_workflow_diagrams.py`, `generate_infrastructure_pdf.py` | Doc build scripts |
| `.ruff_cache/`, `**/__pycache__/` | Regenerated by Python / Ruff |
| `.cursor/` | IDE metadata |
| `sync_downloads/` | Legacy SFTP staging (~19 GB); recreated empty at project root |
| `generated_reports/` | Saved report outputs; recreated empty at project root |
| `exports/` | Export cache; recreated empty at project root |
| `Nokia PM Measurements.xlsx` | Unused duplicate (param dict lives under `modules/parameter_dictionary/`) |

## Not moved (still required or in use)

- `databases/`, `raw/` — PM and metadata data
- `uploads/` — user uploads (kept in place)
- `modules/ran_features/docs/*.hdx` — only if you use RAN Features (~1.25 GB)
- `modules/parameter_dictionary/huawei_params/` — Huawei parameter dictionary HTML
- `PrimeNet_Tool_Overview_With_Screenshots.pptx` at project root — file was locked; move manually when closed

## Restore

Move any item back to its original path under the project root. For `license_service`, copy the folder back if you use remote licensing.

## Delete

You can delete this entire `Excess/` folder when you no longer need archives.
