The Problem

Radio operations live in too many disconnected systems

  • 10+ separate tools — vendor OSS, assurance portals, drive-test platforms, site databases, spreadsheets.
  • Nokia and Huawei data live apart — inconsistent KPI definitions slow cross-vendor decisions.
  • Manual exports & merges — analysts spend hours reconciling before they can analyze.
  • No config discipline — nowhere to compare files, track tasks, or retain change history.
  • No unified picture — leadership lacks a single view of operational sites by tech & vendor.
🧭

Context switching

Every incident means logging into multiple systems.

📑

Spreadsheet sprawl

Ad-hoc merges that don't agree with each other.

⏱️

Slow to insight

Hours between data drop and decision.

⚠️

Config drift

Undetected changes, no audit trail.

The Solution

One secure web platform that unifies the workflow

  • Automates collection of PM, grouping, neighbor, metadata & small-cell data on hourly/daily schedules.
  • Stores & serves it through one dashboard with consistent KPI definitions across vendors.
  • Supports config discipline — lookup, convert, compare, schedule, and version history.
  • Acts as an operations hub — live site metrics plus one-click launch of the tools teams already use.

PrimeNet complements vendor OSS — it does not replace it.

Security & Governance

Controlled access, full accountability

  • Role-based access — user → operator → NOC/systems → administrator.
  • Server-side sessions — httponly token cookie, expiry & active-user checks.
  • Password policy — 60-day rotation enforced globally via before-request gate.
  • CSRF + input sanitization on every state-changing request.
  • Activity logging & optional license activation for production.
  • Registration disabled — provisioned accounts only.
